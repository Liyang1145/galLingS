# 作者源读写边界

- 这里只服务独立本机编辑入口，不挂入游戏开发入口、游戏包或原生宿主。
- 读取纯 JSON 导出，不执行 `game.js`。预览和保存共用 `compileSourceContent`，不维护宽松的第二套转换器。
- 预览外观通过共享 `whaleAppearance()` 只读装配现有鲸鱼图形；提取器只读固定标记区，不执行旧 HTML，也不新增作者源/图片写入 API。
- 写入路径固定为当前仓库的 `海风与布丁/game.js`。请求不得指定文件路径、命令或任意字段；原摘要、节点 ID、原值与可写字符串范围逐项核对。
- 字符串 token 定位只用于保留其余原字节/格式，不承担剧情解释职责。禁止整包重排、扩展映射或顺手修改素材。
- 保存先取得合作锁、完成转换和备份，再用候选替换；最终替换前重查摘要和路径。合作锁不能保证拦住不遵守锁的外部编辑器，不能宣称无竞态。
- 备份、失败候选和异常锁保留为本机恢复证据，不自动递归清理，也不提交。不要在作者 JSON/错误响应中暴露完整作者文件、Node 对象、绝对错误路径或本机会话令牌。
- API 限本机固定端口，检查 Host、Origin、本次服务令牌、方法及载荷上限；新增写入能力须同步协议与说明。
- `api.ts` 是开发/构建入口唯一作者 API 装配，令牌只在本次 HTML 响应注入，不生成构建期秘密、磁盘令牌或引导写入接口。`media.ts` 只按本次转换已登记的精确 ID/字节摘要读原件，不接受路径；普通文件/物理边界和实际摘要重查，Range 不跳过校验，取消仅清理原读取，不重执行剧情。
- `build.ts` 仅显式生成 `dist/editor` 的独立前端/清单，`serve.ts` 仅显式核对指定摘要后启动固定本机服务；互不自动调用，不进入游戏/宿主路径。清单严格读取并绑定前端、固定运行源码/身份映射/依赖锁，作者文件及全库素材不随前端复制，不将本机集成当正式分发决定。失败临时目录/异常锁保留，不覆盖旧产物或递归清理；每次作者操作前仍核对运行输入，原保存冲突规则不变。
