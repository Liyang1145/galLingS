# 独立声音偏好

从 `437affb` 接续共享表现与正常退出协调。本片已编写配乐、环境声、语音和音效四轨音量、即时应用及独立持久化，并接到独立试播页；未启动、测试、类型检查、构建、额外审查或验收。试播控件及显式保存方式不代表最终设置界面决定。

## 默认值与声音应用

`packages/player/src/preferences.ts` 的 `authorAudioVolumes(settings)` 读取唯一作者源中的四个设置，不修改作者内容：

| 通道 | 来源字段 | 当前作品默认值 | 缺少字段时的原混音器回退值 |
|---|---|---|---|
| 配乐 `music` | `vbgm` | 35% | 60% |
| 环境声 `ambience` | `vamb` | 30% | 30% |
| 语音 `voice` | `vvo` | 100% | 100% |
| 音效 `effects` | `vse` | 55% | 80% |

输入必须是 0～1 的有限数值，已出现但非法的字段明确拒绝。来源音量、素材增益、场景压低与渐变分别处理：最终声音为当前通道音量乘以原素材/场景/渐变增益，再限制到播放范围。

`WebPresentation` 可显式接收初始 `AudioVolumes`，并通过 `setAudioVolumes()` 即时更新现有音轨。混音器不因调音重新播放、跳转位置或重建渐变；正在退出的淡出音轨也应用最新通道值。水下/慢动作压低、配乐存在时的环境声压低、同曲继续和停奏保留既有处理。

配乐、环境声及语音调到 0 时继续按当前播放时间静音运行，语音完成仍可释放自动阅读等待。一次性音效在实际触发时检查音效音量，0 音量时不创建音轨，不在稍后调高音量时补播；已经播放中的音效只调整当前声音。调音不发剧情命令、进入动作或全局事实。

## 存储契约

纯模块 `AudioPreferenceRepository` 使用独立格式 `haifeng.audio-preferences/1`，包含作品、范围及稀疏 `overrides`。键由格式、作品、范围种类及范围 ID 构成，不按剧情修订分槽；没有记录时只使用作者默认，不创建记录。

仅显式调整的通道形成覆盖。`update(changes)` 中缺省通道保持已存值，`null` 删除该通道覆盖并跟随作者默认；“使用作者默认音量”先在内存生效，点击保存后才持久保存这一选择。未覆盖通道随之后加载的作者默认变化，不把整份旧默认固定为玩家选择。

浏览器仍使用新 TypeScript 记录的 IndexedDB 数据库和现有对象仓库，以独立协议键隔离；没有新增数据库版本或读取旧 localStorage。`updateAudio()` 在同一读写事务内重新读取、校验及合并提供的通道，再整体提交。不同页面只修改不同通道时不会以旧整份副本覆盖；同时修改同一通道时以最后提交值为准。损坏、未知字段或身份不符的已有记录拒绝更新，不静默重置。

声音偏好不进入进度检查点、全局解锁或通关上下文；读档和回退沿用当前玩家音量，不从进度快照恢复旧音量。存档、玩家记录及宿主桥格式均未改变。

## 试播接线与失败处理

第一话试播使用 `development/normal-entry` 的偏好范围，显式“保存音量偏好”才写入。标题及游玩中均可调整；滑块修改立即作用于当前播放。限时选择样例单独使用本页内存及作者默认，不读取或写入第一话偏好；编辑预览同样只使用作者默认，不接玩家偏好仓库。

应用在启用初始标题按钮前读取可选偏好，最多等待 5 秒。失败或超时显示提示，本次继续使用作者默认，不替换原记录；迟到结果或已离开页面的读取不能被采用。读取和保存期间禁用调音控件，不暂停主线剧情计时。

保存通过 `PendingWrites` 跟踪，失败保留本次捕获的通道修改，玩家可显式重试。失败后若又调整了音量，重试仍只写原修改；成功后保留后来尚未保存的调整并提示其状态。保存时的原子合并不能被误称为多页面实时同步，其他页面更改不会自动推送到当前混音器。

[正常退出](exits.md)等待已显式发起的音量保存，并在失败时允许重试原修改或取消退出；不自动保存尚未点击保存的滑块调整。取消退出会刷新调音控件的禁用状态，但不会取消已开始的数据库事务。

文字速度、显示/窗口偏好、交互提示音与最终设置界面尚未迁移；没有补设正式读档语音默认、自动存档或旧偏好迁移规则。

## 留待统一测试

使用 [可视入口](player.md#统一测试时的可视入口)，本轮不执行：

1. 正常开局分别调整四轨，确认只改变对应声音；换曲淡入/淡出中连续调音，确认没有重播、跳回开头或延长渐变。
2. 保存一组音量并刷新页面，确认再次开局采用已保存值；另存/读取旧进度及回退，确认当前音量与全局解锁不被覆盖。
3. 将音效设为 0，经过一次性音效，再调高，确认过期音效不补播；语音设为 0 时自动阅读仍能继续。
4. 使用作者默认后先不保存并刷新，再重复操作并保存，分别确认原偏好保留及覆盖被清除。
5. 保存失败后再调整同一轨及另一轨，重试原保存，确认后续调整仍可听见且显示尚未保存；退出重试也应沿用相同规则。
6. 进入限时样例和编辑预览，确认不会沿用或改变第一话已存音量；两个页面分别保存不同通道，确认数据库合并保留另一通道。
7. 保存进行中请求原生退出并取消，确认写入继续、调音控件恢复可用；未点击保存的音量不因退出自动落盘。存储损坏或长时间无响应时显示提示，主线入口仍可使用作者默认。
