## 独立对白编辑

### 入口与范围

仓库根、Node `>=24.15.0 <25` 环境，统一测试阶段由用户选择执行：

```powershell
npm ci --ignore-scripts
npm run editor:dev
```

浏览器访问 `http://127.0.0.1:5174`。只监听本机，端口占用则失败；与游戏试播 `5173` 分开。此服务具有修改当前作者源的显式能力，应仅由本机制作人员使用；不进入游戏包或原生宿主。

另已编写[编辑器本机集成产物](<editor.md#editor-delivery>)入口：`editor:build` 独立构建前端及清单，`editor:serve -- <产物摘要>` 核对匹配的本机输入后服务该前端；不依赖 Vite 的开发转换。它仍依赖当前仓库及唯一作者源，未执行、未决定正式分发或提供独立安装包，开发入口继续保留。

- 唯一作者源是 `content/story/project.json` 登记的章节及配置。打开只读取，不自动保存，也不生成另一份可编辑剧情工程。
- 按稳定节点 ID、章节、当前草稿说话人和对白查找，列表按作者顺序每页 200 项，可前后翻页浏览全部匹配节点；当前编辑节点在筛选外或其他页时另设置顶项，保留搜索、当前表单与草稿。显式定位跳到匹配页，不匹配时保留筛选。
- 仅开放原节点中已存在的 `speaker/text` 字符串。缺失或非字符串字段只读，不自动补字段。节点身份、顺序、选择、动作、流转、演出及资源不开放写入。
- 当前选项 ID 已明确保存在章节中，不再按原文匹配基线；本编辑页仍不开放选项写入，不因源切换扩大功能。
- 草稿仅在本页内存中。刷新、关闭或热重载会丢失未保存内容；离开提示受浏览器规则约束，可主动导出草稿。
- 页面“撤销草稿操作 / 重做草稿操作”提供[有界操作历史](<editor.md#editor>)，包括跨节点修改、还原和导入；只影响当前内存草稿，不是文件版本恢复或游戏回退。
- “导出修改草稿”下载 `haifeng.author-text-patch/1` JSON，含原作者源摘要和每项节点 ID、字段、原值、新值。它是修改记录，不是第二作者源；同一入口可重新导入并逐项比较，不自动猜测或覆盖冲突。
- “保留草稿并与磁盘源比较”复用原读取接口，保留原基线/历史/预览，逐字段比较原文、这次读取的磁盘文字与本页修改；明确采用后才更换本页基线，未采用项可按原摘要导出，不自动保存。
- “当前草稿变更”只读显示现有差量，按节点/章节/原新文字及字段筛选，每页 25 项，展开完整原值/新值并定位已有节点；不等于保存确认或磁盘最新状态，草稿变化后须刷新。
- “所选节点 · 场面与演出”只读显示规范化背景/立绘、音乐意图、环境声、语音/音效及演出参数，资源路径只作文字、元数据按需展开，不加载媒体或执行动作。
- 作者操作失败时可显示已有结构化诊断的代码/来源/字段/节点，只有同一请求快照的明确稳定节点身份才可定位；读取失败、源冲突及旧草稿诊断只保留说明。
- 运行预览的问题另在制作区显示当前节点来源、运行修订与启动时基线/草稿代次；同一会话/呈现/步骤及问题仍匹配才可只读定位，原媒体重试不变。
- 预览操作按钮复用[共享按钮声音](<player.md#feedback>)，仅采用作者 `btnSe` 默认，暂停/快进/结束时不触发。源编辑、草稿保存等制作操作不套游玩声音；不读取或写入正常游玩按钮偏好，停止/离开取消旧声音。
- 预览使用[共享作者外观及原鲸鱼图形](<player.md#appearance>)，对白采用作者字号基准、选择与场面共同缩放；编辑器不再另设预览选择字号或 padding。主题只作用于舞台，制作控件不随之变化；没有新增主题编辑/图形写入。
- 预览的[主线旧画面淡出](<player.md#performance>)显式提供同一预览舞台及选择节点，复用游戏的触发条件、360ms 静态淡出及取消；副本不含制作控件，不接输入或玩家存储，恢复不重放。。
- 预览[首次终态过渡](<player.md#performance>)复用共享 `StageFade`，只捕获本舞台场面、选择及结局卡片；停止/换预览、后台、全屏/尺寸变化及离开清理，不因卡片刷新重播。不复制制作控件或接入玩家写入。
- 预览的选择使用[共享面板和舞台比例](<player.md#appearance>)，采用同一首立绘左右/多列规则，显示会话倒计时；时间刷新不重建按钮，窄舞台的字号、按钮与滚动复用游戏规则。停止清除旧选择监听，缩放不重开剧情或计时；[竖屏分区](<player.md#appearance>)也复用同一接线，制作控件继续在外部。
- [只读节点流转定位](<editor.md#flow>)展示当前节点的一层前驱/后继、原条件两侧、选项/超时默认、空目标及结局，分别分页并显示完整条件/动作/来源。图中文字采用当前草稿，修改后须刷新；点击邻接节点只复用既有表单定位，不启动预览或写流转。
- 预览复用[共享输入与隐藏界面](<player.md#input>)：先聚焦预览舞台/操作栏，再用继续、A、Ctrl、H 和 Esc；编辑输入及制作控件不触发游玩快捷键。隐藏不暂停，下一次继续只恢复显示，停止/换预览清理临时快进和旧手势；预览没有回看入口，不启用回看手势。
- 预览复用[共享全屏](<player.md#fullscreen>)，按钮/F11/Alt+Enter 只在预览区工作，进入目标不包含制作控件；浏览器 Esc 先退出显示。停止或销毁处理尚未完成的进入，不因显示重开剧情或读取玩家偏好。
- 编辑区已接[只读引用与影响查询](<editor.md#references>)：查看节点引用、按 ID/路径/变量/选项文字查目标、反查使用位置并定位节点；分页保留全部结果。采用当前对白草稿，修改后显式刷新，不用旧结果定位，不启动预览或写入源。
- 已接[检查点初始条件预览](<editor.md#preview-checkpoints>)：捕获当前预览、在本机导入/导出独立封装，严格同作品/修订恢复已生效进度及剩余时间。每次显式选语音，使用保存时投影并标明；不读写玩家槽位或上传检查点。
- 到达结局后复用[共享结局卡片](<storage.md#endings>)，明确只属草稿预览、不写玩家解锁及通关次数，按钮仅停止原预览；脚本末尾与作者结局分开，不传正式已保存状态或接聊天按钮。

### 节点目录与分页定位

搜索变化回到第一页；普通翻页不改 `selected`、表单、搜索词或草稿，不自动选中该页首项。当前编辑节点不在本页时，列表最多额外显示一个置顶项，明确区分“不匹配筛选”和“不在本页”；零匹配仍保留当前节点，不伪造匹配结果。状态显示总节点、匹配数、本页项范围与草稿字段数，计数不变时不重复改写播报文字。

“定位当前节点”、引用/流程定位及单节点撤销/重做会在匹配集中定位该节点所在页；不匹配时保持查询及当前页并置顶，不能为了定位清除筛选。引用/流程继续按原来源/草稿代次校验，并聚焦编辑标题；手动定位按钮聚焦原生节点列表。多节点草稿导入/历史操作保持当前节点与页，普通编辑保持页和列表滚动，匹配减少时只将无效页收回最后有效页。

匹配缓存仅由已读取内容对象、本页草稿代次和规范化查询词共同确定；编辑、还原、导入、撤销/重做及源替换后重新计算，单纯翻页/定位复用相同结果。DOM 仍最多 200 个本页匹配项加一个当前节点；不创建第二内容源或解释器。源读取/保存期间禁用分页与定位，成功采用后保留搜索及仍存在的节点 ID，离开清理缓存和列表监听。

查询、翻页、定位不进入草稿历史、不触发保存/预览或写入玩家记录，也不将制作按钮纳入预览全屏/输入/声音范围。服务端、补丁协议、可写字段、来源摘要保护均不变。

### 所选节点的只读场面与演出

| 显示组 | 原结构和边界 |
|---|---|
| 身份/来源 | 稳定节点 ID、原标签/章节、作者来源及可选原索引；不把规范化字段当成原 token 行列 |
| 背景/氛围 | 背景 ID 或明确的 `null`，`scene.mood`、转场、瞬时效果原值 |
| 立绘 | 原数组及显示层顺序、实例/资源 ID、作者 x/y/高度、翻转、进退场、外观和切姿态原值 |
| 音乐 | 区分 `stop` 及其淡出参数、`play` 的资源/`continue`/淡变；不猜此前曲目或播放位置 |
| 环境声/语音/音效 | 原资源身份、环境声/音效节点增益、一次性音效延迟；语音 `null` 与有资源分别说明 |
| 时长/动作 | 原 `waitMs/typeMultiplier/holdMs` 及角色动作映射键/值；不计算自动等待、路线或当前有效时间 |
| 资源与提示 | 作者资源路径只用文字，种类、完整资源元数据和 `sourceHints` 原 JSON 按需展开 |

立绘、环境声、音效和动作映射各按 20 项分页，保留原顺序及全部结果；空列表明确说明。资源元数据和保留提示在展开时才创建全文，收起、翻页或失效清理原文本和相应监听。所有值用 `textContent`，空字符串、false、0、null 分别保留，不执行 HTML 或占位插值。

摘要显示的是规范化作者结构及资源元数据原值，**不是另一套表现解释或渲染验收**。例如 `shot.focus` 的合法性/缩放限制、`view.position` 的取景、角色明暗与背景调色、音乐继续/停奏和最终声音增益仍由共享播放器处理；面板不复制算法、计算最终 CSS 或把 `sceneFit/shot/playbackGain` 原值冒充实际生效结果。角色动作映射键与立绘实例 ID 分别显示，不按位置推断对应关系。完整播放预览继续复用原实现。

选择节点或经引用/流程/变更定位时同步显示新节点；普通草稿输入使旧摘要失效并清空，刷新后绑定新代次。还原、导入、撤销/重做及来源采用按原表单刷新；读取/保存期间禁用按钮、分页和展开，成功采用新源后刷新。每次交互检查原页面状态、来源/内容/草稿代次、节点身份和视图代次，旧折叠或分页不能作用于新节点。显示失败独立报告，不将已确认的作者保存改报失败。

没有新增场面可写字段、作者格式、资源修复/替换、文件选择、保存触发、预览或玩家记录能力。

### 当前草稿的只读变更清单

显式点击“按当前草稿刷新变更”后显示修改字段数/节点数、原源摘要及本页代次，可按节点 ID、章节、原值、新值搜索，并选择说话人/对白。每页最多 25 个字段，上一页/下一页保留全部结果，筛选重回第一页；来源/草稿变化不自动清除筛选，刷新时收回超出结果的页。无修改与无匹配分别说明，不制造空变更。

每项默认显示最多 120 个 UTF-16 单元的原/新摘要；空字符串明确标注。展开后才创建完整原值/新值 `pre`，保留空白、换行和原文字，并显示原长度；收起释放完整 DOM。文本全部用 `textContent`，不执行 HTML、对白占位或表达式，不计算人物好感/路线结果。显示裁切不是补丁裁切，原差量没有被改写。

定位前核对相同来源、内容对象、草稿代次及本次列表代次，复用 `navigateNode()`：匹配原节点搜索时跳到对应节点页，不匹配则保持筛选并置顶，聚焦原节点标题；不自动选新预览入口或写草稿。普通节点选择不使差量失效，也不重新计算草稿。

编辑、还原、导入采用、撤销/重做或源替换会清空旧对照和行监听，保留筛选并要求刷新；旧按钮和折叠事件不能定位新数据。读取/保存期间禁用清单控件及完整内容展开，成功采用新源后刷新为空差量；失败保留草稿，可继续查看原对照，但不能据此声称文件未写入。当前已读源仍可能落后于磁盘，真实冲突保护继续由保存端重查摘要执行。

完整面板留在制作区，位于预览全屏/输入/按钮声音范围外；销毁释放差量快照、章节查找和监听。服务端 API、修改补丁、可写字段和命令不变。

### 草稿撤销与重做

`packages/story-model/src/author-history.ts` 的 `AuthorDraftHistory` 统一持有当前字段修改及操作差量。基线来自已读取作者源摘要、稳定节点 ID 和已有可编辑字符串；`update/removeNode/replace` 分别处理单字段、整节点还原及完整导入采用。单字段和导入继续通过 `readAuthorTextPatch` 校验，最多 1000 个字段、每值 100000 个 UTF-16 字符；原值必须匹配该基线，不接受缺失字段或其他源摘要。

- 在同一次焦点停留中连续编辑同一字段合为一步，输入法产生的文字仍由输入事件同步。切换字段/节点、失焦、预览准备、导出或导入比较会结束合并；粘贴、拖放、剪切和浏览器原生撤销/重做产生的输入各自分开。
- “还原本节点草稿”将已有说话人/对白草稿一起还原，作为一个可撤销操作；没有实际修改时不制造历史项。
- 点击采用导入结果时，将本次实际改变的全部字段作为一步；冲突选择、只读文件、取消比较和未采用项导出不进入内容操作历史。撤销一次导入会一起找回导入前的本页修改。
- 撤销后作出新的实际修改会丢弃旧重做分支；查询、翻页和节点选择不制造内容修改或丢弃重做。全部改变字段属于同一节点时，撤销/重做自动定位该节点；多节点导入保留当前选中项。搜索条件、其他草稿和筛选外当前项继续保留。
- 每次实际撤销/重做递增草稿代次，取消旧导入比较，使旧引用结果失效，并拒绝请求期间尚未采用的旧预览结果。已运行预览保持原修订，页面提示重新预览，不逐键改写运行状态。
- 成功保存或重新读取并采用新作者源后清空两侧历史，绑定新基线；响应失败或源冲突时保留当前草稿和历史。保存响应不确定时仍须重新读取确认真实磁盘结果，保留历史不证明文件没有写入。

历史只用字段差量，不为每个输入复制整份剧情。当前页面显式设置最多 100 步、两侧合计最多 2000000 个 UTF-16 单位的保守历史文字预算，包含身份、标签及差量的前后字符串；这不是整个编辑器的堆内存上限，不包含已读取内容、当前草稿及对象开销。超出总预算时丢弃最早的历史项，当前草稿保持原值。单次操作本身超过预算仍可采用，但清空无法跨越该操作的旧链并明确提示不可撤销，避免跳过这次操作恢复到错误状态；当前草稿仍可导出或保存。

`patch()` 返回当前修改副本，历史条目和字段记录只读。撤销/重做先检查全部目标字段，再整体替换草稿；没有文件、定时器、预览或剧情核心调用。销毁时释放基线及历史，历史不进入导出补丁、服务端、游戏包或玩家存储。

输入框内 Ctrl+Z/Ctrl+Y 等仍交给浏览器，不注册页面级撤销快捷键；页面按钮负责上述跨字段草稿操作。浏览器原生撤销触发的文字变化视为一次新的草稿输入，而不是替代页面历史。按钮位于制作区，不接游戏快捷键或按钮声音。

### 草稿导入与冲突恢复

2026-10-24 从 `5390d90` 接续，编写草稿恢复及逐字段冲突处理，仍。新增 `packages/story-model/src/author-draft.ts` 纯比较函数、浏览器文件读取与比较面板；没有新增命令、作者格式或服务端写入 API。

操作流程：

1. 需要保留的本页修改可先导出。若真实作者源已被其他工具改动，可用下述“保留草稿并与磁盘源比较”；原“明确丢弃并重读，再导入已导出 JSON”的手动路径继续保留。
2. 入口只在浏览器本页读取用户选中的文件；校验 UTF-8、JSON 和 `readAuthorTextPatch`，拒绝未知格式、扩展字段、重复节点/字段项、非法字段及超限内容。不执行文件脚本，不上传文件或写入作者源。
3. 面板按稳定节点 ID 与字段列出每项的旧原文、已读取作者源、本页当前草稿、导入新值。当前源与导出摘要不同会显式显示两个摘要；即使原摘要相同，字段原值不一致也不能跳过比较。
4. 有冲突的字段逐项选择“保留本页当前值”或“采用导入新值”。所有冲突已选择后，点击“采用本次选择到当前草稿”；需要人工组合文字时，可先采用适当一方，再在普通编辑框修改。
5. 采用后再通过原有转换器预览，确认后显式保存。服务端仍按新的草稿基线核对真实源摘要和原值，不能绕过保存冲突保护。

比较与默认建议如下，默认建议只有点击采用后才生效：

| 情况 | 建议与限制 |
|---|---|
| 已读取源等于导入旧原文，且本页没有另行修改 | 建议采用导入新值 |
| 本页当前值已等于导入新值 | 保留当前值，不制造重复修改 |
| 导入旧值与新值相同 | 视为无实际修改，保留当前草稿 |
| 源文件已包含导入新值，但本页又有不同修改 | 默认保留本页修改；仍可明确选导入值来还原该字段 |
| 源或本页有不同修改，且当前值不等于导入新值 | 不预选，须明确选择；不做模糊文本合并 |
| 当前节点或原字符串字段缺失/不可写 | 只允许跳过，不添加字段、不按节点顺序猜位置 |

`prepareDraftImport` 对已读取作者源和当前草稿作一致性检查，返回冻结的比较结果；`resolveDraftImport` 按全部字段的明确处理结果生成新草稿。当前其他字段的草稿保留，所采用字段以**当前已读取源的值**作为 `before`，整体使用当前源摘要；不会直接将旧摘要改掉后无条件发送旧补丁。新草稿完整通过同一修改协议校验后才一次性替换本页草稿，合并超限或任一决定无效时不部分采用。

未采用且尚未存在于当前值中的实际导入修改，可点击“导出未采用的导入修改”另存；它保留原文件的旧摘要及原 `before/after`，不会补造当前基线。原导入文件始终不被改动，缺失节点或被跳过的修改不会悄悄写入其他位置。

每次文件读取、取消及重新选择文件都有代次检查；不可中止的浏览器文件读取完成后也不能采用旧结果。本页修改或还原字段会取消当前比较，防止在旧草稿上合并；比较未结束时，读取、预览和保存按钮暂不可用，可先采用或取消。比较完成后，未采用项的独立导出仍可使用。离开页面会丢失尚未采用的处理选择，浏览器离开提示仍受浏览器规则约束。

每个导入文件最多 4 MiB，遵循原协议最多 1000 个字段、每值 100000 个 UTF-16 字符的限制；合并后的总字段数也不超过 1000。文件选择器的扩展名提示不是校验依据。比较只依据页面已读取的源，不能证明磁盘此刻未再改变；最终保存的实际路径、摘要、原值核对和合作锁仍按下一节执行。

### 保留草稿与磁盘源比较

1. 有本页草稿且没有其他作者操作或待处理比较时，点击“保留草稿并与磁盘源比较”。捕获原文档对象/摘要、草稿代次及完整原补丁；只调用现有 `/__editor/source`，不发送保存或预览请求。读取期间禁用作者编辑，可取消采用读取；旧请求迟到不得打开新比较。失败、取消或响应无效均保留原基线、草稿历史与预览。
2. 完整校验读取结果后，只显示候选比较，尚不采用新源。按稳定节点 ID/字段对照本页原文、这次读取的磁盘文字和需要保留的本页修改。每页 25 项，翻页保留全部选择，完整文本展开才创建 DOM，全部按文字处理。
3. 磁盘仍等于原文时建议保留本页修改；磁盘已等于本页修改时不生成重复修改；其他冲突须明确选择。节点或原字符串字段不可用时只能跳过，不添加字段或猜测身份。这里“已有相同文字”只描述这次读取结果，不能确认某次保存请求成功、备份完成或磁盘此刻未再变化。
4. 比较期间取消，原基线/草稿/历史及预览继续保留。继续编辑、还原、撤销/重做会使旧比较失效，旧页面或按钮不得采用后来草稿；待比较时禁用新读取、导入、预览准备和保存。制作区与预览输入/全屏/声音范围仍分开。
5. 点击“采用所选草稿与这次读取的基线”，先用完整比较选择生成新补丁，再在新的 `AuthorDraftHistory` 中校验新源基线、原值及全部修改，全部成功后才替换本页基线和历史并停止旧预览。跨基线旧历史清空；恢复修改作为现有“采用导入草稿”一步，超出原历史预算时明示不能撤销。当前节点和搜索保留，节点确已不存在才采用新源入口；引用、流程、变更与场面改用新基线。
6. 采用后仍只在内存中。可导出比较前完整补丁，以及未采用且尚未存在于磁盘文字中的旧修改；它们保持原摘要与原 `before/after`。不可用或主动跳过的修改不悄悄丢失，也不写到其他节点。未采用修改副本存在时阻止新磁盘比较覆盖它，并启用浏览器离开提示；明确关闭结果才释放该副本，浏览器提示不保证拦截强制离开。导出点击只请求下载，不能保证文件已落盘。

重新预览并显式保存时，保存端仍重查实际源摘要与原值；本次比较不是磁盘锁、保存确认或旧补丁的无条件重试。不新增自动写入、备份恢复、跨修订检查点迁移、玩家记录或联网依赖。源读取沿用原完整转换/资源摘要计算，未改变现有大小限制。

### 同一转换与预览

`tools/content/build.ts` 的 `compileSourceContent(project)` 是内容构建路径的复用入口：`source.ts` 先读取/组装分章文件，`compile.ts` 编译受限表达式与稳定目标，再检查真实登记素材并计算修订。`loadSourceContent()` 与编辑候选共用这条路径，不再读取旧 JS 或旧选项原文映射。

编辑器读取、草稿预览和保存都调用这条路径；预览候选不写入磁盘，也不产生 `dist` 内容。转换失败显示来源、节点与字段诊断。每次转换会读取并计算登记资源摘要，较大作品的请求可能耗时；不是全部媒体解码或全路线验证。

`apps/editor` 在浏览器对返回内容执行 `readStoryContent`，校验资源位置、来源摘要和可编辑字段，再复用 `createGameSession`、`WebPresentation` 与媒体资源访问器。没有编辑器专属解释器；当前复用试播表现样式，也不代表最终编辑界面。

| 预览方式 | 初始条件 |
|---|---|
| 正常开局 | 作品正常入口，全部声明变量初值，周目 1、结局数 0 |
| 所选节点 | 所选节点作为临时入口，全部声明变量初值，周目 1、结局数 0，再正常执行该节点进入动作；页面持续标明是人工初始条件 |
| 检查点 | 只接同作品、同草稿修订的预览封装，恢复已生效变量、保存时玩家投影、完整文字和剩余有效时间，不执行进入动作；每次明确选择语音 |

所选节点的临时修订不写入作者源或发行清单；这不是恢复真实路线存档。变量初值、当前变量和玩家投影可展开查看。预览不读取玩家槽位，也不写 IndexedDB、全局成果、正式偏好或聊天；已读仅在本次预览的内存集合内，重新预览丢弃。

检查点预览沿用共享恢复，封装记录原预览起点及真正恢复位置；文件头读取成功与完整校验/采用分开显示，校验失败保留现有预览及最近已校验项。草稿发生任何修订变化都不会自动迁移旧检查点。封装字段、隔离和待试用情景见[检查点初始条件说明](<editor.md#preview-checkpoints>)。

点击、选项、自动、暂停、有效计时与媒体重试均交给共享会话。切后台独立暂停；停止、换预览及离开取消旧媒体和计时。编译过程中草稿又有变化，旧结果不采用；停止也会取消待采用预览。新预览准备失败不把现有会话切到旧解释器。

编辑后当前画面继续使用启动时的修订，页面明确提示重新预览；保存或成功重新读取会停止旧预览。没有逐键热替换正在运行的剧情状态。

### 显式保存与冲突

“保存到作者源”才调用写入；保存期间锁住编辑。后台只按作品清单/稳定节点定位当前仓库中的普通章节文件，调用者不能传任意路径。**当前多章事务及恢复步骤以[分章源保存说明](<content.md#author-source>)为准**，下面单文件算法仅记录早期切片，不作为当前写入契约。

1. 取得作品目录 `.rebuild-editor-lock` 合作锁，校验 `haifeng.author-text-patch/1`、完整原 SHA-256、稳定节点 ID、字段类型和原值；同一字段不能重复出现。单次最多 1000 个字段、每值最多 100000 个 UTF-16 字符、HTTP 载荷最多 4 MiB、作者源及候选最多 16 MiB。
2. 在纯 JSON 包装内定位原 `speaker/text` 字符串 token；只替换这些范围，保留其余字段、节点与资源顺序、原格式和 UTF-8 BOM。重复对象键或超出扫描范围明确拒绝，不整包序列化。
3. 对完整候选执行同一转换及资源读取；失败不替换源文件。
4. 先将原字节写为唯一的 `.rebuild-editor-backup-<原摘要>-<随机标识>.js`，再写同目录 `.rebuild-editor-<随机标识>.tmp` 候选。备份或候选写入失败不删除原文件。
5. 最终替换前重查源路径、原摘要和候选路径；发现变化拒绝覆盖，保留备份与候选。成功替换才返回新的摘要、内容与备份相对位置。

整个保存过程持锁。锁只协调遵守本约定的保存操作，最后摘要检查与替换之间仍存在不遵守锁的外部编辑器竞态；制作时应避免并行写同一作者文件。没有完整跨进程事务或断电持久性承诺。

正常结束仅尝试移除空锁目录，不递归清理异常目录。异常锁需先确认没有进行中的保存并检查作品目录，再由制作人员处理；本片没有自动解锁。原文件备份和失败候选均保留为本机恢复证据，已精确加入忽略规则，不提交、不充当内容构建来源，也不自动清理。

源摘要不一致会返回冲突，当前草稿保留；可用“保留草稿并与磁盘源比较”，逐项处理后明确采用新基线，或按原导出/丢弃重读/导入路径恢复。HTTP 断开、服务中断或响应校验失败时，界面只报告“未确认完成”；文件可能已经替换，不能假定保存未发生，也不能直接无条件重试覆盖。比较只读取实际文字，不反推此前请求的提交回执。

重新读取/预览/保存 API 都是固定路由 POST，校验固定 Host、同源 Origin、JSON 类型及本次启动的随机令牌，服务内只允许一个作者操作进行；令牌不写入磁盘。只返回规范化内容、允许字段、本机资源位置和备份相对位置，不把原始作者文件、文件句柄或 Node 错误绝对路径序列化到浏览器。

### 运行预览问题与编辑定位

`EditorPreview.problem()` 只返回当前 `SessionView.problem` 的冻结副本，包括问题代码/说明/阻断状态、原会话/呈现/步骤令牌、当前预览节点及该节点的作者来源、运行修订和启动来源。它不返回会话、文档、变量、可写内部状态或重试闭包。没有问题、已停止/销毁或无法在该预览内容中定位当前节点时返回空值，原预览文字错误提示仍保留。

`apps/editor/src/preview-problem.ts` 的 `PreviewProblemPanel` 放在预览全屏和游玩输入范围外，显示上述只读信息以及“在编辑区定位这个预览节点”。**来源属于问题发生时的当前节点，不表示已经确定错误字段、跳转目标或资源。** 面板不解析错误字符串、不按数组下标猜节点，也不把 `MediaProblem` 伪装为服务器内容诊断；原“重试当前媒体”仍由共享会话处理。

定位按钮点击时同时核对：

- 仍是原预览会话/呈现/核心步骤、当前节点和同一问题代码/文字/阻断状态，运行修订与候选源摘要仍匹配。
- 启动时作者基线摘要及本页草稿代次与现在一致；原节点仍在当前基线且来源文件匹配。
- 页面未离开，且没有进行作者读取、保存或新的预览准备。

匹配时复用 `navigateNode()`，只打开原编辑表单并保留搜索、节点分页/筛选外置顶，不暂停、重试、停止或重开预览，不执行任何剧情或存储写入。编辑/导入/还原/撤销/重做后，即使文字又改回原样，草稿代次已变化，旧预览仍不能定位后来草稿；须显式重新预览采用当前修订。

同一问题只更新定位许可，不随计时重复重建按钮；实际问题/令牌变化才替换原行并取消旧监听。问题消失、重试采用新呈现、推进、停止、换预览和销毁清理原归属；焦点在被移除操作内时，仅在许可且可见的情况下回到已有编辑标题，不抢其他控件焦点。来源变化或旧草稿不抹去运行问题说明，但定位禁用。预览失败准备仍遵循原先“准备成功后才替换旧预览”的边界。

没有修改共享 `SessionView/MediaProblem`、唯一核心、媒体重试、作者写入、预览检查点或玩家记录格式；新增的预览来源/问题读取仅是编辑应用内接口。

### 作者操作的结构化诊断

`apps/editor/src/diagnostic.ts` 的 `AuthorDiagnostic` 在制作区显示本次操作、代码、诊断说明、来源文件/字段、可选稳定节点 ID/原索引、请求采用的源摘要及本页草稿代次。字符串全部作为文字显示，不构造链接、文件路径请求或可执行 HTML。字段和索引是来源说明，不冒充原 token 行列，也不能被当成节点 ID。

诊断上下文由应用在发起请求前固定，绑定本次请求 ID、已读取内容对象、原源摘要和草稿代次。服务返回诊断不等于返回了新的源身份；普通节点选择/翻页不改变其归属。定位每次重新核对快照，并且只允许：

- 原操作为预览或保存，已有匹配的基线内容，原请求/来源/草稿代次均未变化。
- 诊断不是 `AUTHOR_CONFLICT`，且明确提供当前内容中存在的稳定 `nodeId`。
- 诊断来源文件与该节点记录的原来源文件一致。

满足条件时调用既有 `navigateNode()`，只切换表单并保留节点查询，匹配则跳到对应目录页，不匹配则置顶；不聚焦或写入推测字段、不重试请求、不启动预览或执行修复。读取源失败涉及尚未采用内容，源冲突涉及可能变化的磁盘节点，缺失/不匹配身份或只有索引的诊断均只保留说明，不猜映射。

普通编辑、还原、导入及撤销/重做后，旧诊断仍可见但失去定位许可；新作者请求清理旧诊断及旧按钮监听，取消待用预览使旧请求失效，迟到响应不能重新显示。读取/保存期间禁用定位，页面销毁释放快照与监听。诊断面板留在预览全屏、游玩快捷键和按钮声音范围之外。

诊断不授予新的写入/采用权限。保存失败继续保留草稿和“未确认完成，必要时导出后重读源确认”的说明，不能因为结构化错误出现就宣称文件肯定未写入；查看定位也不解除服务端摘要冲突保护。只有服务器失败响应使用本片结构化面板，网络/响应校验/本页表现错误仍沿原文字提示，不伪造服务端诊断。

## 编辑器本机集成

### 命令和产物

统一测试阶段按用户安排，在当前仓库、Node `>=24.15.0 <25` 环境显式执行：

```powershell
npm run editor:build
npm run editor:serve -- <editor:build 输出的完整产物摘要>
```

`editor:build` 只调用已有 Vite 构建独立的 `apps/editor` 前端和共享预览，生成 `dist/editor/<产物摘要>/`：

| 路径 | 内容 |
|---|---|
| `editor-package.json` | 严格的 `haifeng.editor-package/1` 清单，目的固定 `local-integration-trial` |
| `frontend/index.html` | 构建的编辑页面，运行令牌位置只有固定占位标记 |
| `frontend/assets/` | Vite 产生的脚本、样式和实际前端静态依赖；不复制完整作品素材 |

清单记录前端文件的相对路径/字节数/SHA-256、Git 提交/工作区状态、依赖锁/Vite 版本和原鲸鱼皮肤来源摘要。产物身份由清单的共享规范化表示计算，不是剧情修订或存档版本。未增加时间戳、凭据、机器绝对路径、玩家记录、作者剧情、草稿、备份或失败候选。

产物还绑定当前固定本机服务的运行输入：`tools/editor/`、`tools/content/`、`packages/story-model/src/` 内 TypeScript 源码，以及 `package.json`、`package-lock.json`，不再绑定旧选项原文映射。这里只登记摘要，不复制第二套作者源或后台源码到前端。构建前后核对这些输入；编辑分章作者文件不改变该清单，后端仍在请求时读取当前唯一作者源。

Vite 不读取额外环境文件或 public 目录，不写源码、不启动服务，不运行内容构建或收集全部剧情资源。共享预览的鲸鱼图形随本体改为读取 `content/game-ui/whale.json` 的原载荷；清单读取仅兼容原 HTML 和新定义这两个明确来源，`uiSkin` 结构及清单版本保持。此处只维护已有共享消费者兼容，编辑器扩展已按用户要求暂停。生成前端不得残留 `/@fs/` 开发地址；HTML 必须保留唯一的会话占位标记。

每次构建在物理边界核对后的 `dist/editor` 创建独占 `.build-lock` 和本次 `.building-*` 临时目录；清单完整后才将临时目录改名为摘要目录。相同摘要目录存在则拒绝覆盖，不重写已有产物。失败临时目录保留作定位，不递归清理；异常/残留锁须先确认没有活跃构建再人工处理。

### 显式本机启动

`editor:serve` 只接受一个完整产物摘要，不接受服务地址、任意目录、作者文件路径或命令。它先核对清单身份、全部前端文件及完整运行输入集合，再绑定固定 `127.0.0.1:5174`；端口冲突或输入变化直接失败，不自动构建、换端口、打开浏览器或修改来源。

服务直接读取已构建文件，不启动 Vite、不提供开发源码转换或通用目录浏览。仅清单内前端文件可访问，每次请求重新核对字节；额外文件、越界/链接和文件变化不放行。每次作者 API 操作前重查运行输入，发生变化时拒绝本次操作并要求停止重建。它不提供对外部编辑器的原子快照保证，最终作者写回继续核对原摘要、原值与固定路径。

这是依赖当前仓库源码、分章作者源和原素材目录的本机集成入口；不能只复制 `frontend` 就宣称独立分发完成。实际运行不依赖 Vite 转换，但仍需要受支持 Node 和完整匹配的仓库输入。正式可移动作者工程、后台打包、安装/更新与编辑器框架仍未决定。游戏构建及 Windows/Android 准备不消费这个产物或后台。

Ctrl+C/终止信号停止接收新连接并等待已有请求结束，不新增保存。强制终止或连接断开仍可能使保存响应未确认；按[保留草稿的磁盘比较](<editor.md#editor>)处理，不能据此假定未写入。

### 共用作者 API 和运行会话

`tools/editor/api.ts` 的 `createEditorApi()` 同时服务 `editor:dev` 和构建入口，二者复用 `tools/editor/source.ts` 的原读取、预览与显式保存；没有第二个转换器或写回实现。端口同为 5174，不能同时运行。

本次服务启动才生成随机令牌，在 HTML 响应的专用 meta 内注入；前端 `session.ts` 严格读取此令牌并放入原请求头。磁盘上的 HTML 只有占位标记，没有可用令牌。没有令牌引导 API、磁盘令牌或构建期固定秘密，令牌也不进入清单或控制台。

原 `/__editor/source`、`/__editor/preview`、`/__editor/save` 的 POST、JSON、本次令牌、固定 Host/Origin、4 MiB 上限与单一作者操作限制保留；保存仍只允许现有 `speaker/text`。同源媒体读取与 JSON 作者操作分开检查，未改变补丁/内容/预览检查点或玩家存储格式。导入草稿、检查点、磁盘比较和共享预览继续沿原路径。

### 已登记素材读取

为脱离 Vite 的 `/@fs/`，作者文档 `locations` 改为 `/__editor/media/<素材字节摘要>/<编码资源 ID>`。文档形状不变，浏览器严格核对同源路径和该资源的精确 ID；旧开发地址不再接受。这是服务会话内的位置协议变更，须使用同一版本页面与后台、重载旧页；不迁移或修改任何持久记录。

素材只从本次服务已通过完整转换、实际摘要读取并返回过的资源登记表中选取。请求不能指定文件路径；每次读取重查真实作品目录边界、普通文件、字节数及摘要，不将后来变化的字节冒充旧预览资源。不加载整个素材库，也不把作品素材带进前端构建。

同摘要/ID 可以复用相同内容，已返回的不同摘要位置在服务内继续独立登记；服务重启后登记表清空，不能直接重用旧页面。素材失败由原共享表现报告、显式重试，不重执行剧情、自动重读作者源或切换解释器。

读取支持 GET/HEAD 和单段 `bytes` Range，供原图片和声音使用；错误/多段/无效范围明确拒绝，不忽略后当作其他资源。未登记身份、未支持的图片/声音扩展名明确拒绝，不提供任意文本/脚本原件。每次只读取所请求的原件并验摘要，Range 也须先读取该文件全部字节，未引入长期解码/字节缓存，较大声音的重复范围读取成本仍待实际试用。取消媒体请求可中止文件读取，服务错误不暴露本机绝对路径。

## 只读引用查询

### 入口与快照

沿用[独立编辑入口](<editor.md#editor>)的 `npm run editor:dev`，没有新增命令或服务端 API。读取作者源成功后，编辑页的“引用与影响查询”显示当前节点的引用、可搜索的目标目录和反向使用位置。查询和制作控件均在预览全屏区域外，不接游玩声音或快捷键。

每份结果绑定已读取的作者源摘要、内容对象及本页草稿代次。读取和保存成功后自动刷新；普通编辑、还原及采用导入草稿会使旧结果失效，保留旧结果供辨认，但禁用查询和定位按钮，须点击“按当前草稿刷新引用”。刷新采用当前对白草稿，不以正在播放的旧预览修订冒充当前草稿。

读取/保存期间禁用面板操作。每次定位还核对当前摘要及草稿代次；旧按钮另有查询代次检查。定位只切换选中节点并聚焦其标题，保留草稿和节点搜索条件，不启动预览、不执行节点、不写作者文件或玩家记录。[节点目录](<editor.md#editor>)现按每页 200 项浏览全部匹配结果；定位匹配节点时进入其所在页，不匹配时保留筛选/当前页并置顶。普通翻页不改所选节点，原来源/代次校验保持。

节点引用、查询目标及反向使用位置各按 50 项分页，保留完整结果及原结构遍历顺序。目标目录包含已声明但没有使用位置的节点、资源、变量、选项、立绘实例和结局。结构引用不是路线可达性分析，条件两侧及所有选项都列出，不根据某次游玩的值隐藏结果。

### 从场面资源查看引用

`AuthorReferences.openResource(assetId, origin)` 先核对当前捕获与调用者原内容对象、源摘要、草稿代次一致，并确认资源实际登记。原调用已过期时拒绝，不刷新成后来内容的查询；身份仍匹配而引用索引失效时，才按原 `createReferenceIndex()` / `playerReferences()` 路径重建当前草稿引用，再核对身份后采用精确 `resource` 目标。不维护第二索引或跳过共享设置校验。

打开后保留引用文字/类型筛选，重置该资源的反向使用位置到第一页；目标匹配筛选时进入其目录页，不匹配时另置顶“当前引用目标（不匹配筛选）”。普通目标翻页时当前目标在其他页也置顶并明确“不在本页”，额外项不计入匹配总数。该规则也用于原节点/引用目标选择，避免目标已采用却在目录里看似无选择。

焦点交给使用位置标题，当前编辑节点、节点搜索、草稿和运行预览不变；沿使用位置再显式定位节点仍走原来源/草稿代次检查。跨目标查询使旧引用行代次失效，场面换页/换节点/草稿变化取消旧按钮监听；读取/保存期间门控继续由原应用控制。引用构建失败显示原诊断，不显示成有效零引用；零引用仍不证明无消费者或授予删除权。

此联动没有新增作者写入、资源删除/替换/修复、媒体加载、自动保存或预览操作。

### 共享接口

`packages/story-model/src/references.ts` 提供无 DOM 的纯查询：

| 接口 | 职责 |
|---|---|
| `createReferenceIndex(content, options?)` | 对已校验的 `StoryContent` 建立只读索引，可传当前对白覆盖和已解析的附加引用 |
| `definitions()` | 返回声明目录及显式标记的未解析查询项；未解析项不算新声明 |
| `outgoing(nodeId)` | 返回该节点持有的结构引用 |
| `incoming(target)` | 按带类型的稳定身份返回使用位置 |
| `referenceKey(target)` | 以 JSON 数组编码目标类型和身份，避免简单分隔符拼接冲突 |

节点、资源、变量和结局用各自类型与 ID 定位；选项和立绘实例另带所属节点 ID，不能把不同节点中的同名实例合并。返回条目、目标、来源和数组均冻结，内部查找表不暴露。索引不执行条件、动作或剧情命令，也不访问网络、媒体和存储。

每个引用包含目标、所属节点/选项、用途、规范化字段路径、作者来源、是否来自转换或默认规则，以及是否找到声明。对白引用额外提供包含花括号的 UTF-16 起止偏移，末端不含。

**规范化字段路径与作者来源不同。** 例如 `nodes.12.presentation.scene.background` 是转换后模型中的路径；原 `game.js` 的背景字段名称不同。普通剧情引用沿用已有节点或选项的原始来源定位，不声称掌握原表达式中每个 token 的准确行列。对白草稿的偏移属于当前草稿字符串，也不是原文件字节位置。

| 类别 | 查询的结构 |
|---|---|
| 流转 | 作品入口、后续节点、条件两侧、选项目标、无可见选项去向 |
| 选项与结局 | 超时默认选项的稳定身份、结局声明与使用位置 |

`packages/story-model/src/text.ts` 的 `dialoguePlaceholders()` 与 `fillDialogue()` 共用原运行规则 `/\{([^{}\s]{1,16})\}/gu`。唯一剧情核心改为调用同一填充函数；未知名字保留原文，并在查询中作为未解析引用显示，不默认零或偷偷声明变量。查询不推导插值后的显示值。

`packages/player/src/references.ts` 的 `playerReferences(content)` 复用 `readAuthorAppearance`、`readUiSounds`、`readFeedbackVariables`，沿用实际播放的设置解析及默认选择。默认封面和缺省反馈变量明确标记为派生引用，不伪称源文件存在相应配置。`readFeedbackVariables` 从原 `StoryFeedback` 中提取，供播放和查询共用，不增加反馈触发或内容字段。

后续[话末数值显示](<player.md#readout>)增加 `readReadoutVariables()` 的实际绑定，角色为 `readout-variable`，编辑页显示“话末数值变量”。它与声音反馈分开，保留 uiSe/既有 soul 显示字段的真实来源及默认派生标记；只消费字段名字，不启动旧 Agent 或网络，也不改变作者写回范围。非法绑定明确报错，不能当成零引用。

普通节点的引用仍依模型字段顺序生成，表达式先左后右读取；附加设置引用随后追加。这里的顺序方便定位，并不代表剧情执行顺序。外观或声音设置不合法时，面板显示解析错误并清空本次结果；已有编辑草稿保留，不以不完整查询冒充成功。

## 只读节点流转

### 读取与展示

`apps/editor/src/flow.ts` 的 `AuthorFlow` 只持有已校验内容、来源摘要、草稿代次及当前说话人/对白覆盖，接受显式 `capture/current/selected/navigate` 能力。没有作者文件写入、网络请求、剧情会话、存档或玩家记录接口。

刷新时按当前规范化内容建立全部节点及结构连线索引，不按旧数组相邻位置猜目标，不计算条件、执行动作或推断可达性：

| 规范化输入 | 显示 |
|---|---|
| `entryNodeId` | 独立作品入口标记；没有实际前驱节点 ID，不丢开局之前保留的其他节点 |
| `next` | 实际后续节点，空目标明确为脚本末尾 |
| `branch` | 条件成立和不成立两条连线，详情保留同一原条件；不求值、不把当前变量或人工预览初值当成路线判定 |
| `choice` | 原顺序的全部选项、稳定选项 ID、原目标、条件及动作；超时默认在对应原选项旁显示时长，不另造一条默认路线 |
| `emptyTarget` | 明确显示“无可见选项时”的目标，不假定总有可见选项 |
| `ending` | 结局名称及终态，不能冒充普通后续节点或已解锁成果 |
| 回到自身或多个流转到同一节点 | 保留每条结构连线，不递归展开或按目标合并选项 |

屏幕以当前编辑节点居中，前驱/后继分别每页最多八条。索引覆盖当前内容全部节点，分页可访问全部邻接连线；不会一次布局 3315 张节点卡片，也不把局部视图冒充全作品可达性分析。图形箭头只用固定布局数值，节点文字使用 `textContent`；键盘与辅助阅读通过实际按钮/分组工作，不依赖可点击 SVG。

节点卡片展示稳定 ID、章节/标签、当前草稿说话人及对白摘要，长内容在卡片内滚动。点击卡片中以流转标签为文字的按钮，会显示完整标签、条件、选项动作和来源。表达式只是从既有 AST 生成带括号的可读表示，不是另一套解析器或求值器；字符串和数值的类型区别保留，进入动作另在当前节点详情中只读列出。

规范化 `nodes.*.flow.*` 路径与作者 `source.file/field` 分开展示。前者是内容协议路径，不能当成作者文件原始 token 位置；当前图也不读取可能仍使用旧修订的预览运行态。

### 修订、定位与隔离

索引绑定 `sourceSha256`、已读取内容对象和本页草稿代次。编辑、还原、导入、撤销/重做及源替换会将旧图标为失效，保留可见但禁用查询/定位，须显式刷新；刷新不保存或启动预览。读取/保存作者源时禁用操作，失败不丢草稿或现有预览。

点击邻接节点复用编辑器现有 `navigateNode()`：先核对原图代次及当前来源，再保留搜索和草稿、定位该节点、更新表单及其他只读查询并聚焦节点标题。后续[节点目录分页](<editor.md#editor>)使匹配节点定位到其所在的 200 项页，筛选外节点仍置顶且保留当前页；不清查询或自动选中页首。不改变预览节点、剧情进度、变量或检查点，也不调用删除/重命名/修改流转。

翻页、重新定位及失效都更新视图代次，旧按钮不能继续定位或显示后来数据。源替换重新建立索引；离开取消监听并释放索引与副本。面板位于制作区，留在预览全屏、输入与按钮声音范围之外。

### 本片边界

没有开放节点、选项、条件、动作、变量、资源或连线写入，没有拖动、自动布局全图、路线模拟或死路诊断，也没有作者源切换。当前唯一作者源仍为 `海风与布丁/game.js`，实际保存范围仍只有已有 `speaker/text` 字符串。图中是否出现入边、出边或入口标记，不证明内容被实际游玩、可以删除或已经验收。

## 预览检查点

### 当前操作

沿用仓库根 `npm run editor:dev`，没有新增命令、服务端 API 或依赖。“检查点初始条件预览”位于制作区，留在预览全屏/游玩快捷键范围外，不套游戏按钮声音。

1. 正常开局或从所选节点预览。场面就绪、文字完整且处于非结局 `ready/choosing` 时，可以点击“捕获当前预览检查点”；限时选择可先暂停再捕获。
2. 捕获由 `GameSession.captureCheckpoint(token)` 在同一队列中完成，得到当时已经生效的变量、目标场景、计时及声音位置。继续预览不会更新这个分离副本。
3. 可以导出最近一次已校验的检查点 JSON。它只供制作预览，不是第二作者源、整套工程或正式玩家进度槽位；没有主动写入数据库或作者文件。
4. 从本机选择此前导出的 JSON，先在本页读取 UTF-8 与文件头，不执行或上传文件。此时明确标为待校验，不启动预览，不以“文件已读”冒充可恢复；最近一次已完整校验的数据仍可导出。
5. 每次显式选择本句静音、重播或尝试续播，再点击“从待用检查点继续预览”。先通过原编辑 API 转换当前草稿，然后在浏览器对检查点完整校验，成功后才取消旧预览、建立新的共享会话。

转换请求仍只发送原有 `haifeng.author-text-patch/1`，不包含检查点、文件内容或玩家资料。导入只选取本机文件；导出请求浏览器下载，没有共享、上传或自动写回动作。刷新、关闭或热替换会丢失本页保留的检查点，需要提前导出。

### 独立封装与身份

`apps/editor/src/checkpoint.ts` 定义内部 `haifeng.editor-checkpoint/1`：

| 字段 | 含义 |
|---|---|
| `format` | 明确的编辑器预览命名空间 |
| `workId` | 作品身份 |
| `contentRevision` | 未改临时入口前的规范化草稿修订 |
| `selectedEntry` | 正常开局为 `null`，所选节点预览为原临时入口的稳定节点 ID |
| `checkpoint` | 原 `haifeng.game-checkpoint/1`，沿用同一核心/媒体/计时校验 |

`readPreviewCheckpointInput` 只读取严格文件头，未知字段、格式或非法身份拒绝；检查点体继续保持 `unknown`。`inspectPreviewCheckpoint(content, input)` 核对作品和**完全相同的当前草稿修订**，按原临时入口构造相同预览内容，再调用 `inspectGameCheckpoint` 完整校验、`prepareGameRestore` 准备实际恢复状态。封装保留原捕获数据，预览初始条件显示准备后的计时及关闭自动/快进的状态。没有改写快照修订、按节点下标猜位置或跳过动作/计时校验。

所选节点预览原有的 `editor-preview:<起点>:<内容修订>` 临时身份沿用，封装另存其起点；从这个检查点继续不重新进入临时起点。当前编辑列表选中哪一项不改变文件中的原预览身份，也不改变真正恢复的节点。

文字草稿变化也会改变内容修订。当前入口拒绝跨修订恢复，不将旧检查点自动套进新对白、演出或路线。可以采用匹配草稿再重新预览，或从新草稿继续并捕获新检查点。本片不决定正式存档兼容、作者源迁移或跨修订编辑预览策略。

文件最多 4 MiB；UTF-8、JSON、封装、修订、变量、阶段、选项、场景停奏、音轨身份和计时均须通过各自读取器。只接该预览封装，不接受 `haifeng.save/1` 游戏槽位、裸旧档或不带来源身份的逻辑快照。即使数据可恢复，也只说明结构合法，不证明它来自实际完整路线；人工或改写文件的初始条件不能冒充路线验收。

### 恢复与隔离

`EditorPreview.start` 现在显式区分正常入口、所选节点和检查点三种启动方式。检查点及本次语音方式在取消旧预览前准备；格式、版本或状态校验失败时，当前预览及草稿保留。通过校验后，仍由 `createGameSession({ resume: { checkpoint, voice } })` 恢复，不先开局再跳转。

页面持续显示检查点恢复模式、恢复节点、保存时玩家投影及本次语音方式；展开预览状态可查看初始变量、计时、声音及当前变量。只使用检查点保存时的 `周目/结局数` 作为这次隔离预览的显式初始条件，不读正式玩家全局记录，也不把它写回任何成果。这不改变正式游戏读档使用当前已提交全局投影的既有规则。

共享恢复关闭自动/快进，保留必要的剩余有效等待，恢复稳定目标场景和完整文字；不重新执行进入动作、一次性进入音效或结局事实。声音仍按每次明确的 `silent/replay/resume` 处理，缺少可续播位置时沿用共享诊断，不补造零位置。已读从新预览的空内存集合开始，检查点不导入已读、对白回看、偏好或聊天。

捕获核对原会话和呈现代次。面板的文件读取/捕获另有代次，停止、换预览、草稿变化、作者操作、清除及离开会拒绝迟到结果；不可中止的浏览器文件读取结束后也不能覆盖后来选择。取消读取不改变当前草稿或旧预览。销毁时取消监听并释放待用项、已校验项与预览内容引用。

文件头读取成功只更换待校验项。完整校验成功或捕获成功才替换最近已校验项；读取或校验失败不能丢掉它。可以导出最近已校验项后重新选择，清除按钮则明确清除本页的全部检查点数据。这里没有多槽位管理、自动保存、正式玩家存储接入或新旧档迁移。

## 保留的旧完整制作与导出

独立对白编辑尚未覆盖美术、演出、素材库和完整项目导出，所以原 HTML/JS/CSS、美术编辑页及 Python 导出仍保留。它们不进入正式本体或两端包。

使用本机旧制作服务读取当前作品投影；仓库旧 HTML 不再从磁盘 game.js 读取剧情，外部旧项目仍可持有自己的数据。旧制作不得向当前原作品地址或 content/story 回写，不能用保存的旧整包覆盖分章作者源。

美术制作可保存 project.vnproj.json 草稿，保留资源 ID、位置/高度/翻转与来源备注。完整 HTML/文件夹导出应从旧制作服务按项目实际采用素材完成；只做浏览/微调的离线演示不等于正式游戏包。工具保留不等于本轮启动或扩展编辑器。

作品页、设置、插件与手账只保留其辅助用途；旧回放按钮、时间轴和剧情接口已退役。API 主服务保留本机 Host/Origin 约束，不能据旧作品页说明绕过当前作者源的只读边界。
