## 3. 画风、构图与交付标准

背景：保留日式视觉小说的手绘空间感、清楚透视和海光，主要材质为浅木、奶白、海蓝与少量翡翠绿。精细程度集中在窗光、海面、生活道具；植物、桌面小物和反光适当简化，让角色成为视觉中心。住宅有生活使用痕迹，甜品店更整齐实用，商业后厨有工作台与设备，家庭厨房尺度更亲近。

人物：线条干净，面部与眼睛的画法固定；阴影以少量清楚色块为主，再加柔和环境光。CG 参照同一套人物母图，不因夜景或水下就改变脸型、发量、年龄、服装剪裁。真正的受伤与疏远用低落、视线回避、红眼表达，减少喜剧怒气符号。

背景与 CG 采用 16:9；1920×1080 是目标交付尺寸，网页输出按实际尺寸登记，保存原件。当前画面为 1280×720，底部约 28% 常被对话框占用；脸、关键手势、戒指与尾鳍尽量在此区域上方。角色立绘使用透明 PNG 或支持透明的运行副本，同服装同一画布、锚点和人物高度，切表情不跳位。需要时同时保留完整尾鳍版及经实际舞台验证的取景版。

CG 直接放人物与环境；普通背景提供空舞台，让角色由立绘层显示，避免出现两个鲸鱼小姐。市场可有低细节远景顾客，人物不挡主角位置。双人 CG 可使用玩家视角的手、肩或背影，但手部、身高差和衣袖始终接男主简参。

同场景先定一个机位，再编辑晨、日、暮、夜；需要近景时参照同一地理/建筑板。固定门窗、楼梯、桌椅、海平线与光线方向；夜景的月相按同一晚对齐。初秋主要体现光线和路人薄外套，沿海常绿植物保留；深秋剧情若需要女主外套，另设计差分。

书名、诗、契约、日记、招牌和“验/存”刻字均保留后期文字层，用准确原文排版。通用 UI 图标继续使用现有代码/矢量实现；这轮视觉重制不需要把它们改成生图素材。

每项交付至少记录：清单编号、参考图、地点、时段、服装、饰物状态、实际尺寸、透明状态、原件路径与采用状态。使用清单编号协作即可，早期探索阶段不命名游戏发布版本。

这些选择不妨碍先整理其余场景。未定稿项在制作台账中保留状态，不把当前草稿默认当作最终设计。

## 13. 建议制作顺序与接入验收

第一步做 R01/R02 女主与道具板，同时固定 R04 海岸结构；随后用 B02、L01/L05、C01/C02 组成第一话的一组实际画面。检查脸型、人物与背景的上色是否相容、站位、尾巴和对白遮挡，通过这组样片后再扩展差分。

第二步补主海岸晨暮夜和礁石机位、营地内外结构，完成 L19/L20 与 C05/C06/C13 的正确身体结构。第三步统一 R06/R07 住宅和店铺，优先补 B19/B36/B40 三个真实背景，重制已撤下的手链、新家、早安、泳装、戒指、店内事件图。第四步按章节完成剩余 CG、情绪与服装差分、秋季变化和封面；再处理增强项。

每次验收同时看参考母图、当前图、前后剧情画面及带 UI 的实际舞台：脸与耳鳍、尾根和徽记、服装与饰物、时段/季节、空间位置、手部/接触动作、对话框/选项遮挡都应成立。图片能加载仅是最基础的检查。

接入尽量保留旧素材 ID 与剧情节点 ID；一对多的资产要按段落分配：深水区拆 B11/B12，夏/秋集市拆 B21/B22，潜水姿态拆 L19/L20。CG 内人物由画面显示，避免同时叠加重复立绘。保留原件、草稿和明确的替换台账；继续本地验证，不推送、不发行新版本。

运行副本根据实际显示尺寸导出，保留原始高清图；候选 PNG 约 1672×941，无需先扩成超大纹理。静态背景不用每句重复换源，避免每张图另附大动画图层。透明人物检查边缘白边及压缩后的细发丝，图片压缩与素材重制分开记录。
