# M3 共享游戏会话与表现

共享实现位于 `packages/player/src/`。这是新核心的消费者，不是另一套剧情解释器；游戏应用和后续编辑器预览都应从这里接入。当前仅表示代码已编写，未运行、未类型检查或验收。

## 会话的公开接口

`createGameSession` 接收已校验内容、只读玩家投影、宿主单调时钟、表现适配器、隔离的内存已读集合和结果回调，返回 `view / send / dispose`。

- `send` 是点击、选项、菜单/后台暂停、自动和快进的统一串行入口。
- 每个可推进操作携带 `{session, epoch, step}`，分别识别运行实例、当前呈现和核心步骤。应用用递增整数分配会话代次，不用墙钟。
- 表现只通知文字完成、语音结束或媒体问题，不持有核心的可写引用。
- 每次换节点或重建场面取消旧 `AbortSignal`、文字/选择/自动等待、播放句柄；无法取消的媒体加载仍须核对有效信号。
- 暂停原因分别记录，关闭菜单不会误解除后台或宿主暂停。有效时间不把后台时长补算进去。
- 媒体重试重建同一个已生效节点，不再次进入、加变量或发剧情事实；选择剩余时间沿用，不重置倒计时。

`ActiveTimer` 只依赖 `{now, schedule}`，用于可暂停的延迟和倒计时；剧情核心仍不读取时钟。文字首次点击只补全当前句，不顺带推进；自动不会代答，快进遇选择或未读停止。M3 的已读只在内存中，不写正式玩家记录。

## 本阶段边界

M3 不新增正式存档、读档、回退或玩家记录持久化。会话取消与有效计时是 M4 一致检查点的基础，不等于 M4 已实现。语音恢复、旧存档迁移及跨局记录规则仍按原待决策处理。
