## 3. 合并别人的单文件改动（如 Atri 的试玩版）
单文件版是“作品文件夹 + 内嵌素材”拼出来的，不能直接替换文件夹版：
1. 把对方的 HTML 和我们上一份构建都去掉 base64 素材（`data:...;base64,` 换成占位），按 `<script>\nconst __D=[` 切成 页头 / 数据 / 页尾 三段。
2. 逐段 diff。页头、页尾的差异就是播放器代码与样式的改动；数据段差异多半只是对方底稿旧，不要搬。
3. 只移植对方**新增/修改**的块，删除块逐个确认（常见是对方底稿比现行版旧，不是他删的）。
4. 跑全作回归，再在浏览器里点验新功能。记录写进 work-ledger（例：`atri-ui-sync-android-20261019.md`）。

## 5. 美术（Image2.5 修图）
- **图片改动先出候选给用户验收，确认后才推**；剧情 / 音频 / 界面可自行判断直接推。
- 模型：Rinko `gpt-image-2.5-sunburst`（不可用 gpt-image-2 代替），`stream=true`，并发 ≤2，脚本 `tools/hark/rinko_edit.py`。
- 只改局部：裁局部放大给模型 → 只把差异区合成回原图，其余逐像素不变（整图编辑会让人物漂移）。
- 尾巴基准：L01（斑驳蓝、浅色腹面、波浪分界、深蓝描边、一对尾鳍、一个白色新月旋纹），从后腰长出，有两条人腿，不是美人鱼下半身。改尾巴**不移植像素**（用户 10-19 纠正）：待改图局部裁切 + L01 尾巴参考图做 Image2.5 双图编辑，让模型照 L01 合理重画，再只把差异区合成回原图。
- 立绘透明底：发丝间真透明，清掉 alpha<16% 的薄雾；检查尾巴有没有跑到腿间、有没有切断身后头发。
- 用户/朋友的稿子不改，只放大到原尺寸或抠图。
