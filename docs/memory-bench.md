# 记忆系统实测：灵枢 vs 灵枢 + AGM（2026-10-10）

基准：[hive-memory-bench](https://github.com/FuRongJun-1999/hive-memory-bench)。只测机械层，没有生成器/判官（无 API key）。

## 口径
- 公开的"保地基 68.4%/65.0%"与"矛盾覆盖 2/9"所用题集未公开，无法复现；逐字率 100% 已复现。
- 代理口径：公开主轮 92 张题卡的逐字证据引文，只留切点内（切A 前 8 章 58 题 301 条；切B 前 16 章 84 题 467 条）。命中判据：只留汉字、≥20 字连续公共块。
- 另一侧覆盖：证据跨 ≥2 章的题，取与题面词面重叠最低、且在另一章的那条证据，看是否被召回。
- 段节点（每段 ≥300 汉字），k=10，灵枢取前 30 条作 AGM 种子。

## 结论
1. AGM 帮助小，所有差异都不显著；简单 BM25 不输。
2. 补位两切点都不劣于灵枢；纯重排在切B 下降，不采用。
3. 加 BM25 式关键词桥（IDF 加权、饱和、度数归一）只换序不增证据，写入成本约 6 倍；参数扫描最佳（λ_bridge=0.5 + 种子并集 + 补位）切A 38.5% p=0.007、切B 34.7% p=0.064，系事后挑选，仅作线索。
4. 瓶颈在边质量：哈希 n-gram 向量、只有章内相邻段的赫布边。游戏中边来自真实对话共现，更接近 AGM 的设计场景。

**决定**：灵枢底座 + AGM 补位，可开关；AGM 换句向量、接真实对话后复测。

## 偏离提案
- 向量用字符 1/2-gram 哈希（256 维）；共现以"同章前 2 段"近似；召回时关闭学习；静态语料下遗忘与固化不起作用；种子激活取灵枢 RRF 分数归一。
