# M3 共享游戏会话与表现

共享实现位于 `packages/player/src/`。这是新核心的消费者，不是另一套剧情解释器；游戏应用和后续编辑器预览都应从这里接入。当前仅表示代码已编写，未运行、未类型检查或验收。

## 统一测试时的可视入口

用户已安排在重构末尾统一测试；以下为保留的操作说明，不要求逐片试玩，本轮没有执行。

在仓库根，使用 Node `24.15.0` 环境：

```powershell
npm ci --ignore-scripts
npm run game:dev
```

浏览器打开 `http://127.0.0.1:5173`。这是用户选择执行的开发入口，本轮没有执行安装、启动或构建。端口占用会报错，不自动换到未知端口；默认只监听本机。

1. 选“从第一话开始”，点击画面补全文字，再点继续，听一下语音、环境声和换曲。
2. 返回试播标题，选“限时选择样例”。它从真实节点 `pm8x8v2h` 开始，但五个变量明确使用声明初值 0、周目 1、结局数 0；**不是第五话真实路线进度**，也不用于路线好感验收。
3. 选项出现后打开菜单或切到其他标签页，回来确认剩余倒计时没有偷跑。选“（沉默）”或等待到期，应只结算一次并进入目标；可展开状态查看当前变量。
4. 在文字/声音播放中“重新开始此入口”或返回标题，确认旧文字、延迟音效和计时没有继续污染新场面。

自动不会代选；快进只经过当前范围的已读节点，第一次游玩不能跳过未读。M4 已接上[存读档](saves.md#独立试播接入与手动试用)、[全局玩家记录与主页鉴赏](records.md)及[会话内回退](rollback.md)：第一话已读持久保留，限时样例只使用独立内存已读。聊天尚未接入；查看详情与实际读取进度仍是不同操作。

## 会话的公开接口

`createGameSession` 接收已校验内容、当前只读玩家投影、宿主单调时钟、表现适配器、按范围隔离的已读集合和结果回调，返回 `view / send / dialogueHistory / rollbackTargets / rollback / captureCheckpoint / dispose`。可选 `resume` 要求显式提供检查点与本次语音恢复方式，直接从已生效进度创建核心，不先进入开局节点。可选 `rollback: {capacity}` 显式开启当前会话的有界检查点历史。

- `send` 是点击、选项、菜单/后台暂停、自动和快进的统一串行入口。
- 每个可推进操作携带 `{session, epoch, step}`，分别识别运行实例、当前呈现和核心步骤。应用用递增整数分配会话代次，不用墙钟。
- 表现只通知场面就绪、文字完成、语音结束或媒体问题，不持有核心的可写引用。场面资源未就绪时单独暂停有效时间，不能让重试消耗选择时间。
- 每次换节点或重建场面取消旧 `AbortSignal`、文字/选择/自动等待、播放句柄；无法取消的媒体加载仍须核对有效信号。
- 暂停原因分别记录，关闭菜单不会误解除后台或宿主暂停。有效时间不把后台时长补算进去。
- 媒体重试重建同一个已生效节点，不再次进入、加变量或发剧情事实；选择剩余时间沿用，不重置倒计时。
- [对白回看](history.md)返回当前会话最近 300 条文字副本；独立 `history` 暂停不影响菜单、后台或宿主的暂停归属，打开与关闭只读对话框不推进剧情。
- `rollback(request)` 通过同一队列校验目标、本次跨选择策略、语音方式和当前全局投影；采用后更新核心步骤及呈现代次，截断未来路线历史，保留全局成果。当前只支持稳定非结局阶段，捕获失败通过 `SessionView.rollbackIssue` 显示，不补造数据。

`ActiveTimer` 只依赖 `{now, schedule}`，用于可暂停的延迟和倒计时；剧情核心仍不读取时钟。文字首次点击只补全当前句，不顺带推进；自动不会代答，快进遇选择或未读停止。已读由应用接到独立全局记录，正式发行记录范围仍未切换。

## 画面与声音的归属

| 实现 | 本阶段能力 |
|---|---|
| `web/presentation.ts` | 1280×720 作者坐标、自适应缩放、完整背景/立绘、逐字与停留、外观/光色、角色动作、镜头特效、软切姿态、背景变化转场及镜头提示 |
| `web/audio.ts` | 持续 BGM 与环境声按 ID 保持、换曲淡变、空曲停奏、对白语音、至多四路一次性音效及延迟；菜单/后台暂停，检查点声音捕获与显式方式恢复 |
| `web/saves.ts` | M4 起步的 IndexedDB 原子槽位替换；范围与实际接入见存储说明，尚未运行 |
| `apps/game/` | 独立 DOM 试播装配、按钮/键盘输入、菜单、标签页生命周期和状态显示；不是最终 UI 方案 |
| `tools/dev/vite.config.ts` | 通过同一 M1 转换器生成可信本地模块，Vite 仅开放应用/共享代码及作品 assets 的开发读取范围 |

只加载当前背景与当前立绘，不一次解码全部图片或声音。未支持的实际转场/外观/动作会给出阻断诊断，不静默跳过。必需图片失败暂停场面，可重试当前已生效节点；声音读取/解码/浏览器播放权限失败显示可见提示，主线可继续，“启用声音”可重试播放。没有合成提示音或替换素材。

持续轨道由混音实现拥有，不因每句呈现取消而重启；语音、一次性音效、延迟和动画属于当前呈现，离开时取消。重试不重播进入音效，当前对白语音可重新尝试播放。实际读档另走准备和新会话，语音按本次显式方式处理；媒体重试不能冒充读档。音乐继续、停奏和位置恢复代码已接入，但未执行听感验收。

开发入口使用 `/@fs/` 本地资源 URL，可能包含开发机路径；这些只存在于开发模块，不写入规范化内容，也不是可分发游戏清单。可视入口当前直接复用转换器的已校验结果，不用类型断言读取外部 `dist/story.json`，也没有加载旧 `game.js` 脚本、旧播放器或插件。内容和资源按每次服务启动固定一份修订，修改作者源或资源后需要重启服务。

试播页展示的是最小可操作切片，不是原作品全部 UI/动画的等价迁移。主页已增加基本 CG/结局鉴赏；手账、完整偏好界面及 `settings.uiSe` 的交互提示音尚未迁移，现有配置保留在内容来源中。M5 前仍需全量路线、完整声音/演出观感及平台接入；当前不会据此删除旧表现或宿主。

## M4 接续

会话现新增 `captureCheckpoint(token)`，通过同一串行队列捕获稳定检查点；`SessionView.canCheckpoint` 表示当前切片是否可捕获，`Playback.capture` 提供分离的声音数据。过时步骤、未就绪场面及结局明确拒绝。格式、覆盖范围和存储契约见[检查点与存储](saves.md)。

试播页增加手动保存、按入口查看与实际读档，数据只进入各自开发/预览槽位，第一话全局成果另外保存。读档与会话内回退采用当局变量与有效计时、刷新当前全局投影，不回滚已解锁结局、CG 和周目；只读查看、对白回看和鉴赏不产生新事实。回退不自动写手动槽位，也不跨新开、读档或页面离开保留历史。

## 本阶段边界

M3 本身不含正式存档、读档、回退或玩家记录持久化；后续 M4 切片以专门说明为准，不等于 M4 全部实现。语音恢复、旧存档迁移及跨局记录规则仍按原待决策处理。

没有游戏发行构建命令；Vite 配置中的内容模块是开发专用，不应直接打包当 Windows/Android 发行物。React/Vue、正式编辑器、宿主统一及资源安装方式仍未决定。旧入口、作品、素材、原生宿主和 CI 均未改变。
