### 接口与兼容变化

- `/api/status` 仅报告 `purpose: legacy-authoring-and-chat`、模型/记忆及独立聊天等辅助状态，不再返回旧章节、剧情模式、旧预留裁决能力。卡片校验与 AI 填卡不再隐式加载剧情，也不执行旧章节槽位适配；原卡字段和通用校验保留。
- 主辅助服务原有 Host/Origin、设置保存、插件启停、卡片保存、静态访问边界及独立聊天令牌规则不扩大。独立 `server.api.post_ending` 仍可使用，不代表新游戏已经完成联网聊天接入。
- `config.example.yaml` / Python 依赖说明已移除旧解释器安装与推进配置。没有读取、改写用户私人 `config.yaml`、记录目录或系统安装状态；旧配置中的剧情字段不会再次触发编译或旧核心。
- 分章作者源、素材、`haifeng.story/1`、新本体的存档/成果/偏好和两端协议均未修改。没有重新构建此前 Windows 产物，不把清理当作平台验收。
- 本机旧日志、导入缓存、记录、模型配置和忽略的 wheel/编译产物留在原位置，不自动迁移或删除。

### 为什么还保留一些旧文件

当前保留不是“以后也许用得到”，而是下面这些明确能力尚未被废弃或完整替代：

1. 原 HTML/JS/CSS、美术制作和导出：新对白编辑尚未覆盖完整美术/演出制作；仍由制作模板和导出工具实际消费。它们不进入正式本体包。
2. `web/vn*`、旧制作服务路由和 Python 只读作者投影：支撑上述旧制作、设置和外部独立项目，不再加载已删除的旧托管解释器。
3. `server/plugins`、卡片、模型/记忆、GalAgent/手账：仍是独立聊天的实现和消费者，正式新聊天尚未接替，不能整删。
4. 分章源、固定基线、素材库、母版、WAV、授权/生产资料和历史评测证据：属于内容或来源，不属于退役引擎。

至此，本轮明确无需保留的旧解释/回放/离线核心链及其入口已成组清退；上列真实消费者保留，不再把它们笼统列作“尚未删除的无用文件”。统一试用时确认新本体仍可开局，以及确需使用时旧制作/角色卡/独立聊天辅助入口可用即可；本轮未执行。
