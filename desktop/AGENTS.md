# 桌面宿主局部约束

- 先遵循根入口与 `docs/rebuild/windows.md`。2026-10-25 用户授权清理后，此目录只保留共享 TypeScript 本体宿主；旧启动器及配套打包已删除，范围见 `docs/rebuild/cleanup.md`，不恢复旧入口或存档兼容。
- 随后用户明确授权准备工具及产出 Windows 应用，现已完成 release 编译和本地 x64 EXE/ZIP；下文未编译描述记录各模块最初接线时状态，运行/试玩和功能验收仍未执行。打包路径须使用相对 `src-tauri` 的前端目录，不能让 Windows 盘符被当成 URL；修复生成入口后重新准备，不手改旧快照。具体来源及摘要见 Windows 文档。
- `src-tauri/src/main.rs` 唯一调用 `rebuild::run()`，不再有 `rebuild-host` 特性或 `legacy.rs`。不得接回 Python 探测、旧协议、旧文件/模型配置/工作区命令或失败回退；源码清理不等于编译/运行验收。
- `src-tauri/src/rebuild.rs` 只处理本地前端、窗口和生命周期；不启动 Python，不注册旧宿主工具/存档接口，不回落到另一解释器，不决定剧情分支。
- 唯一宿主仍须消费 `windows:prepare` 复制核对的游戏包及生成配置；根 `tauri.conf.json` 只是同身份/受限能力的基础配置，不带旧资源或可玩内容，也不默认生成安装器。生成路径、配置和玩家数据不得提交。
- 宿主状态经有格式和序号的桥进入应用，异常保留暂停；不得直接改核心变量或把失焦时间补入计时。原生窗口、标签页、菜单和准备操作的暂停原因分别管理。
- `rebuild_power.rs` 只登记固定系统休眠/唤醒回调并更新同步状态，不等页面、做 I/O、阻止休眠或自动保存。自动唤醒不冒充用户交互恢复；每次中断/恢复按原页面桥的暂停回执再释放综合条件，旧代次/旧页不得解暂停。状态采样及序号分配同锁，原 Windows 状态脚本另核对本地主文档的私有初始化身份，不依赖可选全屏能力；身份和电源状态不进入存储或新剧情协议。
- 电源接口动态探测失败时诊断拒绝重构宿主启动，不宣称旧系统适配或最低系统已决定；不因功能缺失切旧解释器。窗口销毁使监听/待投递状态失效，回调参数只用进程期静态空上下文；注销不确认时保留系统模块，不卸载仍可能被引用的代码，不把清理结果当退出写入许可。真实设备通知与脚本时序尚待统一验证。
- `rebuild_audio_devices.rs` 仅在同一专用 MTA 线程构造/查询/注销 MMDevice 监听。回调不等待、查询 COM、分配身份文字或释放最终引用，只以原子状态/不可变身份快照和事件通知工作线程；设备 ID 不解析、不输出/持久化。注销未确认保留登记相关对象，迟到通知失效；对外只有代次/可用/读取稳定性，不将它当播放许可或恢复回执，不新增设备选择、录音、存储或剧情命令。
- `rebuild_audio.rs` 将后端接入专用线程和原声音请求，队列有界、原页面/请求/输出代次匹配后才确认授权；中断不自动续播，换页撤销旧请求许可。独立 `haifeng.audio-output/1` 只传声音状态/请求及回执，配套客户端能力须随包登记，新宿主拒绝旧能力输入；不改基础桥或存储版本。监听不可用及请求未获准保留静音继续，已有中断未确认不冒充恢复；关闭清理与正常退出写入许可无关。当前仅已编写接线，未编译/运行。
- 当前唯一宿主默认在应用本地 `records/` 打开原生后端，只允许本作品 `game/main`，不需要运行参数；先核对 `purpose: game` 和客户端能力，失败不加载其他记录源。约束见 `docs/rebuild/run-profile.md`、`native-storage.md`，未编译运行或验收。`rebuild_storage.rs` 只处理登记地址、原样 JSON 和物理提交，不执行剧情/成果合并或向页面开放目录/通用命令；安装方式、备份和最低系统仍另行安排。
- `rebuild_storage_bridge.rs` 在独立工作线程执行四种受限操作，核对主页面来源、加载代次、作品、页面身份及单调请求 ID；重复原请求只重发缓存回执，页面换代不采用旧回执。文件已提交但确认丢失不能报肯定未写入；保留原回执与 `NATIVE_STORAGE_UNCONFIRMED`，不换存储源或绕过正常退出。已开始的文件操作不会因页面取消而撤销，界面线程不执行同步文件 I/O。
- 正常关闭通过桥 `/3` 的本次退出票据等待已有写入；无效、超时、页面换代或写入失败不能当作关闭许可。保留取消和错误定位，不擅自自动保存当前剧情或绕过协调强制关窗。
- 可选显示扩展仅接本页布尔全屏目标；主线程按页面代次及请求去重，实际窗口状态匹配才确认，失败原样可见。不开放通用原生命令，不把显示超时变成剧情错误或存储写入，见 `docs/rebuild/fullscreen.md`。
- 不自动执行 Cargo、Tauri、依赖安装、编译、安装器、试玩或额外审查。本文只约束实现，不授予构建、推送或发布权限。
