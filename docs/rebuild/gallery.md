# 主页鉴赏与本地图片

接续 M4 已确认的全局成果归属，在现有主页鉴赏补上本地图片失败、重试及关闭生命周期。只编写实现、接线和文档，未启动、类型检查、测试、构建、额外审查或使用子代理，尚未验收。没有改变 CG/结局目录、解锁条件、周目计次或存储格式，也不决定正式界面框架。

## 读取与权限

`apps/game/src/gallery.ts` 的 `GalleryPanel(root, content, resources)` 只接当前已校验内容、本地资源访问和应用传入的已提交 `PlayerRecords`。`open(records)` 核对作品身份后展示，`close()/dispose()` 释放当次内容；面板不接存储写入、剧情会话、进入动作或结局结算接口。

应用打开前仍先提交已有待写事实，再从同一 `development/normal-entry` 仓库重新读取记录。异步读取同时绑定应用入口请求及本次鉴赏请求；关闭、开始游玩、退出或页面离开后不能采用旧响应。每次重开重新读取当前记录，不用图片缓存或旧面板充当全局成果来源。

结局和 CG 均沿用共享 `galleryCatalog()` 的当前内容目录及原顺序；结局首次日期、周目和通关次数继续来自已提交记录。目录之外的历史成果由原仓库保留，不因当前面板没有条目而删除。

锁定 CG 只显示禁用占位：不创建图片、不读取资源位置，也不显示未解锁名称。已解锁条目可以在缩略图不可用时继续尝试大图，不以图片成功显示作为新的解锁条件。

## 图片的当次归属

| 对象 | 当前行为 |
|---|---|
| 缩略图 | 原生懒加载、异步解码，只在本地登记位置读取；说明分别显示待读取、名称或带资源 ID 的失败原因 |
| 本地大图 | 每次只拥有一张，显式点击后开始读取，解码完成才显示；状态包含本次名称/资源 ID，错误提供原资源重试 |
| 缩略图重试 | 取消原尝试，再读取同一条已解锁资源；不刷新成果、不换到其他图片或联网补图 |
| 收起大图 | 取消当次图片并清空来源，收起查看区；焦点回到原条目的实际按钮 |
| 返回主页、Esc、原生返回、开始游玩、正常退出或离开 | 同步关闭面板，注销当次按钮/媒体监听，移除全部当次图片来源及元素；重开建立新面板状态 |

文件内 `GalleryImage` 每次载入用独立对象识别图片、事件与解码。重试、换图和关闭先使旧对象失效；无法真正中止的解码完成或错误必须匹配原对象，不能更新新图、新面板或已关闭的状态。资源路径异常与图片读取/解码失败都留在鉴赏说明中，不把已提交成果改报为丢失，也不触发剧情重试或重新进入节点。

所有名称和诊断使用文字节点，不拼成 HTML。缩略图状态不逐条进行 live 播报；大图状态使用单独的状态区域，打开查看区可聚焦，关闭恢复原按钮。图片解码及可见性状态只在当前面板内存中，不进入进度、成果、偏好、预览或聊天。

本片没有提供新的解锁、解锁调试、导出、上传、资源替换或删除入口；没有接声音收藏、完整剧情结局树/路线图编辑或全部旧鉴赏视觉过渡。当前结局收藏仍是作品已有结局的只读列表。

## 留待统一测试

以下只是统一测试阶段的操作建议，本轮没有执行：

1. 从主页打开鉴赏，核对当前已提交的周目、通关次数、结局及 CG 数量。读旧进度后再返回主页，已经解锁的条目仍保留；打开、关闭与重试图片都不能增加次数。
2. 对锁定条目确认只有禁用占位，不显示未解锁图片或名字；在专用测试环境查看资源请求，锁定图片不应被读取。
3. 在专用测试副本中模拟某张已解锁图片缺失、损坏或读取失败，分别检查缩略图/大图的资源 ID、诊断和原资源重试。恢复本地资源后再次重试；不要删改权威素材来制造故障。
4. 快速切换不同大图、重复重试、收起再打开、Esc/原生返回关闭并立即重开，检查旧加载/解码结果不能改后来条目或重新打开面板；收起时焦点回到原按钮。
5. 读取全局记录期间开始游玩或正常退出，检查旧结果不能弹出鉴赏；关闭后原图片与监听被清理，重新打开使用重新读取的成果。图片故障不影响保存的解锁、当局进度或下一次正常开局。
