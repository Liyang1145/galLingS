# 美术素材开发页

双击仓库根目录 [引擎开发.html](../引擎开发.html) 即可编辑当前《海风与布丁》。这是现有 VN Studio 引擎的编辑入口，与 [游玩.html](../游玩.html) 读取同一个游戏；玩家入口不会加载编辑素材库。

## 素材与微调

- 顶部 **美术素材**：按名称、场景编号、素材 ID、文件名搜索；可筛选背景、人物 CG、立绘及采用状态。209 个生产图像文件按内容校验合并为176项，同内容副本仍列出原路径；审核截图、缩略图不冒充生产素材。
- **设为当前句 / 添加到当前句**：只改当前节点。**替换关联画面 / 添加到关联画面**遵循顶部“关联画面”开关。新草稿默认关闭关联，避免初次微调扩散到其他句。
- **画面微调**：选择当前角色，精确修改横向位置、纵向位置、人物高度和水平翻转。也可以舞台拖动、拖动缩放手柄或用方向键移动；画面修改支持撤销、重做。
- **编辑来源 / 微调备注**：登记制作方、工具、请求模型、后端模型、依据和备注，写入项目草稿的资产 `artNotes`。仓库已有自动登记见 [来源与路线 CSV](art-production/美术资产来源与路线登记.csv)。人工填写模型名不自动变成“路由已核实”。
- **退选留档 / 待重制**：保留以供比较、返工，调用仅改变编辑草稿。7张退出剧情的错误CG不会因建立素材库而自动恢复播放。

全部176项已注册到原生素材选择器与脚本接口；包含94个原有图像ID和84个新增图像ID，共178个图像ID。当前开发项目另保留103个音频ID，共281资产。分页每次显示36项，只按需加载大图，浏览素材不同时解码全部原图。

## 保存与交接

1. 修改自动保存在当前浏览器、当前入口的编辑草稿中。编辑草稿、玩家存档、普通空白编辑器使用不同存储键；离线页和本地服务页的草稿也分别保存。
2. 点 **保存项目** 下载 `project.vnproj.json`，将它交给拥有完整仓库的队友。已有原图保留可迁移的 `libraryPath`，新导入的临时图片内嵌到项目；JSON不是所有原件的独立拷贝。
3. 队友在开发页点 **打开项目** 导入。剧情ID、资产ID、位置/高度/翻转、来源备注均保留。保存草稿不会直接改写仓库的 `game.js` 或图片原件。
4. **载入仓库最新版**先询问并下载当前项目备份，再加载当前检出的 `game.js`。它不会联网拉取Git；要使用团队新提交，先更新本地仓库。旧基线草稿会提示另存并载入新版，避免静默覆盖新剧情。

## 导出游戏

需要单文件游戏时，运行 `start.bat`，打开 [本地服务的开发页](http://127.0.0.1:8765/vn/%E6%B5%B7%E9%A3%8E%E4%B8%8E%E5%B8%83%E4%B8%81/index.html?editor=1)，导入保存的项目，点顶部游戏导出按钮。它将微调后的剧情、实际采用的新增美术、原有画廊、音乐/音效及样式内嵌，离线打开即可玩；未采用的新增素材原件不塞进玩家包。文件夹导出使用同一项目筛选和内嵌样式。

双击离线开发页可编辑、保存；受浏览器本地文件读取限制，单文件及文件夹导出请从本地服务进行。离线页的游戏导出按钮会给出保存与转到服务页的步骤，不下载带失效链接的伪单文件。

也可由队友在仓库根目录打包已保存项目：

```powershell
python tools/build_single_file_game.py --project "project.vnproj.json" --output "海风与布丁_单文件游玩.html"
```

省略 `--project` 则打包当前仓库游戏。命令行打包同时输出素材校验清单，不重写原件；保存的人工微调项目才会改变该次导出的画面。在线聊天仍需模型和后端，不包含在离线剧情验收中。

## 重建索引与接续

新增或替换美术原件、改变剧情引用后，安装可选美术依赖并重建：

```powershell
python -m pip install ".[art]"
python tools/build_art_catalog.py
```

生成 `art-catalog.js`、轻量WebP缩略图和CSV。原件内容校验合并不等于删除原件；重建索引不修改游戏剧情。可用 `python tools/build_art_editor_preview.py` 生成缩小图片内嵌的单HTML演示，供浏览素材与试摆人物；演示不含音频、不开存储与导出，不代替正式开发页。

人物、CG及封面的画风统一仍待制作；现有背景请求Image2.5的记录与实际后端未回传模型要分开说明。下一轮提交人工微调时，逐节点核对台词ID和画面差分，保留Atri的音乐段落，不用旧整包覆盖团队新提交。
