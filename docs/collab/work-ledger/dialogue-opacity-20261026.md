# 对话框背景不透明度与调节修复（2026-10-26）

- 用户反馈：整合版背景过实、难看，要求处理并确保可调整性。
- 分支：`fix/character-performance`，基线 `694fd812611a499e097167d84d59309f6bc48db0`。本记录的 45% 和调节规则取代上一轮默认 55% 的说明。

## 改动

- 移除独立的近乎实色托底与皮肤至少 72% 的强制下限。鲸鱼皮肤和底色放进同一个背景层，用同一个值控制整体透明度。
- 设置 → 声音与阅读 → 对话框不透明度：可调 0%–100%，步进 1%，即时预览；0% 时背景完全消失，100% 时可实色遮挡，文字、名字牌和操作按钮不随背景淡化。
- 新默认值 45%，并提供“默认”按钮恢复 45%。已保存的玩家自定义值保留。
- 修复零值被兜底逻辑覆盖、读取玩家设置后 CSS 未同步的问题，调到 0% 后刷新或回标题仍有效。竖屏与无台词演出同步遵守背景层规则。
- 只改 `game.js` 的 `settings.ghost`（0.55 → 0.45）。3315 个节点和全部其他内容逐字段一致；不改素材、声音、剧情或已确认图片。
