# 共享播放器的局部约束

- `src/session.ts`、`src/clock.ts` 不依赖 DOM、网络、宿主或编辑器；浏览器实现只放 `src/web/`。Node 与 Web 类型检查范围保持分离，不为方便给纯模块开放 DOM。
- 剧情决策只通过 `story-runtime`。会话拥有串行输入、暂停原因、有效计时和取消；表现只能报告场面就绪、文字/语音完成和媒体问题。
- 应用分配递增会话代次；所有延迟回调核对呈现代次，推进操作再核对核心步骤。换节点、重试、离开及重开必须取消旧工作。
- 场面资源未就绪时暂停有效时间。菜单、后台、宿主、资源加载及错误是不同暂停原因，不能相互误解除。
- 原生/后台状态通过 `initialPauses` 在首次呈现前生效；读档及回退准备使用独立 `operation` 原因，完成准备不能解除真实宿主暂停。
- 媒体重试不重新进入剧情，不重播进入音效，不重置选择剩余时间。持续音轨保持同曲连续、换曲和停奏意图；一次性语音/音效属于当前呈现，不能遗留到下一节点。
- `web/presentation.ts` 的背景镜头沿用旧缩放/时长范围，`shot.focus` 只管缩放中心，不替代 `view.position`；恢复直接采用稳定场面，快进清除镜头。转场与瞬时特效分别使用遮罩，共用当前呈现的暂停/取消通道；无背景也是已有场面，不能用空背景 ID 判断首次。`web/scene-fade.ts` 只复制显式同舞台的直接子图层，去除 ID、自动焦点、监听与交互，静止并保留隐藏/滚动。主线快照只接场面/对白/选择，一次最多一个，失败/取消/快进清理，优先于背景转场；不延后核心或有效计时，范围见 `docs/rebuild/performance.md`。
- `web/stage-fade.ts` 只拥有界面副本及视觉帧/定时/动画，接显式图层和许可，不持有会话、存储或有效时钟。异步准备成功后、采用界面前才捕获；新事务使旧归属失效，旧解码/完成不能清理新副本。现有标题/暂停菜单/终态沿原 360ms 淡出，菜单自身暂停不能冻结旧菜单；后台/宿主/退出/快进/尺寸/全屏/离开取消，减少动态效果跳过或清理。终态保存状态刷新不反复采样，不复制外部弹层或编辑制作区；失败只能是视觉提示。
- `web/camera.ts` 的场面镜头由背景 ID 及已校验参数归属，同背景正常换句只暂停并接续，不因单句取消跳到终点或重播。它不持有旧呈现上下文/步骤，完成只核对原归属并释放自身句柄；换背景/快进/销毁先失效原归属，恢复/重试/终态采用稳定目标。旧 `Playback` 暂停/快进必须拒绝失效调用，镜头帧不进入存档或驱动有效计时。
- `web/motion.ts` 保留原角色动作/进退场的关键帧时刻、方向、时长及每段缓动，不把 CSS 分段缓动改成整个时间轴的缓动。角色移动/高度和滤镜由当前呈现动画拥有，不用恢复时会重新触发的 CSS 过渡；说话焦点用亮度/饱和度滤镜，目标顺序更新层级，软切副本保留旧位置并归原呈现清理。快进/恢复/重试/减少动态效果直接采用稳定目标，不写存储或改变有效计时。
- 瞬时镜头也按原分段帧执行，只移动背景/立绘的 `scene-layers`，氛围覆盖、闪光/转场遮罩和对白不跟着移动或被场面滤镜染色。持续氛围沿原 CSS，用真实细节子节点使暂停覆盖气泡/脉冲，同名节点不重建时间轴；恢复不重播瞬时效果，有限慢推近直接采用终点。减少动态效果保留静态场面，闪烁层不得留下不透明黑色；快照冻结气泡位置，不加入帧级存储。
- 检查点由会话在同一个串行操作中捕获核心状态、有效计时和表现数据；异步存储不得再拼接后续的实时状态。`checkpoint.ts`、`saves.ts` 保持无 DOM/宿主依赖，浏览器存储在 `src/web/`。
- 外部检查点先经唯一核心和封装校验，失败不改变当前会话或旧槽位。读档显式使用当前全局投影，不采用旧档投影覆盖成果；准备成功后换会话代次并取消旧工作，恢复不发进入或结局事实。正式语音默认体验和回退边界仍待决定，试播语音方式由本次调用者明确指定，见 `docs/rebuild/saves.md`。
- `SaveRepository.list()` 只在本作品/范围内按地址有界分页，完整检查后返回摘要，损坏地址或不兼容载荷返回诊断；不得静默省略、采用到会话或改写槽位。列表摘要不能替代读档时重新读取和校验；存储须区分不存在的键与已存在但值为 `undefined` 的损坏记录，后者不能按空记录初始化。
- `records.ts` 管全局成果，不接受进度槽位覆盖。事实重试保留交付 ID，结局解锁与通关计次原子合并；记录失败不冒充已保存。开发、预览与正式记录分别隔离。
- `recordWithReceipt()` 的首次结局列表须在同一全局事务内判定，提交后才返回，失败/重试已有批次不能冒充新解锁；回执是瞬时结果，不加持久字段。应用按原批次与当前会话/表现/终态匹配，`ending-unlocked` 只确认反馈，不写剧情或再计次。终态 `end/setPaused` 保留声音生命周期，返回标题和销毁仍取消全部轨道；静音或退出跳过的提示不补播。
- `web/ending.ts` 只显示 `SessionView` 终态及显式 `EndingRecordState`，不能调用剧情/存储或以节点流转重放结局；只有 `committed` 摘要可宣称已保存。预览、不含结局的脚本末尾与待确认分开，离开/重试只交原令牌意图给应用；重复状态更新保留按钮/滚动，不重复改写相同播报文本，清理取消旧监听。
- `preferences.ts` 保持无 DOM，只管理独立声音偏好及作者默认解析；稀疏通道修改在事务中合并，不进入检查点或全局成果，不覆盖损坏记录。保存重试使用原捕获修改，后来未保存的调整仍保留。混音器分离玩家音量与素材/场景/渐变增益，实时调音不重播或重置渐变；0 音量触发的一次性音效不积攒补播。
- `reading-preferences.ts` 是独立阅读协议，不复用声音、进度或全局记录键。`auto-wait` 意图只更新后续自动等待的倍率，不重置当前等待、限时选择或恢复剩余时间；表现捕获本次呈现的逐字间隔，字号/透明度可即时更新，不重建场面或文字。
- `appearance.ts` 严格读取作者主题/封面，保持无 DOM；`web/appearance.ts` 只向给定舞台写受限样式，现有鲸鱼皮肤覆盖通用主题的关系保留。应用/预览使用同一图形和作者坐标，不在预览另设字号/选择样式；字号基准取作者值再乘阅读倍率。收藏装饰类型与剧情资源身份分开，原图标形状/原图片由构建只读提取并登记来源，不能运行旧解释器或用另一张图片替代。封面加载独立取消，失败可重试且不推动剧情；对白图片未就绪归属当前场面错误，不重入。
- `web/choices.ts` 只显示会话已经给出的可见选项，点击原令牌和稳定选项 ID 仍交回共享会话；不自行求条件、排序或计时。时间/暂停更新保留按钮及滚动，换步骤/清空取消旧监听。`web/stage-layout.ts` 只管理同一舞台比例、小屏单位及横竖分区，游戏/预览共用；容器尺寸与内部布局单向更新，不以输出反改容器尺寸。缩放/旋转不能重建会话、文字、声音或剩余计时；竖屏的显示高度不改变 1280×720 作者场面和人物坐标，全部正式 UI 仍须单独迁移。
- 游戏壳可向 `connectStageLayout` 提供可选底部操作栏，仅测量真实占用以避开对白/选择；隐藏界面保留占用，观察不改会话或计时。不传操作栏的编辑预览保持原布局；游戏弹层的原会话暂停归属由应用持有，不加入共享核心或存储。
- `web/button-label.ts` 只向按钮可选的 `data-player-label` 直接子项写显示文字，保留图标、按钮身份与监听；无标签槽时沿用纯文本控件，不改变游戏/编辑预览动作、读屏名称或显示确认规则。
- `web/input.ts` 只向当前会话提交意图，菜单/回看由应用回调接续；自动/快进互斥仍由共享会话执行。隐藏不暂停，下一次继续只显示，保留可访问的显示按钮；临时 Ctrl 只解除自身发起的模式。手势及迟到触屏点击核对原会话/令牌，生命周期重置不得抹去待拒绝点击的身份；新物理按下不得被旧手势抑制。输入、焦点及隐藏不进入检查点/存储，销毁恢复 inert 并取消监听；回退策略不在键盘层猜定。
- `web/fullscreen.ts` 只管理受限显示驱动、控件、焦点与布局；浏览器进入须保留原用户激活，不以按钮点击冒充成功或退出其他区域。停止/销毁须处理迟到进入并取消监听，显示改变清理输入手势而不重建会话或有效时间。`host-bootstrap.js` 的可选 `haifeng.fullscreen/1` 扩展保持基础 `/3`，临时页面身份、递增请求和确认匹配；失败/超时不影响基础桥、剧情或存储，不接受通用原生动作。
- `button-preferences.ts` 管独立布尔开关及稀疏事务合并，不向既有严格音量/阅读格式加字段。`web/button-sounds.ts` 只绑定应用明确给出的操作按钮，鼠标悬停不受子元素重复进入影响；按消费者生命周期取消监听。应用核对当前会话、开关、暂停与快进，混音器继续执行许可/音量门控；选择和存档不能同时套一般按钮音。
- `readout.ts` 只从原话末存档点标记及核心已生效变量构造可选剧透正文；绑定按旧 uiSe/soul/名字优先序校验，soul 仅为显示字段来源，不启动联网或 Agent。`readout-preferences.ts` 使用独立布尔协议，缺省关闭、false 保留、null 跟随作者默认；损坏记录不能覆盖，不向现有严格偏好、进度或成果加字段。
- 会话每次呈现固定 `readout` 显示副本，普通自动等待用同一正文长度；`readout` 意图仅更新后续开关，不重打当前文字、重置当前/恢复剩余时间或执行动作。核心视图、回看及槽位摘要保持原文，检查点不加偏好字段；编辑预览只用作者默认。只读引用必须复用实际绑定来源，不能用声音变量引用替代数值显示引用。
- `readCompletions()` 只从重新读取的已提交全局记录提供作品、范围、解锁结局及逐次通关引用；不混入进度槽位、待写事实、路线变量或准确通关时间。通关后模块只接这个最小读取能力，不持有全局写入或剧情接口。
- 对白回看只持有当前会话的文字、语音资源 ID 及当次 `visitId` 副本，实际接受的选择归属原访问并在后续对白之前记录；媒体重试不重复追加。条目回退只按 `visitId` 匹配仍保留的目标，显式意图经应用刷新投影后交回原 `rollback()`，不按节点 ID、文字或列表位置猜检查点。`history` 暂停原因独立于菜单、后台与宿主，读取或关闭回看不采用进度或写全局事实；关闭取消尚未采用的条目回退准备，但不撤销已经完成的恢复。
- `AudioMixer.previewVoice()` 只由回看等只读消费者以独立混音实例使用，不在剧情表现的混音器上调用；只接受登记的 `vo`，最多保留本次试听，错误/结束不发主线 `voiceEnded`。消费者在关闭、换句、前后台/许可失效时取消原试听；迟到播放/错误不能污染后来试听或自动补播。实时语音音量沿用当前独立偏好，不捕获试听位置到检查点。
- `audio-library.ts` 只读已校验资源的显式 `audioCategory/auditionOnly` 及显示/试听元数据，保留原顺序；不猜分类、读取存储或预加载。`AudioMixer.previewLibrary()` 在独立已清空实例重新用同一读取器确定分类、通道和增益，配乐/环境循环、音效单次，不接剧情或检查点；开始时无许可/暂停/零音量拒绝，旧回调归原试听，不能给主线实例套试听报告。
- `chapters.ts` 只读原非空章节标记和节点顺序，不合并同名标题或推断路线/解锁。准备只接受真实章节起点，临时入口修订与声明初值、周目 1/结局数 0 必须明确，不读取玩家记录/存档或执行进入动作；实际试阅仍用同一共享会话及唯一核心，不新增解释器或存档迁移。
- `rollback.ts` 只管理有界的会话内检查点；容量由调用者显式提供，跨选择与语音方式由本次操作显式给出，不内置正式默认。首次稳定及离开前在会话队列中捕获，准备成功才由唯一核心恢复并截断未来历史；核心步骤与呈现代次更新使旧回调失效。恢复不重入，已解锁成果不回滚；媒体错误在已恢复位置重试。
- `src/web/package.ts` 只消费严格校验的随包清单与规范化内容；基址由宿主页面显式给出，资源映射保持包内相对位置。启动先校验剧情字节及修订，失败不开始会话或回落旧实现；不预加载全部媒体，不把启动校验写成安装或媒体验收。
- `src/web/host-bootstrap.js` 是两端原生在页面脚本前注入的最小桥；当前 ABI 为 `haifeng.host-bridge/3`，平台标记由明确宿主装配替换，保持来源约束、初始暂停、递增序号及失效保护。桥不含剧情逻辑，返回键只能交给应用处理菜单或弹层；音频通道仅允许请求/释放焦点。
- `writes.ts` 只跟踪显式写入，失败重试复用原捕获载荷，不重新读取当前进度。正常退出使用独立 `exit` 暂停，等待写入和全局事实完成；票据取消不能撤销存储事务或解除其他暂停，不等于自动存档或强杀恢复。
- 宿主声音许可与会话暂停分别管理；未获准不播放，语音不可用不得卡住自动阅读，一次性音效不得积攒到稍后补播。焦点中断后恢复当前声音，不重入剧情或重发进入事实。
- `ui-sounds.ts` 校验作者提示音映射，并把核心已提交的分组变量变化及目标背景/话末转换为纯声音计划，不计算剧情或执行表达式。选择反馈来自被接受的核心事实及每次访问首次就绪，恢复/重试/重绘不重复发一次性提示；循环声只跟随当前选择与暂停，不驱动结算或进入检查点。变量提示延迟使用有效计时并归属本次呈现，换节点/恢复/错误/快进/离开取消。交互播放失败不阻断主线，不把已提交保存改报失败；未播一次性提示不积攒到启用声音时补放。
- `references.ts` 保持无 DOM，只用既有外观/提示音/反馈变量读取器提供实际消费设置的结构引用，默认封面及反馈变量明确标记派生；不猜任意元数据中的资源 ID，不改变播放器状态或加入作者写入接口。
- 根规则仍适用：不自动测试、构建、审查或启动子代理；本目录规则不额外授予验证、推送或发布权限。
