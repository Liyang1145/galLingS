## 弹层与会话归属

`apps/game/src/panels.ts` 的 `GamePanels` 只持有当前壳弹层、关闭监听及应用提供的暂停释放函数，不持有剧情核心、进度或存储。打开设置/存档/回退/开发工具时，应用捕获当前会话；只有原来没有 `menu` 暂停才添加，并只在关闭时向同一仍活动会话释放。

从 `2ec7d83` 接入[游戏弹层视觉过渡](performance.md#游戏弹层视觉过渡)：`GamePanels` 使用应用传入的显示委托，其他现有弹层复用同一 `DialogFade`。登记的游戏画面/弹层在封闭影子树中静态淡出，不扩大共享舞台快照或采样编辑器。开关、取消准备、试听停止和暂停释放仍同步执行，不等待视觉帧；换会话/退出直接取消旧视觉事务。现有原生 dialog、焦点与迟到 close 防护不变。

因此从正在游玩的画面打开再关闭可继续原位置；从暂停菜单进入弹层再返回仍停在菜单。后台、宿主、加载、回看和退出暂停均不被弹层关闭解除。没有新增暂停原因、检查点字段或恢复默认。

Esc、弹层返回按钮和 Android 返回键沿同一关闭路径处理。关闭时使尚未采用的开局/读档请求失效并释放该次操作准备；已经发起的存档或偏好事务仍可完成。回退单独持有取消信号：关闭前未采用则拒绝迟到结果，已经采用则不能因关闭撤销它。

正常开局、读档、返回标题、退出及销毁清理所属弹层；成功换会话时先取消旧会话，再关闭壳弹层，旧暂停释放函数不能操作新会话。重复及迟到的原生 dialog close 事件不能关闭重开的同一面板。弹层期间游玩快捷键不向主线发意图，原浏览器全屏 Esc 优先规则保留。
