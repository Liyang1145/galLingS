## 命令与环境

所有命令在仓库根执行。Node 要求 `>=24.15.0 <25`，TypeScript、Vite 及其他锁定版本以 package.json/package-lock.json 为准。Python 辅助制作与聊天使用现有 Python 3.11+ 环境；Windows 原生构建另需 Rust/Cargo、Tauri、MSVC 与 WebView2 配套，Android 另需 Java/SDK/Gradle。已有开发依赖不等于本机具备原生构建环境。

| 用途 | 显式命令 | 说明 |
|---|---|---|
| 安装锁定前端依赖 | `npm ci --ignore-scripts` | 不自动安装原生工具链 |
| Windows 双击游玩 | 根目录 `start.bat` | 检查已有 Node/npm 与依赖，启动新版开发服务并自动打开浏览器，无需先出包 |
| 浏览器游戏开发 | `npm run game:dev` | 开发记录范围，不是离线发行包 |
| 终端逻辑试播 | `npm run story:dev` | 内存逻辑快照，不播放媒体或写玩家记录 |
| 内容阶段输出 | `npm run content:build` | 不复制完整游戏媒体，不能单独充当发行包 |
| 正式共享游戏包 | `npm run game:build` | 装配同一核心、前端、内容和随包资源 |
| 完整包核验 | `npm run game:verify -- <完整产物摘要>` | 逐文件读取，不启动游戏 |
| Windows 准备 | `npm run windows:prepare -- <完整产物摘要>` | 生成隔离输入；原生编译另行显式执行 |
| Android 准备 | `npm run android:prepare -- <完整产物摘要>` | 生成隔离输入；Gradle 另行显式执行 |
| Windows 双击编辑 | 根目录 `start-editor.bat` | 检查已有 Node/npm 与依赖，启动新版编辑器并自动打开浏览器；关闭前保存或导出草稿 |
| 编辑开发 | `npm run editor:dev` | 独立于正式游戏 |
| 编辑构建/服务 | `npm run editor:build`；`npm run editor:serve -- <完整产物摘要>` | 只服务本机对白编辑，不是正式编辑器发行 |
| 编辑器专项检查 | `npm run editor:test`；`npm run editor:test:browser` | 后者需已有 Playwright/浏览器，可通过 `HAIFENG_PLAYWRIGHT_PACKAGE`、`HAIFENG_BROWSER_EXECUTABLE` 指定；使用隔离作品 |
| 类型检查 | `npm run typecheck` | 两份 TS 工程；运行由用户安排 |
| 聊天离线用例 | `npm run chat:test` | 脚本模型，不用真实服务费用 |
| 聊天浏览器验证 | `npm run chat:test:browser` | 隔离浏览器，详情见聊天文档 |

`start.bat` 现在执行 `npm run game:dev -- --open`，服务就绪后自动打开浏览器，地址为 `http://127.0.0.1:5173`。游玩时保持启动窗口开启，结束后按 Ctrl+C 或关闭窗口。它使用当前源码与分章作者源及开发记录范围，不是原生 EXE 或正式发行包；缺少环境/依赖或端口冲突时保留错误窗口，不自动安装、构建或切换旧服务。本次只完成脚本接线，未实际启动或试玩。

Python 服务继续保留制作、卡片和独立聊天辅助，可在已有 Python 环境显式执行 `python -m server`，不再由 `start.bat` 启动。它不安装或启动旧 galcore，也不是新本体入口。没有启用替代 CI、签名、安装器或自动发布。

## 领域术语

本词汇表统一剧情制作、游戏游玩和通关后角色聊天中的用语。它不规定技术实现或尚未确定的产品规则。

## 游戏与内容

**游戏本体**：
玩家安装和游玩的作品，包括主线剧情及其画面、声音和交互。它不是面向任意项目的通用游戏引擎或通用 Agent 平台。

**主线游戏**：
由作者预先制作的剧情、选择、分支和结局构成的游玩内容。必要资源安装完成后，主线游戏可以完全断网游玩。

**作品内容**：
描述剧情、角色、变量、分支、画面和声音的作者创作成果。
_避免混称_：播放器、运行引擎。

**剧情节点**：
剧情流转中的一个可定位内容单元，可以包含对白、场景、变量变化、选择或结局。节点不一定等同于一句台词。

**场景描述**：
一个剧情位置应当呈现的完整场面，包括背景、角色状态以及应持续存在的音乐或环境声。
_避免混称_：转场动画、演出指令。

**演出指令**：
使场面发生变化或产生一次性表现的要求，例如淡入、角色动作和一次性音效。它描述过程，不等同于场景的最终状态。

**流转规则**：
决定剧情从当前位置如何继续的规则，包括顺序推进、选项、条件跳转和结束。

**剧情变量**：
参与当前剧情计算的数值或状态，例如好感及分支标记。它与跨越多次游玩的玩家记录不是同一个概念。

**选项**：
在特定剧情位置允许玩家作出的一项选择，可能附带显示条件、变量变化和后续去向。

**限时选择**：
在有效选择时间内等待玩家选择，并在到期后按作者指定规则继续的剧情交互。

**结局**：
作者定义的一条剧情路线的结束结果。到达结局与关闭游戏不是同一件事。

## 游玩与记录

**游戏会话**：
从开始或恢复游玩到离开游玩的这一段交互过程。它包含当前剧情推进以及与之相配套的展示和操作。

**进度快照**：
用于恢复某个剧情位置的一致记录，包括已生效的剧情状态及恢复该位置所需的信息。
_避免混称_：截图、玩家记录、对白回看。

**存档**：
被持久保存、以后可以读取的游玩进度。存档可以包含用于识别和展示该进度的信息。

**玩家记录**：
跨越单次游戏会话保留的游玩成果，例如已读内容和已解锁结局。它不等同于当前剧情进度。

**对白回看**：
查看已经出现过的对白。仅仅查看不会改变当前剧情位置和剧情变量。
_避免混称_：进度回退。

**进度回退**：
把游玩进度恢复到之前的剧情位置。它不仅改变显示的文字，也改变与该位置对应的剧情状态。

**自动播放**：
满足当前对白的展示等待条件后，自动请求继续剧情的游玩方式。它不等同于跳过未读内容。

**快进**：
以较快速度经过允许跳过的剧情表现的游玩方式。它不会取消剧情变量和分支规则。

## 制作与角色聊天

**编辑器**：
供制作人员编辑和预览作品内容的工具。它不是玩家游玩游戏本体的必要组成部分。

**预览**：
制作人员针对草稿或选定剧情位置进行的试播。它与玩家正式游玩不是同一份游玩记录。

**通关后角色聊天**：
玩家到达满足解锁条件的结局后，通过联网生成内容继续与角色交谈的玩法。它不是主线剧情的运行前提。

**通关上下文**：
提供给角色聊天的、与某次通关有关的事实，例如到达的结局和必要的关系状态。它不等同于整份主线存档。

**角色聊天会话**：
一次可以继续的角色对话及其聊天记录。它与游戏会话和主线存档相互区别。
