# 作者源读写边界

- 这里只服务独立本机编辑入口，不挂入游戏开发入口、游戏包或原生宿主。
- 读取纯 JSON 导出，不执行 `game.js`。预览和保存共用 `compileSourceContent`，不维护宽松的第二套转换器。
- 预览外观通过共享 `whaleAppearance()` 只读装配现有鲸鱼图形；提取器只读固定标记区，不执行旧 HTML，也不新增作者源/图片写入 API。
- 写入路径固定为当前仓库的 `海风与布丁/game.js`。请求不得指定文件路径、命令或任意字段；原摘要、节点 ID、原值与可写字符串范围逐项核对。
- 字符串 token 定位只用于保留其余原字节/格式，不承担剧情解释职责。禁止整包重排、扩展映射或顺手修改素材。
- 保存先取得合作锁、完成转换和备份，再用候选替换；最终替换前重查摘要和路径。合作锁不能保证拦住不遵守锁的外部编辑器，不能宣称无竞态。
- 备份、失败候选和异常锁保留为本机恢复证据，不自动递归清理，也不提交。不要在响应中暴露完整作者文件、Node 对象、绝对错误路径或本机会话令牌。
- API 限本机固定端口，检查 Host、Origin、本次服务令牌、方法及载荷上限；新增写入能力须同步协议与说明。
