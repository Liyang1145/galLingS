# 通关后玩法边界

- 本模块独立于剧情核心和主线会话；包含只读通关上下文、独立聊天会话及显式 HTTP 接入，事实和缺口见 `docs/rebuild/chat.md`、`docs/rebuild/agent.md`。
- 上游仅提供已提交的全局通关事实读取接口，不传核心、存档仓库、记录写入接口或宿主命令。
- 上下文逐条绑定某次通关事实，不自动选择最新结局或合并多条路线。当前记录只有结局事实，不能从存档、已读集合或变量初值补造历史路线。
- 当前内容修订只作引用定位，不能写成达成结局时的历史修订。预览范围不能作为聊天准备依据；开发记录不得冒充正式游玩成果。
- 结构校验不证明玩家已解锁；按原作品和范围重新读取已提交事实后才能准备上下文。客户端本地记录也不是未来服务端鉴权或付费凭据。
- 上下文只读并复制隔离；不因查看、切换或失败改写主线或增加周目。不接收模型输出为剧情命令。
- 结局与角色的正式解锁规则、模型供应和费用尚未决定，不默认“任意结局可聊天”，不自动接入旧联网服务。当前只在开发工具显式接无工具的独立开发服务，角色/结局允许列表由服务明确配置，不授予正式身份或付费权限。
- 每次发送先重新读取通关事实，展示原目标与完整上传载荷，采用单次确认后再读事实；改目标须销毁旧会话。模型或服务凭据不得进入载荷、展示历史、持久记录或日志。
- 流式事件只接收有序、匹配原请求的文本与终态；模型输出永远不是工具或主线命令。取消、关闭、换上下文及超时立即拒绝旧回调，不等待服务端合作才恢复本地操作。
- 不自动重试、重连、续流、降级供应商或重复计费。失败片段保留为本页可见诊断，不当作完整历史上传；显式重试须新请求和新确认。停止不保证服务端停止生成/计费。
- 聊天只保存在本页独立内存，离开清空；这不是持久聊天记录、长期记忆或远程删除功能。增加持久化或正式入口需另外接线并维护隐私和身份边界。
