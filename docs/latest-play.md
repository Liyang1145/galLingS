# 最新游玩与模块状态

## 统一入口

下载完整仓库后，双击根目录 [游玩.html](../游玩.html) 进入离线剧情，含现有场景、音乐音效、章节试阅和试听。HTML使用同仓库的game.js与assets，不能单独拿走一个HTML后期待素材仍能播放。

要使用托管作品页、手账后端和GalAgent，运行 `start.bat`，打开 `http://127.0.0.1:8765/vn.html`。第一次启动需要Python依赖及galcore轮子/编译环境，见根目录运行说明；在线聊天还需在作品页设置填写模型地址、名称和密钥。已有个人config.yaml保持个人设置：如要启用新插件，按 [GalAgent配置](galagent.md) 添加提供者与工具配置。密钥与存档不进仓库。

这两条入口都读取 `content/vn/海风与布丁/`，不另维护旧previews游戏副本，也不生成新发行版本。
