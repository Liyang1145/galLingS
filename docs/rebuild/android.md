# M5 Android 宿主接入切片

从 `77a18a3` 接续原方案步骤 19，先独立提交平台共享准备逻辑，再接入 Android。当前仅编写代码与文档，未安装依赖、运行准备命令、执行 Gradle、生成 APK、启动模拟器或连接设备；未类型检查、测试、额外审查或验收。

## 入口与产物

保留 `mobile/android/app` 及其默认入口、资源、旧桥和构建配置。新增同一 Gradle 工程下的 `:rebuild` 模块，使用独立应用 ID `net.gallings.haifeng.rebuild`，从已准备的共享前端启动，不加载旧作者脚本、播放器、WASM 或插件。Android 与 Windows 仍复用唯一 TypeScript 核心，不决定两端以后是否统一宿主。

`npm run android:prepare -- <产物摘要>` 调用 `tools/game/prepare.ts`，复用 Windows 的清单摘要、剧情修订、文件边界及逐文件大小/SHA-256 核对。只复制已登记文件，写入：

```text
dist/android/<产物摘要>/
  assets/game/             完整共享游戏包
  assets/host-bootstrap.js 原生文档启动时注入的宿主桥
  preparation.json         游戏清单与桥摘要、用途和存储范围
```

目录独占创建，不覆盖已有产物；失败保留不完整目录供定位，不自动删除。桥来自当前共享实现，只替换平台标记。准备命令不执行 Gradle、安装 SDK、编译或连接设备。

Gradle 参数 `-PrebuildPackage=<产物摘要>` 指定这份输入；`:rebuild` 的 `preBuild` 拒绝没有完成记录的目录，并核对记录身份、游戏清单和桥摘要。它不重新核对每个素材字节，准备后须保持目录原样，不能据此宣称具备已验证的安装校验。未指定参数时只在执行新模块构建任务时报告，不将准备要求加到旧 `:app` 的任务上。

新模块沿用现有 Android 工程的编译配置及版本环境输入，没有编新的作品发行版本。新模块只提供明确的调试构建入口，没有为其启用旧模块的 release 调试签名安排，没有改 CI 或发布工作流。

## 本地读取与启动

原生 `RebuildActivity` 使用已有 AndroidX WebKit 依赖和 `WebViewAssetLoader`，只提供 `https://appassets.androidplatform.net/assets/game/`。关闭文件/内容访问及真实网络加载，未声明互联网权限；缺失包内文件返回本地错误，不联网补齐或切换旧解释器。

宿主桥必须在页面脚本前注入。通过 `WebViewFeature.DOCUMENT_START_SCRIPT` 和 `WEB_MESSAGE_LISTENER` 检查实际 WebView 能力；不支持时显示原生诊断并停止开局。没有虚构最低 WebView 版本号或把 Android API 级别当成完整浏览器能力保证；前端仍独立检查 Web Crypto 和内容格式。

导航仅允许本地入口，关闭远程导航、弹窗及页面内框架。媒体由共享播放器按需读取，没有一次解码全部素材。用户手势要求继续保留，系统播放限制和媒体解码仍需真机确认。

## 生命周期和返回键

两端共用 `packages/player/src/web/host-bootstrap.js`，当前接口是 `haifeng.host-bridge/3`；状态消息仍使用 `haifeng.host-state/1`。桥缓存单调序号的窗口状态，提供本页返回键、受限音频焦点请求及正常退出协调，不暴露文件、网络或剧情指令。游戏清单使用 `haifeng.game-package/2`，原生、页面和 Gradle 准备记录均拒绝旧协议，旧准备目录需要重新生成。

Android 在 `onPause/onResume`、窗口焦点和页面完成时发送当前综合暂停状态。页面启动先暂停；会话通过既有 `initialPauses` 采用当前状态，窗口恢复只解除 `host`，不解除菜单、后台、回看、加载或操作准备的暂停。没有墙钟补算，不重入节点或重放进入动作。

应用返回键处理顺序：

1. 已有退出请求时取消本次票据。
2. 关闭当前对白回看、主页鉴赏或通关后面板；回看只解除自身暂停。
3. 界面隐藏时只恢复显示。
4. 游玩中打开或关闭菜单；原生全屏模式不改变此顺序。
5. 标题页交回原生，沿用旧宿主连按两次退出的试用方式；提示进度须先手动保存。第二次返回先走本次退出票据，已有手动写入及全局事实提交完成才结束 Activity，失败可重试或取消，超时保留应用，见[退出协调](exits.md)。

返回键不模拟点击、下一句或选择；原生等待本页处理结果时防止重复请求，回调核对页面代次，旧页面结果不能关闭新页面。缺失或无效处理结果给出提示，不据此退出。当前显式关闭预测返回回调，使用既有 Activity 返回入口；正式手势体验尚未验收。

原生投递现在要求页面返回当前序号，单次最多尝试三次，每次等待 250 毫秒；页面、WebView 实例或当前序号变化时丢弃旧任务。前台每秒发送新快照，暂停时停止周期任务但仍投递暂停消息。连续失败显示原生提示，页面侧每秒检查宿主状态是否超过 3500 毫秒未刷新，超时则暂停并关闭声音；只有新的有效序号才能刷新时效。恢复有效状态只解除宿主自己的暂停，不补算错过的剧情时间。这是内部试用参数，未做后台节流、丢包或系统挂起验证。

## 音频焦点

应用沿用已有播放/启用声音操作，通过只允许本地主框架的消息通道请求焦点；通道只识别请求与释放两个常量，不接受可执行脚本、变量或文件路径。Android 原生使用系统焦点接口，API 26 起采用 `AudioFocusRequest`，较低系统采用既有接口；没有新增依赖。

未请求或未获准时，共享混音器保持声音关闭；请求被拒给出可重试提示，主线仍可静音继续。不可播放的当前语音不会使自动阅读永远等待；当时不能播放的一次性音效会丢弃，不在稍后获准时补播。持续音轨和当前句重试仍由原混音实现拥有，不重新进入剧情。

已获准播放后失去焦点（包括临时打断和要求压低声音）时，本切片统一暂停当前游玩及声音，不擅自改变各轨音量比例。系统重新给回焦点后，按当前窗口和菜单等状态继续原位置；永久丢失可由玩家点击“启用声音”重新申请。后台、回标题、页面重载或销毁释放焦点；返回前台只在本次此前请求过声音时重新申请，旧申请的回调由代次拒绝。

焦点状态使用独立的 `haifeng.audio-focus/1`，明确区分未请求、已获准、被打断及被拒。声音许可与剧情暂停分别管理；焦点拒绝不是重算剧情或媒体重试的理由。本片只是试用接线，不定义正式读档语音默认方式。

耳机拔出等设备事件、各系统 WebView 自身焦点处理与原生焦点之间的交互、电话/锁屏和真实播放限制仍需后续处理或真机确认，不能据此宣称音频与后台验收完成。

## 可选全屏与系统栏

从 `b64340e` 接续的[显示切片](fullscreen.md)使用基础桥 `/3` 上的可选 `haifeng.fullscreen/1`；共享游戏页面有显式按钮/F11/Alt+Enter，原生不改走 DOM 全屏。旧宿主没有显示扩展时仅禁用该操作，已有主线、声音及返回键保持原接口。

专用 `__HAIFENG_NATIVE_DISPLAY__` 只接受本地主框架的固定格式、布尔目标、临时页面身份及递增请求 ID。先在已完成加载的当前页确认身份，页面/WebView 换代、旧消息、重复请求或不在前台时不执行；显示状态独立返回，不把失败变成剧情错误。

API 30 起请求系统栏隐藏并允许边缘滑动暂显，较低系统使用沉浸标志；进入前保留原相关设置，退出恢复所管理的位。确认表示原生已接受此沉浸模式，临时出现系统栏不算离开模式，不等于设备视觉已验收。重载或错误页尝试恢复原系统栏；没有新增方向锁定、自动首次触摸全屏、依赖或持久字段。

本片未构建或真机运行，须重建游戏包、准备和 APK；基本桥、随包清单与 Gradle 准备格式未改。刘海/手势区、系统栏实际布局、后台往返和各 WebView 的显示行为留到统一测试。

## 存储和进程重建

独立应用 ID 使新模块拥有独立应用数据目录。游戏内仍通过相同的 IndexedDB 原子适配器保存进度和全局成果；第一话是 `development/normal-entry`，限时样例保持独立预览。没有迁移旧 APK 数据，没有切正式记录范围，没有接原生文件存档或云同步。

Activity 或渲染进程重建后重新开标题，由玩家显式读手动档；不会使用 `WebView.restoreState` 猜剧情位置。渲染进程退出显示可见诊断，当前未保存位置不承诺恢复。正常标题页退出已接等待写入及全局事实排空，但没有自动保存或自动恢复点；系统回收/强杀不走这一流程，可靠恢复仍需后续落实。

本片关闭系统备份，不将试播记录默认交给系统云备份；正式备份、卸载保留和导出策略尚未决定。

## 统一测试阶段入口

以下命令本轮均未执行。在仓库根满足 Node 环境后：

```powershell
npm ci --ignore-scripts
npm run game:build
npm run android:prepare -- <game:build输出的产物摘要>
```

随后使用已配置的 JDK 17、与现有 Android Gradle Plugin 8.5.2 兼容的 Gradle 及 Android SDK 34，在 `mobile/android` 按准备命令打印的摘要执行：

```powershell
gradle :rebuild:assembleDebug -PrebuildPackage=<产物摘要>
```

仓库当前没有 Gradle wrapper；本轮没有安装工具或生成 wrapper，不能把命令存在当作环境已就绪。APK 的预期位置是 `mobile/android/rebuild/build/outputs/apk/debug/`；须以未来实际 Gradle 输出为准。

人工试用重点是安装完整后断网启动、声音和选择、切后台/锁屏/失焦后时间保持、焦点打断与拒绝后重试、返回键弹层顺序、手动保存后重开读取，以及旧进度不回滚全局解锁。另核对显式全屏的系统栏隐藏/恢复、暂时唤出、旋转及页面重载，旧显示请求不得作用于新页，模式确认与实际设备画面分别观察。宿主消息中断后应暂停，新快照恢复不能解除菜单；不可用声音不能卡住自动阅读或补播过期音效。缺少桥能力、旧协议、缺损准备记录或本地资源时应给出诊断。所有情景均未执行；M5 全量主线、平台存储与设备兼容验收仍未完成。
