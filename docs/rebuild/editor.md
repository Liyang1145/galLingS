## 入口与范围

仓库根、Node `>=24.15.0 <25` 环境，统一测试阶段由用户选择执行：

```powershell
npm ci --ignore-scripts
npm run editor:dev
```

浏览器访问 `http://127.0.0.1:5174`。只监听本机，端口占用则失败；与游戏试播 `5173` 分开。此服务具有修改当前作者源的显式能力，应仅由本机制作人员使用；不进入游戏包或原生宿主。

- 唯一作者源仍是 `海风与布丁/game.js`。打开只读取，不自动保存，也不生成另一份可编辑剧情工程。

## 草稿撤销与重做

`packages/story-model/src/author-history.ts` 的 `AuthorDraftHistory` 统一持有当前字段修改及操作差量。基线来自已读取作者源摘要、稳定节点 ID 和已有可编辑字符串；`update/removeNode/replace` 分别处理单字段、整节点还原及完整导入采用。单字段和导入继续通过 `readAuthorTextPatch` 校验，最多 1000 个字段、每值 100000 个 UTF-16 字符；原值必须匹配该基线，不接受缺失字段或其他源摘要。

- 在同一次焦点停留中连续编辑同一字段合为一步，输入法产生的文字仍由输入事件同步。切换字段/节点、失焦、预览准备、导出或导入比较会结束合并；粘贴、拖放、剪切和浏览器原生撤销/重做产生的输入各自分开。
- “还原本节点草稿”将已有说话人/对白草稿一起还原，作为一个可撤销操作；没有实际修改时不制造历史项。
- 点击采用导入结果时，将本次实际改变的全部字段作为一步；冲突选择、只读文件、取消比较和未采用项导出不进入内容操作历史。撤销一次导入会一起找回导入前的本页修改。
- 撤销后作出新的实际修改会丢弃旧重做分支；查询、翻页和节点选择不制造内容修改或丢弃重做。全部改变字段属于同一节点时，撤销/重做自动定位该节点；多节点导入保留当前选中项。搜索条件、其他草稿和筛选外当前项继续保留。
- 每次实际撤销/重做递增草稿代次，取消旧导入比较，使旧引用结果失效，并拒绝请求期间尚未采用的旧预览结果。已运行预览保持原修订，页面提示重新预览，不逐键改写运行状态。
- 成功保存或重新读取并采用新作者源后清空两侧历史，绑定新基线；响应失败或源冲突时保留当前草稿和历史。保存响应不确定时仍须重新读取确认真实磁盘结果，保留历史不证明文件没有写入。

历史只用字段差量，不为每个输入复制整份剧情。当前页面显式设置最多 100 步、两侧合计最多 2000000 个 UTF-16 单位的保守历史文字预算，包含身份、标签及差量的前后字符串；这不是整个编辑器的堆内存上限，不包含已读取内容、当前草稿及对象开销。超出总预算时丢弃最早的历史项，当前草稿保持原值。单次操作本身超过预算仍可采用，但清空无法跨越该操作的旧链并明确提示不可撤销，避免跳过这次操作恢复到错误状态；当前草稿仍可导出或保存。

`patch()` 返回当前修改副本，历史条目和字段记录只读。撤销/重做先检查全部目标字段，再整体替换草稿；没有文件、定时器、预览或剧情核心调用。销毁时释放基线及历史，历史不进入导出补丁、服务端、游戏包或玩家存储。

输入框内 Ctrl+Z/Ctrl+Y 等仍交给浏览器，不注册页面级撤销快捷键；页面按钮负责上述跨字段草稿操作。浏览器原生撤销触发的文字变化视为一次新的草稿输入，而不是替代页面历史。按钮位于制作区，不接游戏快捷键或按钮声音。

## 草稿导入与冲突恢复

2026-10-24 从 `5390d90` 接续，编写草稿恢复及逐字段冲突处理，仍未运行。新增 `packages/story-model/src/author-draft.ts` 纯比较函数、浏览器文件读取与比较面板；没有新增命令、作者格式或服务端写入 API。

操作流程：

1. 需要保留的本页修改先导出。若真实作者源已被其他工具改动，按原流程明确丢弃本页旧草稿并重新读取源，再选择此前导出的 JSON。
2. 入口只在浏览器本页读取用户选中的文件；校验 UTF-8、JSON 和 `readAuthorTextPatch`，拒绝未知格式、扩展字段、重复节点/字段项、非法字段及超限内容。不执行文件脚本，不上传文件或写入作者源。
3. 面板按稳定节点 ID 与字段列出每项的旧原文、已读取作者源、本页当前草稿、导入新值。当前源与导出摘要不同会显式显示两个摘要；即使原摘要相同，字段原值不一致也不能跳过比较。
4. 有冲突的字段逐项选择“保留本页当前值”或“采用导入新值”。所有冲突已选择后，点击“采用本次选择到当前草稿”；需要人工组合文字时，可先采用适当一方，再在普通编辑框修改。
5. 采用后再通过原有转换器预览，确认后显式保存。服务端仍按新的草稿基线核对真实源摘要和原值，不能绕过保存冲突保护。

比较与默认建议如下，默认建议只有点击采用后才生效：

| 情况 | 建议与限制 |
|---|---|
| 已读取源等于导入旧原文，且本页没有另行修改 | 建议采用导入新值 |
| 本页当前值已等于导入新值 | 保留当前值，不制造重复修改 |
| 导入旧值与新值相同 | 视为无实际修改，保留当前草稿 |
| 源文件已包含导入新值，但本页又有不同修改 | 默认保留本页修改；仍可明确选导入值来还原该字段 |
| 源或本页有不同修改，且当前值不等于导入新值 | 不预选，须明确选择；不做模糊文本合并 |
| 当前节点或原字符串字段缺失/不可写 | 只允许跳过，不添加字段、不按节点顺序猜位置 |

`prepareDraftImport` 对已读取作者源和当前草稿作一致性检查，返回冻结的比较结果；`resolveDraftImport` 按全部字段的明确处理结果生成新草稿。当前其他字段的草稿保留，所采用字段以**当前已读取源的值**作为 `before`，整体使用当前源摘要；不会直接将旧摘要改掉后无条件发送旧补丁。新草稿完整通过同一修改协议校验后才一次性替换本页草稿，合并超限或任一决定无效时不部分采用。

未采用且尚未存在于当前值中的实际导入修改，可点击“导出未采用的导入修改”另存；它保留原文件的旧摘要及原 `before/after`，不会补造当前基线。原导入文件始终不被改动，缺失节点或被跳过的修改不会悄悄写入其他位置。

每次文件读取、取消及重新选择文件都有代次检查；不可中止的浏览器文件读取完成后也不能采用旧结果。本页修改或还原字段会取消当前比较，防止在旧草稿上合并；比较未结束时，读取、预览和保存按钮暂不可用，可先采用或取消。比较完成后，未采用项的独立导出仍可使用。离开页面会丢失尚未采用的处理选择，浏览器离开提示仍受浏览器规则约束。

每个导入文件最多 4 MiB，遵循原协议最多 1000 个字段、每值 100000 个 UTF-16 字符的限制；合并后的总字段数也不超过 1000。文件选择器的扩展名提示不是校验依据。比较只依据页面已读取的源，不能证明磁盘此刻未再改变；最终保存的实际路径、摘要、原值核对和合作锁仍按下一节执行。

## 同一转换与预览

`tools/content/build.ts` 的 `compileSourceContent(bytes)` 是已有内容构建路径的复用入口：读取固定选项映射，执行严格旧数据转换，检查真实登记资源并计算修订。`loadSourceContent()` 仍从同一作者文件读取后调用它；内容和游戏构建职责保持原样。

编辑器读取、草稿预览和保存都调用这条路径；预览候选不写入磁盘，也不产生 `dist` 内容。转换失败显示来源、节点与字段诊断。每次转换会读取并计算登记资源摘要，较大作品的请求可能耗时；不是全部媒体解码或全路线验证。

`apps/editor` 在浏览器对返回内容执行 `readStoryContent`，校验资源位置、来源摘要和可编辑字段，再复用 `createGameSession`、`WebPresentation` 与媒体资源访问器。没有编辑器专属解释器；当前复用试播表现样式，也不代表最终编辑界面。

| 预览方式 | 初始条件 |
|---|---|
| 正常开局 | 作品正常入口，全部声明变量初值，周目 1、结局数 0 |
| 所选节点 | 所选节点作为临时入口，全部声明变量初值，周目 1、结局数 0，再正常执行该节点进入动作；页面持续标明是人工初始条件 |
| 检查点 | 只接同作品、同草稿修订的预览封装，恢复已生效变量、保存时玩家投影、完整文字和剩余有效时间，不执行进入动作；每次明确选择语音 |

所选节点的临时修订不写入作者源或发行清单；这不是恢复真实路线存档。变量初值、当前变量和玩家投影可展开查看。预览不读取玩家槽位，也不写 IndexedDB、全局成果、正式偏好或聊天；已读仅在本次预览的内存集合内，重新预览丢弃。

检查点预览沿用共享恢复，封装记录原预览起点及真正恢复位置；文件头读取成功与完整校验/采用分开显示，校验失败保留现有预览及最近已校验项。草稿发生任何修订变化都不会自动迁移旧检查点。封装字段、隔离和待试用情景见[检查点初始条件说明](preview-checkpoints.md)。

点击、选项、自动、暂停、有效计时与媒体重试均交给共享会话。切后台独立暂停；停止、换预览及离开取消旧媒体和计时。编译过程中草稿又有变化，旧结果不采用；停止也会取消待采用预览。新预览准备失败不把现有会话切到旧解释器。

编辑后当前画面继续使用启动时的修订，页面明确提示重新预览；保存或成功重新读取会停止旧预览。没有逐键热替换正在运行的剧情状态。

## 显式保存与冲突

“保存到作者源”才调用写入；保存期间锁住编辑。后台固定写当前仓库作品目录中的普通 `game.js` 文件，拒绝源文件符号链接；调用者不能传任意路径。

1. 取得作品目录 `.rebuild-editor-lock` 合作锁，校验 `haifeng.author-text-patch/1`、完整原 SHA-256、稳定节点 ID、字段类型和原值；同一字段不能重复出现。单次最多 1000 个字段、每值最多 100000 个 UTF-16 字符、HTTP 载荷最多 4 MiB、作者源及候选最多 16 MiB。
2. 在纯 JSON 包装内定位原 `speaker/text` 字符串 token；只替换这些范围，保留其余字段、节点与资源顺序、原格式和 UTF-8 BOM。重复对象键或超出扫描范围明确拒绝，不整包序列化。
3. 对完整候选执行同一转换及资源读取；失败不替换源文件。
4. 先将原字节写为唯一的 `.rebuild-editor-backup-<原摘要>-<随机标识>.js`，再写同目录 `.rebuild-editor-<随机标识>.tmp` 候选。备份或候选写入失败不删除原文件。
5. 最终替换前重查源路径、原摘要和候选路径；发现变化拒绝覆盖，保留备份与候选。成功替换才返回新的摘要、内容与备份相对位置。

整个保存过程持锁。锁只协调遵守本约定的保存操作，最后摘要检查与替换之间仍存在不遵守锁的外部编辑器竞态；制作时应避免并行写同一作者文件。没有完整跨进程事务或断电持久性承诺。

正常结束仅尝试移除空锁目录，不递归清理异常目录。异常锁需先确认没有进行中的保存并检查作品目录，再由制作人员处理；本片没有自动解锁。原文件备份和失败候选均保留为本机恢复证据，已精确加入忽略规则，不提交、不充当内容构建来源，也不自动清理。

源摘要不一致会返回冲突，当前草稿保留；先导出草稿，明确勾选丢弃后重新读取，再导入旧草稿逐项处理差异。HTTP 断开、服务中断或响应校验失败时，界面只报告“未确认完成”；文件可能已经替换，不能假定保存未发生，也不能直接无条件重试覆盖。

重新读取/预览/保存 API 都是固定路由 POST，校验固定 Host、同源 Origin、JSON 类型及本次启动的随机令牌，服务内只允许一个作者操作进行；令牌不写入磁盘。只返回规范化内容、允许字段、本机资源位置和备份相对位置，不把原始作者文件、文件句柄或 Node 错误绝对路径序列化到浏览器。

## 统一测试阶段的操作建议

本轮没有执行以下步骤：

1. 打开编辑入口，查找一个普通对白节点，修改一个字；先预览再停止，确认源文件没有因预览被改写。重新预览时应采用新草稿，旧媒体和计时不能遗留。
2. 在所选节点预览中查看初始条件说明；选限时节点 `pm8x8v2h`，分别点击、等到期、暂停、切后台，确认继续使用共享会话的一次结算和有效计时。
3. 导出草稿后点击保存；确认仅对应字符串变化、其他原字节保留、备份内容为保存前原文件；再重新读取与预览。试用文字修改属于作者内容变化，应自行保留或还原，不混入工程提交。
4. 留着未保存草稿，用其他制作工具修改同一源文件；预览或保存应拒绝旧摘要，并允许导出草稿后明确重新读取，不静默覆盖。
5. 在转换期间继续编辑或停止预览，旧结果不能采用；保存时断开连接，重新读取确认实际结果。随后回游戏试播查看原玩家记录，预览不得增加解锁或周目。
6. 导出一份修改，重新读取后导入，比较并采用；再预览，确认导入本身未写作者源，保存仍需点击。当前本页其他字段的草稿应保留，重复导入已采用值不会重复修改。
7. 在其他工具改写同一字段后重读源，再导入旧草稿；冲突必须选择，分别保留本页或采用导入值。已在源中的导入新值、缺失节点和不可写字段须正确标明；未采用的修改可按原摘要重新导出。
8. 导入比较期间修改本页草稿、取消或重新选文件，旧文件读取和旧决定不得采用；损坏 JSON、非法字段、重复字段、超限文件或合并超过 1000 字段时，当前草稿保持原值。
9. 所选限时节点的预览显示共享倒计时条；暂停/继续、Tab 聚焦或缩放预览区，按钮不因时间刷新重建。缩至 0.75 倍以下核对正文、名字、选择尺寸和列表滚动；停止后旧按钮、进度条和点击监听清除，玩家记录不变。
10. 在竖长窗口中预览同一草稿，核对上方场面、下方对白与单列选择，再切回横屏。实际变量、语音、步骤和剩余时间不因布局改变而重新开始；文字输入等制作控件不被游戏布局染色或移动。
11. 编辑对白或使用输入法时按空格、方向键、A、H、Ctrl，预览不能因此推进；聚焦预览后核对继续、自动、临时快进和隐藏。隐藏后点击只恢复，长按后不多跳句；松键、切到编辑框、后台、停止/重开均不能遗留临时快进、隐藏按钮或旧合成点击，草稿与玩家成果不变。
12. 聚焦预览后用全屏按钮/F11/Alt+Enter 往返，制作控件保持在全屏区域外；Esc 只退出显示，下一次再操作暂停。进入尚未完成就停止/换预览，迟到进入应随后退出，不重放剧情、遗留监听或改写草稿/玩家成果。
13. 使用引用面板查看节点跳转、资源及变量的使用位置；改对白、还原或采用导入后，旧结果须刷新才能定位。翻过 50 项分页并跳到筛选外节点，草稿与搜索不丢失，预览不重启；详细边界见[引用查询](references.md#留待统一测试)。
14. 在一个字段连续输入，再切换字段或节点修改；逐次用页面按钮撤销/重做，核对分组、跨节点定位及筛选保留。再试原生文字撤销、粘贴及输入法，文字应同步为当前字段草稿，不触发游戏操作。
15. 还原一个同时修改说话人/对白的节点，再撤销；导入多个字段后撤销一次，应整体回到导入前草稿。撤销后再修改则不再重做旧路线；同值输入、空还原或无实际修改的导入不制造内容操作。
16. 在导入比较或预览准备期间撤销，旧比较/旧预览结果不得采用；已运行预览和玩家记录不变。保存失败保留历史，成功保存/重读清空旧历史；文件实际修改仍只由显式保存触发。
17. 使用受控的大草稿和多次操作核对步数/文字预算：丢弃较早历史不丢当前草稿；单次超预算的导入有明确提示且不能跨过它撤销，随后的新编辑仍能撤销。关闭后历史释放，导出格式不含历史字段。
18. 从普通和限时预览分别捕获、导出、重新读取并恢复检查点；保存时变量/投影及剩余时间须明确且不重复进入动作。改对白修订后恢复旧检查点应拒绝，文件读取、停止或新预览期间的迟到结果不能采用；详见[检查点预览](preview-checkpoints.md#留待统一测试)。
19. 从现有结局节点按明确人工初值预览，完成对白后核对共享结局卡片、隔离说明及“停止预览”；正常游戏的收藏/次数不变，重开或停止后旧卡片按钮失效。完整情景见[结局卡片](endings.md#留待统一测试)。

已接只读的局部流程定位，尚未接入可写剧情图、资源/演出编辑、引用自动修复、跨修订检查点迁移、磁盘版本恢复、旧编辑器工程导入、完整艺术工具、编辑器发行构建或正式作者源切换。引用/流程查询只覆盖规范化结构与已消费设置，不证明可达性或无旧工具/外部消费者，不授权删除。当前导入只支持内部对白修改补丁及独立预览检查点，不是任意工程/作者包或正式玩家进度导入。游戏和内容构建入口仍独立使用当前作者源；游戏开发服务每次启动固定一份内容，编辑保存后需重启游戏开发服务才能看到新内容。是否转用新的作者格式，应在编辑回路可靠且明确授权后再决定。
