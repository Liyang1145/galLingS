# 章节目录与初始条件试阅

接续 M5 的原 `showChapterReview()` 能力，提取真实章节目录及明确初始条件的纯准备接口，接到开发主页“章节试阅”。共享能力及页面接线已编写；未启动、类型检查、测试、构建、额外审查或使用子代理，尚未验收。

## 章节与初始条件

`packages/player/src/chapters.ts` 的 `chapterCatalog(content)` 只消费已校验内容中非空的 `node.chapter`，保持全部节点原顺序。每项含原章节标题和稳定起点 `nodeId`；标题相同也不合并，不根据台词、标签或数组间距猜章节，不推断路线或提前解锁成果。

`prepareChapterTrial(content, nodeId)` 只接受当前目录中的原节点；非章节节点、未知节点明确拒绝。返回临时入口内容、全部变量的声明初值及明确的人工玩家投影（周目 1、结局数 0），不读取玩家存档、全局记录或设置，不求条件、执行进入动作或创建媒体。

临时内容修订为 `chapter-preview:<原节点 ID>:<原内容修订>`，不修改作者源、节点/资源身份、顺序、选择、流转或实际内容修订算法。这不是存档迁移或此前路线恢复；章节节点的进入动作仍只能由共享会话中的唯一核心在真实开始时执行一次。

旧章节入口也从声明变量初值开始，但会采用旧 `applyGlobals()` 并进入旧正式记录通道。新开发切片明确属于隔离试阅，采用上述固定人工投影，不能冒充原存档或承诺真实路线条件。这是沿用户“预览与正式记录隔离”要求的开发入口，不改变正常游玩全局成果规则，也不决定正式章节解锁体验；旧入口保留。

## 开发主页与共享会话

`apps/game/src/chapters.ts` 的 `ChapterPanel` 只展示只读目录、每项原节点 ID 及全部声明初值/人工玩家投影，把明确选择的条目交给应用；它不接会话、资源读取、存储或成果。打开目录不启动任何章节、解码媒体或采用进度。Esc、原生返回键、切换主页弹层、开始/读档采用、退出和页面离开清除目录及旧监听，再次打开重建本次选择。

应用在同一 `start()` 准备/采用通道中重新校验章节起点，准备成功后取消旧工作并采用新会话代次。实际游玩使用已有 `createGameSession`、`WebPresentation`、选择、输入、有效计时、后台/宿主暂停、媒体错误与原步骤重试，不增加章节解释器。开始后持续显示原起点、全部声明初值及人工投影，不将试阅条件当作真实路线进度。开始失败不切换旧核心；采用后的异常也取消已创建会话与表现，避免后台遗留。

每次开始或重新开始该章节均使用新内存已读；不会把上一章节、限时样例或正式已读带入。后续仍按作者分支、选项和结局执行，允许走到后续章节，不以章节目录截断剧情。对白回看和显式会话内回退复用原实现，回退继续使用本次人工投影，不读取全局成果；回退边界和本次语音仍须显式选择，不新增正式默认。

章节试阅没有持久进度仓库；“保存当前检查点”显示试阅不写槽位且有函数边界拒绝，不新设章节槽位或混入原 `main/timed`。查看既有槽位仍是只读操作；用户明确读取第一话或限时样例时，走原准备/采用流程后离开试阅。试阅到达结局显示共享卡片的 `preview` 状态，不写已读、CG、结局、通关次数或聊天解锁，也不伪装为已保存。

音量、阅读和按钮声音在 `PreferencesPanel` 的独立 `chapter` 内存中，从作者默认开始；本页切换章节保留自己的临时调整，与第一话、限时样例三份值分开。面板不开放保存/重试正式偏好；返回标题后重新采用正常入口当前值。未改变任何偏好持久格式或已捕获保存的原目标，先前已发起的正常写入仍可独立完成。

主页现有鲸鱼菜单增加第六项，继续沿原右侧逐项 18px 错位，小舞台/竖屏使用原紧凑覆盖；没有重画图形或决定正式框架。正常退出仍只等待此前已发起写入，不能因试阅触发正式自动存档；退出取消后沿原会话暂停规则继续，页面销毁取消试阅媒体/计时。

没有新存储格式、素材、宿主协议、依赖或命令。当前实现不是完整正式章节菜单、全路线验证或 M5 完成。

## 留待统一测试

以下只是统一测试阶段的操作建议，本轮没有执行：

1. 对照原 18 个章节标记核对标题、原顺序和起点节点，包括两个番外；同名章节仍按节点分别定位。
2. 任一试阅以声明初值及固定人工投影开始，不会读入旧路线数值或玩家解锁；非章节节点无法冒充目录项启动。
3. 章节节点进入动作只执行一次，后续分支、选择和有效计时仍由相同核心处理；到达结局不写全局成果，回主页后原存档与偏好保留。
4. 从后续章节开始试阅、做出选择，打开菜单/后台再恢复，核对当前变量和剩余有效时间；回退仍需显式选择范围/语音，采用目标检查点而不反算变量。
5. 从试阅返回标题再选其他章节、重新开始、读第一话进度或正常退出，旧步骤/媒体/计时不能污染新场面；目录打开即关闭、关闭后快速重开，也不能由旧按钮启动章节。
6. 试阅、限时样例分别调整三种设置再回主页，核对第一话当前及已保存偏好均保留；试阅保存按钮不可用且不产生槽位。实际达成结局只能显示试阅结果，主页周目/结局/CG/通关后记录不因它变化。
