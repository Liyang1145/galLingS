# 只读节点流转定位

接续 M6 现有对白编辑、引用查询及共享预览，在编辑页增加当前节点的一层前驱/后继图。只编写实现、接线和文档，未启动、类型检查、测试、构建、额外审查或使用子代理，尚未验收。此切片是规范化流转的只读查询，不决定正式剧情图工具或编辑器选型。

## 读取与展示

`apps/editor/src/flow.ts` 的 `AuthorFlow` 只持有已校验内容、来源摘要、草稿代次及当前说话人/对白覆盖，接受显式 `capture/current/selected/navigate` 能力。没有作者文件写入、网络请求、剧情会话、存档或玩家记录接口。

刷新时按当前规范化内容建立全部节点及结构连线索引，不按旧数组相邻位置猜目标，不计算条件、执行动作或推断可达性：

| 规范化输入 | 显示 |
|---|---|
| `entryNodeId` | 独立作品入口标记；没有实际前驱节点 ID，不丢开局之前保留的其他节点 |
| `next` | 实际后续节点，空目标明确为脚本末尾 |
| `branch` | 条件成立和不成立两条连线，详情保留同一原条件；不求值、不把当前变量或人工预览初值当成路线判定 |
| `choice` | 原顺序的全部选项、稳定选项 ID、原目标、条件及动作；超时默认在对应原选项旁显示时长，不另造一条默认路线 |
| `emptyTarget` | 明确显示“无可见选项时”的目标，不假定总有可见选项 |
| `ending` | 结局名称及终态，不能冒充普通后续节点或已解锁成果 |
| 回到自身或多个流转到同一节点 | 保留每条结构连线，不递归展开或按目标合并选项 |

屏幕以当前编辑节点居中，前驱/后继分别每页最多八条。索引覆盖当前内容全部节点，分页可访问全部邻接连线；不会一次布局 3315 张节点卡片，也不把局部视图冒充全作品可达性分析。图形箭头只用固定布局数值，节点文字使用 `textContent`；键盘与辅助阅读通过实际按钮/分组工作，不依赖可点击 SVG。

节点卡片展示稳定 ID、章节/标签、当前草稿说话人及对白摘要，长内容在卡片内滚动。点击卡片中以流转标签为文字的按钮，会显示完整标签、条件、选项动作和来源。表达式只是从既有 AST 生成带括号的可读表示，不是另一套解析器或求值器；字符串和数值的类型区别保留，进入动作另在当前节点详情中只读列出。

规范化 `nodes.*.flow.*` 路径与作者 `source.file/field` 分开展示。前者是内容协议路径，不能当成作者文件原始 token 位置；当前图也不读取可能仍使用旧修订的预览运行态。

## 修订、定位与隔离

索引绑定 `sourceSha256`、已读取内容对象和本页草稿代次。编辑、还原、导入、撤销/重做及源替换会将旧图标为失效，保留可见但禁用查询/定位，须显式刷新；刷新不保存或启动预览。读取/保存作者源时禁用操作，失败不丢草稿或现有预览。

点击邻接节点复用编辑器现有 `navigateNode()`：先核对原图代次及当前来源，再保留搜索和草稿、定位该节点、更新表单及其他只读查询并聚焦节点标题。节点在筛选外或超过列表前 200 条时仍采用现有置顶规则。不改变预览节点、剧情进度、变量或检查点，也不调用删除/重命名/修改流转。

翻页、重新定位及失效都更新视图代次，旧按钮不能继续定位或显示后来数据。源替换重新建立索引；离开取消监听并释放索引与副本。面板位于制作区，留在预览全屏、输入与按钮声音范围之外。

## 本片边界

没有开放节点、选项、条件、动作、变量、资源或连线写入，没有拖动、自动布局全图、路线模拟或死路诊断，也没有作者源切换。当前唯一作者源仍为 `海风与布丁/game.js`，实际保存范围仍只有已有 `speaker/text` 字符串。图中是否出现入边、出边或入口标记，不证明内容被实际游玩、可以删除或已经验收。
