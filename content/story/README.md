# 分章剧情作者源

本目录是《海风与布丁》的唯一作者源，不是发行生成物。先读 `project.json` 的章节清单，再打开所属 `chapters/*.json` 编辑；不要重新生成或写回旧 `海风与布丁/game.js`。

- 十六话正文：`chapter-01.json` ～ `chapter-16.json`。
- 两篇番外：`extra-01.json`、`extra-02.json`。
- `opening.json` 保留原先位于正式开局前的两个节点，正常起点仍由 `entryNodeId` 明确指定。
- 条件/变量修改仍写受限表达式文本；跨章目标写稳定节点 ID，选项保存自己的稳定 ID，限时 `cdef` 写本节点选项 ID。
- 变量、设置、五类资源、资源顺序与迁移来源各自独立；原图片/音乐/语音不随此迁移搬动。
- `.author-lock/`、`.author-backups/` 是本机事务与恢复材料，不是可编辑副本，不提交、不要随意删除。
