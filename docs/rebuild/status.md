- 同步已确认的 3315 个剧情节点、1115 个资源身份及 824 句语音绑定。节点身份/顺序、选择、变量动作、跳转及结局逻辑保持；两处此前批准的配音文字同步保留。首两话 150 句批准版、#187 A 版及开场触尾 C 版随资源接入。
- 保留 nnn 已接受 18 张图的 279 处使用；V10/V11/V15/V16 撤回，V13/V14 待定；未引入 nnn 视频或 Live2D。L15/C20 仍用批准保留的旧图。

- 对话框默认不透明度 45%，允许 0～100%。只有背景层受影响，不再强制最低 72%，文字/按钮不被一起淡化；零值能独立保存和重读。
- 补齐低调的“语音开关”：前两话默认开，从作者声明的第三话节点起默认关；当前章节可以手动开。两段偏好独立保存、章节试阅只用内存；回看独立试听不受自动配音开关阻断。不往旧严格音量格式或剧情存档塞字段。
- 修复 6 处严格类型错误，包括鉴赏状态联合类型及嵌套回调中的已验证 DOM 引用。
- 修复构建工具通过 Windows 用户目录别名执行时静默退出的问题。共用真实路径入口判断，只在命令直接执行时运行，导入仍无构建副作用。
