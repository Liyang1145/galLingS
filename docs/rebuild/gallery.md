# 主页鉴赏与本地图片

接续 M4 已确认的全局成果归属，在现有主页鉴赏补上本地图片失败、重试及关闭生命周期。只编写实现、接线和文档，未启动、类型检查、测试、构建、额外审查或使用子代理，尚未验收。没有改变 CG/结局目录、解锁条件、周目计次或存储格式，也不决定正式界面框架。

## 读取与权限

`apps/game/src/gallery.ts` 的 `GalleryPanel(root, content, resources, transition?)` 只接当前已校验内容、本地资源访问、可选同步显示委托和应用传入的已提交 `PlayerRecords`。`transition(change)` 须同步执行一次显示变更，缺省直接执行；游戏只委托给已登记鉴赏弹层的 `DialogFade.change()`，没有解锁、记录或剧情能力。`open(records)` 核对作品身份后展示，`close()/dispose()` 释放当次内容；面板不接存储写入、剧情会话、进入动作或结局结算接口。

应用打开前仍先提交已有待写事实，再从同一 `development/normal-entry` 仓库重新读取记录。异步读取同时绑定应用入口请求及本次鉴赏请求；关闭、开始游玩、退出或页面离开后不能采用旧响应。每次重开重新读取当前记录，不用图片缓存或旧面板充当全局成果来源。

结局和 CG 均沿用共享 `galleryCatalog()` 的当前内容目录及原顺序；结局首次日期、周目和通关次数继续来自已提交记录。目录之外的历史成果由原仓库保留，不因当前面板没有条目而删除。

锁定 CG 只显示禁用占位：不创建图片、不读取资源位置，也不显示未解锁名称。已解锁条目可以在缩略图不可用时继续尝试大图，不以图片成功显示作为新的解锁条件。

## 图片的当次归属

| 对象 | 当前行为 |
|---|---|
| 缩略图 | 原生懒加载、异步解码，只在本地登记位置读取；说明分别显示待读取、名称或带资源 ID 的失败原因 |
| 本地大图 | 每次只拥有一张，显式点击后进入独立查看区并开始读取，解码完成才显示；顶部返回目录，状态包含本次名称/资源 ID，错误提供原资源重试 |
| 缩略图重试 | 取消原尝试，再读取同一条已解锁资源；不刷新成果、不换到其他图片或联网补图 |
| 返回鉴赏目录 | 取消当次图片并清空来源，收起查看区，恢复本次目录滚动；焦点回到原条目的实际按钮 |
| 返回主页、Esc、原生返回、开始游玩、正常退出或离开 | 同步关闭面板，注销当次按钮/媒体监听，移除全部当次图片来源及元素；重开建立新面板状态 |

文件内 `GalleryImage` 每次载入用独立对象识别图片、事件与解码。重试、换图和关闭先使旧对象失效；无法真正中止的解码完成或错误必须匹配原对象，不能更新新图、新面板或已关闭的状态。资源路径异常与图片读取/解码失败都留在鉴赏说明中，不把已提交成果改报为丢失，也不触发剧情重试或重新进入节点。

所有名称和诊断使用文字节点，不拼成 HTML。缩略图状态不逐条进行 live 播报；大图状态使用单独的状态区域，打开查看区可聚焦，关闭恢复原按钮。图片解码及可见性状态只在当前面板内存中，不进入进度、成果、偏好、预览或聊天。

本片没有提供新的解锁、解锁调试、导出、上传、资源替换或删除入口；没有接声音收藏或完整剧情结局树/路线图编辑。当前结局收藏仍是作品已有结局的只读列表，视觉过渡的已接范围见下节，不能据此宣称全部旧鉴赏效果或布局已验收。

## 旧版分类与布局

从 `9bb43be` 接续界面迁移，鉴赏恢复旧入口的 CG/结局分类及解锁计数按钮，每次打开先显示 CG。分类只切换本次已读取成果对应的可见区域，不重新结算或刷新成果。CG 宽屏四列、窄屏三/两列，锁定项保留深海绿色虚线占位；结局使用名称和首次日期的逐行列表，未解锁名称继续隐藏。空目录、图片失败和原资源重试仍可见。

弹层返回区与内容滚动分开。切换到结局分类会同步取消当前大图、清空选中身份并收起查看区，旧解码不能将其重新打开；分类按钮保留焦点。缩略图仍沿原尝试归属，不因切类重新获取解锁或请求锁定图片。每次重开仍重新读取成果并重建目录；格式、解锁规则、图片来源和关闭清理不变。已编写并接入，未启动、类型检查、测试、构建或视觉验收。

## 独立大图与内部切换

从 `5eac4bd` 接续，将原先排在缩略图列表前的大图改为同一鉴赏弹层内的独立查看区。显式点击已解锁条目才隐藏目录、保存当次目录滚动并显示该资源的名称/ID；顶部“返回鉴赏目录”独立于图片与长诊断的滚动，外层“返回主页”仍关闭整个鉴赏。大图不裁掉原图比例，错误及重试在查看正文中，窄屏返回按钮分行，小高度缩紧留白。没有新建模态框、下一张/自动播放、锁定图入口或新持久字段。

返回目录立即使原大图请求失效、清空来源/选择并恢复原目录滚动与条目焦点；隐藏目录保留原缩略图实例，不为这次切换重读成果或重新装载全目录。重试使用仍选定的原资源，关闭鉴赏/换会话/离开仍清理全部图像与监听；Esc/原生返回继续关闭鉴赏，未新增返回键优先级。

分类实际变化、显式打开/返回大图、原资源重试及当次解码成功显示，通过应用提供的同步委托复用[登记弹层内静态过渡](performance.md#游戏弹层视觉过渡)。同一分类重复点击不采样，缩略图逐张完成和故障说明不反复制造动画。加载/失败说明即时生效，解码完成再次核对原尝试及原选择对象，才显示当前图像；旧结果不能重新开启已经离开的查看区。副本只带已有可见画面，无输入、事件或媒体能力，不延迟真实图片取消、焦点或分类采用。

仍消费重新读取的已提交成果和当前目录，不新增成果/进度/偏好/宿主格式，不扩大共享舞台的快照范围；该接口不进入编辑预览。已编写并接入，未启动、类型检查、测试、构建或视觉验收。

## 留待统一测试

以下只是统一测试阶段的操作建议，本轮没有执行：

1. 从主页打开鉴赏，核对当前已提交的周目、通关次数、结局及 CG 数量。读旧进度后再返回主页，已经解锁的条目仍保留；打开、关闭与重试图片都不能增加次数。
2. 对锁定条目确认只有禁用占位，不显示未解锁图片或名字；在专用测试环境查看资源请求，锁定图片不应被读取。
3. 在专用测试副本中模拟某张已解锁图片缺失、损坏或读取失败，分别检查缩略图/大图的资源 ID、诊断和原资源重试。恢复本地资源后再次重试；不要删改权威素材来制造故障。
4. 快速切换不同大图、重复重试、收起再打开、Esc/原生返回关闭并立即重开，检查旧加载/解码结果不能改后来条目或重新打开面板；收起时焦点回到原按钮。
5. 读取全局记录期间开始游玩或正常退出，检查旧结果不能弹出鉴赏；关闭后原图片与监听被清理，重新打开使用重新读取的成果。图片故障不影响保存的解锁、当局进度或下一次正常开局。
6. 切换 CG/结局，核对计数、锁定名称和原顺序；大图加载/解码中返回目录再切到结局，迟到响应不能重新打开 CG。手机、矮横屏和长名称检查返回区、分类及条目可访问，重开默认显示 CG 并重读成果。
7. 目录滚到下方打开大图，再返回目录，应恢复原位置与条目焦点；顶部返回目录、外层返回主页分别可达。大图加载中返回、重开同图/另一图、失败后重试，旧解码不能显示到后来条目或覆盖目录；不因切换重建缩略图或写入成果。
8. 分类、打开/返回大图及解码成功时核对 360ms 静态淡出，副本不可点、无 live 播报或焦点。快速连续切换、后台/宿主暂停、尺寸/全屏改变、开启减少动态效果和关闭鉴赏应清理原副本；真实操作不等动画，失败只留视觉提示，不撤销已采用的界面变化。
