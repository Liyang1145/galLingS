# 共享播放器的局部约束

- `src/session.ts`、`src/clock.ts` 不依赖 DOM、网络、宿主或编辑器；浏览器实现只放 `src/web/`。Node 与 Web 类型检查范围保持分离，不为方便给纯模块开放 DOM。
- 剧情决策只通过 `story-runtime`。会话拥有串行输入、暂停原因、有效计时和取消；表现只能报告场面就绪、文字/语音完成和媒体问题。
- 应用分配递增会话代次；所有延迟回调核对呈现代次，推进操作再核对核心步骤。换节点、重试、离开及重开必须取消旧工作。
- 场面资源未就绪时暂停有效时间。菜单、后台、宿主、资源加载及错误是不同暂停原因，不能相互误解除。
- 原生/后台状态通过 `initialPauses` 在首次呈现前生效；读档及回退准备使用独立 `operation` 原因，完成准备不能解除真实宿主暂停。
- 媒体重试不重新进入剧情，不重播进入音效，不重置选择剩余时间。持续音轨保持同曲连续、换曲和停奏意图；一次性语音/音效属于当前呈现，不能遗留到下一节点。
- 检查点由会话在同一个串行操作中捕获核心状态、有效计时和表现数据；异步存储不得再拼接后续的实时状态。`checkpoint.ts`、`saves.ts` 保持无 DOM/宿主依赖，浏览器存储在 `src/web/`。
- 外部检查点先经唯一核心和封装校验，失败不改变当前会话或旧槽位。读档显式使用当前全局投影，不采用旧档投影覆盖成果；准备成功后换会话代次并取消旧工作，恢复不发进入或结局事实。正式语音默认体验和回退边界仍待决定，试播语音方式由本次调用者明确指定，见 `docs/rebuild/saves.md`。
- `records.ts` 管全局成果，不接受进度槽位覆盖。事实重试保留交付 ID，结局解锁与通关计次原子合并；记录失败不冒充已保存。开发、预览与正式记录分别隔离。
- `recordWithReceipt()` 的首次结局列表须在同一全局事务内判定，提交后才返回，失败/重试已有批次不能冒充新解锁；回执是瞬时结果，不加持久字段。应用按原批次与当前会话/表现/终态匹配，`ending-unlocked` 只确认反馈，不写剧情或再计次。终态 `end/setPaused` 保留声音生命周期，返回标题和销毁仍取消全部轨道；静音或退出跳过的提示不补播。
- `preferences.ts` 保持无 DOM，只管理独立声音偏好及作者默认解析；稀疏通道修改在事务中合并，不进入检查点或全局成果，不覆盖损坏记录。保存重试使用原捕获修改，后来未保存的调整仍保留。混音器分离玩家音量与素材/场景/渐变增益，实时调音不重播或重置渐变；0 音量触发的一次性音效不积攒补播。
- `reading-preferences.ts` 是独立阅读协议，不复用声音、进度或全局记录键。`auto-wait` 意图只更新后续自动等待的倍率，不重置当前等待、限时选择或恢复剩余时间；表现捕获本次呈现的逐字间隔，字号/透明度可即时更新，不重建场面或文字。
- `appearance.ts` 严格读取作者主题/封面，保持无 DOM；`web/appearance.ts` 只向给定舞台写受限样式，现有鲸鱼皮肤覆盖通用主题的关系保留。应用/预览使用同一图形和作者坐标，不在预览另设字号/选择样式；字号基准取作者值再乘阅读倍率。封面加载独立取消，失败可重试且不推动剧情；对白图片未就绪归属当前场面错误，不重入。
- `web/choices.ts` 只显示会话已经给出的可见选项，点击原令牌和稳定选项 ID 仍交回共享会话；不自行求条件、排序或计时。时间/暂停更新保留按钮及滚动，换步骤/清空取消旧监听。`web/stage-layout.ts` 只管理同一舞台比例和小屏单位，游戏/预览共用；缩放不能重建会话、文字、声音或剩余计时，完整竖屏模式另行接入。
- `button-preferences.ts` 管独立布尔开关及稀疏事务合并，不向既有严格音量/阅读格式加字段。`web/button-sounds.ts` 只绑定应用明确给出的操作按钮，鼠标悬停不受子元素重复进入影响；按消费者生命周期取消监听。应用核对当前会话、开关、暂停与快进，混音器继续执行许可/音量门控；选择和存档不能同时套一般按钮音。
- `readCompletions()` 只从重新读取的已提交全局记录提供作品、范围、解锁结局及逐次通关引用；不混入进度槽位、待写事实、路线变量或准确通关时间。通关后模块只接这个最小读取能力，不持有全局写入或剧情接口。
- 对白回看只持有当前会话的文字及语音资源 ID 副本，实际接受的选择在后续对白之前记录；媒体重试不重复追加。`history` 暂停原因独立于菜单、后台与宿主，关闭回看只解除自身暂停。读取或关闭回看不发剧情命令或全局事实，不据此定义进度回退边界。
- `AudioMixer.previewVoice()` 只由回看等只读消费者以独立混音实例使用，不在剧情表现的混音器上调用；只接受登记的 `vo`，最多保留本次试听，错误/结束不发主线 `voiceEnded`。消费者在关闭、换句、前后台/许可失效时取消原试听；迟到播放/错误不能污染后来试听或自动补播。实时语音音量沿用当前独立偏好，不捕获试听位置到检查点。
- `rollback.ts` 只管理有界的会话内检查点；容量由调用者显式提供，跨选择与语音方式由本次操作显式给出，不内置正式默认。首次稳定及离开前在会话队列中捕获，准备成功才由唯一核心恢复并截断未来历史；核心步骤与呈现代次更新使旧回调失效。恢复不重入，已解锁成果不回滚；媒体错误在已恢复位置重试。
- `src/web/package.ts` 只消费严格校验的随包清单与规范化内容；基址由宿主页面显式给出，资源映射保持包内相对位置。启动先校验剧情字节及修订，失败不开始会话或回落旧实现；不预加载全部媒体，不把启动校验写成安装或媒体验收。
- `src/web/host-bootstrap.js` 是两端原生在页面脚本前注入的最小桥；当前 ABI 为 `haifeng.host-bridge/3`，平台标记由明确宿主装配替换，保持来源约束、初始暂停、递增序号及失效保护。桥不含剧情逻辑，返回键只能交给应用处理菜单或弹层；音频通道仅允许请求/释放焦点。
- `writes.ts` 只跟踪显式写入，失败重试复用原捕获载荷，不重新读取当前进度。正常退出使用独立 `exit` 暂停，等待写入和全局事实完成；票据取消不能撤销存储事务或解除其他暂停，不等于自动存档或强杀恢复。
- 宿主声音许可与会话暂停分别管理；未获准不播放，语音不可用不得卡住自动阅读，一次性音效不得积攒到稍后补播。焦点中断后恢复当前声音，不重入剧情或重发进入事实。
- `ui-sounds.ts` 校验作者提示音映射，并把核心已提交的分组变量变化及目标背景/话末转换为纯声音计划，不计算剧情或执行表达式。选择反馈来自被接受的核心事实及每次访问首次就绪，恢复/重试/重绘不重复发一次性提示；循环声只跟随当前选择与暂停，不驱动结算或进入检查点。变量提示延迟使用有效计时并归属本次呈现，换节点/恢复/错误/快进/离开取消。交互播放失败不阻断主线，不把已提交保存改报失败；未播一次性提示不积攒到启用声音时补放。
- 根规则仍适用：不自动测试、构建、审查或启动子代理；本目录规则不额外授予验证、推送或发布权限。
