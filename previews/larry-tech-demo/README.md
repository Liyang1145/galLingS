# LarryE 技术 DEMO · 音乐音效整合版 v1.0

当前场景与声音试玩基于用户提供、并确认由 **LarryE135** 制作的《海风与布丁 技术DEMO》。保留完整十六话、两篇番外和原版画面、剧情、选项、变量、行标识。

下载仓库后双击本目录的 **`开始试玩.bat`**，或在浏览器中打开 **`index.html`**。移动时复制整个目录；不需要启动后端。

## 本版声音

- 《翡翠之梦》使用音乐负责人 @Liyang1145 指定的原始主曲，在剧本 23 处对应入口播放，同曲跨台词继续播放。
- 收录 15 个环境音和 18 个剧情音效的游戏用副本；33 个来源都已在场景中接入，并提供标题/设置里的“音频试听”。
- 环境声拥有独立持续音轨，随浅滩、集市、营地、水下、店铺与室内切换；跨台词持续，切换时渐变。
- 默认音乐 35%、环境音 30%、动作音效 55%，可分别调整。
- 第九话电话使音乐立即停止；救起后的滴水段按剧本保留留白。快进不堆叠动作声音，返回标题停止所有声音。
- 存档记录音乐和环境声播放位置，读档不会重复播放该句动作音效。浏览器标签隐藏时暂停声音。

《深海之光》及各主题变奏仍待音乐负责人提供；对应场景使用环境声或停奏。原主曲保持 MP3 字节不变，当前采用整曲循环，尚未编辑音乐无缝循环点。

## 素材与修改边界

原音效位于 [素材库](../../content/assets/audio/sfx/README.md)。本目录 `assets/audio/*.ogg` 是裁切、响度处理、环境循环接缝处理后的游戏副本，原 WAV/FLAC/MP3 保留；短片段并不表示原素材已被替换。

主曲原文件位于 [配乐素材库](../../content/assets/audio/bgm/bgm_emerald_dream_main_v01.mp3)，本目录的 MP3 与其相同。

原 DEMO 的背景、立绘、CG 与其自带补充音效继续使用；没有把旧版仓库播放器或 Ren'Py 历史备份恢复成入口。尚未连接 galLingS 后端、AI 或实时记忆服务。

来源、文件校验值、裁切区间、循环处理、109 处剧情音效接入及各环境音使用记录见 [audio-manifest.json](audio-manifest.json)。音频制作副本：2026-10-12。

## 验证

在 Edge 中验证分文件版和本地单文件版；全部 34 段试听音频、23 处主曲入口、18 章入口、7 类场景环境声，以及三类音量、存读档、试听返回、循环、电话骤停、滴水留白、快进与返回标题均通过检查。标签隐藏的暂停恢复逻辑通过模拟可见性事件检查。无 JavaScript 错误、缺失资源或外部网络请求。详见 [verification.json](verification.json)。另以正常点击走完第一话四个选项并进入第二话，检查 896×414 横屏触控的试听、音量与开始阅读，见 [additional-qa.json](additional-qa.json)。

原 DEMO 作者归属来自用户说明。图像与原音效制作链、额外开放许可证未提供；本目录素材不默认适用引擎代码许可证。
