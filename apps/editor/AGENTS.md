# 独立编辑入口

- 本目录是对白编辑试用切片，命令和限制见 `docs/rebuild/editor.md`。DOM 实现不决定最终框架或编辑器选型。
- 唯一作者源仍是 `海风与布丁/game.js`；草稿是相对原摘要的字段修改，不生成第二套长期维护的剧情源。
- 只允许现有 `speaker/text` 字符串修改，不在本片扩展节点、选项、变量或素材写入；未知字段由共享转换器保留或拒绝。
- 预览复用 `createGameSession`、`WebPresentation` 及内容转换结果，不写推进或变量算法。全部声明初值和玩家投影必须可见，所选节点预览不能冒充真实路线进度。
- 预览不接玩家存储、全局成果或聊天；已读仅在本次预览内存中。换预览及离开要取消旧会话、计时、媒体和待采用响应。
- 浏览器仅调用固定本机编辑 API；作者文件写入在 `tools/editor/`，只能由显式保存按钮触发。网络失败不能假定未写入，保留草稿并提示重新读取确认。
- 草稿导入只读本机所选 JSON，经同一修改协议校验后逐字段比较旧原文、已读取作者源、本页草稿和导入新值。冲突必须明确选择，找不到的节点/字段不能猜测；合并完整校验成功才替换本页草稿，不写作者文件。未采用项保留原摘要，可单独导出。
- 导入比较绑定当前源摘要及草稿代次；本页修改、取消或离开使旧比较失效。已有比较须采用或取消后才能读取、预览或保存，最终写入仍由服务端重查真实作者源。
- 本目录不进入游戏发行构建；引用现有表现样式不代表正式制作界面已决定。根规范的测试、提交及推送授权仍适用。
