# 共享全屏与原生显示控制

从 `b64340e` 的干净工作区接续 M5。游戏、独立编辑预览、Windows 集成宿主和 Android 集成宿主已编写显示切换接线；没有安装、启动、类型检查、测试、构建、额外审查、子代理或设备验收。原入口、作者内容、素材、剧情/存储格式及发行默认未改。

## 共享控件与浏览器

`packages/player/src/web/fullscreen.ts` 的 `PlayerFullscreen` 接收全屏目标、游玩区域、按钮、状态元素、键盘作用域和启用判定，可选接收原生 `FullscreenDriver`。驱动只提供显示状态、请求、订阅和销毁，不取得 `GameSession`、内容变量或存储。

| 操作或状态 | 当前接入 |
|---|---|
| 全屏按钮、F11、Alt+Enter | 同一显示请求；组合键、输入法和重复按键按明确条件处理，等待中不叠加按钮请求 |
| 浏览器游戏 | 全屏目标为整页，保留所有弹层及正常退出对话框；游玩区域占当前视口，设置/存档通过标题或底部操作栏打开，弹层内容可滚动 |
| 独立编辑预览 | 仅预览区域进入全屏，快捷键也只在该区域；编辑器其他控件不被纳入或触发全屏预览 |
| 浏览器 Esc | 当前区域全屏时先退出显示，不同时传给游玩菜单；浏览器自身退出全屏也由状态事件反映，不自动重新进入 |
| 原生 Esc/返回 | 保留既有菜单、弹层和退出流程，不改为显示退出键；显示退出仍用按钮或 F11/Alt+Enter |
| 不支持、拒绝或失败 | 明确显示状态，继续窗口游玩；原生缺少显示能力时不偷偷改走浏览器全屏 |

浏览器驱动在原用户操作中直接调用 `requestFullscreen`，以实际 `fullscreenElement` 和 `fullscreenchange` 确认状态，不把按钮点击当成成功。进入和退出失败显示可重试信息，其他区域已经全屏时不抢占它。

`refresh()` 同步状态和按钮；`reset()` 请求退出，停止预览会调用它。进入尚未完成时停止/销毁，原请求完成后接续退出，不把迟到进入当作新预览的选择。监听由消费者拥有，销毁取消订阅；退出只处理自身目标，不退出其他区域。当前焦点与页面滚动仅在本页内保存用于显示往返，已有弹层打开时不抢焦点。

全屏后的舞台继续由同一尺寸观察器缩放，场面、对白和选择沿既有横竖规则；进入/退出清理未完成手势与临时 Ctrl，不重建剧情、文字、音乐或有效计时。[游戏界面迁移](game-ui.md)将操作栏放在画面底部，按实际占用给对白/选择留位置；状态与媒体错误在画面可见，弹层长内容可滚动，并读取浏览器提供的安全区变量。没有宣称刘海屏、系统栏和所有尺寸已验收。

## 可选原生显示扩展

基础桥保持 `haifeng.host-bridge/3`，主线状态、音频焦点、返回键及退出协议不变。在桥上新增独立可选 `fullscreen` 扩展，协议为 `haifeng.fullscreen/1`；这不是持久记录版本，也不新增通用原生命令入口。

- 扩展的 `identity` 是本页临时随机身份；无法生成身份时仅此扩展不可用，不阻断基础桥。`read()` 返回支持情况、显示模式、待处理请求及问题。
- `request(active)` 只接受布尔目标，分配本页递增 ID；请求附带原页面身份。Windows 从本地桥读取请求，Android 只接受本地主框架的专用消息，均不接文件、网络、脚本或剧情参数。
- `receive()` 严格读取 `haifeng.fullscreen-state/1`，包含递增序号、显示模式、确认请求 ID/页面身份和可空错误。旧序号拒绝，只有匹配本页及本次请求的确认才能清除等待。
- 等待 8 秒未确认时显示超时，保留当前已知模式；新请求使用新 ID，原确认不能清掉后来请求。超时问题保留至明确重试或对应迟到确认，不由无关周期状态抹掉。
- 页面驱动独立检测显示状态超过 3500ms 未更新的情况；显示失败不改变剧情暂停、音频许可或已有写入。已有宿主状态通道继续独立决定真实失焦/后台暂停。

旧 `/3` 宿主没有此扩展或不报告支持时，显示按钮不可用，已有主线入口仍可用。要试用本片须用当前源码重新生成游戏包、准备目录和原生程序；没有改既有随包清单及准备格式，没有自动执行命令或覆盖旧目录。

## Windows

`desktop/src-tauri/src/rebuild.rs` 随已有窗口事件和每秒状态采样读取显示扩展，窗口操作仍只针对 `rebuild` 窗口。严格解析本页请求，在主线程按 ID 去重，调用窗口的 `set_fullscreen(bool)`；只有实际采样的 `is_fullscreen()` 与目标一致，或明确失败，才确认本次请求。

请求与原生页面代次绑定；页面换代、窗口销毁或回调超过 2 秒才到主线程时不采用原请求。状态和错误都经独立显示扩展返回，不开放旧 `/__host/`、Tauri 通用调用、远程导航或第二解释器。切全屏造成的焦点/尺寸事件继续走原生命周期接线，显示本身不是新暂停原因。

## Android

`RebuildActivity` 的 `__HAIFENG_NATIVE_DISPLAY__` 只接受固定来源的主框架及 `haifeng.fullscreen-request/1`。页面身份先由当前 WebView/页面代次确认；旧页消息、重复 ID、非法字段及超限消息不执行。后台、失焦或退出中拒绝切换并返回问题。

API 30 起通过 `WindowInsetsController` 请求隐藏系统栏并允许边缘滑动暂时唤出；较低系统沿用原生沉浸标志。进入前保留原系统栏相关设置，退出恢复所管理的位，不覆盖无关窗口标志。这里返回的是原生已接受的沉浸模式，临时系统栏出现不算退出该模式；不是已观测到每个设备的像素结果。

页面重载和错误页尝试恢复原系统栏；后台/恢复仍由既有宿主通道暂停/继续当前会话，Activity 重建不恢复此临时模式或猜剧情位置。没有引入依赖、HTML 视频自定义视图、横屏锁定或自动首次触摸全屏。

## 留待统一测试

以下尚未执行。使用[游戏](player.md#统一测试时的可视入口)、[编辑器](editor.md#入口与范围)及两端已有的[准备](windows.md#留待统一测试的命令)/[构建入口](android.md#统一测试阶段入口)：

1. 标题、普通对白和限时选择分别用按钮、F11、Alt+Enter 往返，确认标签与实际模式一致、选择只结算一次、变量/声音/剩余时间不因显示重建。
2. 浏览器 Esc 只退出全屏，之后再按才操作菜单；浏览器系统退出、拒绝请求或不支持时显示真实状态，无自动重新进入。长对白、选择、底部操作栏及设置/存档弹层仍可访问。
3. 仅预览区全屏，编辑输入不触发快捷键；进入请求中停止、换预览或关闭页面，迟到结果不遗留全屏/监听/临时 Ctrl，也不写玩家记录或作者源。
4. Windows 切换后核对窗口实际状态、焦点暂停、菜单/回看弹层、读档及退出等待；显示请求失败或状态超时不能冒充成功，旧页面确认不能关闭新请求。
5. Android 核对系统栏隐藏/恢复、边缘滑动暂显、返回键菜单顺序、后台/前台、旋转及重载；旧页请求不采用，已接受沉浸模式与设备实际显示须分别观察。
6. 两端断网重复切换，核对本地桥仍工作；游戏记录、手动进度、偏好及编辑草稿不因显示切换改变。退出等待对话框、媒体错误和返回标题在全屏内仍可操作。

当前只是显示能力迁移。后续[游戏界面切片](game-ui.md)已接底部操作栏；旧页面首次触摸自动进入全屏、横屏锁定、旋转提示及完整窗口设置仍未迁移或决定，没有以本片设置正式默认体验或完成 M5。
