# 精修图包接续标准

依据2026-10-16音乐负责人交付的《修复后CG图包.zip》和随后对两张勾脚踝候选的反馈。用户成品与本页分析须区分：这是对画面的观察与执行约束，不虚构队友未提供的提示词或生成过程。

## 这包图的主要改进

19张完整CG和1张白底P02基本保留原角色、服装、镜位、表情与事件，只调整尾巴的完整结构。尾根、尾柄、尾端能顺着同一条曲线读通；成对扁阔尾鳍有明确中央缺口，单叶、三叶和互相交叉的叶片减少。尾鳍上的白色圆形海洋纹样也比原图一致。人物和背景同时重绘，使接触阴影、光色和透视能服从同一空间。

不能把这总结成“尾柄越细越长越好”。用户随后明确否定拉长的勾脚踝画面：应把两人排近，让正常比例的尾鳍够到脚踝，而不是让尾巴迁就错误站位。

## 后续每张都要过的审核

1. **剧情动作**：先找到具体台词。接飞出的本子是单手拦住空中物体；不得变成双手递还。食物在说“门口放着”时就出现，不延后一两句。
2. **完整连接**：从她腰后尾根一路追到末端；尾巴不能长在男主裤腿上、凭空悬浮、接到头发上。两条人腿保持独立。
3. **比例与距离**：用同一画面中的人物身高作尺度，检查尾根厚度、收细过程、尾柄弧长和两叶总宽；不能只数“有两叶”就通过。接触动作先排近两人，再画尾巴，避免长绳或水管。
4. **尾端设计**：一根尾柄、一个末端连接、一对扁阔尾鳍、中央缺口。透视可以缩短远侧鳍，但不能画出第三叶。纹样附着同一片鳍的表面，跟随光照和透视。
5. **物体与手**：笔记本两半共用同一装订轴，页高与物理大小一致。内页与封面有区别，手指与抓握位置合理。鱿鱼必须能识别出躯干、触腕、烤痕，而不是一句文字占位。
6. **身体与服饰**：皮肤完整健康，情绪受伤不画成擦伤；裙摆连续，大腿/膝盖/脚部可顺着姿态理解。已明确保留人工处理的泳装不擅自换装。
7. **进游戏再看**：对话框、选项、取景动画可能挡住动作或裁掉物体，审核实际1440×900与960×540画面。图片单独漂亮不等于剧情成立。
8. **透明底与来源**：白底图不直接当立绘；检查发丝孔隙、白袜、鞋与边缘，透明化有杂点则退选。队友包没有模型与提示词记录，不继承旧图的生成参数来冒充新来源。

## 音效审核原则

用实际动作与材质配音，不给提到尾巴、拍水或风铃的所有句子自动加声。真实短音源优先；三下、五下要对应实际次数，离开本句取消余下调度。正常播放查声音是否实际起播、是否被音乐遮住；快进仍应静音，避免音效挤成一团。没有合适录音的拍身体、细小碰纸、柜台下轻拍等材质未确定的短声登记待补，不用程序提示音顶替。
