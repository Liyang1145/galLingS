# 共享播放器的局部约束

- `src/session.ts`、`src/clock.ts` 不依赖 DOM、网络、宿主或编辑器；浏览器实现只放 `src/web/`。Node 与 Web 类型检查范围保持分离，不为方便给纯模块开放 DOM。
- 剧情决策只通过 `story-runtime`。会话拥有串行输入、暂停原因、有效计时和取消；表现只能报告场面就绪、文字/语音完成和媒体问题。
- 应用分配递增会话代次；所有延迟回调核对呈现代次，推进操作再核对核心步骤。换节点、重试、离开及重开必须取消旧工作。
- 场面资源未就绪时暂停有效时间。菜单、后台、宿主、资源加载及错误是不同暂停原因，不能相互误解除。
- 原生/后台状态通过 `initialPauses` 在首次呈现前生效；读档及回退准备使用独立 `operation` 原因，完成准备不能解除真实宿主暂停。
- 媒体重试不重新进入剧情，不重播进入音效，不重置选择剩余时间。持续音轨保持同曲连续、换曲和停奏意图；一次性语音/音效属于当前呈现，不能遗留到下一节点。
- 检查点由会话在同一个串行操作中捕获核心状态、有效计时和表现数据；异步存储不得再拼接后续的实时状态。`checkpoint.ts`、`saves.ts` 保持无 DOM/宿主依赖，浏览器存储在 `src/web/`。
- 外部检查点先经唯一核心和封装校验，失败不改变当前会话或旧槽位。读档显式使用当前全局投影，不采用旧档投影覆盖成果；准备成功后换会话代次并取消旧工作，恢复不发进入或结局事实。正式语音默认体验和回退边界仍待决定，试播语音方式由本次调用者明确指定，见 `docs/rebuild/saves.md`。
- `records.ts` 管全局成果，不接受进度槽位覆盖。事实重试保留交付 ID，结局解锁与通关计次原子合并；记录失败不冒充已保存。开发、预览与正式记录分别隔离。
- 对白回看只持有当前会话的文字副本，实际接受的选择在后续对白之前记录；媒体重试不重复追加。`history` 暂停原因独立于菜单、后台与宿主，关闭回看只解除自身暂停。读取或关闭回看不发剧情命令或全局事实，不据此定义进度回退边界。
- `rollback.ts` 只管理有界的会话内检查点；容量由调用者显式提供，跨选择与语音方式由本次操作显式给出，不内置正式默认。首次稳定及离开前在会话队列中捕获，准备成功才由唯一核心恢复并截断未来历史；核心步骤与呈现代次更新使旧回调失效。恢复不重入，已解锁成果不回滚；媒体错误在已恢复位置重试。
- `src/web/package.ts` 只消费严格校验的随包清单与规范化内容；基址由宿主页面显式给出，资源映射保持包内相对位置。启动先校验剧情字节及修订，失败不开始会话或回落旧实现；不预加载全部媒体，不把启动校验写成安装或媒体验收。
- `src/web/host-bootstrap.js` 是两端原生在页面脚本前注入的最小桥；平台标记由明确宿主装配替换，保持来源约束、初始暂停及递增序号。桥不含剧情逻辑，返回键只能交给应用处理菜单或弹层。
- 根规则仍适用：不自动测试、构建、审查或启动子代理；本目录规则不额外授予验证、推送或发布权限。
