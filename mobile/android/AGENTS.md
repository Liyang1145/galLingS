# Android 宿主局部约束

- 遵循根入口及 `docs/rebuild/android.md`。`:app` 是保留的旧试玩模块；`:rebuild` 是新共享前端的独立集成模块，不把新增模块当成发行切换或宿主统一决定。
- 新模块只接 `android:prepare` 生成的隔离输入，不复制旧解释器、插件或 `AndroidHost` 接口，不直接读取作者 `game.js`。不要手改生成 assets 或将素材来源目录搬入模块。
- 生命周期和返回键通过共享宿主桥接到游戏应用；宿主不推进剧情、不改变量。初始暂停、递增序号、页面代次及离开取消必须保留，异常不得切换旧运行实现。
- 使用随包 `/2` 和桥 `/2`；拒绝混用旧准备目录。状态投递确认、有限重试和前台刷新不得变成剧情计时器；音频焦点通道只接受本地主框架的请求/释放，旧焦点回调按代次拒绝。
- WebView 只提供本地 HTTPS 包内资源，启动前注入桥须显式检查支持；不因为兼容旧 WebView 而降为文件 URL、延后到剧情已启动才接线或开放远程页面。
- 进度和全局记录保持分开，当前 IndexedDB 仍是试播范围。进程重建回标题，不能拿 WebView 浏览历史冒充剧情恢复，也不能声称关闭应用自动保存。
- 本机 SDK 路径、Gradle 缓存、编译物、密钥和玩家数据不提交。不改旧试玩发布流程，不自行签名发布或编版本号；工具环境与命令见实施文档。
- 不自动执行 Gradle、SDK 安装、模拟器、设备操作、构建、测试或额外审查；此文件不授予新权限。
