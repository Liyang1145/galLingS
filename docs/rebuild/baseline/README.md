# 固定迁移基线

来源是 `2dfda33ea1eed1c98d6f37ab147bf2a96026b50b` 的作品数据；与实施开工头 `2a0c0a7` 的作品文件一致。这里只保存身份与静态内容记录，不复制媒体，不是新作者源或已生成的游戏发行包。

| 文件 | 含义 |
|---|---|
| `inventory.json` | 作品身份、关键源文件 SHA-256、变量、字段使用计数和能力统计 |
| `nodes.json` | 全部节点 ID、原顺序、标签、章节与结局定位 |
| `assets.json` | 全部资源 ID、原种类、路径与已有来源元数据；不表示文件存在或授权已验收 |
| `choices.json` | 旧无 ID 选项的一次性稳定 ID 分配及原内容对照 |

选项首次分配为 `choice-000001` 起的作品内稳定 ID，映射明确记录原节点和原选项内容。**以后不按文字、顺序或下标重算身份。** 转换器须核对映射；内容变化必须显式维护映射，模糊或不匹配时拒绝，不静默分配新 ID。原选项位置仅用于本次身份分配和来源定位，不是运行身份。

这些文件由本次源数据提取写入，不是自动化校验结果。未逐个检查资源文件、解码、路线、宿主或媒体听感。根入口由新协作规范接管；旧规范保留在重建前的 Git 历史中，不复制过期权限。
