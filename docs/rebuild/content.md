# 使用旧作者源构建新内容

实现位于 `tools/content/` 和 `packages/story-model/src/`，唯一输入仍为 `海风与布丁/game.js`。**尚未执行本入口；没有全量转换、资源完整性或运行通过结论。**

## 手动生成内容

在仓库根、满足[环境要求](README.md#真实命令与环境)后，由用户选择运行：

```powershell
npm run content:build
```

入口只接受 `window.VN_GAME = {...};` 的纯 JSON 包装，绝不执行作者 JavaScript。失败会输出带文件、节点和字段的诊断。资源路径须位于本地作品目录，符号链接越界会拒绝；不联网补资源。

成功时生成不可手改的 `dist/content/<内容修订>/story.json` 和 `resources.json`。读取全部登记资源并计算 SHA-256，登记不等于已安装；任一缺失资源会阻断此入口。相同修订目录已存在时不会覆盖，当前实现会报告写入失败并保留原目录。临时生成目录失败后清理，不删除作者文件。

这是**内容阶段产物**：资源文件尚未复制进该目录，manifest 明确标记源资源基址，不可直接作为 Windows/Android 游戏安装包。[游戏随包入口](delivery.md)复用同一来源读取器，另外装配前端并复制资源，不改变这条命令的内容阶段职责。

## 协议与来源

`haifeng.story/1` 是内部内容格式标识，不是产品版本号。作品 ID、节点 ID、资源 ID、中文变量名、节点顺序保留；入口显式来自首个章节节点。没有给游戏编发售版本。

| 输入 | 发行模型 |
|---|---|
| 声明变量初值 | 显式解析为 number/boolean/string，固定类型；当前 `"0"` 转数值 0 |
| 节点 `set` | 进入动作数组；表达式树不包含任意代码 |
| 标签跳转 | 构建时解析为节点 ID；缺失/重复标签拒绝 |
| 无 ID 旧选项 | 固定映射按原节点与原内容核对；不随重排生成新 ID；有歧义或映射残留拒绝 |
| `ctime/cdef` | 毫秒时长和稳定默认选项 ID；不可用默认项明确报错，不暗选第一/最后项 |
| `bg/sprites/mood/bgm/ambience` | 完整目标场景；空音乐显式停奏；相同曲目继续意图独立于资源文件路径 |
| `trans/fx/acts/voice/seEvents` | 演出、语音和一次性声音与稳定场景分离 |
| `_musicCue/motionCount/amb*` | 明确保留为来源提示，不伪称已有表现消费者 |
| 资源附加字段、作品元数据与设置 | 原样 JSON 来源记录，不作为新核心指令 |

已知节点、选项、立绘、音效字段之外出现扩展字段会阻断转换，不能开了再存就丢失。根作品元数据及资源元数据作为来源保留。新的可写跨局变量、主线 Agent 节点尚未实现，出现时明确拒绝。

`packages/story-model/src/content.ts` 现提供 `readStoryContent(unknown, file?)`，读取规范化 `haifeng.story/1` JSON。它逐字段校验格式、变量及初值、受限表达式树及类型、可写动作、节点和选项身份、目标、限时默认项、媒体种类、完整场景、演出参数和来源；未知字段明确拒绝，不把外部 JSON 断言成 `StoryContent`。

表达式限制 128 层嵌套与每棵树 4096 项，复用已有表达式类型规则。数据读取保持节点、选项和资源数组顺序，不执行进入动作、不创建剧情核心、不加载媒体。表现枚举仍由具体表现适配器报告支持范围，不在读取时静默过滤作者指令。

`packages/story-model/src/package.ts` 提供随包清单读取和作品/资源身份核对；`integrity.ts` 提供共享的规范化序列化和内容修订输入。M1 内容修订算法保持原有字段及排序，作者原文件哈希仍独立追溯，不把随包安装位置加入剧情修订。`loadSourceContent` 额外返回固定选项映射文件的摘要，供产物来源记录使用。该函数现在读取原文件后调用 `compileSourceContent(bytes)`；[独立编辑入口](editor.md)的候选预览和保存复用同一转换与资源读取，不增加另一套内容解释规则。

这些读取器已经编写；浏览器接入和游戏产物状态由[随包加载说明](delivery.md)维护，不由本页宣称已运行。内容阶段的 `resources.json` 仍不是随包游戏清单。

作者 `settings.uiSe` 仍在来源设置中保留；共享表现及会话创建时通过纯[提示音映射读取器](feedback.md)校验已配置资源身份及字段，显式 `favorVar/tailVar` 须指向声明的数值变量。当前接选择、限时循环、手动存档、变量/CG/话末、事务首次解锁结局及操作按钮反馈；不更改规范化剧情或内容修订格式。

资源的 `audioCategory/auditionOnly/name/dur/playbackGain` 仍保留在原元数据中，由共享[声音收藏读取器](audio-library.md)消费实际标记和字段，目录/混音共用同一规则，不猜分类或改变内容格式。当前共享目录及独立试听已编写，页面接入状态见专门说明，未运行验收。

作者 `settings.theme/cover` 仍在来源设置中原样保留，由纯[外观读取器](appearance.md)消费，检查字段、枚举、颜色、有限数值及图像资源种类。旧入口中的已采用鲸鱼 SVG 则由独立装配只读提取，保留原字节并计入前端/来源摘要，不新增剧情资源 ID 或第二作者源；运行端不执行旧页面。

`packages/story-model/src/references.ts` 已编写已校验内容的[只读结构索引](references.md)，按带类型的稳定身份查节点/资源/变量/选项/立绘/结局使用位置，不执行条件或动作、不推断路线可达性；编辑页可附当前对白草稿及共享播放器实际消费的设置引用。`text.ts` 提取原对白占位规则，查询与唯一核心填充共用；未知名字仍保留原文，查询中标明未解析。没有改变内容格式、修订算法或作者写回范围，未运行验收。

`author-history.ts` 的纯 `AuthorDraftHistory` 已接编辑页，按同一源摘要、已有字符串和原值管理当前草稿及有界[撤销/重做](editor.md#草稿撤销与重做)。单字段和导入沿用原修改协议，导出仍只有当前修改，不增加历史字段、磁盘写入或剧情接口；未运行验收。

## 受限表达式的有意差异

支持字面量、声明变量、只读 `周目/结局数`、括号、一元 `!/-`、四则运算、比较与逻辑组合；修改仅 `= / += / -=`。字符串加法只接受两侧字符串；数值运算不隐式转换字符串。未知变量、类型冲突、除零、非有限数值不会像旧实现那样默认零或警告后继续。

当前作品实际使用数值增减、赋值及简单比较，因此不靠旧导入器的整数正则限制新模型。新解析器使用常规一元运算优先级；未来若出现旧语法 `!x > y` 等歧义表达式，必须先显式加括号确认含义，不作为默认兼容承诺。运行中的表达式错误由核心保持旧状态并报告，不能部分执行。

内容修订由规范化内容与实际资源校验值共同生成；对象键顺序和源 JSON 空白不参与修订，节点/选项顺序参与。原文件 SHA-256 单独保留以追溯。元数据当前也参与保守修订，尚未提供跨修订兼容映射。
