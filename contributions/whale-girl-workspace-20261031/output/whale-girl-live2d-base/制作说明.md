# 全身 Live2D 底图 v1

当前交付为 1024 × 1536、带 alpha 通道的合并 PNG，使用内置 image_gen 生成。不是分层 PSD、Cubism 工程或可运行模型；未进行游戏内运行验证。

生成提示词概要：依据两张参考保持蓝发、蓝眼、环形呆毛、蝴蝶结、鳍耳、鲸鱼图案连体泳衣、白色外搭、凉鞋及单条鲸尾；正面全身自然站姿，手臂略离躯干，闭嘴微笑；尾巴从骨盆后方连接并绕向侧后方；透明背景、柔和中性光、清晰动漫线稿，避免道具遮嘴、肢体错误和环境背景。

后续制作要求：
- 手工拆分并补绘遮挡区：脸、耳、颈、躯干、左右上下臂与手、双腿与脚、外搭前后片、前后发束、呆毛、饰品、尾根／尾身／尾鳍。
- 眼睛拆分眼白、虹膜、瞳孔、高光、上下眼睑；口部另绘闭口、张口和口腔，不能直接拉伸整张脸代替。
- 在 Cubism 中制作网格与变形器，绑定眨眼、眼球、口形、头部角度、呼吸及发尾物理；站立时避免脚底漂移、尾根脱离骨盆。
- 输出真实 moc3、model3.json、贴图及所需 physics3.json，再在目标游戏运行时检查。不得以改名 PNG 或空 JSON 冒充 Live2D 模型。
