## 当前实现

`packages/player/src/session.ts` 在当前游戏会话内维护 `DialogueEntry`：

- 进入节点时记录实际求值后的说话人与台词，保留节点及章节定位；空台词不占记录。
- 唯一核心接受选择后，先记录实际选项与是否超时，再记录目标对白。拒绝、过时点击或重复超时不追加选择。
- 媒体重试不追加同一对白；实际再次到达同一节点属于新的出现记录。
- 恢复进度后从当前保存的完整台词开始新的回看，没有把全局已读集合伪造成当前路线对白。
- 沿用旧播放器回看最多 300 条的容量，统一限制对白和选择，只存文字数据，不存图片、播放对象或检查点。该容量不代表尚未确定的回退历史容量。

`GameSession.dialogueHistory()` 返回分离后的数据副本，`SessionView.dialogueCount` 供界面更新入口状态。回看不是可写的核心引用，也不携带回退或语音播放回调。当前切片不提供历史语音重播。

## 试播接入

`apps/game/` 的“对白回看”打开只读对话框，按实际出现顺序显示最近台词和选择。文本通过 `textContent` 渲染，不当作 HTML 执行。

打开前通过同一会话队列加入独立的 `history` 暂停原因，暂停文字、声音及有效计时。关闭按钮与 Esc 只解除该原因；菜单、后台、媒体错误或宿主暂停继续有效。对话框打开期间不向剧情发送空格、方向键或自动播放快捷操作。

新开、读档、返回标题及页面离开会清理旧回看。记录仅属于当前会话，不写进进度槽位、全局记录或聊天记录；读档清空本片内存回看，不等于已经决定正式产品的历史持久化范围。

## 统一测试时确认

以下是预留情景，本轮未执行，不要求用户现在试玩：

1. 在普通对白和一次选择后打开回看，核对台词变量替换、选项文字及先后顺序；超时选择应标明来源。
2. 限时选择中打开回看并停留，关闭后确认仍在同一节点、变量未变、选择时间未消耗这段暂停时长。
3. 回看期间切后台再关闭回看，或在菜单暂停时打开再关闭，确认各项暂停不会互相解除。
4. 媒体重试不重复记录；新开或读档只显示新会话记录，普通入口与限时样例不互串。
5. 长时间推进后最多保留 300 条，打开和关闭回看不增加周目、结局或 CG 成果。
