# 选择与存档提示音

从 `e4ff34a` 接续共享会话和分轨音量。本片已编写作品原配置的选择出现、选择确认、限时选择循环声、超时反馈及手动存档成功提示音，游戏和编辑预览复用同一会话/表现实现。没有安装、启动、测试、类型检查、构建、额外审查、子代理或听感验收。

## 配置与归属

`packages/player/src/ui-sounds.ts` 定义纯数据 `InteractionFeedback` 和 `readUiSounds(content)`，只读作者 `settings.uiSe` 的资源 ID。配置缺省或明确为空时保持无声，不生成提示音、不改素材和作者文件。实际存在的非空映射须指向登记的 `se` 资源，错误带作者文件及字段定位；未知配置字段明确拒绝。

读取器认识旧配置的全部键，以保留既有来源。当前只消费以下五项：

| 配置键 | 当前触发来源 | 恢复/重复处理 |
|---|---|---|
| `choiceShow` | 正常进入节点后第一次达到可见选择阶段，且场面已经就绪 | 暂停刷新、自动按钮刷新、媒体重试、读档与回退不重复播 |
| `choiceConfirm` | 唯一核心实际接受点选后，由 `chosen` 事实触发 | 旧步骤、重复点击或被拒命令不播 |
| `timeoutTick` | 已就绪的当前限时选择所需循环声音 | 跟随当前暂停/许可/音量；不是选择计时器，不驱动超时结算 |
| `timeoutSilence` | 唯一核心实际接受超时默认选择后触发 | 与点击竞争只有被接受者发反馈；当前作者未配置此项，保持留白 |
| `save` | 独立试播手动检查点保存事务完成后 | 失败、只读查看、实际读档及全局记录/偏好保存不触发 |

变量变化、CG、话末、新结局及按钮点击/悬停对应的 `favorUp/favorDown/tailfin/cg/chapterEnd/endingNew/btnClick/btnHover` 已按资源身份读取，但尚未接触发消费者；`favorVar/tailVar` 只校验并保留在原内容来源中。不能把读取器认识全部键写成全部交互音已迁移。按钮声音开关也未接入本片偏好。

## 会话与表现接口

`PresentationAdapter` 可提供 `interaction(feedback)`，无声音的表现消费者可省略；它只接收声音事件，不计算剧情流转、条件或变量。`WebPresentation` 将事件交给当前 `AudioMixer`，游戏及独立编辑预览无需另写选择规则。

会话按一次节点访问记录选择是否已经提示，并区分正常进入与恢复。场面加载完成且核心进入 `choosing` 后才请求选择出现声；同一步骤的重复发布不发第二次请求。媒体重试保留本次已提示状态；读档和回退直接恢复已生效位置，不发一次性选择出现声。恢复后的限时循环声可以重新建立，依旧使用检查点剩余有效时间。

实际选择被接受后先停止当前循环声，再请求对应确认/超时提示；没有先响声再猜命令是否成功的路径。菜单、后台、宿主、回看、操作准备及退出暂停均通过既有会话暂停控制音轨。选择离开、错误暂停、呈现重建、返回标题及会话销毁会结束本次循环；加载结束后只按当前选择状态重建，不重算剧情。

手动保存捕获当前会话和表现身份，提交成功后仅在本次请求仍有效、仍是同一会话/表现、没有进入退出协调或快进时尝试播放。等待期间改为另一会话、返回标题或被新请求取代，不向后来会话播原保存提示。声音失败不能把已提交的存档改报为保存失败。保存成功时如处于声音暂停状态，提示被跳过，不在关闭菜单后补播。

## 混音与生命周期

交互声音使用现有“音效”通道，实时音量、宿主声音许可与会话暂停仍由同一混音器管理；BGM、环境声和语音无需另建。循环声不保存到检查点，也不属于场景环境声，不能因读档残留到没有限时选择的场景。

一次性提示触发时如正在暂停、没有声音许可或音效音量为 0，直接跳过。浏览器拒绝播放的一次性提示移除，不加入“启用声音”之后的重放队列；焦点丢失时也移除一次性提示。已经开始的提示可随普通会话暂停继续，媒体重试及恢复会清除旧提示，离开会话则全部取消。已接受选择的短确认声可跨正常节点切换，避免被紧接着的新节点取消截断。

`timeoutTick` 表示当前仍在进行的选择，暂停时暂停声音；音效调至 0 则停止循环，调回非零时仅在当前选择仍有效、未暂停且有许可时重新创建。播放或资源失败显示非阻断媒体问题并停止本轮自动重试；“启用声音”可显式重试当前循环。循环加载、解码或重播均不改变选择剩余时间、默认项或点击/超时的一次结算。

剧情一次性音效与交互一次性提示共享最多四路及同 ID 开头 400 毫秒内的重复抑制；限时循环单独最多一路。结束的音轨释放，返回标题和销毁释放全部声音。缺失文件、解码或播放拒绝沿用可见的非阻断诊断，不切换解释器或补下载素材。

## 留待统一测试

使用[独立试播入口](player.md#统一测试时的可视入口)，本轮没有执行：

1. 正常游玩至选择，确认出现提示只响一次；反复打开菜单、切后台、切换自动，不重复出现提示。
2. 在限时样例等待，打开菜单或切后台后回来，核对声音和有效倒计时一起暂停；实际点击与超时只产生一次被接受的反馈和变量结算。
3. 将音效调为 0，经过选择后再调高，确认过期出现/确认提示不补播；如果当前仍在限时选择，则只恢复当前循环。
4. 在选择处保存并读档、回退或媒体重试，确认选择出现声不重放，当前循环只保留一路，剩余选择时间没有重置。
5. 手动存档成功时确认提示，失败时没有成功提示；保存期间返回标题、重开、读另一档或取消退出，确认旧保存不会对新会话响声。
6. 浏览器拒绝播放或宿主拒绝焦点后再启用声音，确认不补播旧一次性提示，当前限时循环可重新尝试；反馈失败不阻止继续或改变已经提交的存档结果。
7. 在独立编辑器预览真实选择节点，确认共享选择声音与暂停行为一致，预览仍不写正式成果或玩家偏好；重复重开/停止预览没有残留循环。

资源配置校验和接线不等于完整演出迁移或听感通过；其余交互提示、正式 UI 与两端验收仍待接续。
