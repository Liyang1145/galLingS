# 共享游玩输入与隐藏界面

从 `9d0aa78` 的干净工作区接续原方案第 8、9、19 节，将旧播放器已有的点击、键盘、长按与回看手势接到同一游戏会话。游戏和独立编辑预览均已接线；只编写实现、文档并本地提交，未安装、启动、类型检查、测试、构建、额外审查、子代理或验收。

## 接口与归属

`packages/player/src/web/input.ts` 的 `PlayerInput` 接收舞台、场景、选择区、外部操作栏、隐藏按钮、键盘作用域，以及当前 `GameSession` 的读取函数、输入许可、声音解锁、菜单和可选回看回调。

- `next()`、`toggleAuto()`、`toggleSkip()` 把意图交给当前共享会话；`menu()`、回看交给应用已有入口。输入层不计算条件、变量、选择、已读或超时结果。
- `toggleHidden()` 管显示，`reveal()` 只恢复显示并返回是否消费了这次操作。应用可在原生返回键打开菜单前调用；隐藏不是新的暂停原因。
- 应用在会话状态更新后调用 `refresh()`，新开、读档采用、返回标题或停止预览时调用 `reset()`，销毁时调用 `dispose()`。状态读取不采用存档中的界面隐藏、按键或指针状态。
- 游戏键盘范围为本页；编辑器只包含预览舞台及预览操作栏。制作输入、草稿、文件操作和保存按钮不属于预览快捷键范围。

`session.ts` 同时保留旧操作栏的自动/快进互斥规则：打开自动会关闭快进；请求打开快进会关闭自动，即使当前未读保护拒绝实际快进，也不保留原自动模式。已有的未读和选择限制继续生效，不新增跨未读或代答能力。

## 当前操作

| 操作 | 行为与边界 |
|---|---|
| 点画面、空格、Enter、→、“继续”按钮 | 提交同一 `next`；文字未完成时由会话补全，已完成才继续。界面隐藏时仅恢复显示，不补字或跳句 |
| A、“自动”按钮 | 切换自动；不代选，等待仍由共享会话的有效计时管理 |
| 按住 Ctrl | 当前可操作且非选择阶段时请求快进已读；松开最后一个 Control 键停止本次临时快进。左右 Control 键按各自按键身份登记 |
| “快进已读”按钮 | 显式切换快进，并接管临时 Ctrl 模式；此后松开原按键不会关闭按钮明确开启的模式 |
| H、画面右键、“隐藏界面”按钮 | 切换隐藏；舞台内的选择、标题、菜单及其他交互控件不被当作画面右键 |
| 触屏或笔长按 | 稳定按住 550ms 后切换隐藏；移动超过 12px 取消长按。设备支持时尝试 15ms 振动，失败不影响操作 |
| 场面向下滑 | 下移超过 60px 且大于横移绝对值的 1.5 倍时打开对白回看；只在应用提供回看入口时启用 |
| 画面滚轮向上 | 打开对白回看；Ctrl/Meta 滚轮不接管，选项区和可滚动长对白保留自己的滚动 |
| Esc、“菜单/暂停”按钮 | 未处于浏览器全屏时，隐藏先恢复显示，否则调用已有菜单/暂停入口；加载、媒体错误及终态仍保留菜单入口。浏览器全屏的 Esc 优先由[显示控制器](fullscreen.md)处理 |
| Android 返回键 | 已有弹层优先关闭；界面隐藏时只恢复显示，之后再沿用既有菜单/退出处理 |

文本编辑、输入法组合、重复按键事件不触发游玩快捷键；常规按钮的空格/Enter 保留浏览器按钮激活，避免同时推进剧情。Alt/Meta/Ctrl 组合不映射为普通继续、自动或隐藏命令。焦点离开预览范围或进入编辑输入时释放临时快进。

独立编辑预览复用同一控制器和生命周期，但没有提供对白回看回调，所以下滑/滚轮回看不启用。没有自动迁移旧 ArrowLeft 回退键：正式回退边界和语音方式仍按[显式回退入口](rollback.md)处理。自动全屏、旋转提示、方向锁定和完整正式触控栏仍未接入。

显式全屏按钮/F11/Alt+Enter 已由后续[共享显示切片](fullscreen.md)接入，显示控制器不持有剧情接口。实际显示变化时清理未完成手势/临时 Ctrl，不重建会话；原生 Esc/返回键继续按本页菜单/弹层处理。

## 隐藏及取消

隐藏时对白和选择不可见，场景与选择区设为 inert，其他游玩操作按钮不可见且 inert；外部“显示界面”按钮保留。原来处于被隐藏区域的焦点移到该按钮，避免留下不可访问的焦点。当前页面的状态、诊断与设置面板仍是开发控件，隐藏功能不把它们变成正式游戏 UI。

隐藏只改变显示和交互许可，自动播放、限时选择、声音及剧情有效时间继续按原状态运行。菜单、回看、后台、宿主暂停、正常退出、结局或会话替换会恢复界面并取消未完成手势；内部图片加载暂停单独处理，不因正常换场加载而自动显示或释放临时快进。

Ctrl 只拥有它发起的临时模式；若按钮已经开启快进，按下再松开 Ctrl 不接管该按钮模式。失焦、后台、外部暂停、选择、停止或换会话均清理临时所有权，不在回到页面时自动重新按下 Ctrl。

每个触屏/笔手势捕获原会话对象和 `{session, epoch, step}`。换步骤、加载、读档、重开、多指或离开会取消原长按；正常短点在后续点击到达时再次核对原身份，旧操作不能转成新会话输入。重置保留待到达点击的身份，供迟到点击拒绝使用。

长按、拖动、下滑及取消之后的同指针合成点击最多抑制 350ms，避免恢复界面或打开回看后再跳一句；新的物理按下会清除此旧抑制，即使新按下落在选择按钮也不吞掉明确的新点选。可滚动对白和选择不参与手势接管，场面禁用图片拖拽。定时器与监听由控制器生命周期拥有，销毁取消监听并恢复原 inert 状态。

本片不增加存档、全局成果、玩家偏好或宿主协议字段；隐藏、手势、Ctrl 所有权和输入监听均不持久保存。作者剧情、素材与旧入口未改。

## 留待统一测试

本轮没有执行。统一测试时使用[游戏入口](player.md#统一测试时的可视入口)及[独立编辑入口](editor.md#入口与范围)：

1. 在普通对白点画面、用空格/Enter/→继续，再聚焦操作按钮激活；确认补字/继续只有一次。编辑文字或使用输入法时不得推进预览，焦点回到预览画面后快捷键才生效。
2. 用按钮、H、右键、长按分别隐藏；点画面或按继续只恢复，不额外推进。用 Tab 可找到“显示界面”，不可聚焦隐藏选择；原生返回先恢复显示。自动或限时选择期间隐藏不会暂停，菜单和后台仍按已有规则暂停。
3. 在有已读的位置按住并松开 Ctrl，再切后台、切焦点、打开菜单、读档、重开及停止预览；临时快进不能遗留。先点按钮开快进再按松 Ctrl，以及临时快进中用按钮接管，核对所有权与自动互斥；未读和选择仍拦住快进。
4. 场面下滑/上滚只打开当前回看；长对白、选择列表保留滚动。长按/拖动结束不顺带继续，之后明确点选新选择仍有效；预览不触发不存在的回看入口。
5. 长按中换节点、读档、媒体重试、后台、多指或离开；旧长按和后续合成点击不作用于新位置。图片或声音失败时仍能开菜单、返回标题，不因输入门控卡在错误画面。
6. 横竖切换与小舞台上重复上述操作，核对滚动、焦点、触控和按钮声音；游戏成果、手动档及编辑草稿不因显示/输入操作被重写。
