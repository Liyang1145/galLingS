根 AGENTS.md 要求开工读取本文件。本文件统一原根规则与六份局部约束；目录专用条目仍仅约束其原目录，不扩大任务权限。用户最新要求与更高优先级指令优先，历史材料不授予新权限。

## 协作与授权

- 先读当前用户要求，确认实际分支、git status 和相关 diff，保留他人改动；不 reset、覆盖或重写历史来匹配旧快照。
- 2026-10-26 用户明确授权将 rebuild 通过保留双方历史的普通合并提交并入 main。重构分支阶段已结束，main 为新的集成基线，后续工作分支按当前任务安排；原“只在 rebuild、不在 main 合并”的阶段限制退出。提交继续使用简短中文，推送与发布仍按用户授权执行。
- 小步实现，每个独立交付只暂存相关文件并提交，随后确认提交状态。提交说明使用简短、易懂的中文。不擅自 push、创建 PR、合并、发布、启用工作流或改写历史。
- 项目交付游戏本体，只有一个 TypeScript 剧情核心；必要资源安装完成后主线完全离线。Windows、Android 是首批目标。编辑器独立，预览复用正式运行实现；联网聊天不是主线前置。
- 已有一次性测试、构建或启动授权不自动延续。没有新授权时，不自动测试、构建、类型检查、代码审查、启动子代理或独立复核；列出命令不等于执行授权。实际已通过范围见项目总览，不能把原生未验收写为通过。
- 没有旧存档，不做旧档兼容、迁移或下标兼容，不再为旧档提出审批或保留旧宿主。当前新格式的版本、修订、损坏校验继续保留。
- 正式包使用 game/main，两端默认原生文件；开发、预览、聊天与正式范围隔离。编辑器扩展暂停，存档体验扩展、正式回退规则和异常退出自动恢复后置；模型供应、费用、正式聊天解锁及分发决定仍由用户确认。
- 2026-10-26 用户授权按清点建议减少文档、集中放置。本次授权覆盖归并/删除冗余文档和必要引用维护，不授予测试、构建、服务、素材删除或发布权限。素材来源与授权事实必须保留。

## 不可破坏的工程契约

- 新版本只有一个 TypeScript 剧情核心，拥有节点、变量、条件、选择、流转及结局。禁止在同次游玩遇错回落到旧 JS 或 Rust 解释器。
- 变量变化反馈读取核心已提交的选项/进入分组结果，不在表现重新执行动作或只以整个跳转的总差猜测；变化输出不进入检查点或全局成果。
- 游戏会话串行协调输入、步骤、取消、有效计时及一致检查点；表现不修改变量；平台不定义剧情规则；编辑器不另写解释器。
- 隐藏界面不暂停，下一次继续只恢复显示；自动和快进互斥。Ctrl 临时快进、触屏手势须归属原会话/步骤，松键、失焦、外部暂停或换会话清理；编辑输入不得触发预览快捷键。
- 全屏只使用显示驱动，不进入剧情、检查点或偏好；确认依据浏览器状态或匹配页面/请求的原生回执。原生缺少可选显示扩展只禁用此操作，不回落浏览器全屏或阻断基础桥；不得据此启用自动全屏/方向锁定或开放通用宿主指令。
- 核心不依赖 DOM、音频对象、网络、宿主或编辑器。依赖由应用指向共享模块；通过公开接口协作，不暴露全局可写内部状态。
- 保留剧情、节点和资源身份及顺序、变量、选择、结局、音乐继续与停奏语义。工程变化不夹带文本、美术或音频改版。
- 恢复不是重新进入，不重复进入动作、一次性音效或结局事实。点击和超时只结算一次，旧步骤回调必须拒绝。回退恢复检查点，不反算变量。
- 区分剧情进度、玩家记录、偏好设置、预览记录与聊天记录。没有旧存档，不做旧档导入/迁移或下标兼容；开发/正式/预览/聊天范围仍隔离，新记录的格式/修订/损坏校验保持。
- 存档目录只列举当前作品及范围，损坏或不兼容记录保留可见诊断；选择名称、翻页或查看不采用进度。手动保存及失败重试始终使用原捕获的入口、槽位、检查点和时间，不能随后来选中的名称改变目标。
- 手动保存准备重新读取原槽位，有键即显示原目标覆盖确认，损坏/不兼容值不当空槽，读取失败不交付写入。取消/关闭/换会话使未采用准备失效；确认后原载荷才进入写入跟踪，重试不重采或重新绑定授权。存在性观察不是跨页面原子检查/替换，不据提示扩展持久协议或冲突规则。
- 两端默认原生文件，仅接本作品 `game/main` 登记地址，加载前检查客户端能力；浏览器与开发入口用各自范围的 IndexedDB，页面不能指定路径、切正式宿主到其他记录源或发通用文件命令。确认丢失报告 `NATIVE_STORAGE_UNCONFIRMED`，保留原队首、阻止后续越过，不显示已保存或肯定未写入；迟到回执不自动完成此前失败操作或授予退出，显式重试仍用原载荷及原事实 ID。
- 周目、结局与 CG 解锁全局保留，主页鉴赏读取这些成果；读档只恢复当局进度，不能用旧快照覆盖全局记录。规则与计次来源见全局玩家记录说明。
- 鉴赏只消费已提交成果和当前目录，不接剧情或记录写入；锁定图片不创建或请求。缩略图/大图重试固定原资源，关闭、换图、重开使旧加载/解码失效；图片失败不删除解锁，重开仍重新读取成果，不能因旧响应弹回已离开的鉴赏。
- 新结局反馈只能读取本次已提交事务的首次解锁回执，并匹配当前会话/结局；旧会话迟到结果及同批重试不能产生新提示。回执不持久保存，不改变通关计次或聊天解锁规则。
- 结局卡片只消费核心终态和应用提供的原批次提交摘要，不自行结算、读写成果或授予聊天入口。仅到达结局不能显示已保存，普通脚本结束及隔离预览也不能冒充通关解锁；离开/重试回调核对原会话令牌。
- 玩家声音偏好与作者增益分开；调音只更新现有音轨，不重建剧情或重播声音。偏好按作品及范围独立保存，进度恢复不能覆盖；预览不读取正常游玩偏好。
- 阅读偏好不改变剧情规则或当前计时：逐字间隔用于后续呈现，自动倍率用于后续自动等待；字号与对话框透明度即时应用，读档与回退仍保留检查点中的剩余有效时间。
- 话末数值只追加原匹配存档点的已生效变量，剧透开关缺省关闭且独立保存；本次显示文字和自动等待长度一起捕获，改变开关不重打当前句或重计时。核心正文、回看、存档摘要和全局成果不加入这些显示文本；恢复用当前偏好，仍优先采用检查点剩余时间。显示来源中的旧 soul 字段不能启动联网/Agent，绑定引用与实际读取共用。
- 按钮声音是独立布尔偏好，声音沿用音效轨道。应用明确列出游玩操作按钮，选择与存档各由实际接受/提交事件反馈；暂停、快进、标题、终态或离开时不触发按钮音，编辑预览不读取玩家开关。
- 回看试听只使用当前会话保存的语音资源身份及独立声音实例，不替换主线语音、释放主线等待或改变进度。后台/宿主/其他暂停、关闭回看及离开取消试听，恢复许可不补播；试听不进入进度、全局成果或聊天。
- 主页声音收藏只读作者标记，不新设解锁或预载全库；独立实例最多一段，分类/增益与混音共用读取规则。已有收藏试听随后台/宿主/声音许可暂停后原位置接续，关闭/离开取消并释放主页焦点；初始无许可/零音量拒绝，不排队补播。它沿用正常入口音量，不采用样例偏好或接剧情/成果写入。
- 章节试阅只从当前原章节起点以声明初值、周目 1/结局数 0 开始，条件持续明示，不冒充此前路线。它复用同一共享会话/核心，每次新内存已读，不写进度槽位、全局成果或聊天；章节设置与第一话/限时样例分开，返回标题采用正常入口值。不能据此决定正式章节解锁或把试阅结局当通关成果。
- 作者外观与已采用的皮肤覆盖关系须分别保留：原配置 `cover.menu=left` 不能推翻最终右侧鲸鱼菜单。图形从明确来源保留原字节，装配不执行旧页面；对白字号采用作者基准乘玩家倍率，不改存档或计时。
- 外部内容、存档、宿主消息和网络数据进入模块时校验；错误携带来源及节点定位。不用 `any`、默认零或静默丢字段掩盖未支持语义。
- 当前作者源保持单一；生成物修生成入口，不手改副本。正式切换源需记录切换提交与映射，不长期双写。
- 引用查询只消费已校验内容及实际播放器设置解析；对白占位语法与唯一核心共用。定位核对源摘要和草稿代次，规范化字段路径不冒充原作者 token 位置；零引用不证明无消费者，不能据此删除来源或扩大写入范围。

## 安全、交付与维护

- 不提交凭据、私人配置、玩家资料、机器绝对路径或不相关资源；不默认上传存档或聊天记录。素材来源与授权记录必须保留。
- React/Vue、宿主是否统一、编辑器选型、分发方式和模型供应仍未决定。不把实现便利写成产品决定；旧档兼容已明确不做，不再列为待决策。
- 交付写清目的、影响文件、接口/格式变化、兼容影响、未完成项和简短人工试用方法。区分“已实现”“已接入”“待试用”“已验收”；没有执行的检查不得写成通过。
- 修改目录、命令或契约的人同步维护根入口及本目录对应主题文档；模块事实由修改者维护，产品与权限决定由用户确认。维护责任不附带发布或审批权限。
- 文档集中维护于 docs/；目录差异写入本文的适用范围，不重新分散局部入口或建立逐任务台账。

## 历史工具边界

一次性生产脚本用于追溯某轮制作，不因保留而成为可重复运行的当前工具。写死旧 game.js、下标、旧基线或旧采纳目标的脚本不改接为新源写入入口，也不重跑回灌。新采纳直接面向分章作者格式独立实施；生成物修生成入口，不手改副本。

## 适用目录：`packages/player/`

- `src/session.ts`、`src/clock.ts` 不依赖 DOM、网络、宿主或编辑器；浏览器实现只放 `src/web/`。Node 与 Web 类型检查范围保持分离，不为方便给纯模块开放 DOM。
- 剧情决策只通过 `story-runtime`。会话拥有串行输入、暂停原因、有效计时和取消；表现只能报告场面就绪、文字/语音完成和媒体问题。
- 应用分配递增会话代次；所有延迟回调核对呈现代次，推进操作再核对核心步骤。换节点、重试、离开及重开必须取消旧工作。
- 场面资源未就绪时暂停有效时间。菜单、后台、宿主、资源加载及错误是不同暂停原因，不能相互误解除。
- 原生/后台状态通过 `initialPauses` 在首次呈现前生效；读档及回退准备使用独立 `operation` 原因，完成准备不能解除真实宿主暂停。
- 媒体重试不重新进入剧情，不重播进入音效，不重置选择剩余时间。持续音轨保持同曲连续、换曲和停奏意图；一次性语音/音效属于当前呈现，不能遗留到下一节点。
- `web/presentation.ts` 的背景镜头沿用旧缩放/时长范围，`shot.focus` 只管缩放中心，不替代 `view.position`；恢复直接采用稳定场面，快进清除镜头。转场与瞬时特效分别使用遮罩，共用当前呈现的暂停/取消通道；无背景也是已有场面，不能用空背景 ID 判断首次。`web/scene-fade.ts` 只复制显式同舞台的直接子图层，去除 ID、自动焦点、监听与交互，静止并保留隐藏/滚动。主线快照只接场面/对白/选择，一次最多一个，失败/取消/快进清理，优先于背景转场；不延后核心或有效计时，范围见 `docs/player.md#performance`。
- `web/stage-fade.ts` 只拥有界面副本及视觉帧/定时/动画，接显式图层和许可，不持有会话、存储或有效时钟。异步准备成功后、采用界面前才捕获；新事务使旧归属失效，旧解码/完成不能清理新副本。现有标题/暂停菜单/终态沿原 360ms 淡出，菜单自身暂停不能冻结旧菜单；后台/宿主/退出/快进/尺寸/全屏/离开取消，减少动态效果跳过或清理。终态保存状态刷新不反复采样，不复制外部弹层或编辑制作区；失败只能是视觉提示。
- `web/camera.ts` 的场面镜头由背景 ID 及已校验参数归属，同背景正常换句只暂停并接续，不因单句取消跳到终点或重播。它不持有旧呈现上下文/步骤，完成只核对原归属并释放自身句柄；换背景/快进/销毁先失效原归属，恢复/重试/终态采用稳定目标。旧 `Playback` 暂停/快进必须拒绝失效调用，镜头帧不进入存档或驱动有效计时。
- `web/motion.ts` 保留原角色动作/进退场的关键帧时刻、方向、时长及每段缓动，不把 CSS 分段缓动改成整个时间轴的缓动。角色移动/高度和滤镜由当前呈现动画拥有，不用恢复时会重新触发的 CSS 过渡；说话焦点用亮度/饱和度滤镜，目标顺序更新层级，软切副本保留旧位置并归原呈现清理。快进/恢复/重试/减少动态效果直接采用稳定目标，不写存储或改变有效计时。
- 瞬时镜头也按原分段帧执行，只移动背景/立绘的 `scene-layers`，氛围覆盖、闪光/转场遮罩和对白不跟着移动或被场面滤镜染色。持续氛围沿原 CSS，用真实细节子节点使暂停覆盖气泡/脉冲，同名节点不重建时间轴；恢复不重播瞬时效果，有限慢推近直接采用终点。减少动态效果保留静态场面，闪烁层不得留下不透明黑色；快照冻结气泡位置，不加入帧级存储。
- 检查点由会话在同一个串行操作中捕获核心状态、有效计时和表现数据；异步存储不得再拼接后续的实时状态。`checkpoint.ts`、`saves.ts` 保持无 DOM/宿主依赖，浏览器存储在 `src/web/`。
- `web/native-records.ts` 仅适配现有存储接口，严格校验存在标记、回执、分页及存储代次；CAS 冲突有界重读并调用原 TS 仓库回调，不另写领域规则。`web/native-records-bootstrap.js` 供显式 Windows/Android 文件试用共同注入，平台标记决定受限主页面来源，固定本页作品/身份及队首原载荷，迟到/重复回执不能采用到新请求。确认丢失保留原队首、阻止后续越过并报 `NATIVE_STORAGE_UNCONFIRMED`，不等于成功或肯定未写入；重试与退出仍沿原操作流程。两者不向纯模块开放 DOM，不因文件失败切换记录源，详见 `docs/delivery.md#native-storage`、`android-storage.md`。
- 外部检查点先经唯一核心和封装校验，失败不改变当前会话或旧槽位。读档显式使用当前全局投影，不采用旧档投影覆盖成果；准备成功后换会话代次并取消旧工作，恢复不发进入或结局事实。正式语音默认体验和回退边界仍待决定，试播语音方式由本次调用者明确指定，见 `docs/storage.md#saves`。
- `SaveRepository.list()` 只在本作品/范围内按地址有界分页，完整检查后返回摘要，损坏地址或不兼容载荷返回诊断；不得静默省略、采用到会话或改写槽位。列表摘要不能替代读档时重新读取和校验；存储须区分不存在的键与已存在但值为 `undefined` 的损坏记录，后者不能按空记录初始化。
- `SaveRepository.target(slot)` 只重新读取该原地址的存在性及共用摘要，已有损坏/不兼容/`undefined/null` 返回已占用诊断，存储异常直接上抛；不按目录缓存猜空槽，不返回可采用检查点或写入许可。此观察不是预留或原子检查/替换，不借显示确认扩展进度 CAS、格式或自动触发。
- `records.ts` 管全局成果，不接受进度槽位覆盖。事实重试保留交付 ID，结局解锁与通关计次原子合并；记录失败不冒充已保存。开发、预览与正式记录分别隔离。
- `recordWithReceipt()` 的首次结局列表须在同一全局事务内判定，提交后才返回，失败/重试已有批次不能冒充新解锁；回执是瞬时结果，不加持久字段。应用按原批次与当前会话/表现/终态匹配，`ending-unlocked` 只确认反馈，不写剧情或再计次。终态 `end/setPaused` 保留声音生命周期，返回标题和销毁仍取消全部轨道；静音或退出跳过的提示不补播。
- `web/ending.ts` 只显示 `SessionView` 终态及显式 `EndingRecordState`，不能调用剧情/存储或以节点流转重放结局；只有 `committed` 摘要可宣称已保存。预览、不含结局的脚本末尾与待确认分开，离开/重试只交原令牌意图给应用；重复状态更新保留按钮/滚动，不重复改写相同播报文本，清理取消旧监听。
- `preferences.ts` 保持无 DOM，只管理独立声音偏好及作者默认解析；稀疏通道修改在事务中合并，不进入检查点或全局成果，不覆盖损坏记录。保存重试使用原捕获修改，后来未保存的调整仍保留。混音器分离玩家音量与素材/场景/渐变增益，实时调音不重播或重置渐变；0 音量触发的一次性音效不积攒补播。
- `reading-preferences.ts` 是独立阅读协议，不复用声音、进度或全局记录键。`auto-wait` 意图只更新后续自动等待的倍率，不重置当前等待、限时选择或恢复剩余时间；表现捕获本次呈现的逐字间隔，字号/透明度可即时更新，不重建场面或文字。
- `appearance.ts` 严格读取作者主题/封面，保持无 DOM；`web/appearance.ts` 只向给定舞台写受限样式，现有鲸鱼皮肤覆盖通用主题的关系保留。应用/预览使用同一图形和作者坐标，不在预览另设字号/选择样式；字号基准取作者值再乘阅读倍率。收藏装饰类型与剧情资源身份分开，原图标形状从 `content/game-ui` 独立定义只读装配并登记迁移来源，原配乐图片仍读原文件，不能运行旧解释器或用另一张图片替代。封面加载独立取消，失败可重试且不推动剧情；对白图片未就绪归属当前场面错误，不重入。
- `web/choices.ts` 只显示会话已经给出的可见选项，点击原令牌和稳定选项 ID 仍交回共享会话；不自行求条件、排序或计时。时间/暂停更新保留按钮及滚动，换步骤/清空取消旧监听。`web/stage-layout.ts` 只管理同一舞台比例、小屏单位及横竖分区，游戏/预览共用；容器尺寸与内部布局单向更新，不以输出反改容器尺寸。缩放/旋转不能重建会话、文字、声音或剩余计时；竖屏的显示高度不改变 1280×720 作者场面和人物坐标，正式 UI 的验证范围见项目总览。
- 游戏壳可向 `connectStageLayout` 提供可选底部操作栏，仅测量真实占用以避开对白/选择；隐藏界面保留占用，观察不改会话或计时。不传操作栏的编辑预览保持原布局；游戏弹层的原会话暂停归属由应用持有，不加入共享核心或存储。
- `web/button-label.ts` 只向按钮可选的 `data-player-label` 直接子项写显示文字，保留图标、按钮身份与监听；无标签槽时沿用纯文本控件，不改变游戏/编辑预览动作、读屏名称或显示确认规则。
- `web/input.ts` 只向当前会话提交意图，菜单/回看由应用回调接续；自动/快进互斥仍由共享会话执行。隐藏不暂停，下一次继续只显示，保留可访问的显示按钮；临时 Ctrl 只解除自身发起的模式。手势及迟到触屏点击核对原会话/令牌，生命周期重置不得抹去待拒绝点击的身份；新物理按下不得被旧手势抑制。输入、焦点及隐藏不进入检查点/存储，销毁恢复 inert 并取消监听；回退策略不在键盘层猜定。
- `web/fullscreen.ts` 只管理受限显示驱动、控件、焦点与布局；浏览器进入须保留原用户激活，不以按钮点击冒充成功或退出其他区域。停止/销毁须处理迟到进入并取消监听，显示改变清理输入手势而不重建会话或有效时间。`host-bootstrap.js` 的可选 `haifeng.fullscreen/1` 扩展保持基础 `/3`，临时页面身份、递增请求和确认匹配；失败/超时不影响基础桥、剧情或存储，不接受通用原生动作。
- 设置可通过 `PlayerFullscreen.additionalControls` 绑定同一驱动的额外按钮/状态及只读模式输出；不创建第二控制器、重复订阅或合成点击。同一按钮拒绝重复绑定，切换在原点击栈提交以保留浏览器用户激活；所有控件共用原支持/等待/确认，清理归原消费者，不读取或保存显示偏好。
- `button-preferences.ts` 管独立布尔开关及稀疏事务合并，不向既有严格音量/阅读格式加字段。`web/button-sounds.ts` 只绑定应用明确给出的操作按钮，鼠标悬停不受子元素重复进入影响；按消费者生命周期取消监听。应用核对当前会话、开关、暂停与快进，混音器继续执行许可/音量门控；选择和存档不能同时套一般按钮音。
- `readout.ts` 只从原话末存档点标记及核心已生效变量构造可选剧透正文；绑定按旧 uiSe/soul/名字优先序校验，soul 仅为显示字段来源，不启动联网或 Agent。`readout-preferences.ts` 使用独立布尔协议，缺省关闭、false 保留、null 跟随作者默认；损坏记录不能覆盖，不向现有严格偏好、进度或成果加字段。
- 会话每次呈现固定 `readout` 显示副本，普通自动等待用同一正文长度；`readout` 意图仅更新后续开关，不重打当前文字、重置当前/恢复剩余时间或执行动作。核心视图、回看及槽位摘要保持原文，检查点不加偏好字段；编辑预览只用作者默认。只读引用必须复用实际绑定来源，不能用声音变量引用替代数值显示引用。
- `readCompletions()` 只从重新读取的已提交全局记录提供作品、范围、解锁结局及逐次通关引用；不混入进度槽位、待写事实、路线变量或准确通关时间。通关后模块只接这个最小读取能力，不持有全局写入或剧情接口。
- 对白回看只持有当前会话的文字、语音资源 ID 及当次 `visitId` 副本，实际接受的选择归属原访问并在后续对白之前记录；媒体重试不重复追加。条目回退只按 `visitId` 匹配仍保留的目标，显式意图经应用刷新投影后交回原 `rollback()`，不按节点 ID、文字或列表位置猜检查点。`history` 暂停原因独立于菜单、后台与宿主，读取或关闭回看不采用进度或写全局事实；关闭取消尚未采用的条目回退准备，但不撤销已经完成的恢复。
- `AudioMixer.previewVoice()` 只由回看等只读消费者以独立混音实例使用，不在剧情表现的混音器上调用；只接受登记的 `vo`，最多保留本次试听，错误/结束不发主线 `voiceEnded`。消费者在关闭、换句、前后台/许可失效时取消原试听；迟到播放/错误不能污染后来试听或自动补播。实时语音音量沿用当前独立偏好，不捕获试听位置到检查点。
- `audio-library.ts` 只读已校验资源的显式 `audioCategory/auditionOnly` 及显示/试听元数据，保留原顺序；不猜分类、读取存储或预加载。`AudioMixer.previewLibrary()` 在独立已清空实例重新用同一读取器确定分类、通道和增益，配乐/环境循环、音效单次，不接剧情或检查点；开始时无许可/暂停/零音量拒绝，旧回调归原试听，不能给主线实例套试听报告。
- `chapters.ts` 只读原非空章节标记和节点顺序，不合并同名标题或推断路线/解锁。准备只接受真实章节起点，临时入口修订与声明初值、周目 1/结局数 0 必须明确，不读取玩家记录/存档或执行进入动作；实际试阅仍用同一共享会话及唯一核心，不新增解释器或存档迁移。
- `rollback.ts` 只管理有界的会话内检查点；容量由调用者显式提供，跨选择与语音方式由本次操作显式给出，不内置正式默认。首次稳定及离开前在会话队列中捕获，准备成功才由唯一核心恢复并截断未来历史；核心步骤与呈现代次更新使旧回调失效。恢复不重入，已解锁成果不回滚；媒体错误在已恢复位置重试。
- `src/web/package.ts` 只消费严格校验的随包清单与规范化内容；基址由宿主页面显式给出，资源映射保持包内相对位置。启动先校验剧情字节及修订，失败不开始会话或回落旧实现；不预加载全部媒体，不把启动校验写成安装或媒体验收。
- `src/web/host-bootstrap.js` 是两端原生在页面脚本前注入的最小桥；当前 ABI 为 `haifeng.host-bridge/3`，平台标记由明确宿主装配替换，保持来源约束、初始暂停、递增序号及失效保护。桥不含剧情逻辑，返回键只能交给应用处理菜单或弹层；音频通道仅允许请求/释放焦点。
- `src/web/windows-audio-bootstrap.js` 只在 Windows 本地主文档装配 `haifeng.audio-output/1`；许可复用原 `readAudio` 状态，独立序号/代次及当前页/请求回执校验。首次初始化或精确原请求确认才可采用授权，设备变化、换页、超时/旧回执不自动续播，释放取消候选许可；当前页已确认稳定许可不因完成的正常离开而无端撤销。页面关闭清理计时/请求，不读写偏好/进度、不持有媒体或剧情状态；新宿主按登记的 Windows 客户端能力要求匹配前端，基础桥 `/3` 不升级。
- `writes.ts` 只跟踪显式写入，失败重试复用原捕获载荷及显示名称，不重新读取当前进度。`track` 返回绑定原操作的显式重试句柄，完成/被新操作替代/仍进行中不能重试；退出批量重试沿同一实例，不能改绑后来同键操作。只读 `view/subscribe` 不暴露操作闭包、键、检查点或错误对象，观察者异常不能改变写入结果；消费者清理自己的订阅，摘要和操作完成都不能授权退出或冒充存档提交。正常退出使用独立 `exit` 暂停，等待写入和全局事实完成；票据取消不能撤销存储事务或解除其他暂停，不等于自动存档或强杀恢复。
- 宿主声音许可与会话暂停分别管理；未获准不播放，语音不可用不得卡住自动阅读，一次性音效不得积攒到稍后补播。焦点中断后恢复当前声音，不重入剧情或重发进入事实。
- `ui-sounds.ts` 校验作者提示音映射，并把核心已提交的分组变量变化及目标背景/话末转换为纯声音计划，不计算剧情或执行表达式。选择反馈来自被接受的核心事实及每次访问首次就绪，恢复/重试/重绘不重复发一次性提示；循环声只跟随当前选择与暂停，不驱动结算或进入检查点。变量提示延迟使用有效计时并归属本次呈现，换节点/恢复/错误/快进/离开取消。交互播放失败不阻断主线，不把已提交保存改报失败；未播一次性提示不积攒到启用声音时补放。
- `references.ts` 保持无 DOM，只用既有外观/提示音/反馈变量读取器提供实际消费设置的结构引用，默认封面及反馈变量明确标记派生；不猜任意元数据中的资源 ID，不改变播放器状态或加入作者写入接口。

## 适用目录：`packages/chat/`

- 本模块独立于剧情核心和主线会话；包含只读通关上下文、独立聊天会话及显式 HTTP 接入，事实和缺口见 `docs/chat.md#chat`、`docs/chat.md#agent`。

- 上下文逐条绑定某次通关事实，不自动选择最新结局或合并多条路线。当前记录只有结局事实，不能从存档、已读集合或变量初值补造历史路线。
- 当前内容修订只作引用定位，不能写成达成结局时的历史修订。预览范围不能作为聊天准备依据；开发记录不得冒充正式游玩成果。
- 结构校验不证明玩家已解锁；按原作品和范围重新读取已提交事实后才能准备上下文。客户端本地记录也不是未来服务端鉴权或付费凭据。

- 流式事件只接收有序、匹配原请求的文本与终态；模型输出永远不是工具或主线命令。取消、关闭、换上下文及超时立即拒绝旧回调，不等待服务端合作才恢复本地操作。

- 聊天只保存在本页独立内存，离开清空；这不是持久聊天记录、长期记忆或远程删除功能。增加持久化或正式入口需另外接线并维护隐私和身份边界。

## 适用目录：`apps/editor/`

- 本目录是对白编辑试用切片，命令和限制见 `docs/editor.md#editor`。DOM 实现不决定最终框架或编辑器选型。
- 唯一作者源是 `content/story/project.json` 登记的分章文件；草稿相对整个登记文件集合的原摘要修改字段，不生成第二套长期维护的剧情源。写回仍只开放原有 `speaker/text`，不因源切换扩编辑能力。
- 草稿由纯 `AuthorDraftHistory` 管理；历史只绑定已读取源的可编辑字符串，保存/重读成功后重建基线，失败保留。连续同字段输入可合并，还原节点及一次导入各为一步；新实际修改截断重做，撤销/重做使导入比较、引用和待采用预览按草稿代次失效。历史按步数及保守文字量有界，超大操作清空无法连续恢复的旧链并明确提示；不写磁盘或玩家进度，不拦截输入框原生撤销快捷键。
- 只允许现有 `speaker/text` 字符串修改，不在本片扩展节点、选项、变量或素材写入；未知字段由共享转换器保留或拒绝。
- 节点目录按实际作者顺序每页 200 项浏览全部匹配结果，搜索继续读取当前说话人/对白草稿；缓存绑定内容对象、草稿代次和查询词。翻页/搜索不改当前节点或写草稿，筛选外/其他页当前项明确置顶；显式匹配定位才进入目标页，不清除查询。读取/保存禁用分页，监听/缓存随页面清理，不接预览输入/全屏/按钮声音或服务端新能力。

- 使用随包 `/2` 和桥 `/3`；拒绝混用旧准备目录。状态投递确认、有限重试和前台刷新不得变成剧情计时器；音频焦点通道只接受本地主框架的请求/释放，旧焦点回调按代次拒绝。
- `GameAudioFocus` 独立拥有原生焦点及输出变化监听，Activity 只转发前后台/显式请求并发布快照。输出变化中断经原宿主暂停及声音许可通道处理，后台/焦点回来不能清除这类中断；仅显式前台请求或释放当前声音会话清理。广播、申请回调及监听须按控制器生命周期失效，不把声音恢复变成重入剧情、改变量或补播一次性提示。
- 标题页正常退出须等待本次票据确认已有写入完成，失败或超时保留应用；重复返回可取消。该流程不能代替自动检查点或系统回收恢复，页面/WebView 换代必须拒绝旧关闭结果。
- 可选显示扩展只通过本地主框架的专用消息接收布尔目标、页面身份和请求 ID；先确认当前页身份，旧页和重复请求拒绝。全屏只控制系统栏并恢复相关原设置，状态指原生接受的沉浸模式；不改变返回键、剧情暂停或存档，不擅自锁定方向或自动首触全屏。
- WebView 只提供本地 HTTPS 包内资源，启动前注入桥须显式检查支持；不因为兼容旧 WebView 而降为文件 URL、延后到剧情已启动才接线或开放远程页面。
- `PackagedMedia.java` 只按已登记媒体位置/长度流式提供 GET、HEAD 和单段字节范围；每请求独立流、读取不越过本段，关闭释放原流。无效/多段/条件范围不猜首段，不可满足范围返回 416；未知媒体或读取失败不得回落网络、旧文件或另一解释器。它不设置播放位置、计算有效时间或写入进度，真实 WebView 续播仍待统一验证。
- 进度和全局记录保持分开，正式包使用 `game/main`；进程重建仍回标题，不能拿 WebView 浏览历史冒充剧情恢复或声称自动保存。存档体验、回退和异常恢复扩展后置。
- `:rebuild` 普通启动即使用私有 `files/records/`，不再读取存储 extra；只允许本作品 `game/main` 地址。先核对包用途 `game` 和客户端能力，单一线程成功打开后才加载，失败不换源或迁移开发记录。准备 `/3` 继续登记两份桥摘要，并要求 `storage: native-files/game`，不改游戏包 `/2` 或基础桥 `/3`；历史试用包须重新构建/准备。
- `NativeRecordBridge` 只观察本地主入口的受限队首，按加载代次、页面身份、单调 ID 缓存原请求/回执；重复不得重新执行，迟到不得采用到新页。确认丢失沿 `NATIVE_STORAGE_UNCONFIRMED` 保留队首、不越过、不授权退出；后台/正常退出等待仍可投递，销毁排完已开始操作后释放锁。没有 `addJavascriptInterface`、路径、删除或通用文件命令。
- `NativeRecordStore.java`、`NativeRecordAddress.java`、`NativeRecordJson.java` 只处理登记逻辑地址、原样 JSON 和完整容器提交/CAS，不定义剧情或成果合并；同步方法只由工作线程调用。目录与文件拒绝符号链接，已提交后的清理/目录同步失败须作为警告；已编写接线不等于运行或自动恢复。
- 本机 SDK 路径、Gradle 缓存、编译物、密钥和玩家数据不提交。旧试玩工作流已清退，不恢复或启用自动交付，不自行签名发布或编版本号；工具环境与命令见实施文档。
