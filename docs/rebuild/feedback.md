## 配置与归属

`packages/player/src/ui-sounds.ts` 定义纯数据 `InteractionFeedback` 和 `readUiSounds(content)`，只读作者 `settings.uiSe` 的资源 ID。配置缺省或明确为空时保持无声，不生成提示音、不改素材和作者文件。实际存在的非空映射须指向登记的 `se` 资源，错误带作者文件及字段定位；未知配置字段明确拒绝。

读取器认识旧配置的全部键，以保留既有来源。当前已消费：

| 配置键 | 当前触发来源 | 恢复/重复处理 |
|---|---|---|
| `choiceShow` | 正常进入节点后第一次达到可见选择阶段，且场面已经就绪 | 暂停刷新、自动按钮刷新、媒体重试、读档与回退不重复播 |
| `choiceConfirm` | 唯一核心实际接受点选后，由 `chosen` 事实触发 | 旧步骤、重复点击或被拒命令不播 |
| `timeoutTick` | 已就绪的当前限时选择所需循环声音 | 跟随当前暂停/许可/音量；不是选择计时器，不驱动超时结算 |
| `timeoutSilence` | 唯一核心实际接受超时默认选择后触发 | 与点击竞争只有被接受者发反馈；当前作者未配置此项，保持留白 |
| `save` | 独立试播手动检查点保存事务完成后 | 失败、只读查看、实际读档及全局记录/偏好保存不触发 |
| `favorUp/favorDown` | 核心已提交的选项动作组及进入动作组中，配置好感变量的数值变化 | 初始化、恢复和重试不发；下降沿用相对增益 0.75 |
| `tailfin` | 同一动作组中配置尾鳍变量实际增加 | 没有变化或减少时不播；不读取默认零或重算表达式 |
| `cg` | 正常进入时背景发生变化，且目标符合共享鉴赏 CG 规则 | 不要求首次解锁；同一背景连续节点、开局和恢复不重复播 |
| `chapterEnd` | 正常进入有文字的结局节点，或下一顺序目标带章节标记的普通节点 | 选择/分支节点不猜话末；初始呈现及恢复不发 |
| `endingNew` | 当前会话的结局事实在事务中首次加入全局解锁，并已提交成功 | 已有结局、同批重试、旧会话迟到回执、鉴赏、预览及恢复不触发 |

按钮点击/悬停对应的 `btnClick/btnHover` 已按资源身份读取，但尚未接触发消费者；按钮声音开关也未接入偏好。不能把读取器认识全部键写成全部交互音已迁移。首次结局反馈以事务回执为准，不从页面缓存、存档或再次到达结局猜测。

`favorVar/tailVar` 显式配置时须指向已声明的数值变量；省略时分别使用既有 `好感/尾鳍` 名称，有对应数值变量才消费。缺少默认变量时不报假变化，显式配置无效则带来源拒绝。此设置只选择反馈对象，不改变剧情变量定义或可写性。

## 会话与表现接口

`PresentationAdapter` 可提供 `interaction(feedback)`，无声音的表现消费者可省略；它只接收声音事件，不计算剧情流转、条件或变量。`WebPresentation` 将事件交给当前 `AudioMixer`，游戏及独立编辑预览无需另写选择规则。

会话按一次节点访问记录选择是否已经提示，并区分正常进入与恢复。场面加载完成且核心进入 `choosing` 后才请求选择出现声；同一步骤的重复发布不发第二次请求。媒体重试保留本次已提示状态；读档和回退直接恢复已生效位置，不发一次性选择出现声。恢复后的限时循环声可以重新建立，依旧使用检查点剩余有效时间。

实际选择被接受后先停止当前循环声，再请求对应确认/超时提示；没有先响声再猜命令是否成功的路径。菜单、后台、宿主、回看、操作准备及退出暂停均通过既有会话暂停控制音轨。选择离开、错误暂停、呈现重建、返回标题及会话销毁会结束本次循环；加载结束后只按当前选择状态重建，不重算剧情。

手动保存捕获当前会话和表现身份，提交成功后仅在本次请求仍有效、仍是同一会话/表现、没有进入退出协调或快进时尝试播放。等待期间改为另一会话、返回标题或被新请求取代，不向后来会话播原保存提示。声音失败不能把已提交的存档改报为保存失败。保存成功时如处于声音暂停状态，提示被跳过，不在关闭菜单后补播。

## 分组变量变化与本次呈现

`RuntimeResult.variableChanges` 是动作实际执行后的输出。每组包含 `origin: choice/enter`、原节点及变化项的 `name/before/after`；选择组还带稳定 `choiceId`。同一动作组内先改后还原的变量没有净变化，不形成提示；选项动作加值而目标节点又减回时保留两组结果，不能以跳转前后总差抵消。

数组只随整个命令成功提交返回。目标进入、表达式或描述失败时返回空数组，并保留原运行状态；初始化、恢复和拒绝命令也返回空数组。它不是待执行动作、全局成果事实或可重放日志，不写入进度/全局记录，不改变任何存储格式。终端逻辑试播只额外显示分组结果，仍无声音。

纯 `StoryFeedback` 缓存当前内容的节点话末标记和共享鉴赏 CG 目录，把已提交的动作分组转换成声音计划；不运行条件、表达式或变量赋值。会话在目标场面第一次就绪后采用本次计划。选项变量提示延后 300 毫秒；进入节点存在即时动作音效时，变量提示避让 350 毫秒，否则随场面就绪触发。旧播放器只对独立 `se` 做这项避让，新规范化模型将即时 `seEvents` 也视为即时动作声；这是本片明确的调度差异，未进行听感验收。

延迟使用既有有效计时，按本次呈现代次归属，普通文字完成的核心步骤变化不会误取消它。菜单/后台/宿主暂停已安排的延迟；换节点、重试、恢复、错误、快进或销毁取消旧计划及计时。场面在其他暂停中才就绪时跳过本次计划，不在后来关闭菜单时补播。快进进入未读节点而停止时，按新场面的实际非快进状态采用提示。

读档、回退和媒体重试不重新生成这些一次性计划；已经保存的变量差异、CG 解锁或文字回看也不是新的声音事件。编辑预览复用同一规则，只反映本次内存剧情结果，仍不写正常游玩的成果。

## 首次结局解锁与终态反馈

`PlayerRepository.recordWithReceipt(batch)` 在原全局记录读写事务的合并回调中判定本批首次加入的结局，事务提交后返回 `{records, receipt:{batchId,newEndingIds}}`。失败/中止不交付回执；同批重复交付或后来再次达成已有结局时，首次解锁列表为空。并发页面以事务读取的最新值为准，不能各用旧缓存声称首次解锁。既有 `record(batch)` 仍只返回记录，持久化格式及计次规则均不改变。

`PlayerRecordWriter` 的提交回调增加回执参数。应用只为含结局事实的待提交批次保留本页会话代次/表现身份；回执完成即移除这份关联，离开页面清空。当前会话、表现和结局必须都匹配，且不是退出协调，才经队列发送 `ending-unlocked`。旧会话即使在后来才保存成功，也只更新全局成果，不向新会话播放。

会话校验步骤标识、终态结局 ID，并在本次会话最多确认一次；`SessionView.newEnding` 只是这次首次解锁已提交的显示状态，不写进度档。页面据此显示“新结局已保存，可从主页鉴赏”。音效音量 0、没有声音许可或暂停时可以不响，但已提交事实和显示状态仍保留；后来启用声音、关闭菜单或再次发布视图不补响。仅因退出/旧身份而未采用的回执也不在后来补播。

`PresentationAdapter` 新增可选 `end(PresentationEndContext)` 及终态 `setPaused()`。`end` 取消进入表现、语音、音乐、环境声、一次性效果及循环，但保留终态反馈能力；没有该能力的消费者沿用销毁行为。`WebPresentation` 结束后只接受 `endingNew`，禁止重启剧情呈现，并继续响应音量、声音许可及菜单/后台/宿主/回看/退出暂停。返回标题、重开、读档或页面销毁仍完整 `dispose()`，取消终态声音和迟到回调。这里沿用新试播此前结束时停止剧情声音的行为，不增加结局音乐方案。

终态声音错误通过专用非阻断回调报告，不复用已取消的最后一句呈现信号。声音失败不改报全局保存失败，不撤回解锁，也不增加通关次数。回执及本页关联不是持久通知队列：提交后崩溃、关闭页面或身份失效可能没有提示，但解锁以数据库成果为准，不承诺跨进程声音“恰好一次”。限时样例与编辑预览不提交正常游玩结局事实，因此不播放这项首次解锁提示。

## 混音与生命周期

交互声音使用现有“音效”通道，实时音量、宿主声音许可与会话暂停仍由同一混音器管理；BGM、环境声和语音无需另建。循环声不保存到检查点，也不属于场景环境声，不能因读档残留到没有限时选择的场景。

一次性提示触发时如正在暂停、没有声音许可或音效音量为 0，直接跳过。浏览器拒绝播放的一次性提示移除，不加入“启用声音”之后的重放队列；焦点丢失时也移除一次性提示。已经开始的提示可随普通会话暂停继续，媒体重试及恢复会清除旧提示，离开会话则全部取消。已接受选择的短确认声可跨正常节点切换，避免被紧接着的新节点取消截断。

`timeoutTick` 表示当前仍在进行的选择，暂停时暂停声音；音效调至 0 则停止循环，调回非零时仅在当前选择仍有效、未暂停且有许可时重新创建。播放或资源失败显示非阻断媒体问题并停止本轮自动重试；“启用声音”可显式重试当前循环。循环加载、解码或重播均不改变选择剩余时间、默认项或点击/超时的一次结算。

剧情一次性音效与交互一次性提示共享最多四路及同 ID 开头 400 毫秒内的重复抑制；限时循环单独最多一路。结束的音轨释放，返回标题和销毁释放全部声音。缺失文件、解码或播放拒绝沿用可见的非阻断诊断，不切换解释器或补下载素材。

## 留待统一测试

使用[独立试播入口](player.md#统一测试时的可视入口)，本轮没有执行：

1. 正常游玩至选择，确认出现提示只响一次；反复打开菜单、切后台、切换自动，不重复出现提示。
2. 在限时样例等待，打开菜单或切后台后回来，核对声音和有效倒计时一起暂停；实际点击与超时只产生一次被接受的反馈和变量结算。
3. 将音效调为 0，经过选择后再调高，确认过期出现/确认提示不补播；如果当前仍在限时选择，则只恢复当前循环。
4. 在选择处保存并读档、回退或媒体重试，确认选择出现声不重放，当前循环只保留一路，剩余选择时间没有重置。
5. 手动存档成功时确认提示，失败时没有成功提示；保存期间返回标题、重开、读另一档或取消退出，确认旧保存不会对新会话响声。
6. 浏览器拒绝播放或宿主拒绝焦点后再启用声音，确认不补播旧一次性提示，当前限时循环可重新尝试；反馈失败不阻止继续或改变已经提交的存档结果。
7. 在独立编辑器预览真实选择节点，确认共享选择声音与暂停行为一致，预览仍不写正式成果或玩家偏好；重复重开/停止预览没有残留循环。
8. 走实际好感/尾鳍变化路线，对照核心返回的选项组和进入组，确认上升/下降及尾鳍增加提示分别正确；在草稿预览中构造选项先加、目标节点再减的情景，确认没有被跳转前后总差吞掉。
9. 延迟变量提示尚未发生时立即换节点、回退、读档或返回标题，确认旧声音不进入后来场面；菜单/后台暂停期间不消耗延迟。媒体重试和恢复不重播变量/CG/话末提示。
10. 正常进入 CG、继续相同背景、离开后再次进入，分别确认切换提示、同背景不重复及再次进入可提示；首次开局/所选节点初始化不冒充一次新的 CG 切换。
11. 正常进入话末及结局对白，确认 `chapterEnd` 在本次场面就绪时触发，选择/条件分支不被误判话末；首次结局只在全局事务提交后显示新解锁并响 `endingNew`，已有结局仍计本次真实通关但不响新解锁声。
12. 首次结局写入失败后显式重试，确认成功提交前不显示新解锁或响声，同批重试不重复计次；两个页面同时提交同一未解锁结局时仅实际首先加入的事务取得首次回执。
13. 结局提交尚在等待时返回标题、读其他档或开始新会话，确认旧回执不改变后来会话的“新结局”状态或播放声音；原成果仍能从主页鉴赏读取。
14. 新结局声音播放中切后台、失去焦点或打开回看，确认暂停/许可仍有效；返回标题即取消。静音或退出等待中完成首次提交时，不在后来调高音量或取消退出后补播。

资源配置校验和接线不等于完整演出迁移或听感通过；按钮提示、正式 UI 与两端验收仍待接续。
