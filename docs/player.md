## 作者外观与舞台布局

### 作者配置与实际覆盖

`packages/player/src/appearance.ts` 的 `readAuthorAppearance(content)` 保持无 DOM，只读唯一作者源已经保留的 `settings.theme/cover`：

| 配置 | 读取及应用 |
|---|---|
| `theme.preset` | 沿用 default、wafu、pastel、scifi、retro、minimal 的原默认值 |
| `box/alpha/text/name/accent` | 主题底板、渐变、文字、名字牌和强调色；色值限 `#rrggbb`，透明度为 0～1 |
| `font/size/radius/layout` | 四种既有系统字体栈、正字号、非负圆角、float/wide 布局；不加载网络字体 |
| `theme.img` | 只能指向登记的背景/角色图片，显式配置但无效则报带来源的错误 |
| `cover.img` | 登记的背景；未设时沿用旧播放器的首个原节点背景，不猜首章节或后续节点 |
| `cover.menu/title/style/ty` | 原位置、标题隐藏、glass/theme 及有限标题纵坐标；无封面时用旧居中标题规则 |

未知字段、枚举、非法数值或资源种类明确拒绝，不把任意字符串当作 CSS、HTML、URL 或脚本。缺省字段采用既有作者默认，不修改 `game.js` 或规范化内容格式。

当前作品的主题是 `#14292b` 底板、0.85 透明度、sans、25px、10px 圆角；封面为资源 `32lrbngt`，标题靠左、纵坐标 135。作者数据的 `cover.menu` 是 left，但原入口随后载入的已采用鲸鱼 UI 及仓库适配将菜单覆盖为右侧，不能只读该字段便把菜单搬左。

新实现沿用这项最终覆盖：主页菜单靠右 66px、底部 85px、宽 362px，每一项向左再错位 18px，间隔 26px；按钮、选择和对白底板使用原鲸鱼皮肤。作者默认字体/字号继续参与对白，名字牌继续采用本句已有的角色颜色；鲸鱼皮肤的固定底色、文字色、边框、名字牌、浮动对白布局等覆盖通用主题项，保持原入口的优先关系。没有让低优先级原主题重新盖住已采用的皮肤。

后续[游戏界面迁移](<player.md#game-ui>)已将标题入口恢复为“开始游戏、读取进度、鉴赏、[章节试阅](<player.md#chapters>)、[声音收藏](<player.md#audio-library>)、设置”，沿用右侧逐项 18px 错位，小舞台/竖屏仍使用紧凑菜单。限时样例和通关后只读入口准备收进开发工具；存读档、设置和回退使用弹层。布局复用不等于完整正式界面或所有弹层已迁移。`cc857b0` 后接入下文的首立绘避让、两列选择与小舞台对白/选择规则；`cbccf3a` 后接入竖屏分区及小屏标题，`9d0aa78` 后另接[隐藏界面及共享输入](<player.md#input>)。仍非全部手机界面，原作品继续保留完整入口。

### 共享表现与加载

`web/appearance.ts` 只在给定舞台/场景根上写受限 CSS 变量和数据属性，不影响页面其他编辑控件。`WebPresentation` 可接第七个可选参数 `WhaleArtwork`；应用与编辑预览传入同一图形，均通过同一作者外观读取器。预览不修改主题、作者源或玩家偏好。

标题和选择使用 1280×720 的作者坐标，与背景/人物按同一舞台比例缩放；预览不再以另一套选择字号和 padding 覆盖共享样式。对白基准字号从试播固定 27px 改为作者 `theme.size`，本作品为 25px，再乘当前阅读偏好 `textScale`；小舞台的原可读性下限见下一节，偏好值和存储格式保持原样。

底板采用独立背景层，默认透明度 45%、允许 0～100%；文字和按钮保持不透明。文字过长时在当前对白框中滚动，不裁掉内容。字体或字号变化不重建剧情、重播语音、重算选择或当前有效计时。

标题背景独立按需加载，失败显示本地资源 ID 和“重试本地标题背景”，主线入口仍可使用；没有联网下载或替换封面。重试/离开注销原图片监听并清除源，旧加载不能更新新请求。若作者配置的对白框图片无法加载，归入当前场面阻断诊断并沿同一步骤重试，不重新执行进入动作。没有预解码全部资源。

### 共享选择布局与小舞台

`web/choices.ts` 的 `ChoicePanel(root, choose)` 仅消费 `SessionView` 中核心已经给出的可见选择；`render(view)` 不求值条件、不改变量、不决定超时结果。游戏和编辑预览均经同一面板发送原 `{session, epoch, step}` 与稳定选项 ID，由共享会话串行结算。

| 规则 | 本次接入 |
|---|---|
| 四项以内 | 首个立绘横坐标小于 640 则放右侧，否则放左侧；无立绘沿用左侧。宽 390、侧边距 42、顶端 174，按钮 21px、左对齐、间隔 12，保留原皮肤覆盖 |
| 超过四项 | 顶端 48、左右 48、底部 210 的两列区，沿用原次序；不根据文字或空间重排选择 |
| 高度不足 | 选择列表在限定区域滚动；少量选择也有高度上限，长文字、更多行数或倒计时不会只能落到舞台裁剪外 |
| 倒计时 | 两个入口都显示同一 `choiceRemainingMs` 进度条和辅助说明；面板不另开计时器，不发送超时意图 |
| 暂停及刷新 | 只改按钮禁用状态与进度条，不替换原按钮或重置列表滚动；单纯时间更新保留当前焦点，暂停禁用时的焦点遵循浏览器行为 |
| 新步骤及离开 | 清空旧列表并取消监听；迟到点击同时受面板身份和原会话令牌约束，不转成新步骤的选择 |

选择画布仍是 1280×720，列表放在其中，不把未缩放的页面坐标混入作者坐标。只有列表及其按钮接收指针，画布空白不遮住主线点击；列表本身可接滚动和触摸，顺序及条件隐藏仍由核心决定。隐藏列表不保留可聚焦按钮，不把 `aria-disabled` 代替真实禁用。

`web/stage-layout.ts` 的 `connectStageLayout(stage, {controls?})` 是游戏/预览共用的 `ResizeObserver` 接线，以舞台内容宽高设置 `--stage-scale`、一个屏幕 CSS 像素对应的作者坐标 `--stage-unit` 和布局属性。横屏按可用宽高容纳完整 1280×720，场景、标题和选择共用比例及居中偏移，不分别取整；暂时不可见的零宽/高舞台不写入无效比例，销毁断开观察并清理所写属性。游戏可选传入底部操作栏，按实际占用更新 `--stage-controls-inset`，独立编辑预览不传；不访问剧情、媒体或有效计时。

横屏舞台比例小于 0.75 时，沿用原小舞台对白/选择适配：对白底板按实际 140px 高、正文至少 15px、名字至少 14px 呈现；选择顶端为实际 18px、间隔 8px，少量选择宽 300px 并限制在舞台内，按钮至少 40px 高、文字至少 15px。字号更大时继续允许滚动，不改玩家偏好值或重建逐字/语音。

首立绘判断只是旧作品的启发规则，不声称能避开每个角色或所有脸部。竖屏和紧凑标题由下一切片接入，见下节。

### 竖屏分区与小屏标题

共享试播样式在浏览器可用窗口宽高比不超过 `20/23` 时，按窗口短视口高度减 32px 安排较高舞台，旧环境回退到 `vh`，最少 560px，页面可滚动。独立编辑预览仍采用这项容器安排；后续[游戏界面迁移](<player.md#game-ui>)通过游戏专用样式改为铺满当前窗口，设置/存档收进可滚动弹层。这些安排不规定正式最小分辨率、自动全屏或玩家设备限制，不把整页制作控件放进游戏布局。

共享布局继续按原 `fit()` 的 `高 > 宽 × 1.15` 判断舞台是否进入竖屏；该条件只读容器尺寸，写出的变量不改变容器宽高，避免自己触发尺寸反馈循环。竖屏以宽度确定场面比例，扩大场景/选择画布的显示高度，背景与人物仍只在原 1280×720 场面内呈现，人物位置、大小、图片与演出不重算。

| 区域 | 竖屏规则 |
|---|---|
| 场面 | 放在上方，沿原公式留 0～48px 顶部空间，完整作者场面按宽缩放；氛围、镜头与遮罩仍在场面内 |
| 对白 | 在场面下方留 16px 间隔，按可用空间取 150～240px 高；两侧各 12px，正文可滚动，当前作品默认正文为 `25 × 0.68 = 17px` 再乘玩家字号倍率 |
| 名字牌 | 16px 字、30px 高，保留当前说话人颜色；按原竖屏规则独立于场面缩放 |
| 选择 | 在对白下方单列展示，按钮至少 48px 高、16px 字；不改变选项身份、次序或条件。不足 150px 的选择空间改为覆盖场面/对白上方的可滚动区域，沿原 fallback 保留可访问内容 |
| 选择外观 | 沿原竖屏渐变和边框，横屏继续使用原鲸鱼 SVG；对白采用原仓库竖屏深蓝可读性覆盖，不改图形字节或来源 |
| 标题 | 原封面采用 66% 横向取景和下半部渐暗；标题 30px，菜单沿原竖屏规则居中放下半部，按钮至少 44px。横屏桌面仍是右侧错位，不移动到左侧 |
| 操作 | 游戏操作栏覆盖在画面底部，竖屏为五列两行，布局扣除真实占用及底部安全区；触摸按钮至少 44px，竖屏至少 46px。独立编辑预览仍使用外部操作栏，不重复留游戏操作栏空间 |

横屏的小舞台标题也沿用原规则：菜单靠右 18px、底部 12px、宽 160px，按钮至少 36px、15px 字，暂取消逐项错位；空间不足时菜单滚动，试播样例说明仍有实际字号。恢复宽屏后回到原右侧错位和作者尺寸，不替换任何按钮或重新加载封面。

旋转或改窗口尺寸只更新 CSS 变量和布局属性，不请求继续、暂停、重建表现或重新开始计时；已有文字、音频、选择监听、滚动位置和步骤身份继续属于同一次呈现。布局没有自己的计时器，也不决定限时结果；后台/宿主暂停继续由既有会话处理。

这不是完整正式 UI 迁移：[游戏界面切片](<player.md#game-ui>)已接原六项标题入口、底部触控操作栏、存档卡片、设置/回看、主页收藏/章节布局及现有弹层开关过渡，诊断收进开发工具；[方向建议](<player.md#game-ui>)沿原文案放在非模态提示区，可关闭而不暂停或请求显示。存档缩略图和完整窗口设置仍未完成，现有布局/过渡未验收。[隐藏界面](<player.md#input>)接到共享表现，[显式全屏](<player.md#fullscreen>)复用同一尺寸观察与横竖布局；最终界面框架和发行入口保持待定。

## 镜头、角色、氛围与过渡

### 镜头提示

旧 `海风与布丁/player.js` 的 `stageShot()` 将资源 `shot.focus` 用作缩放中心，`view.position` 独立决定背景取景。原镜头缩放限制为 1～1.04，时长限制为 600～3000ms，缓动为 `cubic-bezier(.2,.65,.3,1)`；快进与系统减少动态效果时清除镜头缩放。

共享实现采用上述数值及关系：

| 输入或状态 | 当前行为 |
|---|---|
| `shot.focus` | 非空时须为两个有限数值，直接转换为百分比缩放中心；非法值报告带节点及背景资源 ID 的场面错误，不改成默认焦点 |
| 缺省或空的 `shot.focus` | 不启用镜头；单独存在的 `scale` 不产生缩放 |
| `shot.scale`、`shot.ms` | 读取有限数值并按旧范围限制，缺省沿用既有读取值 1、2200ms |
| `view.position` | 显式值决定取景，未配置时居中；不能用镜头焦点替代背景取景 |
| 正常首次呈现或更换背景 | 当前资源准备完成后执行镜头，不等待动画结束才开始对白或选择有效时间 |
| 同背景的后续正常呈现 | 保留原镜头进度；换句及资源准备间隙暂停，就绪后继续，已完成的不再重播 |
| 媒体重试或检查点恢复 | 直接显示镜头终点，不重放进入演出，不保存或恢复动画帧 |
| 快进或本次呈现时系统减少动态效果 | 不采用镜头缩放；当前呈现中进入快进也清除缩放，停止快进不在本句中补跑镜头 |

内容内原始资源元数据保持原样，限制只在表现时应用。焦点是否有效在场面提交前判断；错误仍走原媒体问题及当前场面重试，不重新进入剧情。镜头使用独立 `scale`，不改场面坐标、剧情变量、声音或记录格式。

`web/camera.ts` 的 `BackgroundCamera` 由共享表现实例拥有，以背景 ID 与已校验镜头参数识别原镜头。单句的取消只暂停该场面镜头，目标正常呈现后决定沿用或替换；它不持有旧 `PresentationContext`、步骤、信号或剧情完成回调。正常换句不因句内演出清理而跳到镜头终点，也不从 1 倍重新开始。

菜单、后台、宿主、资源加载及错误仍通过当前呈现暂停镜头；暂停时间不补算。进入快进、无镜头/无背景、关闭该表现或采用不同背景/镜头参数时，先使原归属失效再取消动画，迟到完成不能改后来场面。快进结束不在本句补播，后续正常呈现可按旧规则重新采用镜头；读档/回退、媒体重试及终态直接采用稳定目标，不回放镜头帧。旧 `Playback` 的暂停/快进调用也必须先通过有效性判断，不能影响后来呈现。

原镜头完成后释放动画句柄、保留目标样式和已完成归属；解除暂停不会把刚完成但尚未处理回调的镜头重新播一遍。旧画面快照读取当前镜头的可见缩放，冻结为副本自己的值；与新背景镜头没有共享回调。以上只改变表现内部生命周期，不扩展核心、检查点、偏好或应用构造接口。

### 独立转场遮罩

未采用下述旧画面快照时，转场 `black/flash` 使用 `transition-veil`，按旧 `#veil.go` 的 800ms 从不透明淡出；瞬时 `flash/redflash/blink/quake/whip` 继续使用另一层遮罩，位于转场之上。两者可以在同一节点分别设置颜色及透明度，不再由后设置的特效改掉转场颜色或覆盖同一透明度动画。

“已有场面”独立于背景 ID 记录。没有背景也是有效场面；从无背景切到有背景，仍按实际更换和当前 `trans` 处理。第一次呈现不冒充从旧场面转场，读档/回退及媒体重试继续直接采用稳定场面。

两层动画均归属当前呈现，复用原暂停、恢复、快进及取消通道；菜单或后台暂停动画，换节点/重试/离开取消旧动画并清理遮罩。新增层没有输入处理或剧情回调，不决定点击、超时、声音完成或检查点时机。

### 主线旧画面淡出

旧 `VN_FADE` 在主线流转前保留旧舞台，下一画面就绪后以 360ms、`ease-in-out` 淡出。共享实现保留这个主线行为，应用显式向 `WebPresentation` 的末项可选 `SceneFadeSurface` 提供本舞台和选择面板；不读取全局 ID、全页样式表、作者脚本或其他应用界面。

正常进入下一节点时，已有场面、非快进、未启用减少动态效果、`trans !== "cut"`，并满足以下任一条件才捕获旧画面：

- 背景或立绘资源、取整后的坐标/高度、翻转发生变化。
- 氛围或当前对白显示/隐藏状态变化。
- 原选择面板仍然可见，即正在离开选择。

纯文字更新、自动/快进状态刷新、倒计时刷新不制造快照。首次呈现、媒体重试、检查点恢复和回退也不重放该进入演出。

`web/scene-fade.ts` 只复制当前场面及显式提供的选择面板。副本移除 DOM ID，整体 `aria-hidden`、`inert` 并禁止指针事件；没有复制事件监听或会话、语音、存储能力。复制的氛围、立绘及布局过渡静止，保留当时的可见变换、透明度、角色位置以及对白/选择滚动位置。两块作者画布继续采用共享舞台比例，不另开舞台尺寸观察或有效计时。

目标图片仍由原场面加载通道准备；旧画面在等待期间可见，目标采用后才淡出。动画不等待旧播放器的定时器、不额外阻止推进、不延后选择有效时间；旧选项副本不能接受点击或重复结算。一次最多保留一个快照，失败、快进、换节点、读档/回退、终态或离开都会清理；动画暂停/恢复继续由本次 `Playback` 管理。快照准备失败报告非阻断显示问题，仍沿原场面流程继续。

沿旧 `showPlay()` 的优先关系，采用快照时不再叠加背景自身淡入或黑/白转场；当前节点的瞬时特效仍正常执行。没有接 `SceneFadeSurface` 的独立表现消费者继续使用已有背景转场。此差异只涉及视觉，不切换剧情实现或跳过节点。

### 标题、暂停菜单与终态过渡

`web/stage-fade.ts` 的 `StageFade` 接续旧 `VN_FADE` 的界面事务行为。应用在异步准备已完成、即将真正采用界面变化时采样；下一帧对新界面的可见 DOM 图片最多等待 180ms，再以 360ms、`ease-in-out` 淡出旧副本。不等待离屏的场面预加载器，不延后剧情执行、声音、选择计时或存储事务，也不承诺在任意慢资源读取期间一直覆盖旧标题。

| 接点 | 本次接入 |
|---|---|
| 游戏开始、重新开始、实际读档采用 | 来源、全局投影及检查点准备成功后才采样，准备失败保留原界面；这只是应用界面变化，恢复仍不执行进入动作或重播节点演出 |
| 返回试播标题 | 取消原会话前采样，标题出现后淡出旧场面、选择、暂停菜单或结局卡片；原会话声音仍由原生命周期停止 |
| 游戏暂停菜单打开/关闭 | 只有菜单可见性实际变化才采样；倒计时、自动状态及其他暂停原因刷新不重复制造副本 |
| 首次显示核心终态 | 同一会话终态只触发一次；记录待保存、失败、重试、成功或新结局提示更新不重复淡出，未保存事实不能因过渡被当成已提交 |
| 独立编辑预览终态 | 使用同一 `StageFade` 和样式，只复制预览场面、选择及结局卡片；停止/换预览直接取消，不复制制作控件、读写玩家记录或假造正式解锁 |

界面过渡和主线单句淡出分别拥有各自句柄，均复用 `scene-fade.ts` 的 `capturePlayerLayers()`。只接收明确提供的同一舞台直接子节点；不采样整页、其他过渡副本、弹层对话框、编辑表单或外部操作栏。副本去除 ID 与自动焦点，保留可见变换、隐藏状态及滚动，整体 `inert/aria-hidden` 并禁止指针、CSS 动画和过渡；原副本不能继续选择、返回标题或抢焦点。界面副本位于现有舞台菜单/终态之上，主线副本仍在场面层。

一次只保留一个界面副本，新事务先清理旧事务。动画完成、失败、后台、宿主暂停、正常退出、实际快进、舞台尺寸/全屏变化及离开清理；运行中开启系统减少动态效果也直接清理。显示回看、鉴赏或通关后对话框前取消舞台过渡，对话框本身由下节的游戏专用驱动处理，不扩大共享舞台快照的范围。旧解码、帧、动画完成及兜底定时回调只核对原归属，不能删除新事务的副本或重新播放。

菜单自身的暂停不暂停这层界面淡出，否则关闭菜单时会留下冻结的旧菜单。场面和声音仍由共享会话执行原有效暂停；后台/宿主暂停直接取消界面视觉副本，不等待隐藏期间的动画。视觉错误只报告非阻断提示，不能把已接受的开局、读档或菜单操作改报剧情/存储失败。旧标题页没有背景音乐，并通过最终样式取消封面运动；本片维持这两个行为，不新增标题声音或封面动画。

### 游戏弹层视觉过渡

打开时在实际显示之前采样原游戏画面，再同步打开 native dialog；壳弹层通过显示前回调在采样后取得暂停，回看继续沿原 `history` 暂停通道。副本作为新 dialog 的子层显示，以适应其浏览器顶层。关闭时先采样原弹层及背景遮罩，随后立即关闭 native dialog、停止独立试听/媒体、取消未采用准备并释放原归属暂停，静态副本在独立页面层淡出。采样失败只保留直接切换，不能把已接受操作改报失败。

副本使用封闭 Shadow DOM，仅注入构建明确导入的游戏 `style.css` 与 `shell.css`，不扫描 `document.styleSheets`、整页或编辑制作区。影子树中的局部 ID 保留用于原版 ID 选择器、滑块与伪元素外观，不在主文档产生重复 ID；不保留自动焦点、表单关联、链接、事件或 live 区域。整层 `inert/aria-hidden` 且无指针，CSS 动画/过渡禁用，保留当时可见变换、控件值及滚动。活动音视频、脚本、iframe、canvas 和其他过渡副本不复制；图片只复制已完成且可见的当前图像，未加载/隐藏图不发起新尝试，离屏盒保留布局但省去深层内容。

下一帧仅对新弹层视口内的未完成图片最多等待 180ms，然后按原 360ms、`ease-in-out` 淡出；等待和动画均不阻塞实际 UI、核心、有效时间或事务。一次只保留一个弹层副本，每次开关先使旧事务失效；迟到解码、动画结束和兜底回调只处理原副本。页面隐藏、宿主暂停、快进、窗口/舞台尺寸或全屏变化、开启减少动态效果、准备退出、换会话/返回标题及销毁均清理。正常换会话或退出中的程序性关闭直接清理，不重放离开动画。

`GamePanels` 只新增应用提供的显示委托，仍持有原暂停释放函数；正常开关、读档准备取消、已有持久写入及旧 dialog close 事件归属保持原通道。独立编辑预览继续只用共享 `StageFade`，不引入游戏弹层副本或游戏样式。没有增加存储/内容/宿主格式、依赖或命令。

该入口已交给[鉴赏内部显示](<player.md#gallery>)：实际分类变化、打开/返回独立大图、原图重试和当次解码成功。图片取消/原资源读取、焦点、原目录滚动及状态变更同步完成，不等待动画；同分类重复点击、缩略图完成或失败诊断不反复采样。面板不获得显示驱动的打开/关闭或任意根采样能力，旧图解码仍须先通过原尝试及原选择身份核对。。

### 角色动作、移动和层级

`web/motion.ts` 按旧 `index.html` 的 `sIn/sInL/sInR/sInU/sPop` 和 `aJump` 至 `aSettle` 保存实际关键帧、偏移、时长、方向及缓动。它只提供可信代码中的表现计划，不读取作者表达式、写剧情或自行安排时间。

| 原演出 | 共享实现 |
|---|---|
| 淡入/左右入场/上移入场/轻弹 | 450/550/550/400ms；左右偏移 280px，上移 140px，轻弹从下方 40px 上移，不用额外缩放替代 |
| 淡出/左右或向下离场 | 400/500ms，沿原入场帧反向、`ease-in`，完成后清理原立绘 |
| 跳跃/发抖/点头 | 500/500/600ms，保留分段时刻、二次小跳/点头及原位移 |
| 探身/怔住/坐稳 | 550/380/550ms，保留探身旋转与三种原位移，不统一成同一条平移曲线 |
| 已有角色改位置/高度 | 500ms、`ease`；先设置稳定目标，再由当前呈现从旧坐标插值 |
| 光色/外观/说话焦点变化 | 滤镜 900ms、`ease`；非说话角色追加 `brightness(.62) saturate(.85)`，不使用透明度露出后方背景 |
| 同场景无动作的软切姿态 | 140ms 淡出旧角色静态副本，保留旧坐标、大小、翻转、滤镜和层级；不让旧姿态跟着新位置移动 |

CSS 动画缓动作用于相邻关键帧区间。共享 `cssMotion()` 将它写入每个关键帧，时间轴本身保持线性，避免把原分段节奏改成整段时间扭曲。动作和入场仍沿旧优先关系：本节点有动作就执行该动作，否则新角色才执行入场。

立绘继续按原角色身份复用；每次采用目标场面都按目标 `sprites` 顺序重新写入层级，不能以 DOM 最初插入顺序替代作者顺序。原实例 ID 仍保留在 `data-instance`，不改变内容身份或资源顺序。

移动、滤镜、动作及进退场都由本次 `Playback` 拥有，暂停/恢复沿用动画句柄，快进结束到稳定目标，换节点或离开取消旧工作。删除原 CSS 位移过渡后，媒体重试、读档和回退直接采用目标坐标/滤镜/层级，不因恢复再走一遍；减少动态效果也直接显示稳定目标。离场和软切副本只由原呈现清理，不用不受暂停控制的延迟删除，不加入检查点。

### 瞬时镜头与持续氛围

瞬时镜头只在正常进入时执行，计划同样放在 `web/motion.ts`，来自旧 `playFx()` 及 `index.html` 的实际关键帧；不再把不同镜头近似为同一个摇动。`scene-layers` 只包含背景及立绘，氛围覆盖、转场/闪光遮罩与对白在它之外：移动镜头不能连遮罩一起摇动，场面滤镜也不染色对白或瞬时闪光。

| 瞬时效果 | 保留的演出 |
|---|---|
| `shake` | 500ms、`ease`，原分段水平/垂直位移 |
| `quake` | 900ms、原贝塞尔曲线，原分段位移及逐步收回的缩放，同时白闪 |
| `zoom` | 500ms、`ease-out`，在 25% 时到 1.12 倍后收回 |
| `whip` | 620ms、原贝塞尔曲线，百分比横甩、缩放及 18/9/3px 动态模糊，同时白闪 |
| `flash/redflash` | 白色/原红色从不透明淡出，800ms、`ease-out`，不另造先淡入的半段 |
| `blink` | 黑色 1600ms、`ease-in-out`，保留 25/40/65/78% 的反复睁闭 |

镜头保留 CSS 的分段缓动。`dizzy` 与 `whip` 同时使用时，沿旧动画列表的优先关系由持续晕眩拥有模糊滤镜，横甩仍执行几何运动。所有瞬时动画归当前 `Playback` 暂停及取消，快进和减少动态效果跳过，读档/回退或媒体重试不重播。

持续氛围使用同一 `.world[data-mood]` 下的场面层、`mood-layer` 覆盖和实际 `mood-detail` 子节点；细节不用无法被现有暂停选择器覆盖的伪元素。原 CSS 曲线及渐变保存在共享游戏样式，编辑预览直接复用：

| 氛围 | 当前表现 |
|---|---|
| `dizzy` | 7s 晃动、5.3s 模糊、4.2s 黑色明暗脉冲和静止暗角 |
| `flicker/strobe` | 3.6s 原明暗关键帧 / 1.1s 原阶跃闪烁，作用于独立黑色覆盖 |
| `blur/sway` | 覆盖层 4px 背景模糊 / 6s 原旋转、平移和缩放 |
| `gray/dark` | 原灰度/对比与暗角 / 原深色暗角，不用统一亮度替代 |
| `danger` | 原红色暗角及 1.2s 心跳透明度 |
| `underwater` | 原蓝色渐变、场面滤镜、5.5s 漂移和四组原渐变气泡的 4.5s 上浮 |
| `slowmo` | 原褪色/对比/亮度、暗角和 9s 推近至 1.08 倍 |

同名氛围连续节点不重建这些层或重启 CSS 时间轴，加载/菜单/后台暂停覆盖所有动态子节点。静态场面滤镜及非脉冲覆盖的进入变化采用原 600ms 过渡，但动画句柄归当前呈现；脉冲氛围继续拥有自己的透明度。减少动态效果时停止漂移、脉冲、闪烁和气泡，保留静态着色；闪烁层的静态透明度为 0，不能因此把画面整片遮黑。

恢复仍采用稳定场面，不加入帧级存储。有限的 `slowmo` 推近在媒体重试、读档/回退或减少动态效果下直接采用 1.08 倍终点，并在同名后续节点保持；离开该氛围才清除。循环氛围不是进入事实，可以作为当前场面继续，离开清理。旧画面快照额外固定气泡的 `background-position`，不把副本气泡放回动画起点。

本片没有新增声音或视觉素材，气泡、暗角和滤镜沿用原 CSS；水下/慢动作的声音压低仍由现有混音器处理。本片只接通原帧及分层，镜头、角色和氛围组合后的观感及平台合成仍待统一对照，不据代码迁移声称逐像素等价或设备验收。

### 弹层与会话归属

`apps/game/src/panels.ts` 的 `GamePanels` 只持有当前壳弹层、每次打开的取消信号、关闭监听及应用提供的暂停释放函数，不持有剧情核心、进度或存储。打开设置/存档/回退/开发工具时，应用捕获当前会话；只有原来没有 `menu` 暂停才添加，并只在关闭时向同一仍活动会话释放。

Esc、弹层返回按钮和 Android 返回键沿同一关闭路径处理。关闭时使尚未采用的开局/读档请求失效并释放该次操作准备；已经发起的存档或偏好事务仍可完成。回退单独持有取消信号：关闭前未采用则拒绝迟到结果，已经采用则不能因关闭撤销它。

正常开局、读档、返回标题、退出及销毁清理所属弹层；成功换会话时先取消旧会话，再关闭壳弹层，旧暂停释放函数不能操作新会话。重复及迟到的原生 dialog close 事件不能关闭重开的同一面板。弹层期间游玩快捷键不向主线发意图，原浏览器全屏 Esc 优先规则保留。

### 暂停菜单焦点与背景交互

菜单可操作时首次取得当前会话的焦点归属，先将焦点移到“继续游戏”，再暂时排除场面/标题/选择/操作栏的可访问树；关闭时恢复这些根的原 `aria-hidden`，不写共享 `PlayerInput` 管理的 `inert` 或隐藏标记。Tab/Shift+Tab 在可见且可用的菜单控件之间循环，包含移动进来的原异常重试和方向提示按钮；焦点移到远端菜单项时允许正文滚到该项。普通组合键不接管，Esc/F11/Alt+Enter 仍由原输入/显示控制器处理。

菜单活动期间，只在登记的游玩表面捕获对菜单外的指针按下、点击和右键；不把拦下的操作转成继续、隐藏或选择。原生 `dialog[open]` 出现、后台/宿主暂停或退出时停止焦点循环与指针拦截，将焦点交给原模态/宿主；每次刷新只在当前焦点落到菜单外时补回，不反复定位正在使用的菜单项。打开/关闭设置、存档或回退仍通过 `GamePanels`，不改变它持有的原暂停归属。

同一会话收起菜单时，仅在焦点仍由该菜单持有（或因隐藏回到 body）时尝试恢复原可见可用控件，否则落到舞台；已经交给其他弹层/控件的焦点不夺回。新开、读档、返回标题、换会话与销毁释放旧归属并恢复可访问属性，不恢复旧会话焦点。后台/宿主回执与页面可见性刷新沿现有装配接续，监听随页面销毁清理，不增加计时器、持久字段或全局快捷键。

## 输入与隐藏界面

### 接口与归属

`packages/player/src/web/input.ts` 的 `PlayerInput` 接收舞台、场景、选择区、操作栏、隐藏按钮、键盘作用域，以及当前 `GameSession` 的读取函数、输入许可、声音解锁、菜单和可选回看回调。游戏操作栏在画面底部覆盖显示，DOM 中仍是舞台的相邻元素；独立编辑预览保留外部操作栏。

- `next()`、`toggleAuto()`、`toggleSkip()` 把意图交给当前共享会话；`menu()`、回看交给应用已有入口。输入层不计算条件、变量、选择、已读或超时结果。
- `toggleHidden()` 管显示，`reveal()` 只恢复显示并返回是否消费了这次操作。应用可在原生返回键打开菜单前调用；隐藏不是新的暂停原因。
- 应用在会话状态更新后调用 `refresh()`，新开、读档采用、返回标题或停止预览时调用 `reset()`，销毁时调用 `dispose()`。状态读取不采用存档中的界面隐藏、按键或指针状态。
- 游戏键盘范围为本页；编辑器只包含预览舞台及预览操作栏。制作输入、草稿、文件操作和保存按钮不属于预览快捷键范围。

`session.ts` 同时保留旧操作栏的自动/快进互斥规则：打开自动会关闭快进；请求打开快进会关闭自动，即使当前未读保护拒绝实际快进，也不保留原自动模式。已有的未读和选择限制继续生效，不新增跨未读或代答能力。

### 当前操作

| 操作 | 行为与边界 |
|---|---|
| 点画面、空格、Enter、→、“继续”按钮 | 提交同一 `next`；文字未完成时由会话补全，已完成才继续。界面隐藏时仅恢复显示，不补字或跳句 |

| “快进已读”按钮 | 显式切换快进，并接管临时 Ctrl 模式；此后松开原按键不会关闭按钮明确开启的模式 |
| H、画面右键、“隐藏界面”按钮 | 切换隐藏；舞台内的选择、标题、菜单及其他交互控件不被当作画面右键 |
| 触屏或笔长按 | 稳定按住 550ms 后切换隐藏；移动超过 12px 取消长按。设备支持时尝试 15ms 振动，失败不影响操作 |

| 画面滚轮向上 | 打开对白回看；Ctrl/Meta 滚轮不接管，选项区和可滚动长对白保留自己的滚动 |
| Esc、“菜单/暂停”按钮 | 未处于浏览器全屏时，隐藏先恢复显示，否则调用已有菜单/暂停入口；加载、媒体错误及终态仍保留菜单入口。浏览器全屏的 Esc 优先由[显示控制器](<player.md#fullscreen>)处理 |
| Android 返回键 | 已有弹层优先关闭；界面隐藏时只恢复显示，之后再沿用既有菜单/退出处理 |

文本编辑、输入法组合、重复按键事件不触发游玩快捷键；常规按钮的空格/Enter 保留浏览器按钮激活，避免同时推进剧情。Alt/Meta/Ctrl 组合不映射为普通继续、自动或隐藏命令。焦点离开预览范围或进入编辑输入时释放临时快进。

底部[原图标装配](<player.md#appearance>)只装饰现有按钮。隐藏/显示文字通过 `web/button-label.ts` 更新可选文字子项，不删除图标或替换按钮；独立预览没有文字子项时仍使用纯文本。输入、隐藏状态、焦点与旧手势归属不变。

独立编辑预览复用同一控制器和生命周期，但没有提供对白回看回调，所以下滑/滚轮回看不启用。没有自动迁移旧 ArrowLeft 回退键：正式回退边界和语音方式仍按[显式回退入口](<storage.md#rollback>)处理。[游戏界面迁移](<player.md#game-ui>)已接底部触控操作栏与可关闭的非模态方向建议；方向提示仅管本页显示，不发游玩意图或暂停，自动全屏和方向锁定仍未接入。

显式全屏按钮/F11/Alt+Enter 已由后续[共享显示切片](<player.md#fullscreen>)接入，显示控制器不持有剧情接口。实际显示变化时清理未完成手势/临时 Ctrl，不重建会话；原生 Esc/返回键继续按本页菜单/弹层处理。

### 隐藏及取消

隐藏时对白和选择不可见，场景与选择区设为 inert，其他游玩操作按钮不可见且 inert；“显示界面”按钮保留。原来处于被隐藏区域的焦点移到该按钮，避免留下不可访问的焦点。游戏底部操作栏用 visibility/inert 保留占用，不因隐藏改变对白布局；独立编辑预览保留外部按钮。[游戏壳弹层](<player.md#game-ui>)打开时禁用游玩输入，并清理手势和临时快进；设置/存档/回退经应用持有的原会话暂停处理，技术诊断收进开发工具。

隐藏只改变显示和交互许可，自动播放、限时选择、声音及剧情有效时间继续按原状态运行。菜单、回看、后台、宿主暂停、正常退出、结局或会话替换会恢复界面并取消未完成手势；内部图片加载暂停单独处理，不因正常换场加载而自动显示或释放临时快进。

Ctrl 只拥有它发起的临时模式；若按钮已经开启快进，按下再松开 Ctrl 不接管该按钮模式。失焦、后台、外部暂停、选择、停止或换会话均清理临时所有权，不在回到页面时自动重新按下 Ctrl。

每个触屏/笔手势捕获原会话对象和 `{session, epoch, step}`。换步骤、加载、读档、重开、多指或离开会取消原长按；正常短点在后续点击到达时再次核对原身份，旧操作不能转成新会话输入。重置保留待到达点击的身份，供迟到点击拒绝使用。

长按、拖动、下滑及取消之后的同指针合成点击最多抑制 350ms，避免恢复界面或打开回看后再跳一句；新的物理按下会清除此旧抑制，即使新按下落在选择按钮也不吞掉明确的新点选。可滚动对白和选择不参与手势接管，场面禁用图片拖拽。定时器与监听由控制器生命周期拥有，销毁取消监听并恢复原 inert 状态。

本片不增加存档、全局成果、玩家偏好或宿主协议字段；隐藏、手势、Ctrl 所有权和输入监听均不持久保存。作者剧情、素材与旧入口未改。

## 全屏与原生显示

### 共享控件与浏览器

`packages/player/src/web/fullscreen.ts` 的 `PlayerFullscreen` 接收全屏目标、游玩区域、按钮、状态元素、键盘作用域和启用判定，可选接收原生 `FullscreenDriver`。驱动只提供显示状态、请求、订阅和销毁，不取得 `GameSession`、内容变量或存储。

| 操作或状态 | 当前接入 |
|---|---|
| 全屏按钮、F11、Alt+Enter | 同一显示请求；组合键、输入法和重复按键按明确条件处理，等待中不叠加按钮请求 |
| 浏览器游戏 | 全屏目标为整页，保留所有弹层及正常退出对话框；游玩区域占当前视口，设置/存档通过标题或底部操作栏打开，弹层内容可滚动 |
| 独立编辑预览 | 仅预览区域进入全屏，快捷键也只在该区域；编辑器其他控件不被纳入或触发全屏预览 |
| 浏览器 Esc | 当前区域全屏时先退出显示，不同时传给游玩菜单；浏览器自身退出全屏也由状态事件反映，不自动重新进入 |
| 原生 Esc/返回 | 保留既有菜单、弹层和退出流程，不改为显示退出键；显示退出仍用按钮或 F11/Alt+Enter |
| 不支持、拒绝或失败 | 明确显示状态，继续窗口游玩；原生缺少显示能力时不偷偷改走浏览器全屏 |

浏览器驱动在原用户操作中直接调用 `requestFullscreen`，以实际 `fullscreenElement` 和 `fullscreenchange` 确认状态，不把按钮点击当成成功。进入和退出失败显示可重试信息，其他区域已经全屏时不抢占它。

`refresh()` 同步状态和按钮；`reset()` 请求退出，停止预览会调用它。进入尚未完成时停止/销毁，原请求完成后接续退出，不把迟到进入当作新预览的选择。监听由消费者拥有，销毁取消订阅；退出只处理自身目标，不退出其他区域。当前焦点与页面滚动仅在本页内保存用于显示往返，已有弹层打开时不抢焦点。

游戏操作栏装配文字子项后，`refresh()` 通过共享 `web/button-label.ts` 更新实际标签，不替换按钮或其装饰；纯文本编辑预览沿用原行为。等待/支持状态、实际确认、焦点恢复及可选原生扩展不变，未因这片显示迁移获得额外验证结论。

游戏设置的“显示”行沿用现有设置配色和窄屏换行，显示待确认/正在切换/不可用/窗口/全屏，状态没有确认时不以点击结果假装成功。此行没有保存、默认或跨局恢复；它不进入四组偏好、检查点或成果。设置仍归原 `GamePanels` 暂停/关闭生命周期，切全屏不关闭弹层或解除暂停；现有弹层打开时不把焦点抢到底部按钮。独立编辑预览不传额外控件，保留原入口与范围。

全屏后的舞台继续由同一尺寸观察器缩放，场面、对白和选择沿既有横竖规则；进入/退出清理未完成手势与临时 Ctrl，不重建剧情、文字、音乐或有效计时。[游戏界面迁移](<player.md#game-ui>)将操作栏放在画面底部，按实际占用给对白/选择留位置；状态与媒体错误在画面可见，弹层长内容可滚动，并读取浏览器提供的安全区变量。没有宣称刘海屏、系统栏和所有尺寸已验收。

### 可选原生显示扩展

基础桥保持 `haifeng.host-bridge/3`，主线状态、音频焦点、返回键及退出协议不变。在桥上新增独立可选 `fullscreen` 扩展，协议为 `haifeng.fullscreen/1`；这不是持久记录版本，也不新增通用原生命令入口。

- 扩展的 `identity` 是本页临时随机身份；无法生成身份时仅此扩展不可用，不阻断基础桥。`read()` 返回支持情况、显示模式、待处理请求及问题。
- `request(active)` 只接受布尔目标，分配本页递增 ID；请求附带原页面身份。Windows 从本地桥读取请求，Android 只接受本地主框架的专用消息，均不接文件、网络、脚本或剧情参数。
- `receive()` 严格读取 `haifeng.fullscreen-state/1`，包含递增序号、显示模式、确认请求 ID/页面身份和可空错误。旧序号拒绝，只有匹配本页及本次请求的确认才能清除等待。
- 等待 8 秒未确认时显示超时，保留当前已知模式；新请求使用新 ID，原确认不能清掉后来请求。超时问题保留至明确重试或对应迟到确认，不由无关周期状态抹掉。
- 页面驱动独立检测显示状态超过 3500ms 未更新的情况；显示失败不改变剧情暂停、音频许可或已有写入。已有宿主状态通道继续独立决定真实失焦/后台暂停。

旧 `/3` 宿主没有此扩展或不报告支持时，显示按钮不可用，已有主线入口仍可用。要试用本片须用当前源码重新生成游戏包、准备目录和原生程序；没有改既有随包清单及准备格式，没有自动执行命令或覆盖旧目录。

### Windows

`desktop/src-tauri/src/rebuild.rs` 随已有窗口事件和每秒状态采样读取显示扩展，窗口操作仍只针对 `rebuild` 窗口。严格解析本页请求，在主线程按 ID 去重，调用窗口的 `set_fullscreen(bool)`；只有实际采样的 `is_fullscreen()` 与目标一致，或明确失败，才确认本次请求。

请求与原生页面代次绑定；页面换代、窗口销毁或回调超过 2 秒才到主线程时不采用原请求。状态和错误都经独立显示扩展返回，不开放旧 `/__host/`、Tauri 通用调用、远程导航或第二解释器。切全屏造成的焦点/尺寸事件继续走原生命周期接线，显示本身不是新暂停原因。

### Android

`RebuildActivity` 的 `__HAIFENG_NATIVE_DISPLAY__` 只接受固定来源的主框架及 `haifeng.fullscreen-request/1`。页面身份先由当前 WebView/页面代次确认；旧页消息、重复 ID、非法字段及超限消息不执行。后台、失焦或退出中拒绝切换并返回问题。

API 30 起通过 `WindowInsetsController` 请求隐藏系统栏并允许边缘滑动暂时唤出；较低系统沿用原生沉浸标志。进入前保留原系统栏相关设置，退出恢复所管理的位，不覆盖无关窗口标志。这里返回的是原生已接受的沉浸模式，临时系统栏出现不算退出该模式；不是已观测到每个设备的像素结果。

页面重载和错误页尝试恢复原系统栏；后台/恢复仍由既有宿主通道暂停/继续当前会话，Activity 重建不恢复此临时模式或猜剧情位置。没有引入依赖、HTML 视频自定义视图、横屏锁定或自动首次触摸全屏。

## 独立声音、阅读与语音偏好

### 当前默认与独立语音开关

对话框默认背景 45%，范围 0～100%、步进 1%；原不透明 backing 与强制 72% 下限已去除。零值按正常数字保存，只有 `::before` 背景层随滑块变化，文字/控件保持原有不透明度。作者主题与皮肤合成在同一受控背景层。首次 0%、刷新重读及恢复默认已验证。

独立 `haifeng.voice-preferences/1` 使用 `{early?: boolean, later?: boolean}` 稀疏覆盖；`false` 明确保留，`null` 回到作者默认。作者节点 `voiceOptionalFromChapterId` 按稳定节点及作者顺序区分两段，不在表现层求分支。前段默认开，后段沿 `voiceLaterChapters=false` 默认关。设置只显示当前段一个“语音开关”，标题按前段显示。手动关闭停止当前自动语音并释放原等待；开启用于后续呈现，不补播一次性语音。回看试听仍是独立实例。

正常入口独立显式保存，限时/章节试阅分开用内存；音量/阅读/按钮/剧透/进度及全局成果的既有严格格式均不加字段。IndexedDB 和原生 CAS 复用已有原子更新，Windows/Android 只增加固定记录族地址，不开放路径或通用命令。两端须重新准备并编译，当前尚未完成原生运行验证。

后续[话末数值显示](<player.md#readout>)使用独立 `haifeng.readout-preferences/1` 布尔偏好，复用同一面板的主动开启、显式保存及原修改重试；未向既有音量/阅读/按钮格式加字段。每次呈现固定追加后的文字及自动等待长度，开关改变不重播当前句或重置计时；限时样例、章节试阅使用各自内存，编辑预览只接作者默认，。

[游戏界面迁移](<player.md#game-ui>)将这四组现有控件收进“设置”弹层，标题、底部操作栏及暂停菜单均可进入。弹层暂停由应用捕获的原会话持有，关闭只释放自己加上的暂停；控件保存规则、独立格式和入口隔离保持原样。后续“显示”行只复用当前全屏控制，不属于这些持久偏好。

### 旧版设置布局

`PreferencesPanel` 只增加显示结构、分组标题及滑块样式值，四组原有状态机、独立协议、保存/原修改重试和临时入口隔离不变。没有增加旧快进开关、窗口/方向设置、自动保存或联网配置。

### 默认值与声音应用

`packages/player/src/preferences.ts` 的 `authorAudioVolumes(settings)` 读取唯一作者源中的四个设置，不修改作者内容：

| 通道 | 来源字段 | 当前作品默认值 | 缺少字段时的原混音器回退值 |
|---|---|---|---|
| 配乐 `music` | `vbgm` | 35% | 60% |
| 环境声 `ambience` | `vamb` | 30% | 30% |
| 语音 `voice` | `vvo` | 100% | 100% |
| 音效 `effects` | `vse` | 55% | 80% |

输入必须是 0～1 的有限数值，已出现但非法的字段明确拒绝。来源音量、素材增益、场景压低与渐变分别处理：最终声音为当前通道音量乘以原素材/场景/渐变增益，再限制到播放范围。

`WebPresentation` 可显式接收初始 `AudioVolumes`，并通过 `setAudioVolumes()` 即时更新现有音轨。混音器不因调音重新播放、跳转位置或重建渐变；正在退出的淡出音轨也应用最新通道值。水下/慢动作压低、配乐存在时的环境声压低、同曲继续和停奏保留既有处理。

主线配乐、环境声及语音调到 0 时继续按当前播放时间静音运行，语音完成仍可释放自动阅读等待。一次性音效在实际触发时检查音效音量，0 音量时不创建音轨，不在稍后调高音量时补播；已经播放中的音效只调整当前声音。调音不发剧情命令、进入动作或全局事实。

[历史语音试听](<player.md#history>)使用当前入口的语音通道音量与独立混音实例，已有试听实时调音不重播；触发时语音音量为 0 则明确提示，不创建稍后补播的试听。试听完成/失败不释放主线自动等待，也不进入存档声音位置。按钮声音开关不控制对白试听。

### 存储契约

纯模块 `AudioPreferenceRepository` 使用独立格式 `haifeng.audio-preferences/1`，包含作品、范围及稀疏 `overrides`。键由格式、作品、范围种类及范围 ID 构成，不按剧情修订分槽；没有记录时只使用作者默认，不创建记录。

仅显式调整的通道形成覆盖。`update(changes)` 中缺省通道保持已存值，`null` 删除该通道覆盖并跟随作者默认；“使用作者默认音量”先在内存生效，点击保存后才持久保存这一选择。未覆盖通道随之后加载的作者默认变化，不把整份旧默认固定为玩家选择。

浏览器仍使用新 TypeScript 记录的 IndexedDB 数据库和现有对象仓库，以独立协议键隔离；没有新增数据库版本或读取旧 localStorage。`updateAudio()` 在同一读写事务内重新读取、校验及合并提供的通道，再整体提交。不同页面只修改不同通道时不会以旧整份副本覆盖；同时修改同一通道时以最后提交值为准。损坏、未知字段或身份不符的已有记录拒绝更新，不静默重置。

显式[Windows 文件试用](<delivery.md#native-storage>)与[Android 文件试用](<delivery.md#android-storage>)将同一所选存储交给声音、阅读、按钮和话末数值四组仓库，通过代次 CAS 重读并执行原 TS 合并；原协议/稀疏修改不变，不迁移 IndexedDB。确认丢失按 `NATIVE_STORAGE_UNCONFIRMED` 报告，保留原修改重试与后续未保存调整，不声称肯定未写入或绕过退出等待。浏览器默认 IndexedDB；两端正式入口默认原生文件，具体接线。

声音偏好不进入进度检查点、全局解锁或通关上下文；读档和回退沿用当前玩家音量，不从进度快照恢复旧音量。存档、玩家记录及宿主桥格式均未改变。

### 试播接线与失败处理

第一话试播使用 `development/normal-entry` 的偏好范围，显式“保存音量偏好”才写入。标题及游玩中均可调整；滑块修改立即作用于当前播放。限时选择样例及[章节试阅](<player.md#chapters>)各自单独使用本页内存及作者默认，不读取或写入第一话偏好，也不共用彼此的临时值；编辑预览同样只使用作者默认，不接玩家偏好仓库。

应用在启用初始标题按钮前读取可选偏好，最多等待 5 秒。失败或超时显示提示，本次继续使用作者默认，不替换原记录；迟到结果或已离开页面的读取不能被采用。读取和保存期间禁用调音控件，不暂停主线剧情计时。

保存通过 `PendingWrites` 跟踪，失败保留本次捕获的通道修改，玩家可显式重试。失败后若又调整了音量，重试仍只写原修改；成功后保留后来尚未保存的调整并提示其状态。保存时的原子合并不能被误称为多页面实时同步，其他页面更改不会自动推送到当前混音器。

[正常退出](<storage.md#exits>)等待已显式发起的音量保存，并在失败时允许重试原修改或取消退出；不自动保存尚未点击保存的滑块调整。取消退出会刷新调音控件的禁用状态，但不会取消已开始的数据库事务。

窗口/全屏持久偏好与最终设置界面尚未决定，设置中的本次全屏入口不加入偏好仓库；[交互提示音](<player.md#feedback>)已另外接通选择、限时循环、手动存档成功、变量/CG/话末、事务首次解锁结局及操作按钮。新结局声音同样受当前音效音量及暂停约束，静音时不积攒补播。没有补设正式读档语音默认、自动存档或旧偏好迁移规则。“只快进已读”仍保持现有约束，本片没有添加跳过未读的开关。

### 阅读偏好的字段与时机

`packages/player/src/reading-preferences.ts` 保持纯 TypeScript，提供作者默认读取、字段校验和 `ReadingPreferenceRepository`。它从现有作者设置读取默认值，缺省字段使用下表回退；非法已存在值不当成缺省：

| 新字段 | 作者来源 | 当前默认/缺省回退 | 允许范围 | 生效时机 |
|---|---|---|---|---|
| `textSpeedMs` | `speed` | 30 毫秒 | 5～80 毫秒 | 下次呈现开始时捕获，当前逐字计时不重建 |
| `autoWaitMultiplier` | `autoMul` | 1 倍 | 0.4～2.5 倍 | 后续新安排的普通自动等待 |
| `textScale` | `readerScale` | 1 倍 | 1～1.25 倍 | 当前对白文字即时缩放 |
| `dialogueOpacity` | `ghost` | 0.45 | 0～1 | 当前对话框底板即时调整 |

逐字间隔越小，显示越快；滑块使用直接的毫秒标签，不沿用旧界面的反向滑块值。作者每句的 `typeMultiplier` 与 `holdMs` 继续参与表现，不被玩家设置覆盖。下次呈现包含下一句及显式媒体重试；设置修改本身不会重试或补全文字。

`WebPresentation` 增加可选第六参数及 `setReadingPreferences()`，未传值的编辑预览仍读取作者默认。每次 `present()` 固定本次文字速度；字号与透明度只更新该对话框的 CSS 变量，不改变场景、语音或剧情节点。后续[作者外观接线](<player.md#appearance>)将试播固定 27px 改为作者 `theme.size` 基准，本作品为 25px，再乘 `textScale`；横屏按舞台缩放、小舞台保留原可读性下限，竖屏沿原 0.68 显示比例，本作品实际为 17px 再乘玩家倍率。布局变化不写偏好值或改变格式；透明度直接控制独立背景层，默认 45%、允许 0～100%，文字和按钮保持不透明。原皮肤及主题基础接入不等于正式界面、全量布局或视觉已验收。

`createGameSession()` 可传 `autoWaitMultiplier`；省略时读取作者 `autoMul`。新增串行意图 `{type:"auto-wait", multiplier}` 只更新后续倍率，不调用重新计时。普通自动等待仍按 `(1200 + 文字长度 × 60) × 倍率` 安排，继续等当前语音结束；作者停留、无对白演出、快进间隔与限时选择不乘此倍率。已存在的自动等待、读档或回退带回的剩余有效时间不因调整倍率而重置。自动/快进的启用状态仍属于会话控制，不由本片当成偏好跨局保存。

### 阅读偏好的保存与隔离

格式为 `haifeng.reading-preferences/1`，字段为作品、范围及四个阅读项的稀疏覆盖；按作品和范围单独保存，不按内容修订分槽。存储仍复用同一新数据库，通过独立协议键及 `updateReading()` 原子合并，只修改明确提供的字段；`null` 删除覆盖并跟随作者默认。未知字段、非有限数值、超出范围、身份不符和损坏记录均拒绝，不读取旧 localStorage 或重置原记录。

第一话接 `development/normal-entry`；限时样例、章节试阅和编辑预览不采用或写入该偏好，前两者各有独立内存调整。阅读与音量启动读取并行，各自最多等待 5 秒，失败只让对应设置使用作者默认，不阻止主线以默认设置开始。

共用面板保留即时内存、显式保存、原修改重试和后来调整保留的规则。字号/节奏调整不会创建检查点或全局事实；保存阅读偏好只写阅读键，保存音量不写阅读键。当前页面没有自动接收其他页面的偏好变化。已发起的阅读保存接入正常退出等待与重试，未点击保存的设置不会在退出时自动落盘。

### 按钮声音开关

`packages/player/src/button-preferences.ts` 提供 `ButtonPreferences {enabled:boolean}`、`authorButtonPreferences()` 和 `ButtonPreferenceRepository`。作者 `btnSe` 缺省时开启，明确的布尔值作为作者默认；非法类型拒绝，不把字符串或数值转换成开关。

格式及键前缀是独立的 `haifeng.button-preferences/1`，记录作品、范围及稀疏 `overrides.enabled`，不按内容修订分槽。`update({})` 保留已有覆盖，`update({enabled:null})` 删除覆盖并跟随作者默认。布尔 `false` 必须保留，不能当成缺省；未知字段、损坏记录和身份不匹配均拒绝更新。已有音量/阅读 `/1` 格式、存档、全局记录及宿主桥协议不变；不读旧 localStorage。

浏览器 `updateButtons()` 在现有数据库/对象仓库的同一事务中重新读取、校验及合并，提交完成才报告保存成功。第一话使用 `development/normal-entry`；限时样例、章节试阅各自只调整自己的本页内存，编辑预览只读取作者默认。读档/回退、全局成果及通关上下文不携带该开关。

试播新增“播放按钮声音”复选框及显式保存/作者默认/原修改重试。关闭后不再产生后续按钮音，已经开始的声音仍按原轨道生命周期处理；其他剧情、选择及成功存档提示继续受音效轨道控制。开关本身和设置保存按钮不发按钮音。读取与音量/阅读并行，各自最多等待 5 秒，失败保留原记录并使用默认；迟到结果和离开后的读取不采用。

面板共用原保存状态机，保存失败后的新调整仍留在内存；重试只写原捕获的布尔修改，成功后不抹掉后来未保存的调整。已发起的按钮偏好保存参与正常退出等待、原修改重试和取消后的控件刷新；未点击保存不会因退出自动写入。具体按钮范围及暂停/快进规则见[按钮交互](<player.md#feedback>)。

## 话末数值显示

### 原显示规则

`packages/player/src/readout.ts` 的 `StoryReadout` 不求值、不执行动作，只读取唯一核心已经提交的变量视图。只对原作者文本匹配 `^【[^】]*完[^】]*】\s*存档点` 的节点追加 `　〔好感 数值 · 尾鳍信号 数值〕`；其他对白原样保留，不把所有结局、章节或含“存档”的文字都当成存档点。

匹配使用变量替换前的原文本，追加使用该节点进入动作已经生效的当前变量。正文保持纯文本，变量占位仍由原核心处理，不新增 HTML/富文本解释器。没有新增变量、修改台词、改结局条件或把这类句子作为自动存档触发。

变量绑定保留旧优先序：`settings.uiSe.favorVar/tailVar`，否则有有效 `soul.char` 的既有配置 `soul.aff/signal`，再回退到“好感/尾鳍”。这里只消费旧配置中的显示名字，不启动聊天、网络或 Agent。缺少默认变量时省略该项；显式非法名字或引用未声明变量给出来源诊断，不能按零显示。两个名字相同仍保留原两种标签；读取器供显示及引用查询共用。

### 独立偏好

`readout-preferences.ts` 读取作者布尔 `showStats`，缺省 false；显式非法类型拒绝。玩家覆盖使用独立 `haifeng.readout-preferences/1`，按作品及 `development/preview/game` 范围隔离，只有 `overrides.enabled`，不进入检查点、全局成果或既有音量/阅读/按钮协议。

`update({enabled:false})` 必须保留 false，`enabled:null` 删除覆盖并跟随作者默认，空修改保留原覆盖。存储在现有新数据库和对象仓库中使用独立键，`updateReadout()` 在同一读写事务中读取、严格校验、合并并提交；损坏、未知字段或其他身份拒绝更新，不按空记录重置。没有升级数据库、读取旧 localStorage 或迁移旧偏好。

### 同一正文与有效计时

`createGameSession()` 的可选 `readoutEnabled` 指定本次初值，省略时只读作者默认。每次 `enter/retry/restore` 开始时，`StoryReadout.text()` 从原正文和核心已生效变量固定本次显示文字，仅向表现适配器提供包含该文字的视图副本。核心 `RuntimeView`、动作、条件、事实及插值原文不变，回看和存档摘要继续使用原剧情正文，不把玩家偏好写入剧情或检查点。

普通自动等待沿旧规则，使用同一份实际显示文字的 UTF-16 长度计算 `(1200 + 长度 × 60) × 自动倍率`；限时选择、作者停留及快进间隔继续走原分支。串行 `{type:"readout", enabled}` 只更新后续呈现使用的开关，不重打当前文字、重置当前等待或再执行进入动作。媒体重试算下一次呈现；实际读档/回退使用当前独立开关，已有检查点的剩余有效时间仍优先采用，不按显示文字的新长度重新计算。

### 页面、预览与引用

开发页新增“话末数值”布尔设置，主动开启后显示当前核心变量的只读摘要，实际句后追加用于后续真实存档点。摘要不改变核心，相同值的计时刷新不反复改写辅助播报。关闭时隐藏摘要；标题只说明开始后显示，不读取旧路线或全局记录猜数值。普通结局和脚本结束也不会因此被当作新的存档点。

正常入口使用 `development/normal-entry` 独立偏好，显式“保存话末数值偏好”才持久化；同一 `PreferencesPanel` 保留原修改重试、后来调整及正常退出等待/取消刷新。初始化读取与其他偏好并行，最多等 5 秒，损坏/超时保留原记录。未点击保存不会在退出时自动写入。

限时样例、章节试阅各有自己的本页内存开关，不采用或改写正常游玩偏好。独立编辑预览不接玩家仓库，只由共享会话读取本次草稿的作者默认；预览所显示的数值来自本次人工初值/检查点和唯一核心，不混入全局成果或正式路线。没有新增作者开关编辑入口、联网配置或聊天行为。

共享 `playerReferences()` 使用同一变量读取器补 `readout-variable` 结构引用，标明真实来源或默认派生，编辑查询显示“话末数值变量”。不复用声音变量名来冒充读取关系，也不猜任意配置字段；零引用仍不能作为删除依据。没有改变查询的源/草稿代次保护、内容修订或作者写回范围。

## 剧情与操作声音反馈

### 配置与归属

`packages/player/src/ui-sounds.ts` 定义纯数据 `InteractionFeedback` 和 `readUiSounds(content)`，只读作者 `settings.uiSe` 的资源 ID。配置缺省或明确为空时保持无声，不生成提示音、不改素材和作者文件。实际存在的非空映射须指向登记的 `se` 资源，错误带作者文件及字段定位；未知配置字段明确拒绝。

读取器认识旧配置的全部键，以保留既有来源。当前已消费：

| 配置键 | 当前触发来源 | 恢复/重复处理 |
|---|---|---|
| `choiceShow` | 正常进入节点后第一次达到可见选择阶段，且场面已经就绪 | 暂停刷新、自动按钮刷新、媒体重试、读档与回退不重复播 |
| `choiceConfirm` | 唯一核心实际接受点选后，由 `chosen` 事实触发 | 旧步骤、重复点击或被拒命令不播 |
| `timeoutTick` | 已就绪的当前限时选择所需循环声音 | 跟随当前暂停/许可/音量；不是选择计时器，不驱动超时结算 |
| `timeoutSilence` | 唯一核心实际接受超时默认选择后触发 | 与点击竞争只有被接受者发反馈；当前作者未配置此项，保持留白 |
| `save` | 独立试播手动检查点保存事务完成后 | 失败、只读查看、实际读档及全局记录/偏好保存不触发 |
| `favorUp/favorDown` | 核心已提交的选项动作组及进入动作组中，配置好感变量的数值变化 | 初始化、恢复和重试不发；下降沿用相对增益 0.75 |
| `tailfin` | 同一动作组中配置尾鳍变量实际增加 | 没有变化或减少时不播；不读取默认零或重算表达式 |
| `cg` | 正常进入时背景发生变化，且目标符合共享鉴赏 CG 规则 | 不要求首次解锁；同一背景连续节点、开局和恢复不重复播 |
| `chapterEnd` | 正常进入有文字的结局节点，或下一顺序目标带章节标记的普通节点 | 选择/分支节点不猜话末；初始呈现及恢复不发 |
| `endingNew` | 当前会话的结局事实在事务中首次加入全局解锁，并已提交成功 | 已有结局、同批重试、旧会话迟到回执、鉴赏、预览及恢复不触发 |
| `btnClick/btnHover` | 应用明确列出的游玩操作按钮点击/鼠标进入 | 独立开关；暂停、快进、标题、终态不触发；不覆盖选择和存档事件 |

当前读取器认识的提示音键均已接实际消费者，但这不代表正式界面所有按钮或全部演出已迁移。首次结局反馈以事务回执为准，不从页面缓存、存档或再次到达结局猜测。

`favorVar/tailVar` 显式配置时须指向已声明的数值变量；省略时分别使用既有 `好感/尾鳍` 名称，有对应数值变量才消费。缺少默认变量时不报假变化，显式配置无效则带来源拒绝。此设置只选择反馈对象，不改变剧情变量定义或可写性。

### 会话与表现接口

`PresentationAdapter` 可提供 `interaction(feedback)`，无声音的表现消费者可省略；它只接收声音事件，不计算剧情流转、条件或变量。`WebPresentation` 将事件交给当前 `AudioMixer`，游戏及独立编辑预览无需另写选择规则。

会话按一次节点访问记录选择是否已经提示，并区分正常进入与恢复。场面加载完成且核心进入 `choosing` 后才请求选择出现声；同一步骤的重复发布不发第二次请求。媒体重试保留本次已提示状态；读档和回退直接恢复已生效位置，不发一次性选择出现声。恢复后的限时循环声可以重新建立，依旧使用检查点剩余有效时间。

实际选择被接受后先停止当前循环声，再请求对应确认/超时提示；没有先响声再猜命令是否成功的路径。菜单、后台、宿主、回看、操作准备及退出暂停均通过既有会话暂停控制音轨。选择离开、错误暂停、呈现重建、返回标题及会话销毁会结束本次循环；加载结束后只按当前选择状态重建，不重算剧情。

手动保存捕获当前会话和表现身份，提交成功后仅在本次请求仍有效、仍是同一会话/表现、没有进入退出协调或快进时尝试播放。等待期间改为另一会话、返回标题或被新请求取代，不向后来会话播原保存提示。声音失败不能把已提交的存档改报为保存失败。保存成功时如处于声音暂停状态，提示被跳过，不在关闭菜单后补播。

### 分组变量变化与本次呈现

`RuntimeResult.variableChanges` 是动作实际执行后的输出。每组包含 `origin: choice/enter`、原节点及变化项的 `name/before/after`；选择组还带稳定 `choiceId`。同一动作组内先改后还原的变量没有净变化，不形成提示；选项动作加值而目标节点又减回时保留两组结果，不能以跳转前后总差抵消。

数组只随整个命令成功提交返回。目标进入、表达式或描述失败时返回空数组，并保留原运行状态；初始化、恢复和拒绝命令也返回空数组。它不是待执行动作、全局成果事实或可重放日志，不写入进度/全局记录，不改变任何存储格式。终端逻辑试播只额外显示分组结果，仍无声音。

纯 `StoryFeedback` 缓存当前内容的节点话末标记和共享鉴赏 CG 目录，把已提交的动作分组转换成声音计划；不运行条件、表达式或变量赋值。会话在目标场面第一次就绪后采用本次计划。选项变量提示延后 300 毫秒；进入节点存在即时动作音效时，变量提示避让 350 毫秒，否则随场面就绪触发。旧播放器只对独立 `se` 做这项避让，新规范化模型将即时 `seEvents` 也视为即时动作声；这是本片明确的调度差异，未进行听感验收。

延迟使用既有有效计时，按本次呈现代次归属，普通文字完成的核心步骤变化不会误取消它。菜单/后台/宿主暂停已安排的延迟；换节点、重试、恢复、错误、快进或销毁取消旧计划及计时。场面在其他暂停中才就绪时跳过本次计划，不在后来关闭菜单时补播。快进进入未读节点而停止时，按新场面的实际非快进状态采用提示。

读档、回退和媒体重试不重新生成这些一次性计划；已经保存的变量差异、CG 解锁或文字回看也不是新的声音事件。编辑预览复用同一规则，只反映本次内存剧情结果，仍不写正常游玩的成果。

### 首次结局解锁与终态反馈

`PlayerRepository.recordWithReceipt(batch)` 在原全局记录读写事务的合并回调中判定本批首次加入的结局，事务提交后返回 `{records, receipt:{batchId,newEndingIds}}`。失败/中止不交付回执；同批重复交付或后来再次达成已有结局时，首次解锁列表为空。并发页面以事务读取的最新值为准，不能各用旧缓存声称首次解锁。既有 `record(batch)` 仍只返回记录，持久化格式及计次规则均不改变。

`PlayerRecordWriter` 的提交回调增加回执参数。应用只为含结局事实的待提交批次保留本页会话代次/表现身份；回执完成即移除这份关联，离开页面清空。当前会话、表现和结局必须都匹配，且不是退出协调，才经队列发送 `ending-unlocked`。旧会话即使在后来才保存成功，也只更新全局成果，不向新会话播放。

会话校验步骤标识、终态结局 ID，并在本次会话最多确认一次；`SessionView.newEnding` 只是这次首次解锁已提交的显示状态，不写进度档。页面据此显示“新结局已保存，可从主页鉴赏”。音效音量 0、没有声音许可或暂停时可以不响，但已提交事实和显示状态仍保留；后来启用声音、关闭菜单或再次发布视图不补响。仅因退出/旧身份而未采用的回执也不在后来补播。

后续[共享结局卡片](<storage.md#endings>)消费相同终态与原批次提交摘要，分别显示待保存、失败及已保存，收藏进度来自已提交记录；新结局字样仍以本次 `SessionView.newEnding` 为准。卡片重试原事实，不在显示或返回标题时再次计次、播放提示或自动进入聊天，预览只显示隔离说明；这不改变以下声音生命周期。

`PresentationAdapter` 新增可选 `end(PresentationEndContext)` 及终态 `setPaused()`。`end` 取消进入表现、语音、音乐、环境声、一次性效果及循环，但保留终态反馈能力；没有该能力的消费者沿用销毁行为。`WebPresentation` 结束后只接受 `endingNew`，禁止重启剧情呈现，并继续响应音量、声音许可及菜单/后台/宿主/回看/退出暂停。返回标题、重开、读档或页面销毁仍完整 `dispose()`，取消终态声音和迟到回调。这里沿用新试播此前结束时停止剧情声音的行为，不增加结局音乐方案。

终态声音错误通过专用非阻断回调报告，不复用已取消的最后一句呈现信号。声音失败不改报全局保存失败，不撤回解锁，也不增加通关次数。回执及本页关联不是持久通知队列：提交后崩溃、关闭页面或身份失效可能没有提示，但解锁以数据库成果为准，不承诺跨进程声音“恰好一次”。限时样例与编辑预览不提交正常游玩结局事实，因此不播放这项首次解锁提示。

### 按钮点击与鼠标悬停

共享 `web/button-sounds.ts` 的 `connectButtonSounds()` 只接受应用明确给出的按钮列表、生命周期信号、启用判定和声音回调，不全页扫描、不监听剧情渲染。点击采用捕获阶段，在操作改变当前会话前判断；键盘激活的实际按钮点击也可反馈，空格/方向键直接推进画面不额外发按钮音。

悬停用按钮自身的 `pointerenter`，仅接受鼠标，触屏/笔不会模拟悬停；移动到同一按钮的子元素不重复触发。禁用、隐藏、inert 或明确 aria-disabled 的按钮不发声。应用再检查当前会话存在、未销毁/结束、未暂停/快进、页面可见及开关，混音器最后检查当前声音许可和音效音量。缺少配置保持无声，不生成替代素材。

当前游戏列表为底部操作栏的“继续/补全文字、自动、快进已读、菜单、对白回看、启用声音、隐藏/显示界面、全屏显示/退出、打开存读档、打开设置”；编辑预览为“继续、暂停、自动、启用声音、重试媒体、停止、隐藏/显示界面、全屏显示/退出”。实际选择、保存/读取、设置编辑/保存、源编辑/保存、标题、鉴赏、退出弹层及暂停菜单按钮不套一般按钮音，以各自已接事件为准。[游戏界面迁移](<player.md#game-ui>)只把打开弹层的两个操作栏按钮加入明确列表，弹层自己的按钮不随布局变化扩大声音范围；底部操作栏在 DOM 中仍是舞台相邻元素，编辑预览仍为外部控件。[共享输入](<player.md#input>)和[显示切换](<player.md#fullscreen>)中的直接快捷键/手势不额外套按钮音，隐藏后的其他操作按钮为不可见且 inert，显示按钮继续按原门控反馈。

点击 `btnClick` 使用原相对增益 0.35，悬停 `btnHover` 使用 0.22，继续乘玩家音效音量；原配置复用的资源身份不改。一般按钮音不声称剧情命令已接受或保存已成功。进入快进的这次点击可按点击前状态发声，快进中关闭快进的点击不补发。打开菜单/回看后，已经开始的短声音随既有暂停机制暂停；停止预览、返回标题或销毁会取消声音，不能保证停止按钮的声音完整播完。

第一话开关用[独立按钮偏好](<player.md#preferences>)，限时样例只用自身内存，编辑预览只采用作者 `btnSe`。监听每个消费者只注册一次，页面离开或编辑预览控制器销毁时随 `AbortSignal` 注销；重新渲染选择或重开预览不叠加监听。终态表现仍只接受 `endingNew`，不扩大为标题/结局按钮声音播放器。

### 混音与生命周期

交互声音使用现有“音效”通道，实时音量、宿主声音许可与会话暂停仍由同一混音器管理；BGM、环境声和语音无需另建。循环声不保存到检查点，也不属于场景环境声，不能因读档残留到没有限时选择的场景。

一次性提示触发时如正在暂停、没有声音许可或音效音量为 0，直接跳过。浏览器拒绝播放的一次性提示移除，不加入“启用声音”之后的重放队列；焦点丢失时也移除一次性提示。已经开始的提示可随普通会话暂停继续，媒体重试及恢复会清除旧提示，离开会话则全部取消。已接受选择的短确认声可跨正常节点切换，避免被紧接着的新节点取消截断。

`timeoutTick` 表示当前仍在进行的选择，暂停时暂停声音；音效调至 0 则停止循环，调回非零时仅在当前选择仍有效、未暂停且有许可时重新创建。播放或资源失败显示非阻断媒体问题并停止本轮自动重试；“启用声音”可显式重试当前循环。循环加载、解码或重播均不改变选择剩余时间、默认项或点击/超时的一次结算。

剧情一次性音效与交互一次性提示共享最多四路及同 ID 开头 400 毫秒内的重复抑制；限时循环单独最多一路。结束的音轨释放，返回标题和销毁释放全部声音。缺失文件、解码或播放拒绝沿用可见的非阻断诊断，不切换解释器或补下载素材。

## 声音收藏

### 作者目录

`packages/player/src/audio-library.ts` 的 `readAudioLibrary(content)` 只读取已校验内容的资源元数据，保持资源原顺序。它不读取玩家成果、推断路线、不解析文件名来猜类别、不请求资源位置或预解码媒体。

| 作者字段 | 读取规则 |
|---|---|
| `audioCategory` | `music/ambience/effect` 分别为配乐、环境、音效；未设、空或 null 不纳入收藏，其余值明确拒绝 |
| 资源种类 | 明确标记的条目须为登记的 `bgm/se/vo`，不能把图片或任意位置当成声音 |
| `name` | 沿原规则去掉“作者原声”前缀和环境/剧情/UI 前缀，将下划线显示为空格；未标注或结果为空时显示稳定 ID，非法非字符串拒绝 |
| `dur` | 有限非负的作者标注秒数；未设时显示未标注，不把标注时长冒充已解码的实际时长 |
| `auditionOnly` | 布尔，缺省 false；沿原目录将候选原件与正常分类分开，不把它当成解锁条件 |
| `playbackGain` | 仅配乐试听采用，与旧 `trackGain` 一致限制在 0～1，缺省 1；显式非法数值拒绝。环境/音效不套剧情场景增益或压低 |

单条读取 `readLibraryEntry(resource, source)` 由目录和混音器共用，错误含来源及资源字段。其他来源元数据、资源字节、ID/顺序及内容修订算法保持不变；此目录不是新增权威作者源或媒体授权清单。

### 共享试听

`AudioMixer.previewLibrary(assetId, observer)` 只在独立、已清空的混音实例使用，重新读取已登记资源及同一分类规则，不信任界面传入的类别/增益。配乐采用 music 通道并循环、环境采用 ambience 并循环、音效采用 effects 单次；仍与当前玩家分轨音量相乘，不创建场景、进入动作、有效计时、事实、存档或主线语音完成回调。

原 `previewVoice()` 继续只接受 `vo`，与收藏共用内部试听生命周期及 `AudioPreviewObserver`；旧 `VoicePreviewObserver` 类型名保留。新试听前须取消上一条，独立实例不得同时接主线音轨或两个试听。每次实际 `playing`、结束或非阻断错误只更新原试听观察者，旧取消/播放承诺不能污染后来试听。

开始时未获许可、暂停或该通道音量为 0 明确拒绝，不保留以后自动补播的音轨。已经播放的轨道仍受既有混音器暂停、声音许可和实时音量控制，不因调整而重播。

### 主页接线与生命周期

`apps/game/src/sounds.ts` 的 `SoundLibraryPanel` 只接只读内容/资源、当前分轨音量、应用提供的声音许可/暂停能力及可选同步显示委托 `transition(change)`，不接会话、检查点、玩家成果或偏好仓库。委托须同步执行一次显示变更，未提供时直接执行；游戏只绑定已登记声音弹层的 `DialogFade.change()`。首次打开时才创建独立混音器；打开目录不创建音轨或请求声音，点击具体曲目才请求对应本地资源。

主页提供配乐、环境、音效三个分类，按原顺序列出非候选条目；候选原件在单独折叠的“素材归档 · 候选试听”中。名称、分类和作者标注时长用于识别，时长未标注明确显示。沿旧收藏入口无需剧情解锁，不新设声音收藏成果或通关规则。布局已沿旧版迁移，正式框架和完整视觉尚未验收。

每次试听先停止上一段，支持同曲重播和显式停止；当前曲目标记与状态属于原试听代次。加载、解码或浏览器拒播说明本条资源 ID，可再次点原曲目重试；旧播放承诺、错误和结束不能更新新曲或关闭后的状态。切换分类只浏览目录，不自动换曲。

音量沿用正常入口当前的声音设置；每次打开重新采用该入口值，不把限时样例的内存调整带回主页。音量修改直接更新现有轨道，不重建或重播。面板不新增偏好保存，不能由试听改写剧情进度或解锁成果。

后台、宿主暂停或声音许可中断时，已有试听暂停；窗口和许可恢复后从原试听位置接续，保留旧收藏行为。原生状态常规刷新只同步许可，暂停状态改变时才暂停/接续，不反复请求播放。首次点曲时尚未获得许可则不排队，恢复后须再次点曲；“启用声音 / 重试许可”只申请许可或重试当前仍持有的轨道。浏览器拒播已停止的曲目须再次点曲。

返回主页、Esc、原生返回键、开始/读档采用、返回标题、正常退出和页面销毁均关闭面板、取消试听并清除监听；主页关闭时释放原生声音焦点。正常退出的票据取消不会重新打开或补播旧收藏。再次打开重建本次目录控件，不保存试听位置到存档。这个入口只在主页开放，旧插件/剧情内入口未迁移，也不决定读档语音体验。

没有新增存储格式、偏好、宿主桥、素材、网络服务或依赖。旧声音收藏及旧入口保留；页面接线已编写仍不等于运行集成通过、听感验收或 M5 完成。

### 旧版分类与曲目布局

该布局片只新增分类显示标记及游戏样式，不新增素材或直接复制旧 CSS 的相对资源 URL。随后从 `67ebda9` 将[原装饰来源](<player.md#appearance>)接入现有外观装配：配乐背景为旧 CSS 指向的原 B38 WebP，三个图标只读提取静态形状，内嵌前端并登记来源摘要。收藏打开才设置装饰变量，关闭清理；不新增媒体播放/解锁或将装饰当作剧情资源。

### 试听控制与内部显示切换

真实分类变化及候选区展开/收起使用同一同步显示委托：先静态采样登记的声音弹层，再立即改变原可见区域或原 `details.open`。候选的原生 summary 点击/键盘激活走同一处理，防止内置切换再执行一次；已选分类重复点击不采样。不替换原条目按钮/监听、重设当前试听代次或调用播放、停止、许可请求/暂停/调音；原曲即使属于隐藏分类或收起的候选仍由现有实例持有，可用顶部原停止按钮取消。

试听开始/结束、许可/前后台变化和诊断仍直接更新原状态，不因这些刷新反复制造视觉事务。静态副本不复制活动音频或任何监听，开关、取消及后台/宿主/减少动态效果/尺寸/离开清理复用现有 `DialogFade`；实际显示变更不等待动画。目录、原音频请求与暂停接续语义不变，不新增资源、偏好、存储/宿主格式或正式框架决定。

## 对白回看与独立试听

### 当前实现

`packages/player/src/session.ts` 在当前游戏会话内维护 `DialogueEntry`：

- 进入节点时记录实际求值后的说话人与台词，保留节点、章节、当次 `voiceId:string|null` 及会话内 `visitId`；空台词不占记录。语音身份直接取同次核心呈现，不在回看时按文字或节点索引猜资源。
- 唯一核心接受选择后，先记录实际选项与是否超时，再记录目标对白。选择记录使用选择发生前的访问 ID，与该次选择节点对白归属相同，目标对白属于新访问；拒绝、过时点击或重复超时不追加选择。
- 媒体重试不追加同一对白；实际再次到达同一节点属于新的出现记录。
- 恢复进度后从当前保存的完整台词开始新的回看，没有把全局已读集合伪造成当前路线对白。
- 沿用旧播放器回看最多 300 条的容量，统一限制对白和选择，只存定位文字、语音及访问 ID，不存图片、播放对象或检查点。该容量不代表尚未确定的回退历史容量。

`GameSession.dialogueHistory()` 返回分离后的数据副本，`SessionView.dialogueCount` 供界面更新入口状态。回看不是可写的核心引用，也不携带回退或语音播放回调。新增字段只在当前会话内存中，不改进度/成果/偏好或宿主格式。`visitId` 只用于和同一所属会话的 `rollbackTargets()` 匹配；它不是跨会话稳定 ID，也不能据此获取任意内部检查点。

### 试播接入

`apps/game/` 的“对白回看”打开只读对话框，按实际出现顺序显示最近台词和选择。文本通过 `textContent` 渲染，不当作 HTML 执行。

打开前通过同一会话队列加入独立的 `history` 暂停原因，暂停文字、声音及有效计时。关闭按钮与 Esc 只解除该原因；菜单、后台、媒体错误或宿主暂停继续有效。对话框打开期间不向剧情发送空格、方向键或自动播放快捷操作。

新开、读档、返回标题及页面离开会清理旧回看。记录仅属于当前会话，不写进进度槽位、全局记录或聊天记录；读档清空本片内存回看，不等于已经决定正式产品的历史持久化范围。后续[进度回退](<storage.md#rollback>)采用检查点时会截断未来路线文字并重新显示目标句；打开回看本身仍不触发回退。

### 从条目显式回退

打开面板时，应用同时传入 `dialogueHistory()` 和 `rollbackTargets()` 的副本。`DialoguePanel` 只按 `visitId` 对应目标；同一节点循环访问不会混为一个位置。只有仍保留且不属于当前访问的目标显示按钮：对白为“回到此处”，实际选择为“回到此选择之前”，跨选择的目标另有文字标记。未捕获、被容量淘汰及当前访问不提供可猜测的回退位置。

面板内单独提供“恢复语音”和“回退范围”，每次打开均不预选；明确选好 `silent/replay/resume` 及是否跨选择后才可提交。仅查看、滚动、选择策略、试听或关闭都不恢复进度。当前画面须就绪且文字完整，结局后仍不支持；后台或宿主暂停时禁用发起操作。默认边界、正式容量和语音体验仍未决定。

点击后停止独立历史语音并禁用重复请求。面板只向应用交付目标 ID、明确策略及本次打开的取消信号；它不持有核心、检查点、玩家仓库或文件写入能力。应用的 `rollbackTo()` 与原下拉入口共用准备、全局事实提交、当前投影读取和 `GameSession.rollback()`；核心再次检查原会话/步骤、目标是否仍在历史及选择边界。跨选择被拒绝或准备失败时，保留原进度、历史和面板，可以调整设置重试。

关闭按钮、Esc、原生返回、换会话或退出会使本次打开的信号失效。若检查点尚未采用，准备结果不能后来替换游玩；关闭会立即解除本次 `operation` 暂停，再按原流程解除 `history`，其他暂停继续有效。已发起的全局事实事务可以完成，它不等于已恢复进度；取消不撤销事务或已采用的检查点。

采用成功后才关闭回看，截断未来路线文字，原全局已读、CG、结局和周目保留，不自动写进度槽位。目标媒体错误沿用同一已恢复位置重试，不能冒充回退未发生。旧面板的请求完成、失败和语音回调均须匹配本次打开及所属会话，不能更新重开的面板。

### 旧版条目与弹层布局

返回按钮和简短说明位于正文滚动区之外；打开后只将正文滚到最新记录，不移动返回按钮或焦点。正文顶部操作区保留试听状态/停止按钮及可展开的“回退设置”，范围与语音每次仍为空，展开本身不发恢复意图；回退结果状态在设置收起时仍可见。展开区高度有界，可滚动访问长说明与控件；底层试听、回退准备/关闭取消及会话归属保持原通道。

只调整游戏面板的 DOM/样式与打开时滚动目标，没有修改会话历史、存储、暂停原因、语音默认或回退边界。

### 历史语音试听

`apps/game/src/dialogue.ts` 的 `DialoguePanel` 展示分离后的记录。只有 `line` 且有语音 ID 的条目显示“重播语音”；选择与无配音对白不造按钮。上方状态及“停止历史语音”控件在滚动时保留，文字和诊断继续通过 `textContent` 写入。

面板单独持有一个共享 `AudioMixer`，不持有剧情可写接口。`previewVoice(id, observer)` 校验资源为 `vo`，从头播放本条，并通过实际 `playing` 事件、结束及非阻断问题更新试听状态；不建立场景或触发进入动作、核心 `voiceEnded`、计时、事实或检查点。新的点击先取消上一条，最多一段试听；同一句再次点击从头重播。

试听使用当前入口的语音音量，偏好晚到保存结果/本页调整更新音量时不重播。触发时音量为 0、未获准或暂停则不创建待播音轨；现有试听调为 0 时沿用静音运行规则。按钮声音开关只管操作反馈，不控制对白试听。第一话和限时样例分别采用各自内存设置；本片没有给编辑器增加回看 UI，编辑预览仍共享相同的会话数据能力。

打开回看后主线文字、原语音、音乐和有效计时仍受 `history` 暂停；试听只允许在当前回看仍属于当前会话、页面可见、宿主未暂停且获声音许可，并且没有其他暂停原因时开始。菜单、加载、媒体阻断、操作准备及退出暂停不会被试听解除。

点击可请求既有原生音频焦点；如许可尚未返回或被拒绝，面板说明恢复后再次点击，不等待后补播。失去前台/宿主许可或新增其他暂停会取消试听，不在回来时自动续播。浏览器播放拒绝、资源无法读取或解码只显示本条提示，原进度及主线媒体错误保持原值。

关闭按钮、Esc、原生返回、重新开局、读档、回退准备、返回标题、正常退出及页面离开均取消试听；离开弹层前先取消，随后仅解除原 `history` 暂停。主线原语音仍从自己的原暂停位置继续，试听没有替换它。原试听的代次和取消闭包保护迟到的播放/结束/错误，不得改变后来的条目状态或新会话。关闭时注销本次条目监听，面板销毁时释放独立混音器。

### 仍未实现

进度回退及条目按钮已接入；正式跨选择/结局边界、历史容量与持久化、手账归属仍待后续。回看、试听与实际回退仍为独立操作，单纯查看不修改变量或新增通关事实。历史语音不会因本片进入进度存储或变成读档默认体验。

## 鉴赏图片

### 读取与权限

`apps/game/src/gallery.ts` 的 `GalleryPanel(root, content, resources, transition?)` 只接当前已校验内容、本地资源访问、可选同步显示委托和应用传入的已提交 `PlayerRecords`。`transition(change)` 须同步执行一次显示变更，缺省直接执行；游戏只委托给已登记鉴赏弹层的 `DialogFade.change()`，没有解锁、记录或剧情能力。`open(records)` 核对作品身份后展示，`close()/dispose()` 释放当次内容；面板不接存储写入、剧情会话、进入动作或结局结算接口。

应用打开前仍先提交已有待写事实，再从同一 `development/normal-entry` 仓库重新读取记录。异步读取同时绑定应用入口请求及本次鉴赏请求；关闭、开始游玩、退出或页面离开后不能采用旧响应。每次重开重新读取当前记录，不用图片缓存或旧面板充当全局成果来源。

结局和 CG 均沿用共享 `galleryCatalog()` 的当前内容目录及原顺序；结局首次日期、周目和通关次数继续来自已提交记录。目录之外的历史成果由原仓库保留，不因当前面板没有条目而删除。

锁定 CG 只显示禁用占位：不创建图片、不读取资源位置，也不显示未解锁名称。已解锁条目可以在缩略图不可用时继续尝试大图，不以图片成功显示作为新的解锁条件。

### 图片的当次归属

| 对象 | 当前行为 |
|---|---|
| 缩略图 | 原生懒加载、异步解码，只在本地登记位置读取；说明分别显示待读取、名称或带资源 ID 的失败原因 |
| 本地大图 | 每次只拥有一张，显式点击后进入独立查看区并开始读取，解码完成才显示；顶部返回目录，状态包含本次名称/资源 ID，错误提供原资源重试 |
| 缩略图重试 | 取消原尝试，再读取同一条已解锁资源；不刷新成果、不换到其他图片或联网补图 |
| 返回鉴赏目录 | 取消当次图片并清空来源，收起查看区，恢复本次目录滚动；焦点回到原条目的实际按钮 |
| 返回主页、Esc、原生返回、开始游玩、正常退出或离开 | 同步关闭面板，注销当次按钮/媒体监听，移除全部当次图片来源及元素；重开建立新面板状态 |

文件内 `GalleryImage` 每次载入用独立对象识别图片、事件与解码。重试、换图和关闭先使旧对象失效；无法真正中止的解码完成或错误必须匹配原对象，不能更新新图、新面板或已关闭的状态。资源路径异常与图片读取/解码失败都留在鉴赏说明中，不把已提交成果改报为丢失，也不触发剧情重试或重新进入节点。

所有名称和诊断使用文字节点，不拼成 HTML。缩略图状态不逐条进行 live 播报；大图状态使用单独的状态区域，打开查看区可聚焦，关闭恢复原按钮。图片解码及可见性状态只在当前面板内存中，不进入进度、成果、偏好、预览或聊天。

本片没有提供新的解锁、解锁调试、导出、上传、资源替换或删除入口；没有接声音收藏或完整剧情结局树/路线图编辑。当前结局收藏仍是作品已有结局的只读列表，视觉过渡的已接范围见下节，不能据此宣称全部旧鉴赏效果或布局已验收。

### 旧版分类与布局

弹层返回区与内容滚动分开。切换到结局分类会同步取消当前大图、清空选中身份并收起查看区，旧解码不能将其重新打开；分类按钮保留焦点。缩略图仍沿原尝试归属，不因切类重新获取解锁或请求锁定图片。每次重开仍重新读取成果并重建目录；格式、解锁规则、图片来源和关闭清理不变。

### 独立大图与内部切换

返回目录立即使原大图请求失效、清空来源/选择并恢复原目录滚动与条目焦点；隐藏目录保留原缩略图实例，不为这次切换重读成果或重新装载全目录。重试使用仍选定的原资源，关闭鉴赏/换会话/离开仍清理全部图像与监听；Esc/原生返回继续关闭鉴赏，未新增返回键优先级。

分类实际变化、显式打开/返回大图、原资源重试及当次解码成功显示，通过应用提供的同步委托复用[登记弹层内静态过渡](<player.md#performance>)。同一分类重复点击不采样，缩略图逐张完成和故障说明不反复制造动画。加载/失败说明即时生效，解码完成再次核对原尝试及原选择对象，才显示当前图像；旧结果不能重新开启已经离开的查看区。副本只带已有可见画面，无输入、事件或媒体能力，不延迟真实图片取消、焦点或分类采用。

仍消费重新读取的已提交成果和当前目录，不新增成果/进度/偏好/宿主格式，不扩大共享舞台的快照范围；该接口不进入编辑预览。
