# M3 共享游戏会话与表现

共享实现位于 `packages/player/src/`。这是新核心的消费者，不是另一套剧情解释器；游戏应用和[独立对白编辑预览](editor.md)均从这里接入。编辑预览只使用内存已读，不接玩家存储或聊天。共享能力未完成类型检查或游玩验收；服务器曾按用户要求启动并确认页面响应，随后已停止，不能据此宣称剧情运行通过。

当前游戏入口已开始[沿旧版迁移界面](game-ui.md)：原封面/右侧菜单、窗口舞台和底部操作栏，设置/存读档/回退收进弹层；限时样例、只读通关准备和诊断移入“开发工具”。新壳未启动，仍使用隔离开发记录，不切正式发行或决定最终框架。

## 统一测试时的可视入口

用户已安排在重构末尾统一测试；以下为保留的操作说明，不要求逐片试玩，本轮没有执行。

在仓库根，使用 Node `24.15.0` 环境：

```powershell
npm ci --ignore-scripts
npm run game:dev
```

浏览器打开 `http://127.0.0.1:5173`。2026-10-24 已按用户授权安装本机依赖并启动过迁移前开发服务器，只确认入口 HTTP 响应；服务随后已停止，本次界面迁移没有启动或构建。其他设备仍须准备上述环境。端口占用会报错，不自动换到未知端口；默认只监听本机。

1. 选“开始游戏”（原“从第一话开始”），点击画面补全文字，再点继续，听一下语音、环境声和换曲。
2. 返回标题，打开“开发工具”，选“限时选择样例”。它从真实节点 `pm8x8v2h` 开始，但五个变量明确使用声明初值 0、周目 1、结局数 0；**不是第五话真实路线进度**，也不用于路线好感验收。
3. 选项出现后打开菜单或切到其他标签页，回来确认剩余倒计时没有偷跑。选“（沉默）”或等待到期，应只结算一次并进入目标；暂停菜单的“开发工具”可展开状态查看当前变量。
4. 在文字/声音播放中打开菜单，选择“重新开始”或返回标题，确认旧文字、延迟音效和计时没有继续污染新场面。
5. 用 H/画面右键/长按隐藏，再点画面只恢复；按住 Ctrl 快进已读，松开、切后台或换会话应停止临时模式。下滑/上滚可打开回看，长对白和选择保留滚动；更多焦点及迟到操作情景见[共享输入](input.md#留待统一测试)。
6. 用全屏按钮/F11/Alt+Enter 切换，浏览器 Esc 先退出全屏；限时选择和声音不因显示重新开始，原生返回键仍按既有菜单处理。错误、窗口确认和预览隔离见[显示说明](fullscreen.md#留待统一测试)。
7. 在主页打开[声音收藏](audio-library.md)，分别选配乐、环境和音效试听；核对分类、候选原件、循环/单次和当前分轨音量。切后台后恢复原位置，关闭后声音停止；再开始第一话，不应残留试听或改变成果。
8. 在主页打开[章节试阅](chapters.md)，核对原顺序、节点起点及全部初始条件，选择一章后仍用同一会话推进。试阅不写存档或全局成果，每次新建内存已读和人工投影，设置单独留在本页内存；不是此前真实路线进度。

自动不会代选；快进只经过当前范围的已读节点，第一次游玩不能跳过未读。M4 已接上[存读档](saves.md#独立试播接入与手动试用)、[全局玩家记录与主页鉴赏](records.md)及[会话内回退](rollback.md)：第一话已读持久保留，限时样例只使用独立内存已读。[通关后入口](chat.md)仅准备已提交通关事实的只读上下文，尚未接正式解锁、联网发送或聊天记录；查看详情与实际读取进度仍是不同操作。

## 会话的公开接口

`createGameSession` 接收已校验内容、当前只读玩家投影、宿主单调时钟、表现适配器、按范围隔离的已读集合和结果回调，返回 `view / send / dialogueHistory / rollbackTargets / rollback / captureCheckpoint / dispose`。可选 `resume` 要求显式提供检查点与本次语音恢复方式，直接从已生效进度创建核心，不先进入开局节点。可选 `rollback: {capacity}` 显式开启当前会话的有界检查点历史。

- `send` 是点击、选项、菜单/后台暂停、自动和快进的统一串行入口。
- 自动与快进互斥：开启自动关闭快进，请求开启快进关闭自动；未读或选择仍能拒绝实际快进。按键临时所有权由浏览器输入层管理，不进入检查点。
- `auto-wait` 意图更新后续普通自动等待倍率，不重建当前计时；应用通过独立[阅读偏好](preferences.md#阅读偏好的字段与时机)提供，未传初值时使用作者默认。
- 可选 `readoutEnabled` 和 `readout` 意图控制后续[话末存档点数值显示](readout.md)，缺省采用作者 `showStats`，未设为关闭；每次呈现固定显示正文，普通自动等待使用同一文字长度。只向表现传正文副本，核心、回看、槽位摘要不变；改变开关不重置当前或恢复剩余时间。
- 可选表现能力 `interaction(feedback)` 消费[选择与存档提示音](feedback.md)：选择出现按一次访问的首次就绪发出，确认/超时来自实际接受的核心事实；循环只跟随当前选择与暂停，不进入检查点或替代计时。
- 可选 `end(context)` 结束进入表现并保留终态反馈，终态通过表现的 `setPaused()` 接续生命周期；会话只在匹配的已提交通关回执下接受 `ending-unlocked`，更新本次 `SessionView.newEnding`，不重发结局事实或改写进度。
- 每个可推进操作携带 `{session, epoch, step}`，分别识别运行实例、当前呈现和核心步骤。应用用递增整数分配会话代次，不用墙钟。
- 表现只通知场面就绪、文字完成、语音结束或媒体问题，不持有核心的可写引用。场面资源未就绪时单独暂停有效时间，不能让重试消耗选择时间。
- 每次换节点或重建场面取消旧 `AbortSignal`、文字/选择/自动等待、播放句柄；无法取消的媒体加载仍须核对有效信号。
- 暂停原因分别记录，关闭菜单不会误解除后台或宿主暂停。有效时间不把后台时长补算进去。
- 可选 `initialPauses` 在首次呈现前采用当前宿主/后台状态。读档及回退准备使用 `operation` 原因，不能因准备完成而解除原生窗口的 `host` 暂停；[Windows 接线](windows.md)只更新生命周期，不发推进命令。
- [正常退出](exits.md)使用独立 `exit` 原因，等待已有写入和全局事实；退出票据取消只解除本次暂停，重试不重新捕获进度。正常关闭、自动存档和系统回收恢复仍是不同能力。
- 媒体重试重建同一个已生效节点，不再次进入、加变量或发剧情事实；选择剩余时间沿用，不重置倒计时。
- [对白回看](history.md)返回当前会话最近 300 条文字/语音及 `visitId` 副本；独立 `history` 暂停不影响菜单、后台或宿主的暂停归属，打开与关闭对话框不推进剧情。条目回退须显式选择本次范围/语音，只按当次访问对应仍保留的检查点，继续交回相同的 `rollback()`。
- `rollback(request)` 通过同一队列校验目标、本次跨选择策略、语音方式和当前全局投影；采用后更新核心步骤及呈现代次，截断未来路线历史，保留全局成果。当前只支持稳定非结局阶段，捕获失败通过 `SessionView.rollbackIssue` 显示，不补造数据。

`ActiveTimer` 只依赖 `{now, schedule}`，用于可暂停的延迟和倒计时；剧情核心仍不读取时钟。文字首次点击只补全当前句，不顺带推进；自动不会代答，快进遇选择或未读停止。已读由应用接到独立全局记录，正式发行记录范围仍未切换。

只加载当前背景与当前立绘，不一次解码全部图片或声音。未支持的实际转场/外观/动作会给出阻断诊断，不静默跳过。必需图片失败暂停场面，可重试当前已生效节点；声音读取/解码/浏览器播放权限失败显示可见提示，主线可继续，“启用声音”可重试播放。没有合成提示音或替换素材。

[共享镜头与场面过渡](performance.md)沿用旧镜头的 1～1.04 缩放、600～3000ms 时长及缓动，`shot.focus` 只作缩放中心，背景取景独立读取 `view.position`。场面镜头跨同背景正常对白保留进度，换句/加载暂停后继续，完成不重播；恢复、回退和媒体重试直接采用稳定终点，不加入帧级存储。黑场/白场转场与瞬时特效使用独立遮罩；正常主线变化按旧条件优先保留场面/对白/选择的静态副本，再以 360ms 淡出，不给副本交互或延后剧情计时。无背景也是有效场面；现有标题、暂停菜单和首次终态已另接独立视觉淡出，终态回执不重复触发；现有游戏弹层开关另由应用专用的 `DialogFade` 接线，不扩大共享舞台/预览快照范围，未运行或视觉验收。

[角色演出](performance.md#角色动作移动和层级)保留六种原动作、进退场关键帧及分段缓动；已有角色移动/高度和滤镜分别采用 500/900ms，直接归当前呈现暂停/取消，恢复不触发 CSS 位移过渡。非说话角色沿原亮度/饱和度滤镜，软切副本留在旧位置，每次按目标立绘顺序更新层级；游戏与预览同用，未运行或视觉验收。

[瞬时镜头与持续氛围](performance.md#瞬时镜头与持续氛围)保留原地震、横甩/模糊、缩放、闪光和眨眼曲线，以及原暗角、晕眩、漂移、脉冲、水下气泡和慢推近。背景/立绘运动层与氛围、遮罩、对白分开，动态细节均受暂停控制，同名氛围连续保持；恢复不重播瞬时效果，慢推近直接采用终点，减少动态效果保留静态着色。声音沿既有混音器，未新增素材、存储字段或有效计时，未运行或视觉验收。

持续轨道由混音实现拥有，不因每句呈现取消而重启；语音、一次性音效、延迟和单句动画属于当前呈现，离开时取消。独立场面镜头在换句时暂停，由下一目标决定沿用、稳定或替换，不持有旧步骤回调。重试不重播进入音效，当前对白语音可重新尝试播放。实际读档另走准备和新会话，语音按本次显式方式处理；媒体重试不能冒充读档。音乐继续、停奏和位置恢复代码已接入，但未执行听感验收。

`WebPresentation` 可显式接收初始声音许可，并以 `setAudioAllowed` 更新；混音器把宿主许可与会话暂停分开。Android 未获焦点时保持静音，不让未播放语音阻塞自动阅读，也不积攒过期一次性音效；焦点打断由宿主暂停当前会话，恢复沿用原位置。浏览器与 Windows 仍默认允许尝试播放，浏览器权限失败沿用现有媒体提示。宿主桥和焦点状态见两端说明，尚未运行验证。

Android 的[输出变化中断](android.md#输出变化中断)通过独立原生声音控制器复用同一许可/暂停通道；返回前台不自动确认输出变化，显式重试后才重新申请。共享页面提示覆盖焦点和播放设备变化，不增加剧情或存储字段；轨道处理仍由原混音器拥有，未做真机声音或路由验收。

声音设置已接入配乐、环境声、语音及音效四轨滑块，即时作用于现有音轨；“保存音量偏好”独立持久保存，读档与回退不恢复旧音量。未显式保存的调整留在本页内存，限时样例和编辑预览不接正常游玩偏好。音量协议、默认值、失败重试及统一测试情景见[独立声音偏好](preferences.md)；当前未运行验收。

阅读设置已接入逐字间隔、自动等待倍率、文字大小及对话框透明度。字号/透明度即时生效，文字速度用于下次呈现，自动倍率用于后续新安排的普通自动等待；修改不重置当前计时或恢复剩余时间。阅读单独显式保存，与音量共用控件状态及失败重试实现；范围、默认值与边界见[阅读偏好](preferences.md#阅读偏好的字段与时机)，未运行验收。

[交互声音起步](feedback.md)已接上作者原配置的选择出现、确认、限时循环、可选超时提示及手动存档成功反馈。读档、回退和重绘不补播一次性声音，当前限时循环可以按暂停/声音许可继续；与剧情一次性音效共用音效通道及四路上限。编辑预览复用选择反馈，尚未运行听感或竞态验收。

[新结局反馈](feedback.md#首次结局解锁与终态反馈)进一步接上事务提交后的首次解锁回执，只在仍对应当前终态会话时显示“新结局已保存”并尝试声音。终态表现保留声音许可、音量和暂停接线，离开才完全销毁；静音、重试已有批次、旧会话回执及预览不产生新解锁声音，不改变原计次和存档格式，未运行验收。

[回看语音](history.md#历史语音试听)保留当前会话当次呈现的语音 ID，游戏回看面板可手动单段重播/停止。声音复用共享混音实现的独立实例和当前语音音量，主线保持原暂停；关闭、其他暂停、后台/宿主许可失效及离开取消，恢复不补播。试听不发核心声音完成回调、不改变检查点或全局事实，未运行或听感验收。

[作者外观与鲸鱼皮肤](appearance.md)已接主题/封面读取、原菜单/选择/对白图形及字号字体；菜单沿用最终右侧错位覆盖，标题/选择和场面共用作者坐标缩放。对白字号采用作者 `theme.size`，本作品为 25px，再乘玩家阅读倍率；不改变当前计时。图形由构建装配只读提取，运行端不加载旧页面；封面失败可独立重试，未运行或视觉验收。

[共享输入与隐藏界面](input.md)统一游戏/编辑预览的点击、键盘和长按，按住 Ctrl 仅管理本次临时快进，外部暂停或换会话清理；编辑键盘限定预览舞台/操作栏。H/右键/长按隐藏后下一次继续只恢复显示，隐藏本身不暂停；游戏可下滑/上滚回看，长对白及选择保留滚动。输入层不决定回退边界或修改存储，未运行或验收。

[共享全屏](fullscreen.md)接入按钮/F11/Alt+Enter 和浏览器状态，游戏整页保留全部弹层，编辑器仅预览区全屏。两端使用独立可选显示扩展，原页面/请求匹配后确认，原生缺少能力时仅禁用显示切换；不回落 DOM 全屏、不改变剧情或持久格式。显示往返只更新尺寸并清理旧手势，不重新开始文字/声音/计时；未运行或设备验收。

开发入口使用 `/@fs/` 本地资源 URL，可能包含开发机路径；这些只存在于开发模块，不写入规范化内容，也不是可分发游戏清单。开发可视入口复用转换器的已校验结果，内容和资源按每次服务启动固定一份修订，修改作者源或资源后需要重启服务。

应用现在通过异步 `loadContent(signal?)` 获取内容和资源位置。开发装配仍使用本地转换器；随包装配读取 `game-package.json` 与规范化剧情，校验剧情字节、修订和资源身份后才启用开始及鉴赏按钮。离开页面或开发热替换取消启动任务；读取失败显示诊断与重新读取按钮，不创建会话。两种装配都不加载旧作者脚本、旧播放器或插件。包内路径、产物命令及尚未接入的宿主能力见[随包加载与集成产物](delivery.md)。

当前游戏页已接[沿旧版迁移的界面壳](game-ui.md)，仍不是原作品全部 UI/动画的等价迁移。主页已增加基本 CG/结局鉴赏、独立声音/阅读/按钮偏好、选择/存档/变量/CG/话末/新结局/操作按钮反馈、原鲸鱼皮肤/作者封面、首立绘选择避让、横竖分区及显式全屏；标题六项菜单、底部操作栏和设置/存档/回退弹层已编写，开发诊断收进工具。[存档摘要卡片](slots.md#沿旧版迁移的摘要卡片)已接现有目录与独立操作，未运行或视觉验收。[共享结局卡片](endings.md)已接到核心终态，明确区分达成和原批次提交，提供原记录重试与返回标题，编辑预览明确不写成果。手账、存档缩略图、其他弹层的原版细节、完整窗口设置、自动首触全屏/方向锁定及旋转提示仍待后续，现有配置保留在内容来源中。M5 仍需全量路线、完整声音/演出观感及平台验收；旧入口仍为原图形的构建来源，不能据此删除。

## M4 接续

会话现新增 `captureCheckpoint(token)`，通过同一串行队列捕获稳定检查点；`SessionView.canCheckpoint` 表示当前切片是否可捕获，`Playback.capture` 提供分离的声音数据。过时步骤、未就绪场面及结局明确拒绝。格式、覆盖范围和存储契约见[检查点与存储](saves.md)。

试播页增加手动保存、按入口查看与实际读档，数据只进入各自开发/预览槽位，第一话全局成果另外保存。[命名槽位与目录](slots.md)支持各入口独立选择、每页 20 条只读摘要及损坏/不兼容诊断，原 `manual` 继续保留；选择或浏览不恢复进度，保存及其重试固定原目标。读档与会话内回退采用当局变量与有效计时、刷新当前全局投影，不回滚已解锁结局、CG 和周目；只读查看、对白回看和鉴赏不产生新事实。回退不自动写手动槽位，也不跨新开、读档或页面离开保留历史。

## 本阶段边界

M3 本身不含正式存档、读档、回退或玩家记录持久化；后续 M4 切片以专门说明为准，不等于 M4 全部实现。正式语音恢复仍按当前边界推进，跨局记录以专门说明和用户确认的全局保留规则为准；2026-10-25 用户明确没有旧存档，不做兼容/迁移。

已增加显式 `npm run game:build` 集成构建入口，未来成功时输出独立前端、剧情和随包素材；未执行，没有生成产物。它使用独立的随包内容装配，开发 Vite 配置仍只服务本地试播。当前应用及记录范围仍用于集成试用；[Windows](windows.md)与[Android](android.md)已编写独立启用的宿主和状态接线，尚未编译运行。两端共用初始暂停桥，Android 返回键只关弹层或切换菜单。React/Vue、正式编辑器、宿主统一及资源安装方式仍未决定。旧默认入口、作品、素材和 CI 保留。
