# 作者源读写边界

- 这里只服务独立本机编辑入口，不挂入游戏开发入口、游戏包或原生宿主。
- 读取 `content/story/project.json` 登记的纯 JSON 分章作者源，不执行作者代码。预览和保存共用 `assembleAuthorProject` / `compileSourceContent`，不维护宽松的第二套转换器。
- 预览外观通过共享 `whaleAppearance()` 只读装配 `content/game-ui/whale.json` 中的原鲸鱼图形，不执行旧 HTML，也不新增作者源/图片写入 API。本体迁移共享来源时仅保持现有预览兼容，不因此扩展编辑能力。
- 写入路径只从当前仓库 `content/story/project.json` 的章节清单和已读取节点决定。请求不得指定文件路径、命令或任意字段；整个登记文件集合的原摘要、节点 ID、原值与可写字符串范围逐项核对。
- 字符串 token 定位只用于保留其余原字节/格式，不承担剧情解释职责。禁止整包重排、扩展映射或顺手修改素材。
- 保存先取得 `content/story/.author-lock/` 合作锁，准备全部变更章备份、候选与事务记录后才能替换正式章节；替换前重查全源/路径，替换后核对完整新集合。读源拒绝锁存在期，失败/中断保留锁与恢复记录，不自动采用混合源。备份位于 `.author-backups/`，不是第二作者源。此协议不是跨文件原子 rename，不能保证拦住外部编辑器或断电持久性，不能宣称无竞态。
- 备份、失败候选和异常锁保留为本机恢复证据，不自动递归清理，也不提交。不要在作者 JSON/错误响应中暴露完整作者文件、Node 对象、绝对错误路径或本机会话令牌。
- API 限本机固定端口，检查 Host、Origin、本次服务令牌、方法及载荷上限；新增写入能力须同步协议与说明。
- `api.ts` 是开发/构建入口唯一作者 API 装配，令牌只在本次 HTML 响应注入，不生成构建期秘密、磁盘令牌或引导写入接口。`media.ts` 只按本次转换已登记的精确 ID/字节摘要读原件，不接受路径；普通文件/物理边界和实际摘要重查，Range 不跳过校验，取消仅清理原读取，不重执行剧情。
- `build.ts` 仅显式生成 `dist/editor` 的独立前端/清单，`serve.ts` 仅显式核对指定摘要后启动固定本机服务；互不自动调用，不进入游戏/宿主路径。清单严格读取并绑定前端、固定运行源码/依赖锁，不再绑定旧选项原文映射；作者文件及全库素材不随前端复制，不将本机集成当正式分发决定。失败临时目录/异常锁保留，不覆盖旧产物或递归清理；每次作者操作前仍核对运行输入。
