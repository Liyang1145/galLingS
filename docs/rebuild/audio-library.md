# 声音收藏与独立试听

接续 M5 原播放器声音能力，提取作者标记的只读收藏目录，在共享混音器增加独立试听，并接到开发主页“声音收藏”。共享能力和页面均已编写，未启动、类型检查、测试、构建、额外审查或使用子代理，尚未验收。

## 作者目录

`packages/player/src/audio-library.ts` 的 `readAudioLibrary(content)` 只读取已校验内容的资源元数据，保持资源原顺序。它不读取玩家成果、推断路线、不解析文件名来猜类别、不请求资源位置或预解码媒体。

| 作者字段 | 读取规则 |
|---|---|
| `audioCategory` | `music/ambience/effect` 分别为配乐、环境、音效；未设、空或 null 不纳入收藏，其余值明确拒绝 |
| 资源种类 | 明确标记的条目须为登记的 `bgm/se/vo`，不能把图片或任意位置当成声音 |
| `name` | 沿原规则去掉“作者原声”前缀和环境/剧情/UI 前缀，将下划线显示为空格；未标注或结果为空时显示稳定 ID，非法非字符串拒绝 |
| `dur` | 有限非负的作者标注秒数；未设时显示未标注，不把标注时长冒充已解码的实际时长 |
| `auditionOnly` | 布尔，缺省 false；沿原目录将候选原件与正常分类分开，不把它当成解锁条件 |
| `playbackGain` | 仅配乐试听采用，与旧 `trackGain` 一致限制在 0～1，缺省 1；显式非法数值拒绝。环境/音效不套剧情场景增益或压低 |

单条读取 `readLibraryEntry(resource, source)` 由目录和混音器共用，错误含来源及资源字段。其他来源元数据、资源字节、ID/顺序及内容修订算法保持不变；此目录不是新增权威作者源或媒体授权清单。

## 共享试听

`AudioMixer.previewLibrary(assetId, observer)` 只在独立、已清空的混音实例使用，重新读取已登记资源及同一分类规则，不信任界面传入的类别/增益。配乐采用 music 通道并循环、环境采用 ambience 并循环、音效采用 effects 单次；仍与当前玩家分轨音量相乘，不创建场景、进入动作、有效计时、事实、存档或主线语音完成回调。

原 `previewVoice()` 继续只接受 `vo`，与收藏共用内部试听生命周期及 `AudioPreviewObserver`；旧 `VoicePreviewObserver` 类型名保留。新试听前须取消上一条，独立实例不得同时接主线音轨或两个试听。每次实际 `playing`、结束或非阻断错误只更新原试听观察者，旧取消/播放承诺不能污染后来试听。

开始时未获许可、暂停或该通道音量为 0 明确拒绝，不保留以后自动补播的音轨。已经播放的轨道仍受既有混音器暂停、声音许可和实时音量控制，不因调整而重播。

## 主页接线与生命周期

`apps/game/src/sounds.ts` 的 `SoundLibraryPanel` 只接只读内容/资源、当前分轨音量、应用提供的声音许可/暂停能力及可选同步显示委托 `transition(change)`，不接会话、检查点、玩家成果或偏好仓库。委托须同步执行一次显示变更，未提供时直接执行；游戏只绑定已登记声音弹层的 `DialogFade.change()`。首次打开时才创建独立混音器；打开目录不创建音轨或请求声音，点击具体曲目才请求对应本地资源。

主页提供配乐、环境、音效三个分类，按原顺序列出非候选条目；候选原件在单独折叠的“素材归档 · 候选试听”中。名称、分类和作者标注时长用于识别，时长未标注明确显示。沿旧收藏入口无需剧情解锁，不新设声音收藏成果或通关规则。布局已沿旧版迁移，正式框架和完整视觉尚未验收。

每次试听先停止上一段，支持同曲重播和显式停止；当前曲目标记与状态属于原试听代次。加载、解码或浏览器拒播说明本条资源 ID，可再次点原曲目重试；旧播放承诺、错误和结束不能更新新曲或关闭后的状态。切换分类只浏览目录，不自动换曲。

音量沿用正常入口当前的声音设置；每次打开重新采用该入口值，不把限时样例的内存调整带回主页。音量修改直接更新现有轨道，不重建或重播。面板不新增偏好保存，不能由试听改写剧情进度或解锁成果。

后台、宿主暂停或声音许可中断时，已有试听暂停；窗口和许可恢复后从原试听位置接续，保留旧收藏行为。原生状态常规刷新只同步许可，暂停状态改变时才暂停/接续，不反复请求播放。首次点曲时尚未获得许可则不排队，恢复后须再次点曲；“启用声音 / 重试许可”只申请许可或重试当前仍持有的轨道。浏览器拒播已停止的曲目须再次点曲。

返回主页、Esc、原生返回键、开始/读档采用、返回标题、正常退出和页面销毁均关闭面板、取消试听并清除监听；主页关闭时释放原生声音焦点。正常退出的票据取消不会重新打开或补播旧收藏。再次打开重建本次目录控件，不保存试听位置到存档。这个入口只在主页开放，旧插件/剧情内入口未迁移，也不决定读档语音体验。

没有新增存储格式、偏好、宿主桥、素材、网络服务或依赖。旧声音收藏及旧入口保留；页面接线已编写仍不等于运行集成通过、听感验收或 M5 完成。

## 试听控制与内部显示切换

从 `9042de6` 接续，将同一试听状态与停止/许可按钮留在声音面板顶部，分类曲目和候选原件放入单独的目录滚动容器。长状态有独立文字滚动范围，按钮保留触摸高度，矮横屏缩紧外留白；目录滚动到末尾时仍可停止当前试听。没有新建混音器、控件副本或另一条播放通道。

真实分类变化及候选区展开/收起使用同一同步显示委托：先静态采样登记的声音弹层，再立即改变原可见区域或原 `details.open`。候选的原生 summary 点击/键盘激活走同一处理，防止内置切换再执行一次；已选分类重复点击不采样。不替换原条目按钮/监听、重设当前试听代次或调用播放、停止、许可请求/暂停/调音；原曲即使属于隐藏分类或收起的候选仍由现有实例持有，可用顶部原停止按钮取消。

试听开始/结束、许可/前后台变化和诊断仍直接更新原状态，不因这些刷新反复制造视觉事务。静态副本不复制活动音频或任何监听，开关、取消及后台/宿主/减少动态效果/尺寸/离开清理复用现有 `DialogFade`；实际显示变更不等待动画。目录、原音频请求与暂停接续语义不变，不新增资源、偏好、存储/宿主格式或正式框架决定。已编写并接入，未启动、类型检查、测试、构建或听感/视觉验收。

## 留待统一测试

以下只是统一测试阶段的操作建议，本轮没有执行：

1. 从主页打开“声音收藏”，对照作者 `audioCategory/auditionOnly` 核对分类、候选区、原顺序、名称和标注时长；打开目录不能请求所有音频，未标记资源不能凭名称进入目录。
2. 分别试听配乐、环境和音效，核对循环/单次、分轨音量和配乐 `playbackGain`；不应出现主线环境混合系数或氛围压低。
3. 快速换曲、同曲重播、停止及关闭，确认最多一段且旧播放/失败事件不改新状态；缺失/损坏文件和浏览器拒播有本条诊断。
4. 触发时通道音量 0 或许可未就绪，不应在后来调音/获准时补播；已有轨道实时调音不重启。暂停和恢复使用原试听位置，关闭后不再补播。
5. 试听中切后台、切回、触发原生焦点/输出中断并显式重试，核对原位置暂停/接续；关闭、Esc、原生返回键、开始游玩或退出后都没有残留声音。正常退出取消仍回主页，不补播旧曲。
6. 限时样例调整音量后返回主页，收藏采用正常入口音量；反复打开和关闭、换类、换曲后开始第一话，剧情及全局周目/结局/CG 不因试听改变。
7. 宽/窄窗口、手机与矮横屏核对配乐单列大卡片、环境/音效和候选区换列、长名称及许可失败提示。返回区、停止和许可按钮可达，分类切换及折叠不开始新试听或改变当前曲目。
8. 目录滚到末尾后核对顶部状态、停止/许可操作可达；长错误说明只滚文字，不盖住按钮。试听配乐或候选时切换分类/收起候选，原位置继续，不因为静态过渡重建音轨；点击原停止仍只取消原曲。
9. 鼠标/触摸及键盘 Enter/空格切换候选 summary，每次只开关一次；分类实际变化和候选开关按原 360ms 淡出，重复点已选分类及声音状态刷新不重播动画。快速连续切换、后台/宿主暂停、缩放/全屏、减少动态效果和关闭后无残留副本，旧结束/拒播回调不改新曲或重开面板。
