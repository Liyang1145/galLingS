# 共享场面与角色演出

接续 M5 演出迁移，已编写共享 `WebPresentation` 的背景镜头、独立转场/特效遮罩、主线旧画面淡出、原角色动作/进退场及瞬时镜头/持续氛围，并补上现有标题、暂停菜单及终态界面的视觉过渡；游戏与独立编辑预览复用共享实现及样式，具体接入范围见下文。只编写实现和文档，未启动、类型检查、测试、构建、额外审查或使用子代理，尚未验收。

## 镜头提示

旧 `海风与布丁/player.js` 的 `stageShot()` 将资源 `shot.focus` 用作缩放中心，`view.position` 独立决定背景取景。原镜头缩放限制为 1～1.04，时长限制为 600～3000ms，缓动为 `cubic-bezier(.2,.65,.3,1)`；快进与系统减少动态效果时清除镜头缩放。

共享实现采用上述数值及关系：

| 输入或状态 | 当前行为 |
|---|---|
| `shot.focus` | 非空时须为两个有限数值，直接转换为百分比缩放中心；非法值报告带节点及背景资源 ID 的场面错误，不改成默认焦点 |
| 缺省或空的 `shot.focus` | 不启用镜头；单独存在的 `scale` 不产生缩放 |
| `shot.scale`、`shot.ms` | 读取有限数值并按旧范围限制，缺省沿用既有读取值 1、2200ms |
| `view.position` | 显式值决定取景，未配置时居中；不能用镜头焦点替代背景取景 |
| 正常首次呈现或更换背景 | 当前资源准备完成后执行镜头，不等待动画结束才开始对白或选择有效时间 |
| 同背景的后续正常呈现 | 保留原镜头进度；换句及资源准备间隙暂停，就绪后继续，已完成的不再重播 |
| 媒体重试或检查点恢复 | 直接显示镜头终点，不重放进入演出，不保存或恢复动画帧 |
| 快进或本次呈现时系统减少动态效果 | 不采用镜头缩放；当前呈现中进入快进也清除缩放，停止快进不在本句中补跑镜头 |

内容内原始资源元数据保持原样，限制只在表现时应用。焦点是否有效在场面提交前判断；错误仍走原媒体问题及当前场面重试，不重新进入剧情。镜头使用独立 `scale`，不改场面坐标、剧情变量、声音或记录格式。

`web/camera.ts` 的 `BackgroundCamera` 由共享表现实例拥有，以背景 ID 与已校验镜头参数识别原镜头。单句的取消只暂停该场面镜头，目标正常呈现后决定沿用或替换；它不持有旧 `PresentationContext`、步骤、信号或剧情完成回调。正常换句不因句内演出清理而跳到镜头终点，也不从 1 倍重新开始。

菜单、后台、宿主、资源加载及错误仍通过当前呈现暂停镜头；暂停时间不补算。进入快进、无镜头/无背景、关闭该表现或采用不同背景/镜头参数时，先使原归属失效再取消动画，迟到完成不能改后来场面。快进结束不在本句补播，后续正常呈现可按旧规则重新采用镜头；读档/回退、媒体重试及终态直接采用稳定目标，不回放镜头帧。旧 `Playback` 的暂停/快进调用也必须先通过有效性判断，不能影响后来呈现。

原镜头完成后释放动画句柄、保留目标样式和已完成归属；解除暂停不会把刚完成但尚未处理回调的镜头重新播一遍。旧画面快照读取当前镜头的可见缩放，冻结为副本自己的值；与新背景镜头没有共享回调。以上只改变表现内部生命周期，不扩展核心、检查点、偏好或应用构造接口。

## 独立转场遮罩

未采用下述旧画面快照时，转场 `black/flash` 使用 `transition-veil`，按旧 `#veil.go` 的 800ms 从不透明淡出；瞬时 `flash/redflash/blink/quake/whip` 继续使用另一层遮罩，位于转场之上。两者可以在同一节点分别设置颜色及透明度，不再由后设置的特效改掉转场颜色或覆盖同一透明度动画。

“已有场面”独立于背景 ID 记录。没有背景也是有效场面；从无背景切到有背景，仍按实际更换和当前 `trans` 处理。第一次呈现不冒充从旧场面转场，读档/回退及媒体重试继续直接采用稳定场面。

两层动画均归属当前呈现，复用原暂停、恢复、快进及取消通道；菜单或后台暂停动画，换节点/重试/离开取消旧动画并清理遮罩。新增层没有输入处理或剧情回调，不决定点击、超时、声音完成或检查点时机。

## 主线旧画面淡出

旧 `VN_FADE` 在主线流转前保留旧舞台，下一画面就绪后以 360ms、`ease-in-out` 淡出。共享实现保留这个主线行为，应用显式向 `WebPresentation` 的末项可选 `SceneFadeSurface` 提供本舞台和选择面板；不读取全局 ID、全页样式表、作者脚本或其他应用界面。

正常进入下一节点时，已有场面、非快进、未启用减少动态效果、`trans !== "cut"`，并满足以下任一条件才捕获旧画面：

- 背景或立绘资源、取整后的坐标/高度、翻转发生变化。
- 氛围或当前对白显示/隐藏状态变化。
- 原选择面板仍然可见，即正在离开选择。

纯文字更新、自动/快进状态刷新、倒计时刷新不制造快照。首次呈现、媒体重试、检查点恢复和回退也不重放该进入演出。

`web/scene-fade.ts` 只复制当前场面及显式提供的选择面板。副本移除 DOM ID，整体 `aria-hidden`、`inert` 并禁止指针事件；没有复制事件监听或会话、语音、存储能力。复制的氛围、立绘及布局过渡静止，保留当时的可见变换、透明度、角色位置以及对白/选择滚动位置。两块作者画布继续采用共享舞台比例，不另开舞台尺寸观察或有效计时。

目标图片仍由原场面加载通道准备；旧画面在等待期间可见，目标采用后才淡出。动画不等待旧播放器的定时器、不额外阻止推进、不延后选择有效时间；旧选项副本不能接受点击或重复结算。一次最多保留一个快照，失败、快进、换节点、读档/回退、终态或离开都会清理；动画暂停/恢复继续由本次 `Playback` 管理。快照准备失败报告非阻断显示问题，仍沿原场面流程继续。

沿旧 `showPlay()` 的优先关系，采用快照时不再叠加背景自身淡入或黑/白转场；当前节点的瞬时特效仍正常执行。没有接 `SceneFadeSurface` 的独立表现消费者继续使用已有背景转场。此差异只涉及视觉，不切换剧情实现或跳过节点。

## 标题、暂停菜单与终态过渡

`web/stage-fade.ts` 的 `StageFade` 接续旧 `VN_FADE` 的界面事务行为。应用在异步准备已完成、即将真正采用界面变化时采样；下一帧对新界面的可见 DOM 图片最多等待 180ms，再以 360ms、`ease-in-out` 淡出旧副本。不等待离屏的场面预加载器，不延后剧情执行、声音、选择计时或存储事务，也不承诺在任意慢资源读取期间一直覆盖旧标题。

| 接点 | 本次接入 |
|---|---|
| 游戏开始、重新开始、实际读档采用 | 来源、全局投影及检查点准备成功后才采样，准备失败保留原界面；这只是应用界面变化，恢复仍不执行进入动作或重播节点演出 |
| 返回试播标题 | 取消原会话前采样，标题出现后淡出旧场面、选择、暂停菜单或结局卡片；原会话声音仍由原生命周期停止 |
| 游戏暂停菜单打开/关闭 | 只有菜单可见性实际变化才采样；倒计时、自动状态及其他暂停原因刷新不重复制造副本 |
| 首次显示核心终态 | 同一会话终态只触发一次；记录待保存、失败、重试、成功或新结局提示更新不重复淡出，未保存事实不能因过渡被当成已提交 |
| 独立编辑预览终态 | 使用同一 `StageFade` 和样式，只复制预览场面、选择及结局卡片；停止/换预览直接取消，不复制制作控件、读写玩家记录或假造正式解锁 |

界面过渡和主线单句淡出分别拥有各自句柄，均复用 `scene-fade.ts` 的 `capturePlayerLayers()`。只接收明确提供的同一舞台直接子节点；不采样整页、其他过渡副本、弹层对话框、编辑表单或外部操作栏。副本去除 ID 与自动焦点，保留可见变换、隐藏状态及滚动，整体 `inert/aria-hidden` 并禁止指针、CSS 动画和过渡；原副本不能继续选择、返回标题或抢焦点。界面副本位于现有舞台菜单/终态之上，主线副本仍在场面层。

一次只保留一个界面副本，新事务先清理旧事务。动画完成、失败、后台、宿主暂停、正常退出、实际快进、舞台尺寸/全屏变化及离开清理；运行中开启系统减少动态效果也直接清理。显示回看、鉴赏或通关后对话框前取消舞台过渡，对话框本身由下节的游戏专用驱动处理，不扩大共享舞台快照的范围。旧解码、帧、动画完成及兜底定时回调只核对原归属，不能删除新事务的副本或重新播放。

菜单自身的暂停不暂停这层界面淡出，否则关闭菜单时会留下冻结的旧菜单。场面和声音仍由共享会话执行原有效暂停；后台/宿主暂停直接取消界面视觉副本，不等待隐藏期间的动画。视觉错误只报告非阻断提示，不能把已接受的开局、读档或菜单操作改报剧情/存储失败。旧标题页没有背景音乐，并通过最终样式取消封面运动；本片维持这两个行为，不新增标题声音或封面动画。

## 游戏弹层视觉过渡

从 `2ec7d83` 接续 `apps/game/src/dialog-fade.ts` 的 `DialogFade`，登记当前游戏画面及设置/存读档/回退/开发工具、回看、鉴赏、声音、章节和只读通关准备弹层。它只接显示根、明确弹层名单、视觉许可及诊断，不接剧情/存储/声音控制；正常退出票据弹层保持原同步流程，不加入视觉复制。

打开时在实际显示之前采样原游戏画面，再同步打开 native dialog；壳弹层通过显示前回调在采样后取得暂停，回看继续沿原 `history` 暂停通道。副本作为新 dialog 的子层显示，以适应其浏览器顶层。关闭时先采样原弹层及背景遮罩，随后立即关闭 native dialog、停止独立试听/媒体、取消未采用准备并释放原归属暂停，静态副本在独立页面层淡出。采样失败只保留直接切换，不能把已接受操作改报失败。

副本使用封闭 Shadow DOM，仅注入构建明确导入的游戏 `style.css` 与 `shell.css`，不扫描 `document.styleSheets`、整页或编辑制作区。影子树中的局部 ID 保留用于原版 ID 选择器、滑块与伪元素外观，不在主文档产生重复 ID；不保留自动焦点、表单关联、链接、事件或 live 区域。整层 `inert/aria-hidden` 且无指针，CSS 动画/过渡禁用，保留当时可见变换、控件值及滚动。活动音视频、脚本、iframe、canvas 和其他过渡副本不复制；图片只复制已完成且可见的当前图像，未加载/隐藏图不发起新尝试，离屏盒保留布局但省去深层内容。

## 角色动作、移动和层级

`web/motion.ts` 按旧 `index.html` 的 `sIn/sInL/sInR/sInU/sPop` 和 `aJump` 至 `aSettle` 保存实际关键帧、偏移、时长、方向及缓动。它只提供可信代码中的表现计划，不读取作者表达式、写剧情或自行安排时间。

| 原演出 | 共享实现 |
|---|---|
| 淡入/左右入场/上移入场/轻弹 | 450/550/550/400ms；左右偏移 280px，上移 140px，轻弹从下方 40px 上移，不用额外缩放替代 |
| 淡出/左右或向下离场 | 400/500ms，沿原入场帧反向、`ease-in`，完成后清理原立绘 |
| 跳跃/发抖/点头 | 500/500/600ms，保留分段时刻、二次小跳/点头及原位移 |
| 探身/怔住/坐稳 | 550/380/550ms，保留探身旋转与三种原位移，不统一成同一条平移曲线 |
| 已有角色改位置/高度 | 500ms、`ease`；先设置稳定目标，再由当前呈现从旧坐标插值 |
| 光色/外观/说话焦点变化 | 滤镜 900ms、`ease`；非说话角色追加 `brightness(.62) saturate(.85)`，不使用透明度露出后方背景 |
| 同场景无动作的软切姿态 | 140ms 淡出旧角色静态副本，保留旧坐标、大小、翻转、滤镜和层级；不让旧姿态跟着新位置移动 |

CSS 动画缓动作用于相邻关键帧区间。共享 `cssMotion()` 将它写入每个关键帧，时间轴本身保持线性，避免把原分段节奏改成整段时间扭曲。动作和入场仍沿旧优先关系：本节点有动作就执行该动作，否则新角色才执行入场。

立绘继续按原角色身份复用；每次采用目标场面都按目标 `sprites` 顺序重新写入层级，不能以 DOM 最初插入顺序替代作者顺序。原实例 ID 仍保留在 `data-instance`，不改变内容身份或资源顺序。

移动、滤镜、动作及进退场都由本次 `Playback` 拥有，暂停/恢复沿用动画句柄，快进结束到稳定目标，换节点或离开取消旧工作。删除原 CSS 位移过渡后，媒体重试、读档和回退直接采用目标坐标/滤镜/层级，不因恢复再走一遍；减少动态效果也直接显示稳定目标。离场和软切副本只由原呈现清理，不用不受暂停控制的延迟删除，不加入检查点。

## 瞬时镜头与持续氛围

瞬时镜头只在正常进入时执行，计划同样放在 `web/motion.ts`，来自旧 `playFx()` 及 `index.html` 的实际关键帧；不再把不同镜头近似为同一个摇动。`scene-layers` 只包含背景及立绘，氛围覆盖、转场/闪光遮罩与对白在它之外：移动镜头不能连遮罩一起摇动，场面滤镜也不染色对白或瞬时闪光。

| 瞬时效果 | 保留的演出 |
|---|---|
| `shake` | 500ms、`ease`，原分段水平/垂直位移 |
| `quake` | 900ms、原贝塞尔曲线，原分段位移及逐步收回的缩放，同时白闪 |
| `zoom` | 500ms、`ease-out`，在 25% 时到 1.12 倍后收回 |
| `whip` | 620ms、原贝塞尔曲线，百分比横甩、缩放及 18/9/3px 动态模糊，同时白闪 |
| `flash/redflash` | 白色/原红色从不透明淡出，800ms、`ease-out`，不另造先淡入的半段 |
| `blink` | 黑色 1600ms、`ease-in-out`，保留 25/40/65/78% 的反复睁闭 |

镜头保留 CSS 的分段缓动。`dizzy` 与 `whip` 同时使用时，沿旧动画列表的优先关系由持续晕眩拥有模糊滤镜，横甩仍执行几何运动。所有瞬时动画归当前 `Playback` 暂停及取消，快进和减少动态效果跳过，读档/回退或媒体重试不重播。

持续氛围使用同一 `.world[data-mood]` 下的场面层、`mood-layer` 覆盖和实际 `mood-detail` 子节点；细节不用无法被现有暂停选择器覆盖的伪元素。原 CSS 曲线及渐变保存在共享游戏样式，编辑预览直接复用：

| 氛围 | 当前表现 |
|---|---|
| `dizzy` | 7s 晃动、5.3s 模糊、4.2s 黑色明暗脉冲和静止暗角 |
| `flicker/strobe` | 3.6s 原明暗关键帧 / 1.1s 原阶跃闪烁，作用于独立黑色覆盖 |
| `blur/sway` | 覆盖层 4px 背景模糊 / 6s 原旋转、平移和缩放 |
| `gray/dark` | 原灰度/对比与暗角 / 原深色暗角，不用统一亮度替代 |
| `danger` | 原红色暗角及 1.2s 心跳透明度 |
| `underwater` | 原蓝色渐变、场面滤镜、5.5s 漂移和四组原渐变气泡的 4.5s 上浮 |
| `slowmo` | 原褪色/对比/亮度、暗角和 9s 推近至 1.08 倍 |

同名氛围连续节点不重建这些层或重启 CSS 时间轴，加载/菜单/后台暂停覆盖所有动态子节点。静态场面滤镜及非脉冲覆盖的进入变化采用原 600ms 过渡，但动画句柄归当前呈现；脉冲氛围继续拥有自己的透明度。减少动态效果时停止漂移、脉冲、闪烁和气泡，保留静态着色；闪烁层的静态透明度为 0，不能因此把画面整片遮黑。

恢复仍采用稳定场面，不加入帧级存储。有限的 `slowmo` 推近在媒体重试、读档/回退或减少动态效果下直接采用 1.08 倍终点，并在同名后续节点保持；离开该氛围才清除。循环氛围不是进入事实，可以作为当前场面继续，离开清理。旧画面快照额外固定气泡的 `background-position`，不把副本气泡放回动画起点。

本片没有新增声音或视觉素材，气泡、暗角和滤镜沿用原 CSS；水下/慢动作的声音压低仍由现有混音器处理。本片只接通原帧及分层，镜头、角色和氛围组合后的观感及平台合成仍待统一对照，不据代码迁移声称逐像素等价或设备验收。

## 留待统一测试

以下只是测试阶段的操作建议，本轮没有执行或生成测试内容：

1. 在游戏和编辑预览中查看带镜头的背景，如 `yvwvivzm`（CG_初登场）；确认取景遵循 `view.position`，镜头缓慢向 `shot.focus` 缩放。镜头未完成时补全文字并继续到同背景下一句，应从原进度继续；已经完成后再继续或暂停/恢复，不从头重播。
2. 在统一测试专用内容中把镜头值设到范围外，检查限制为 1～1.04 和 600～3000ms；再提供非法焦点，检查错误定位以及修正后重试。不要修改权威作者源来制造故障。
3. 镜头或黑场转场中打开菜单、切后台、进入快进和返回标题，检查暂停、清理以及旧呈现不污染新场面；系统减少动态效果时检查没有镜头缩放。
4. 用统一测试专用内容组合无背景→有背景及 `black`/`redflash`，检查主线旧画面淡出优先于背景转场，瞬时特效结束且无遮罩残留；未接快照表面的独立适配实例再检查两层颜色互不覆盖。不要把进入演出当成恢复时必须重播的动作。
5. 查看同背景换姿态、换场景、从选择继续及 `cut`：应按触发条件淡出旧场面/对白/选择，`cut` 直接切换；旧选项不能再点中，文字和选择计时不等动画结束。长对白或长选项滚动后流转，检查副本滚动位置、隐藏界面、暂停/后台、快速连续流转及返回标题时清理。
6. 对照旧播放器查看六种角色动作和全部进退场，尤其跳跃/点头的第二次小动作、探身旋转、怔住方向、轻弹不缩放。演出中暂停和切后台，再继续或进入快进；离场副本应按原呈现清理，不残留或被旧回调删掉新角色。
7. 用统一测试专用内容检查已有角色换位置/高度、互换前后层级以及切换说话人。关闭或恢复同一检查点后应直接到目标状态；软切旧姿态保留原位置，非说话角色应变暗而非半透明。游戏和编辑预览采用相同表现。
8. 对照旧播放器查看地震、横甩、缩放、白闪/红闪及眨眼，检查原幅度、动态模糊及反复睁闭；遮罩和对白不随镜头晃动，恢复或重试不重放瞬时效果，快进/离开无残留。
9. 查看全部持续氛围，尤其水下气泡、晕眩分层脉冲与慢推近；连续同名节点不从头播放。暂停/后台时细节也停止，旧画面淡出保留原气泡位置；恢复慢推近直接在终点，减少动态效果不闪烁、不持续漂移且不整屏变黑。
10. 镜头中换背景、进入快进、返回标题或停止预览，再开始新场面；旧完成回调不能改变新画面。媒体重试、读档和回退应直接到该镜头的稳定终点；资源加载间隙及后台时长不补算到未完成的镜头，同背景换姿态时旧画面副本保持捕获时缩放。
11. 从标题开始、开关暂停菜单、重新开始、实际读档、返回标题及首次到达终态，查看旧画面淡出；快速连续操作、缩放/全屏、切后台及开启系统减少动态效果，应清理旧副本。过渡期间点击原选择/菜单位置不能点中副本或重复结算，当前选择剩余时间仍按原暂停规则。
12. 结局到达后等待保存成功、制造统一测试专用的写入失败再重试，应只更新状态，不因保存回执反复淡出或新增解锁。预览终态复用同一视觉过渡，停止/换预览即清理，制作控件与正常玩家记录不受影响。
