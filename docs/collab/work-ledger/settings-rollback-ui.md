## 功能修改

### 1. 对话历史记录支持回退

在游戏内“对话回看”列表的每条历史记录下增加“回退到这里”按钮。

点击后会：

- 回到选中对白节点；
- 恢复进入该句前的变量状态；
- 截断该句之后的回看历史；
- 清理自动播放、快进和限时选项计时器；
- 重新同步当前画面、音乐和演出状态。

回退使用剧情节点稳定状态，不是单纯把显示文字滚回去。原有手动存档和读档流程保持不变。

### 2. 设置中增加对话框不透明度

设置页新增：

> 对话框不透明度

当前范围为 **35%–95%**，最低不透明度提高到 35%，避免文本框背景过淡而影响阅读。

旧版本如果在浏览器偏好中保存过低于 35% 的值，读取时会自动限制到 35%。该设置会实时作用于游戏内对话框背景，包括当前新版游戏的对话框皮肤伪元素。

### 3. 设置控件采用 C「海底刻度」样式

设置页内部的滑块、按钮、开关和关闭按钮改为深海控制台风格：

- 深蓝黑色控件底色；
- 青蓝色细边框；
- 青色发光滑块；
- 方形刻度感滑块按钮；
- 悬停、焦点和按下状态；
- 移动端扩大开关和分段按钮触控区域。

样式作用域限定在 `#psettings` 设置面板，未修改主页、选项按钮、文本框、账本、回看主体或其他游戏 UI。

### 4. 滑块进度高亮与数值显示

设置页所有范围滑块均已接入动态显示：

- 音乐：百分比；
- 音效：百分比；
- 环境音：百分比；
- 语音：百分比；
- 文字大小：百分比；
- 文字速度：毫秒；
- 自动播放等待：倍率；
- 对话框不透明度：百分比。

拖动滑块时：

1. 青色进度高亮实时移动；
2. 滑块右侧数值实时更新；
3. 设置值实时写入现有偏好系统。

## 兼容性与边界

- 保留原项目 ID、剧情节点 ID、资产 ID、变量和分支逻辑。
- 不改变原有语音、音效、环境音和音乐编排。
- 不改变原有存档结构。
- 不改变配乐工作台文件。
- 不新增网络请求，不依赖服务器。
- 浏览器中的旧偏好会继续读取；仅对 `ghost` 不透明度增加 0.35 的下限钳制。

- 设置页滑块右侧显示数值；
