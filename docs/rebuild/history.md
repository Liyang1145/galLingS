## 当前实现

`packages/player/src/session.ts` 在当前游戏会话内维护 `DialogueEntry`：

- 进入节点时记录实际求值后的说话人与台词，保留节点、章节、当次 `voiceId:string|null` 及会话内 `visitId`；空台词不占记录。语音身份直接取同次核心呈现，不在回看时按文字或节点索引猜资源。
- 唯一核心接受选择后，先记录实际选项与是否超时，再记录目标对白。选择记录使用选择发生前的访问 ID，与该次选择节点对白归属相同，目标对白属于新访问；拒绝、过时点击或重复超时不追加选择。
- 媒体重试不追加同一对白；实际再次到达同一节点属于新的出现记录。
- 恢复进度后从当前保存的完整台词开始新的回看，没有把全局已读集合伪造成当前路线对白。
- 沿用旧播放器回看最多 300 条的容量，统一限制对白和选择，只存定位文字、语音及访问 ID，不存图片、播放对象或检查点。该容量不代表尚未确定的回退历史容量。

`GameSession.dialogueHistory()` 返回分离后的数据副本，`SessionView.dialogueCount` 供界面更新入口状态。回看不是可写的核心引用，也不携带回退或语音播放回调。新增字段只在当前会话内存中，不改进度/成果/偏好或宿主格式。`visitId` 只用于和同一所属会话的 `rollbackTargets()` 匹配；它不是跨会话稳定 ID，也不能据此获取任意内部检查点。

## 试播接入

`apps/game/` 的“对白回看”打开只读对话框，按实际出现顺序显示最近台词和选择。文本通过 `textContent` 渲染，不当作 HTML 执行。

打开前通过同一会话队列加入独立的 `history` 暂停原因，暂停文字、声音及有效计时。关闭按钮与 Esc 只解除该原因；菜单、后台、媒体错误或宿主暂停继续有效。对话框打开期间不向剧情发送空格、方向键或自动播放快捷操作。

新开、读档、返回标题及页面离开会清理旧回看。记录仅属于当前会话，不写进进度槽位、全局记录或聊天记录；读档清空本片内存回看，不等于已经决定正式产品的历史持久化范围。后续[进度回退](rollback.md)采用检查点时会截断未来路线文字并重新显示目标句；打开回看本身仍不触发回退。

## 从条目显式回退

打开面板时，应用同时传入 `dialogueHistory()` 和 `rollbackTargets()` 的副本。`DialoguePanel` 只按 `visitId` 对应目标；同一节点循环访问不会混为一个位置。只有仍保留且不属于当前访问的目标显示按钮：对白为“回到此处”，实际选择为“回到此选择之前”，跨选择的目标另有文字标记。未捕获、被容量淘汰及当前访问不提供可猜测的回退位置。

面板内单独提供“恢复语音”和“回退范围”，每次打开均不预选；明确选好 `silent/replay/resume` 及是否跨选择后才可提交。仅查看、滚动、选择策略、试听或关闭都不恢复进度。当前画面须就绪且文字完整，结局后仍不支持；后台或宿主暂停时禁用发起操作。默认边界、正式容量和语音体验仍未决定。

点击后停止独立历史语音并禁用重复请求。面板只向应用交付目标 ID、明确策略及本次打开的取消信号；它不持有核心、检查点、玩家仓库或文件写入能力。应用的 `rollbackTo()` 与原下拉入口共用准备、全局事实提交、当前投影读取和 `GameSession.rollback()`；核心再次检查原会话/步骤、目标是否仍在历史及选择边界。跨选择被拒绝或准备失败时，保留原进度、历史和面板，可以调整设置重试。

关闭按钮、Esc、原生返回、换会话或退出会使本次打开的信号失效。若检查点尚未采用，准备结果不能后来替换游玩；关闭会立即解除本次 `operation` 暂停，再按原流程解除 `history`，其他暂停继续有效。已发起的全局事实事务可以完成，它不等于已恢复进度；取消不撤销事务或已采用的检查点。

采用成功后才关闭回看，截断未来路线文字，原全局已读、CG、结局和周目保留，不自动写进度槽位。目标媒体错误沿用同一已恢复位置重试，不能冒充回退未发生。旧面板的请求完成、失败和语音回调均须匹配本次打开及所属会话，不能更新重开的面板。

## 历史语音试听

`apps/game/src/dialogue.ts` 的 `DialoguePanel` 展示分离后的记录。只有 `line` 且有语音 ID 的条目显示“重播语音”；选择与无配音对白不造按钮。上方状态及“停止历史语音”控件在滚动时保留，文字和诊断继续通过 `textContent` 写入。

面板单独持有一个共享 `AudioMixer`，不持有剧情可写接口。`previewVoice(id, observer)` 校验资源为 `vo`，从头播放本条，并通过实际 `playing` 事件、结束及非阻断问题更新试听状态；不建立场景或触发进入动作、核心 `voiceEnded`、计时、事实或检查点。新的点击先取消上一条，最多一段试听；同一句再次点击从头重播。

试听使用当前入口的语音音量，偏好晚到保存结果/本页调整更新音量时不重播。触发时音量为 0、未获准或暂停则不创建待播音轨；现有试听调为 0 时沿用静音运行规则。按钮声音开关只管操作反馈，不控制对白试听。第一话和限时样例分别采用各自内存设置；本片没有给编辑器增加回看 UI，编辑预览仍共享相同的会话数据能力。

打开回看后主线文字、原语音、音乐和有效计时仍受 `history` 暂停；试听只允许在当前回看仍属于当前会话、页面可见、宿主未暂停且获声音许可，并且没有其他暂停原因时开始。菜单、加载、媒体阻断、操作准备及退出暂停不会被试听解除。

点击可请求既有原生音频焦点；如许可尚未返回或被拒绝，面板说明恢复后再次点击，不等待后补播。失去前台/宿主许可或新增其他暂停会取消试听，不在回来时自动续播。浏览器播放拒绝、资源无法读取或解码只显示本条提示，原进度及主线媒体错误保持原值。

关闭按钮、Esc、原生返回、重新开局、读档、回退准备、返回标题、正常退出及页面离开均取消试听；离开弹层前先取消，随后仅解除原 `history` 暂停。主线原语音仍从自己的原暂停位置继续，试听没有替换它。原试听的代次和取消闭包保护迟到的播放/结束/错误，不得改变后来的条目状态或新会话。关闭时注销本次条目监听，面板销毁时释放独立混音器。

## 统一测试时确认

以下是预留情景，本轮未执行，不要求用户现在试玩：

1. 在普通对白和一次选择后打开回看，核对台词变量替换、选项文字及先后顺序；超时选择应标明来源。
2. 限时选择中打开回看并停留，关闭后确认仍在同一节点、变量未变、选择时间未消耗这段暂停时长。
3. 回看期间切后台再关闭回看，或在菜单暂停时打开再关闭，确认各项暂停不会互相解除。
4. 媒体重试不重复记录；新开或读档只显示新会话记录，普通入口与限时样例不互串。
5. 长时间推进后最多保留 300 条，打开和关闭回看不增加周目、结局或 CG 成果。
6. 出现带语音的对白后打开回看，分别试听两句、再次点击同一句和停止，确认最多一段且重播从头开始；选择及无配音对白没有虚构试听。原主线语音、变量及限时选择仍在暂停位置。
7. 试听中关闭回看、Esc/原生返回、重开、读档或离开页面，确认旧声音取消；主线仍从自己的原声音位置继续，旧试听结束/播放拒绝不得释放自动阅读等待。
8. 试听时切后台、丢失原生声音焦点或发起正常退出，确认立即取消且恢复不补播。许可拒绝或尚未返回时再次点击可重试，不排队播放；浏览器拒播/缺失文件只影响本条提示。
9. 语音音量设为 0 后点试听，确认没有后来补播；已有试听更新音量不重启。第一话与限时样例隔离，关闭一般按钮声音不关闭对白试听。
10. 关闭后马上重开并换条，确认旧事件不更新新面板、不叠加播放；回退后的回看没有未来路线的文字或语音身份，读档只记录新的当前句。
11. 回看中先明确选择范围及语音，再点旧对白“回到此处”；应恢复该次访问的变量、场面和剩余时间，成功后关闭回看，未来路线条目消失。仅切换选择框、滚动和试听都不回退。
12. 对实际选择行点“回到此选择之前”，不跨选择时应拒绝并保留面板；明确允许后恢复选择前的检查点，不逆算变量、不重复进入动作。手动及超时选择使用同一边界规则。
13. 对存在重复访问的节点，核对每条记录匹配各自访问；被淘汰目标、当前访问及没有成功检查点的位置不提供伪造按钮，不按同一节点替代。
14. 在全局记录准备等待期间关闭回看、再打开或换会话，确认旧结果不采用、不更改新面板；取消只释放自己的操作/回看暂停，后台与菜单仍保留。准备失败可在原面板调整策略后重试。
15. 长回看打开后定位最新记录，返回按钮仍可达；手机、矮横屏、长对白和章节变化核对文字、按钮及操作区。展开/收起回退设置不回退或改变暂停，错误结果在收起时仍可见；重开时范围与语音不沿用上次选择。
