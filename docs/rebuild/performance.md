# 共享场面与角色演出

接续 M5 演出迁移，已编写共享 `WebPresentation` 的背景镜头、独立转场/特效遮罩、主线旧画面淡出及原角色动作/进退场；游戏与独立编辑预览共用实现及样式。只编写实现和文档，未启动、类型检查、测试、构建、额外审查或使用子代理，尚未验收。

## 镜头提示

旧 `海风与布丁/player.js` 的 `stageShot()` 将资源 `shot.focus` 用作缩放中心，`view.position` 独立决定背景取景。原镜头缩放限制为 1～1.04，时长限制为 600～3000ms，缓动为 `cubic-bezier(.2,.65,.3,1)`；快进与系统减少动态效果时清除镜头缩放。

共享实现采用上述数值及关系：

| 输入或状态 | 当前行为 |
|---|---|
| `shot.focus` | 非空时须为两个有限数值，直接转换为百分比缩放中心；非法值报告带节点及背景资源 ID 的场面错误，不改成默认焦点 |
| 缺省或空的 `shot.focus` | 不启用镜头；单独存在的 `scale` 不产生缩放 |
| `shot.scale`、`shot.ms` | 读取有限数值并按旧范围限制，缺省沿用既有读取值 1、2200ms |
| `view.position` | 显式值决定取景，未配置时居中；不能用镜头焦点替代背景取景 |
| 正常首次呈现或更换背景 | 当前资源准备完成后执行镜头，不等待动画结束才开始对白或选择有效时间 |
| 同背景的后续呈现、媒体重试或检查点恢复 | 直接显示镜头终点，不重放进入演出，不保存或恢复动画帧 |
| 快进或本次呈现时系统减少动态效果 | 不采用镜头缩放；当前呈现中进入快进也清除缩放，停止快进不在本句中补跑镜头 |

内容内原始资源元数据保持原样，限制只在表现时应用。焦点是否有效在场面提交前判断；错误仍走原媒体问题及当前场面重试，不重新进入剧情。镜头使用独立 `scale`，不改场面坐标、剧情变量、声音或记录格式。

## 独立转场遮罩

未采用下述旧画面快照时，转场 `black/flash` 使用 `transition-veil`，按旧 `#veil.go` 的 800ms 从不透明淡出；瞬时 `flash/redflash/blink/quake/whip` 继续使用另一层遮罩，位于转场之上。两者可以在同一节点分别设置颜色及透明度，不再由后设置的特效改掉转场颜色或覆盖同一透明度动画。

“已有场面”独立于背景 ID 记录。没有背景也是有效场面；从无背景切到有背景，仍按实际更换和当前 `trans` 处理。第一次呈现不冒充从旧场面转场，读档/回退及媒体重试继续直接采用稳定场面。

两层动画均归属当前呈现，复用原暂停、恢复、快进及取消通道；菜单或后台暂停动画，换节点/重试/离开取消旧动画并清理遮罩。新增层没有输入处理或剧情回调，不决定点击、超时、声音完成或检查点时机。

## 主线旧画面淡出

旧 `VN_FADE` 在主线流转前保留旧舞台，下一画面就绪后以 360ms、`ease-in-out` 淡出。共享实现保留这个主线行为，应用显式向 `WebPresentation` 的末项可选 `SceneFadeSurface` 提供本舞台和选择面板；不读取全局 ID、全页样式表、作者脚本或其他应用界面。

正常进入下一节点时，已有场面、非快进、未启用减少动态效果、`trans !== "cut"`，并满足以下任一条件才捕获旧画面：

- 背景或立绘资源、取整后的坐标/高度、翻转发生变化。
- 氛围或当前对白显示/隐藏状态变化。
- 原选择面板仍然可见，即正在离开选择。

纯文字更新、自动/快进状态刷新、倒计时刷新不制造快照。首次呈现、媒体重试、检查点恢复和回退也不重放该进入演出。

`web/scene-fade.ts` 只复制当前场面及显式提供的选择面板。副本移除 DOM ID，整体 `aria-hidden`、`inert` 并禁止指针事件；没有复制事件监听或会话、语音、存储能力。复制的氛围、立绘及布局过渡静止，保留当时的可见变换、透明度、角色位置以及对白/选择滚动位置。两块作者画布继续采用共享舞台比例，不另开舞台尺寸观察或有效计时。

目标图片仍由原场面加载通道准备；旧画面在等待期间可见，目标采用后才淡出。动画不等待旧播放器的定时器、不额外阻止推进、不延后选择有效时间；旧选项副本不能接受点击或重复结算。一次最多保留一个快照，失败、快进、换节点、读档/回退、终态或离开都会清理；动画暂停/恢复继续由本次 `Playback` 管理。快照准备失败报告非阻断显示问题，仍沿原场面流程继续。

沿旧 `showPlay()` 的优先关系，采用快照时不再叠加背景自身淡入或黑/白转场；当前节点的瞬时特效仍正常执行。没有接 `SceneFadeSurface` 的独立表现消费者继续使用已有背景转场。此差异只涉及视觉，不切换剧情实现或跳过节点。

## 角色动作、移动和层级

`web/motion.ts` 按旧 `index.html` 的 `sIn/sInL/sInR/sInU/sPop` 和 `aJump` 至 `aSettle` 保存实际关键帧、偏移、时长、方向及缓动。它只提供可信代码中的表现计划，不读取作者表达式、写剧情或自行安排时间。

| 原演出 | 共享实现 |
|---|---|
| 淡入/左右入场/上移入场/轻弹 | 450/550/550/400ms；左右偏移 280px，上移 140px，轻弹从下方 40px 上移，不用额外缩放替代 |
| 淡出/左右或向下离场 | 400/500ms，沿原入场帧反向、`ease-in`，完成后清理原立绘 |
| 跳跃/发抖/点头 | 500/500/600ms，保留分段时刻、二次小跳/点头及原位移 |
| 探身/怔住/坐稳 | 550/380/550ms，保留探身旋转与三种原位移，不统一成同一条平移曲线 |
| 已有角色改位置/高度 | 500ms、`ease`；先设置稳定目标，再由当前呈现从旧坐标插值 |
| 光色/外观/说话焦点变化 | 滤镜 900ms、`ease`；非说话角色追加 `brightness(.62) saturate(.85)`，不使用透明度露出后方背景 |
| 同场景无动作的软切姿态 | 140ms 淡出旧角色静态副本，保留旧坐标、大小、翻转、滤镜和层级；不让旧姿态跟着新位置移动 |

CSS 动画缓动作用于相邻关键帧区间。共享 `cssMotion()` 将它写入每个关键帧，时间轴本身保持线性，避免把原分段节奏改成整段时间扭曲。动作和入场仍沿旧优先关系：本节点有动作就执行该动作，否则新角色才执行入场。

立绘继续按原角色身份复用；每次采用目标场面都按目标 `sprites` 顺序重新写入层级，不能以 DOM 最初插入顺序替代作者顺序。原实例 ID 仍保留在 `data-instance`，不改变内容身份或资源顺序。

移动、滤镜、动作及进退场都由本次 `Playback` 拥有，暂停/恢复沿用动画句柄，快进结束到稳定目标，换节点或离开取消旧工作。删除原 CSS 位移过渡后，媒体重试、读档和回退直接采用目标坐标/滤镜/层级，不因恢复再走一遍；减少动态效果也直接显示稳定目标。离场和软切副本只由原呈现清理，不用不受暂停控制的延迟删除，不加入检查点。

## 未覆盖及兼容边界

本片没有修改旧作品、旧播放器、作者源、内容协议、检查点、偏好或宿主桥，也没有新增资源、按钮或依赖。共享 DOM 增加转场遮罩和短暂旧画面副本；游戏与预览显式提供同一舞台内的选择节点，不增加核心或存储接口。

当前快照覆盖主线场面、对白和选择，未迁移旧 `VN_FADE` 对标题、菜单、鉴赏、手账等全部界面事务的包装。跨对白连续镜头帧、完整瞬时镜头/持续氛围曲线仍未完成等价迁移；旧进入动画在换节点时按原会话契约取消，快照不承诺捕获其取消前的精确帧。当前修改不代表全量演出或视觉验收。

## 留待统一测试

以下只是测试阶段的操作建议，本轮没有执行或生成测试内容：

1. 在游戏和编辑预览中查看带镜头的背景，如 `yvwvivzm`（CG_初登场）；确认取景遵循 `view.position`，镜头缓慢向 `shot.focus` 缩放，同背景下一句不重放进入动作。
2. 在统一测试专用内容中把镜头值设到范围外，检查限制为 1～1.04 和 600～3000ms；再提供非法焦点，检查错误定位以及修正后重试。不要修改权威作者源来制造故障。
3. 镜头或黑场转场中打开菜单、切后台、进入快进和返回标题，检查暂停、清理以及旧呈现不污染新场面；系统减少动态效果时检查没有镜头缩放。
4. 用统一测试专用内容组合无背景→有背景及 `black`/`redflash`，检查主线旧画面淡出优先于背景转场，瞬时特效结束且无遮罩残留；未接快照表面的独立适配实例再检查两层颜色互不覆盖。不要把进入演出当成恢复时必须重播的动作。
5. 查看同背景换姿态、换场景、从选择继续及 `cut`：应按触发条件淡出旧场面/对白/选择，`cut` 直接切换；旧选项不能再点中，文字和选择计时不等动画结束。长对白或长选项滚动后流转，检查副本滚动位置、隐藏界面、暂停/后台、快速连续流转及返回标题时清理。
6. 对照旧播放器查看六种角色动作和全部进退场，尤其跳跃/点头的第二次小动作、探身旋转、怔住方向、轻弹不缩放。演出中暂停和切后台，再继续或进入快进；离场副本应按原呈现清理，不残留或被旧回调删掉新角色。
7. 用统一测试专用内容检查已有角色换位置/高度、互换前后层级以及切换说话人。关闭或恢复同一检查点后应直接到目标状态；软切旧姿态保留原位置，非说话角色应变暗而非半透明。游戏和编辑预览采用相同表现。
