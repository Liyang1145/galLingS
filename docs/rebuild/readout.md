# 话末存档点的可选数值显示

接续原 `showStats/statsText()`，保留“好感数值（剧透向）”的主动开启能力。纯显示计划、独立偏好/事务、共享会话及开发设置页均已编写并接线；未启动、类型检查、测试、构建、额外审查或使用子代理，尚未验收。

## 原显示规则

`packages/player/src/readout.ts` 的 `StoryReadout` 不求值、不执行动作，只读取唯一核心已经提交的变量视图。只对原作者文本匹配 `^【[^】]*完[^】]*】\s*存档点` 的节点追加 `　〔好感 数值 · 尾鳍信号 数值〕`；其他对白原样保留，不把所有结局、章节或含“存档”的文字都当成存档点。

匹配使用变量替换前的原文本，追加使用该节点进入动作已经生效的当前变量。正文保持纯文本，变量占位仍由原核心处理，不新增 HTML/富文本解释器。没有新增变量、修改台词、改结局条件或把这类句子作为自动存档触发。

变量绑定保留旧优先序：`settings.uiSe.favorVar/tailVar`，否则有有效 `soul.char` 的既有配置 `soul.aff/signal`，再回退到“好感/尾鳍”。这里只消费旧配置中的显示名字，不启动聊天、网络或 Agent。缺少默认变量时省略该项；显式非法名字或引用未声明变量给出来源诊断，不能按零显示。两个名字相同仍保留原两种标签；读取器供显示及引用查询共用。

## 独立偏好

`readout-preferences.ts` 读取作者布尔 `showStats`，缺省 false；显式非法类型拒绝。玩家覆盖使用独立 `haifeng.readout-preferences/1`，按作品及 `development/preview/game` 范围隔离，只有 `overrides.enabled`，不进入检查点、全局成果或既有音量/阅读/按钮协议。

`update({enabled:false})` 必须保留 false，`enabled:null` 删除覆盖并跟随作者默认，空修改保留原覆盖。存储在现有新数据库和对象仓库中使用独立键，`updateReadout()` 在同一读写事务中读取、严格校验、合并并提交；损坏、未知字段或其他身份拒绝更新，不按空记录重置。没有升级数据库、读取旧 localStorage 或迁移旧偏好。

## 同一正文与有效计时

`createGameSession()` 的可选 `readoutEnabled` 指定本次初值，省略时只读作者默认。每次 `enter/retry/restore` 开始时，`StoryReadout.text()` 从原正文和核心已生效变量固定本次显示文字，仅向表现适配器提供包含该文字的视图副本。核心 `RuntimeView`、动作、条件、事实及插值原文不变，回看和存档摘要继续使用原剧情正文，不把玩家偏好写入剧情或检查点。

普通自动等待沿旧规则，使用同一份实际显示文字的 UTF-16 长度计算 `(1200 + 长度 × 60) × 自动倍率`；限时选择、作者停留及快进间隔继续走原分支。串行 `{type:"readout", enabled}` 只更新后续呈现使用的开关，不重打当前文字、重置当前等待或再执行进入动作。媒体重试算下一次呈现；实际读档/回退使用当前独立开关，已有检查点的剩余有效时间仍优先采用，不按显示文字的新长度重新计算。

## 页面、预览与引用

开发页新增“话末数值”布尔设置，主动开启后显示当前核心变量的只读摘要，实际句后追加用于后续真实存档点。摘要不改变核心，相同值的计时刷新不反复改写辅助播报。关闭时隐藏摘要；标题只说明开始后显示，不读取旧路线或全局记录猜数值。普通结局和脚本结束也不会因此被当作新的存档点。

正常入口使用 `development/normal-entry` 独立偏好，显式“保存话末数值偏好”才持久化；同一 `PreferencesPanel` 保留原修改重试、后来调整及正常退出等待/取消刷新。初始化读取与其他偏好并行，最多等 5 秒，损坏/超时保留原记录。未点击保存不会在退出时自动写入。

限时样例、章节试阅各有自己的本页内存开关，不采用或改写正常游玩偏好。独立编辑预览不接玩家仓库，只由共享会话读取本次草稿的作者默认；预览所显示的数值来自本次人工初值/检查点和唯一核心，不混入全局成果或正式路线。没有新增作者开关编辑入口、联网配置或聊天行为。

共享 `playerReferences()` 使用同一变量读取器补 `readout-variable` 结构引用，标明真实来源或默认派生，编辑查询显示“话末数值变量”。不复用声音变量名来冒充读取关系，也不猜任意配置字段；零引用仍不能作为删除依据。没有改变查询的源/草稿代次保护、内容修订或作者写回范围。

## 留待统一测试

以下只是统一测试阶段的操作建议，本轮均未执行：

1. 确认作者未设 `showStats` 时关闭且不展示数值；主动开启后，只有真实话末“存档点”追加。普通台词、结局、分支和相似但不匹配的文字保持原文。
2. 在进入动作改变数值的存档点核对已生效值，以及 uiSe、已有 soul 显示字段和默认名的优先序。缺默认变量可省略，显式坏引用应定位；没有网络或 Agent 请求。
3. 当句逐字/自动等待中开关，不重打文字或重算剩余时间；下一次呈现采用新开关，普通自动等待与实际显示文字长度一致，限时选择仍按原有效时间。
4. 存读档、回退、媒体重试核对不重复进入动作、全局事实或存档写入；回看和槽位摘要仍是原文，检查点剩余时间不因开关变化而重置。
5. 分别在第一话、限时样例、章节试阅调整，再返回标题和开启编辑预览；四处设置归属明确，预览不沿用第一话覆盖，正常存档和全局成果不变。
6. 统一测试专用记录中制造偏好读取/写入失败，核对原记录保留、原修改重试、后续调整保留及退出取消。只读引用应显示实际绑定来源，修改草稿后仍须刷新。
