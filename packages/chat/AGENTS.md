# 通关后玩法边界

- 本模块独立于剧情核心和主线会话；当前只编写只读通关上下文，事实和缺口见 `docs/rebuild/chat.md`。
- 上游仅提供已提交的全局通关事实读取接口，不传核心、存档仓库、记录写入接口或宿主命令。
- 上下文逐条绑定某次通关事实，不自动选择最新结局或合并多条路线。当前记录只有结局事实，不能从存档、已读集合或变量初值补造历史路线。
- 当前内容修订只作引用定位，不能写成达成结局时的历史修订。预览范围不能作为聊天准备依据；开发记录不得冒充正式游玩成果。
- 结构校验不证明玩家已解锁；按原作品和范围重新读取已提交事实后才能准备上下文。客户端本地记录也不是未来服务端鉴权或付费凭据。
- 上下文只读并复制隔离；不因查看、切换或失败改写主线或增加周目。不接收模型输出为剧情命令。
- 结局与角色的解锁规则、模型供应和费用尚未决定，本切片不得默认“任意结局可聊天”或接入旧联网服务。实际发送、隐私确认及聊天持久化另按明确接入实现。
