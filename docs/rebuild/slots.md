## 手动选择与保存

`apps/game/src/slots.ts` 的 `SaveSlots` 只管理两个入口各自选中的名称和目录显示，不持有游戏会话、全局记录或写入/读档能力。第一话使用 `development/normal-entry`，限时样例使用 `preview/timed-choice:pm8x8v2h`；浏览目录的入口与当前游玩入口可以不同，保存按钮始终标明当前游玩入口及其选中名称。

两个入口在每次打开页面时初始选择 `manual`。原有键与载荷保持不变，无迁移或清空；名称只存于本页内存，不加入玩家偏好。输入名称后点击“使用此槽位名称”，或点击目录行的“选择此槽位”，只变更目标。页面输入会裁掉首尾空白，再按共享 `readSaveSlotId()` 检查非空及最多 128 个 UTF-16 单元；已有合法记录的名称按原值选择，不改写。

只有点击保存才创建或替换同名进度，不在选择、翻页、刷新目录、返回标题或退出时新建进度。页面明确提示同名替换；未增加槽位删除、改名、自动编号、缩略图或自动检查点规则。

保存开始即捕获入口、名称、同一会话检查点和显示时间。异步写入期间可以选择后续操作的目标，原保存及正常退出的显式失败重试仍使用原捕获数据。写入跟踪以入口与槽位共同标识；改选名称不能把失败写入重定向到另一个槽位。

查看和读取按钮显示各入口选中的名称，操作开始后固定本次目标。查看只展示重新读取并校验的详情；读档仍由应用准备当前全局投影，成功后换会话，不从目录缓存采用进度。开局/读档准备期间禁用槽位控件及存读按钮，返回标题后立即恢复目录操作；失败沿用原会话与暂停归属。周目、已读、结局、CG、偏好及预览检查点的归属不变。

[游戏存读档弹层](game-ui.md)打开时通过 `SaveSlots.browse(entry)` 选择当前入口的目录范围并刷新第一页；保留该入口已选中的槽位名称，不采用进度或写入记录。章节试阅没有自己的槽位，打开时只浏览正常入口目录；保存仍在应用边界拒绝。

卡片的“选择此槽位”仅调用原名称选择通道，选中后显示边框及 `aria-pressed` 标记；更新标记不替换卡片或移动焦点。当前名称即使不在本页，仍在目录上方明示。空目录显示提示，不虚构六个编号槽位。损坏/不兼容记录保留错误码和消息，合法名称仍可选择，地址无法识别时明确说明不能选择；不删除或修复数据。打开或切换入口先清理上一入口的卡片及监听，异步读取继续核对原代次和入口。

弹层按“保存当前进度”“查看与读取”分组；后者分别列出正常游玩和限时样例所选槽位的操作，语音仍须本次明确选择。按钮沿用原应用接线及捕获目标，不因浏览另一个目录改变当前保存入口。`SaveRepository`、`SaveSlotSummary`、`haifeng.save/1`、数据库版本与命名空间均未变化；没有新增写入、删除、改名或读取触发。此片已编写并接入，未启动、类型检查、测试、构建或视觉验收。

## 有界只读目录

`packages/player/src/saves.ts` 新增以下接口，不改变 `haifeng.save/1` 或数据库版本：

| 接口 | 责任 |
|---|---|
| `AtomicSaveStore.scan(prefix, after, limit)` | 只读当前前缀，按键升序返回游标之后至多 `limit` 条原始记录及续页地址 |
| `SaveRepository.list({after, limit})` | 限定本作品和范围，每页 1～100 条；检查地址顺序及分页，再逐条完整校验检查点 |
| `SaveSlotSummary` | 可读记录返回时间、节点/话、对白摘要、稳定阶段及剩余选择时间；失败返回槽位、错误码和消息 |
| `SaveSlotPage` | 冻结的只读摘要列表与不透明续页地址，不含可直接采用的检查点 |

前缀由格式、作品、范围种类和范围 ID 构成，包含 JSON 数组元素边界；同名槽位不会跨入口、作品或记录类型串读。修订仍在载荷中，不在键中；内容修订不兼容时旧记录继续显示诊断，不伪装成空槽位。

损坏载荷及不兼容记录逐条保留。地址本身无法按规范解出槽位时展示原地址和诊断，禁止猜测名称；地址合法但载荷损坏的行仍可明确选择这个名称，实际查看/读档继续报告错误，手动保存则按已说明的同名替换行为处理。目录不删除或修复记录。

浏览器 `scan` 使用只读游标，读取一页及用于判断续页的一条探测记录，只在事务完成后返回，错误可刷新重试。单条读取及全局/偏好事务也以游标区分空键与已有 `undefined` 值；后者作为损坏载荷交回现有校验，不能按空记录初始化覆盖。

页面每页 20 条，按地址顺序显示，提供上一页、下一页和刷新；不是按保存时间排序。每页来自一次独立事务，跨页期间其他页面或保存可以改变目录，刷新回第一页重新读取，不承诺整个目录是同一时刻的不可变快照。

每次读取绑定目录入口和本次代次。切换入口、再次刷新、进入开局/读档准备、退出或销毁后，迟到结果不能覆盖后来目录；这只拒绝界面采用，不冒充已取消底层事务。保存提交后刷新当前浏览入口的目录，退出期间完成则提示操作结束后刷新。关闭清理监听与未采用结果，不影响已发起写入。

## 留待统一测试

沿用[可视试播入口](player.md#统一测试时的可视入口)，以下留到用户安排的重构末尾，本轮未执行：

1. 在第一话两个不同稳定位置分别保存到两个名称，刷新页面后从目录选择，逐一查看、读取；各自恢复原节点、变量和剩余时间，原 `manual` 仍可访问。
2. 两个入口使用相同名称保存；切换目录范围，确认互相隔离，选择目录项不推进、读档或写全局成果。
3. 同一入口保存超过 20 个名称，在存储未变化时前后翻页，应无遗漏或重复；刷新重新读取第一页，空目录也可输入名称保存。
4. 在专用试播数据中准备损坏载荷、不兼容修订及损坏地址，目录应保留诊断；查看/读档失败保持当前会话及已有记录。已存在而值为 `undefined` 的记录也不能显示成空槽位或初始化成新的全局/偏好记录。
5. 保存等待期间改选名称或返回标题，原事务仍写原入口、原名称和原捕获位置。写入失败后在正常退出面板显式重试，也应保留原目标和时间。
6. 读取目录时切换入口、连续刷新、开始读档或退出再取消，确认迟到结果不覆盖新列表，控件可恢复操作；页面关闭后的结果不写入旧界面。
7. 从目录选择限时档并读取，点击与超时仍只结算一次；读更早的档后，主页鉴赏及通关次数不被覆盖。目录缓存不能替代本次重新读取和完整校验。
8. 宽屏三列、窄屏两列及手机单列检查长名称、长对白、诊断和分页；通过键盘选择卡片后焦点保留，选中标记与操作按钮目标一致。切换入口不能残留另一入口的卡片；空目录不显示伪造槽位。仅选择、翻页和查看均不恢复剧情或写入记录。
