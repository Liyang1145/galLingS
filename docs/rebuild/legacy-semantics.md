# 旧行为到新实现的迁移语义

固定数据见 [baseline](baseline/README.md)，源码基线为 `2dfda33`。下表是内容及播放器静态读取所得，不是已执行的运行对照；新能力在对应阶段实现前均不得声称已保留并验收。

## 逻辑与记录

| 能力及旧位置 | 现有语义 | 新实现约束/交付阶段 |
|---|---|---|
| `player.js` 的标题开始按钮 | 从首个带 `chapter` 的节点开始；数组最初两个节点不属于普通开局入口 | 显式保留 `fhww88n3` 为正式开局入口，同时保留全部 3315 节点；M1 |
| `initVars`、`parseLit` | 五个声明变量初值 `"0"` 显式转为数值；保留原中文名 | 类型转换记录，不改成旧 Rust 通道名；M1 |
| `showPlay` | 先保存进入前变量，再执行节点 `set`，然后插值文字、显示选项 | 新核心在进入时只执行一次动作，输出已生效状态；M2 |
| `visibleChoices` | 条件为假时隐藏选项，不是显示禁用项 | 模型明确隐藏规则；空选择可继续现有流转，不出现死锁；M1/M2 |
| `advance`、`nextIndex` | 有可见选项不能继续；无选项时优先结局，再条件跳转，否则顺序；选择有自己的目标与动作 | 拒绝冲突流转而非猜字段优先级；保留作品现有非冲突用法；M1/M2 |
| `choose` | 先执行选项 `set` 再去标签目标；旧选项无稳定 ID | 固定选项映射；目标转节点 ID；点击与超时竞争只接受一次；M1/M2 |
| `startChoiceTimer` | 15 秒；默认找可见选项中目标等于 `cdef` 的首项，找不到退到最后可见项 | 两个真实节点都有显式默认项；构建绑定选项 ID，不依赖“最后一项”；M1/M2 |
| `startChoiceTimer` | 打开菜单、后台暂停有效倒计时 | 会话拥有时间；存剩余有效毫秒，恢复不重置为 15 秒；M3/M4 |
| `startPlay`、`showSlots` | 旧档保存进入前变量；读取时重进节点；节点 ID 找不到会退到数组索引 | 新档保存已生效快照；恢复不重入；不承诺旧档兼容、不按旧索引猜；M4 |
| `goBack`、`goBackToHistory` | 旧历史保存进入前变量和回看长度，取回后重进；最多 500 项，回看最多 300 项 | [会话内回退](rollback.md)已接：恢复一致检查点、不反算、不重复一次性动作；试播上限 500，本次跨选择策略显式选择，正式容量与跨结局边界待决定；M4 |
| `showBacklog`、`RT.back` | 回看已出现台词及实际选择；对白含当时变量替换，最多 300 条 | 独立试播已接只读文字回看，沿用容量并独立暂停；历史语音和从回看恢复进度尚未接入，见 [回看说明](history.md) |
| `applyGlobals`、`syncGlobals` | 新开/旧读档覆盖跨局变量；周目 = clears + 1，结局数 = 已解锁结局种数 | 用户已确认全局成果与进度分开；开局/读档显式传当前已提交投影，旧进度不能覆盖成果；当前五个变量没有 `global`；M2/M4 |
| `showEnding` | 结局名称去重解锁；每次调用都增加 clears，可能被重复调用 | 真实结局转换产生一次事实，幂等交付后全局计次；恢复/鉴赏不计次，重新实际达成仍沿用旧计次；回退边界未实现；M4 |
| `fillVars` | 用已生效变量替换 `{变量名}`，未知占位保留原文 | 显式构建诊断和展示规则；不把未知变量默认为零；M1/M3 |

## 表现、声音及工具

| 字段/入口 | 保留方式 |
|---|---|
| `bg`、`sprites`、`mood` | 当前作品每节点提供场面；以节点目标场景为基础，不按数组前项继承分支场景 |
| 立绘 `uid/asset/x/y/h/flip/in/out/look/poseSwitch` | 保留实例身份、位置、外观和切姿态提示；不混入变量 |
| `trans/fx/acts`、`motionCount` | 演出过程独立于稳定场景；尚未实现的演出显式列出，不丢字段假装成功 |
| `wait/typeMul/holdMs` | 演出节等待、打字倍率和文字前停留由表现/会话处理，不由纯核心读时钟 |
| `applyLineAudio` 的 `bgm` | 空值停止，不代表继承；同资源通常继续；`_musicFadeOutMs` 保留渐变意图 |
| `ambience` | 完整环境声列表，空列表停止；`amb/amb2/ambv/amb2v` 旧字段保留来源，当前真实播放使用 `ambience` |
| `se/seEvents/_seGain` | 一次性音效、增益与延迟保留；读档/回退默认不重放；延迟回调需步骤取消 |
| `voice` | 对白语音保留 ID；恢复是否重播或续播尚未确认，不在 M0 固化体验 |
| `pref(vbgm/vamb/vvo/vse)`、`refreshAudioVolumes` | [独立声音偏好](preferences.md)保留四轨作者默认与玩家覆盖，实时更新当前音轨并保留渐变进度；0 音量触发的一次性音效不补播；不读旧偏好、不随存读档或回退覆盖 |
| `pref(speed/autoMul/readerScale/ghost)`、`typeText/kick/applyTheme` | [独立阅读偏好](preferences.md#阅读偏好的字段与时机)保留逐字间隔、自动倍率、字号与底板透明度；前两项用于后续呈现/等待，后两项即时应用；当前选择/自动/恢复计时不重置，试播视觉基准仍非完整旧主题迁移 |
| 资源自带 `shot/sceneFit/cg/previewExcluded/audioCategory/gain` 等 | 保留元数据及来源；诊断不能把资源登记视为已安装、可播放或已授权 |
| `settings` 的 cover/theme/UI 音效 | 保留旧作品外观基准；新切片不夹带改版；编辑/插件/聊天设置不成为离线依赖 |
| `playUi(choiceShow/choiceConfirm/timeoutSilence/save)`、`startTick/stopTick` | [共享选择与存档反馈](feedback.md)已接实际首次就绪、接受的选择及存档提交；恢复不补播一次性提示，当前循环随有效计时暂停；其余 UI 音触发待接，不新增素材 |
| `uiVarSe`、`playUi(cg/chapterEnd)` | [剧情反馈](feedback.md#分组变量变化与本次呈现)读取唯一核心分开的选项/进入变量变化，按当前场面安排；CG 共用鉴赏规则，话末按结局/下一顺序章节标记判断；初始化/恢复不发，旧延迟归属本次呈现并可取消，即时 `seEvents` 也参与变量提示避让 |
| `showEnding` 的 `endingNew` | [首次解锁事务回执](feedback.md#首次结局解锁与终态反馈)取代页面缓存判断，提交成功且仍是原会话结局才反馈；已有结局和同批重试不重复响声或计次；终态接续音量/暂停，离开销毁 |
| `agent` | 当前节点非空数为 0；遇到未来非空输入明确拒绝，不能静默略过主线节点 |
| 旧插件、Rust 核心及 Python 后端 | 保留原消费者；不被新核心导入，不进入新会话失败回落 |
| 根作品元数据（开篇修订、美术、音乐、配音等） | 保留来源原样记录，不把作者/审核信息当可执行剧情 |

## 关键对照位置与当前缺口

- `pm8x8v2h`：15 秒，超时选择原 `c5q2c`，好感加 8，目标 `3bu4bzeb`。
- `3nnvr3w2`：15 秒，超时选择原 `c7q9c`，好感加 6；具体目标见固定映射。
- `fhww88n3`：正式开局；包含明确停奏与环境声，不得丢弃前两个旧节点。
- 四个结局、全部条件跳转、完整节点及资源身份记录由固定清单保留；全路线尚未验收。

M0 没有实现解释器、资源打包、快照、计时、表现迁移和两端接入。下一切片先做模型、受限表达式和带来源的转换，再接唯一核心；未支持的真实表现字段必须有保留载体或明确阻断，不靠空对象吞掉。
