# 作品文件夹

把 VN Studio 导出的游戏文件夹（里面有 index.html）放进这里的一个子文件夹，例如 `content/vn/海风与布丁/`，
打开 http://127.0.0.1:8765/vn.html 就能在 galLingS 里玩（窗口模式手账在右侧栏，全屏模式手账在游戏里）。
也可以在作品页 ⚙ 设置里把“作品文件夹”改到别处。
