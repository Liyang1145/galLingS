# 独立编辑入口

- 本目录是对白编辑试用切片，命令和限制见 `docs/rebuild/editor.md`。DOM 实现不决定最终框架或编辑器选型。
- 唯一作者源仍是 `海风与布丁/game.js`；草稿是相对原摘要的字段修改，不生成第二套长期维护的剧情源。
- 草稿由纯 `AuthorDraftHistory` 管理；历史只绑定已读取源的可编辑字符串，保存/重读成功后重建基线，失败保留。连续同字段输入可合并，还原节点及一次导入各为一步；新实际修改截断重做，撤销/重做使导入比较、引用和待采用预览按草稿代次失效。历史按步数及保守文字量有界，超大操作清空无法连续恢复的旧链并明确提示；不写磁盘或玩家进度，不拦截输入框原生撤销快捷键。
- 只允许现有 `speaker/text` 字符串修改，不在本片扩展节点、选项、变量或素材写入；未知字段由共享转换器保留或拒绝。
- `src/references.ts` 只读共享内容索引与播放器已消费设置，查询当前对白草稿；修改、还原、采用导入及源替换使旧结果失效。定位核对源摘要/内容身份/草稿代次，不启动预览或保存；保留搜索及草稿，筛选外节点明确置顶。规范化路径和作者来源分开显示，零引用不作为删除依据；面板留在预览全屏/输入范围外。
- `src/flow.ts` 只索引已校验 `Flow` 的结构连线，不求条件、执行动作、模拟路线或开放连线写入。保留入口、条件两侧、原选项/超时默认、空目标及结局，按当前节点一层邻接分页显示；草稿文字采用当前覆盖，源/修订/草稿变化使旧图失效。定位复用 `navigateNode()` 并核对原视图代次，不能改变预览或写作者文件；规范化路径不冒充原 token 位置，图中无边不授予删除权限。面板留在制作区，不决定最终剧情图工具。
- 预览复用 `createGameSession`、`WebPresentation` 及内容转换结果，不写推进或变量算法。全部声明初值和玩家投影必须可见，所选节点预览不能冒充真实路线进度。
- 预览不接玩家存储、全局成果或聊天；已读仅在本次预览内存中。换预览及离开要取消旧会话、计时、媒体和待采用响应。
- 预览复用共享 `EndingPanel` 显示核心终态，明确标注不写玩家解锁或通关次数，结束按钮只停止原预览。不伪造 `committed` 或首次解锁回执，不连接正常游玩重试或聊天入口；停止/换预览清空原卡片与监听。
- 检查点初始条件预览只接 `haifeng.editor-checkpoint/1`，在浏览器复用共享捕获/校验/恢复；作品、草稿修订和原临时入口须一致，不能改写快照修订或按下标猜位置。文件头读取不算完整校验，不覆盖最近已校验项；完整校验后才换预览，保存时玩家投影明确标为本次初始条件。语音每次显式选择，检查点不上传编辑 API、不读写玩家存储；停止/修改/清除/离开使旧读取与捕获失效，制作控件留在预览全屏与输入范围外。
- 预览操作按钮复用共享按钮声音绑定及混音器，只使用作者 `btnSe` 默认；不读取正常游玩开关，不给源编辑/保存按钮套游玩反馈。停止或离开取消声音，销毁时取消监听。
- 舞台预览使用同一作者外观读取、鲸鱼图形及坐标缩放；只作用于预览舞台，不染色编辑控件，不以单独字号/选择 padding 覆盖共享表现。图形来自只读构建装配，预览不修改主题或图形来源。
- 主线画面淡出只向共享表现显式提供预览舞台及选择节点，复用同一触发、静态副本和取消生命周期；不能复制制作控件、给副本绑定输入或借过渡写玩家记录。
- 选项统一使用共享 `ChoicePanel`，显示会话提供的剩余时间和首立绘/多列布局；暂停和时间刷新不得重建按钮。舞台比例、小舞台可读性及竖屏分区复用共享接线，停止/离开清空旧选择监听，销毁断开尺寸观察；不因预览重新定义选择/计时，不把制作控件套进游戏竖屏布局。
- 预览复用 `PlayerInput`，键盘仅在舞台/预览操作栏范围生效；制作控件、输入法及文本编辑不触发游玩快捷键。停止/换预览清理隐藏、临时 Ctrl 和旧手势，销毁取消监听；没有回看回调则不启用回看手势，不把方向键自动绑定为未定的回退策略。
- 全屏复用 `PlayerFullscreen`，目标及快捷键范围仅为预览区域；不把制作控件纳入全屏或在输入框拦截游玩快捷键。停止请求离开，迟到进入后仍须退出；全屏不重开预览、不改草稿或读取玩家偏好。
- 浏览器仅调用固定本机编辑 API；作者文件写入在 `tools/editor/`，只能由显式保存按钮触发。网络失败不能假定未写入，保留草稿并提示重新读取确认。
- 草稿导入只读本机所选 JSON，经同一修改协议校验后逐字段比较旧原文、已读取作者源、本页草稿和导入新值。冲突必须明确选择，找不到的节点/字段不能猜测；合并完整校验成功才替换本页草稿，不写作者文件。未采用项保留原摘要，可单独导出。
- 导入比较绑定当前源摘要及草稿代次；本页修改、取消或离开使旧比较失效。已有比较须采用或取消后才能读取、预览或保存，最终写入仍由服务端重查真实作者源。
- 本目录不进入游戏发行构建；引用现有表现样式不代表正式制作界面已决定。根规范的测试、提交及推送授权仍适用。
